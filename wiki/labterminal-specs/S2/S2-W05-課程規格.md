## §G 規格治理
- **正典聲明**【規定】：本 spec 是唯一真相；成品迭代回填本檔。
- **綁定實作檔**【規定】：`public/games/s2-w05-ai-tutor.html`。
- **延續前作**【推定・以 S2-W04 成品為準】：沿用阿問、引擎、調色盤、金幣/存檔 chassis、注音渲染器、防硬 A、**AI 審核＋本地後備**（S2-W04 的 `/api/review-tone` 同型）。
- **In Scope**【規定】：**整合應用四法寶**（三要素＋格式＋字數＋語氣）向 AI 家教問出好教材，並通過知識小考。**不教新 prompt 技巧**——本課是 W01–W04 的**整合**。
- **Out of Scope**【規定】：新的 prompt 子技巧；W06 三連挑戰（最終測）；生圖/程式。
- **跨週技能地圖**：W01 三要素 → W02 格式 → W03 字數 → W04 語氣 → **W05 四法寶整合・AI 家教（本課）** → W06 三連挑戰。
- **可數單位**【規定】：法寶（4）／知識任務（5 主題）／小考題／徽章。
- **互動詞彙表・單一真相**【規定】：四法寶各一圖示色（三要素／格式／字數／語氣，沿用前四週）；教材「好版」＝整齊發光可用、「爛版」＝糊成一團／缺重點；小考答對＝發光、答錯＝鎖 2＋N。
- **控制**【推定・以成品為準】：滑鼠點選法寶＋鍵盤打「問家教的問題」＋teach-back 打字；小考＝泡泡選擇。
- **識字負荷**【規定】：每則 ≤20 字；主題用小朋友有興趣的（海洋生物/恐龍/太空/昆蟲/天氣）。
- **跨切面**【規定】：存檔續玩、金幣冪等入帳號、進度單調不可逆、純前端。詳 §6。
- **素材**【規定・下限】：阿問「家教」立繪＋四法寶圖示＋5 主題小圖示＋知識徽章；一角一圖複用、未載入退向量。
- **老師端＋翻轉教育**【規定】：一級需求，見 §7、§5。
- **經濟（已對齊 §21・2026-08-20）**：**本週主線加總 = 250**（5 知識任務分配加總 250，例：各 50）；**TA＝對應任務 50%、不佔 250**；進階/選做不計入。

## §T 時長預算（活動耗時模型 §22）
- **模型估算＝40.2 分鐘【剛好】**（小三 f=2）。組成：報名＋複習四法寶＋**5 個知識任務**（選格式/字數/語氣＋打好問題→家教給教材→讀→小考 3 題→追問→teach-back）＋綜合大挑戰＋領徽章。
- 撐時長靠：整合 4 技能的「組好問題」、5 主題、teach-back 打字、小考——非灌水。以課堂實測校準。

## §GL 遊戲迴圈與判定
- **總目標**【規定】：你要參加「知識大挑戰」（小考），但不會 → 找**阿問家教**。用對的法寶問，家教就給好教材；答對小考、集滿徽章、通過大挑戰。
- **核心迴圈（每個知識任務）**【規定】：**進入知識任務（主題由課程設定、固定依序、非學生自選）→ 用四法寶組一個好問題（選格式＋選字數＋選語氣＋打問題）→ 阿問家教給教材（好/爛看你問得好不好）→ 讀教材 → 小考 3 題 → 追問補強 → teach-back 用自己的話講一次 → 過關拿徽章**。
- **「問得好 → 教材好 → 考得過」閉環（本課核心）**【規定】：**小考的答案藏在「好教材」裡**；問得糊 → 家教只給爛教材（缺重點）→ 小考卡關 → 逼你回去把問題問好。**這讓四法寶真的有用，不是裝飾。**
- **問題品質判定＝AI 審核＋本地後備（沿用 S2-W04）**【規定】：學生打的「問家教的問題」由**平台自建 AI 端點**審「有沒有用到選的格式/字數/語氣＋三要素」、回饋具體（符合第十四節，學生不需帳號）；**逾時 10s／連不上 → 本地檢查（有沒有選法寶＋關鍵詞）後備**，不卡學生。
- **本地判定＋distractor**【規定】：小考、teach-back 關鍵字、法寶選擇的 pass/fail 全本地（預寫題/好教材/爛教材/正解）；阿問只用家教口吻回應、給預寫教材、不當關主。
- **真實應用鐵則**【規定】：靠「爛教材考不過 vs 好教材考得過」的**結果對比**看出「問得好才有用」，不說教。
- **理解兩層**【規定】：隱性（問對＋答對小考＝懂）＋顯性（teach-back 用自己的話講）。
- **防硬 A**【規定】：小考泡泡隨機漂浮、點錯鎖 2＋N＋重洗、正解藏 ≥3 干擾、非致命；teach-back 需含關鍵字（本地）。
- **安全網分層**【A・寫死；B・可調】：A＝不淘汰/不倒退/永遠可重試本任務/保底（連錯自適應：提示該用哪個法寶、AI 連不上走後備、老師端一鍵放寬）；**不提供跳過**，卡關給提示；B＝小考難度/追問要求 逐關可調。
- **動作集封閉**【規定】：選四法寶、打問題、讀教材、小考、追問、teach-back（**主題由課程設定、學生不自選**）。新增走 change-control。
- **難度以學生通過率定義**【規定】：目標班級 80% 於 40 分內通過大挑戰、90% 完成 ≥3 個知識任務；未達→往下調。

## §AI AI 對話與理解＝學習主軸【In-Scope 護欄・規定】
> 學習＝用對法寶跟 AI 家教學＋讀懂教材；小考只是驗收。每個難度都要穿過「問對家教」或「讀懂教材」。
- 每個知識任務都要「用四法寶組好問題」才拿得到好教材；**追問**（教材不夠好就補問）是主要對話練習；評級獎勵「問得精準、法寶用得好」。
- **好/爛教材對比＋小考結果** → 判斷自己問得好不好（讀懂＋評估）。
- **自檢**：這一分難度，是花在「怎麼問家教」或「讀懂家教教材」上嗎？不是 → 改或砍。

## 二、四法寶整合設計（In Scope 核心・複習不重教）
> 開場**快速複習**四法寶（各一句＋何時用），之後每個知識任務都要**同時用上**：
| 法寶 | 一句話 | 問家教時 |
|------|--------|---------|
| 三要素 | 角色＋背景＋問題 | 把「我想學什麼」問清楚 |
| 格式 | 清單/表格/步驟/重點 | 要家教用好讀的格式整理 |
| 字數 | 很短/中等/詳細 | 要剛好的長度（先重點、再詳細） |
| 語氣 | 溫柔/認真/搞笑/有禮貌 | 要家教「像老師、簡單一點」教 |

**核心體感**【規定】：四個一起用，家教給的教材才好用、才考得過；少用幾個 → 教材爛 → 卡關。

## 三、知識任務設計（5 主題；每主題預寫資料）
> 每主題**預寫【規定】**：主題說明、**好教材版 vs 爛教材版**、小考 3 題＋正解＋干擾、teach-back 關鍵字。
- **主題由課程設定（固定 5 個、依序，非學生自選、全班一致）**：**海洋生物 / 恐龍 / 太空 / 昆蟲 / 天氣**（小三有興趣、資訊安全）。→ 好處：好/爛教材＋小考皆可事先預寫、驗收一致；學生的「選擇」花在**怎麼問家教**（四法寶），不是花在挑主題。
- 每主題流程：（依序進入設定好的主題）→ 用四法寶組好問題 →（AI 審＋本地後備判問題品質）→ 家教給對應教材（好/爛）→ 讀 → 小考 3 題 → 不夠好就追問 → teach-back → 過關拿徽章。
- **綜合大挑戰（結尾）**：跨主題 3 題小考，全對＝通過、領總徽章。

## 四、美術與資訊視覺化【規定】
- 阿問「家教」立繪（可複用前作阿問＋加個小黑板/教鞭道具）；四法寶圖示（沿用前四週）；5 主題小圖示；知識徽章 5＋1。
- 好教材（整齊發光）vs 爛教材（糊成一團）視覺對比明顯（非 emoji、自繪）。
- 進度：知識任務板（marker 三態）＋徽章收集列。

## 五、獎勵結構【規定】
- 常駐金幣 HUD（只顯示累計）＋得幣跳動＋「+N」浮字。
- **收集閉環**：開場預告 5 個空徽章格 → 每通過一個知識任務點亮一個具名徽章 → 綜合大挑戰通過＝總徽章＋慶祝。
- 獎勵綁學習成就（問得好＋答對小考＋teach-back 過才給，非純點擊）。
- **TA（小老師）**：「我是小老師」→ 教一位同學「怎麼用四法寶問家教」→ 額外獎勵＋獨立交易 ID。
- 頒獎：「知識大挑戰通過」稱號＋慶祝＋徽章總覽。

## 六、資料與工程【一等公民・規定】
- 進度/金幣/徽章存 `localStorage`＋帳號雲端；**存檔鍵綁 uid**；跨裝置取進度較遠者；登出清本機遊戲存檔。
- **⚠️ 多使用者驗收腳本**【規定・DoD 必測】：
  ```
  □ 共用電腦：A 帳號通過 2 個知識任務 → 登出 → B 帳號登入開同一遊戲
    → B 必須全新進度，且 B 的雲端紀錄不得出現 A 的資料
  ```
- **分數/徽章冪等**：固定交易 ID、查重；重整/斷線/重玩不重複。
- **AI 審核離線後備**：問題品質審核逾時 10s／連不上 → 本地檢查後備，不卡學生。
- **失敗與離線**：本地即時真相、雲端背景備份；資產失敗退向量；載入逾時放行。
- **注音渲染**（若開）：共用渲染器＋驗收清單。

## 七、老師端【一級需求・規定】
- 全班進度總覽（各生通過幾個知識任務）；狀態燈 🟢/🟡（卡同任務過久）/🔴（求助）；**保底一鍵放寬**；小老師派任；教師端網址。（依 spec-governance：若屬 admin 後台則標明歸屬，別當單檔遊戲功能漏做。）
