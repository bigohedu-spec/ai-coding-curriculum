## §G 規格治理
- **正典聲明**【規定】：本 spec 是唯一真相；成品迭代後回填本檔。
- **綁定實作檔**【規定】：`public/games/s2-w06-detective-graduation.html`；完成鎖 `/courses/lesson-lock.js`：`markComplete('game:s2w06')`；admin 重做入口。
- **延續前作**【推定・以 S2-W05/W04 成品為準】：沿用阿問、引擎、調色盤、金幣/存檔 chassis、注音渲染器、防硬 A 泡泡、**AI 審核＋本地後備**（`/api/review-tone` 同型端點）——衝突一律以成品為準（附其實作檔路徑）。
- **In Scope**【規定】：**回顧＋整合四法寶**做出一頁《Prompt 秘笈》小成品（①五案徽章冊 ②四法寶學習總覽小考 ③四法寶「我的招牌 Prompt」＋AI 實作）→ **自動組成一頁**（綁 uid、可列印/可分享 URL、給家長）→ 支援課堂**結業發表**。
- **Out of Scope**【規定】：新的 prompt 子技巧；W07+ 認識 Claude／多 AI 比較；生圖／程式；自由長打字作文。→ 不得混入。
- **與 W05 的分工**【規定】：W05＝用四法寶「玩」（家教班闖關、整合練習）；**W06＝把學會的做成「作品」並發表**（keepsake ＋ 慶祝／兌現）。兩者都整合四法寶但目的不同，不得把 W06 做成第二個 W05 闖關遊戲。
- **跨週技能地圖（S2 模組一）**：W01 三要素 → W02 格式 → W03 字數 → W04 語氣 → W05 家教整合 → **W06 成果發表・Prompt 秘笈（本課・模組一收尾）**。
- **可數單位**【規定】：**法寶**（4）／**案徽章**（5，對應 W01–W05）／秘笈頁（招牌 Prompt 4 頁）／小考題（4）。
- **互動詞彙表・單一真相**【規定】：沿用前四週各法寶的圖示色（三要素／格式／字數／語氣）；秘笈「收錄」＝發光入冊、未完成＝灰位；招牌 Prompt「夠好」＝AI 蓋章收錄、「還沒用到法寶」＝退回補寫。**圖示自繪、非 emoji、注音渲染**。
- **識字負荷**【規定】：小三下短句，每則 ≤20 字（呼應 §22：三年級單則閱讀上限 20 字）；靠圖示＋範例對比，不靠長文；弱讀班可開注音。
- **跨切面（第一版就定）**【規定】：存檔續玩、**金幣 idempotent 入帳號錢包**、進度單調不可逆（衝突取進度較遠者）、純前端無敏感資料。詳 §DATA。
- **老師端＋翻轉教育**【規定】：一級需求，見 §TEACHER、§SHOW。
- **⚠ 經濟待對齊**：課綱原訂 45（原「Prompt 格式三連挑戰」）。本課改為成果發表週，建議金幣＝**製作三部分＋結業發表＋小老師 TA**；沿用 S2 各週經濟（25–73 不一）暫記、**與 S2 整體經濟／TA 比例一併對齊決策**（同前作待辦，見學期頁）。

## §GL 遊戲迴圈與判定
- **總目標／敘事**【規定】：阿問偵探社**結業式**到了。你破完五案、學會四個法寶——畢業考就是**做出你自己的《Prompt 秘笈》**（收錄四法寶招牌 Prompt ＋ 五案徽章），並在結業式上台發表「我最厲害的一個 Prompt」。
- **核心迴圈**【規定】：**回顧四法寶 → 做秘笈三部分（見 §PARTS）→ 自動組成一頁 → 結業發表**。學習目標（整合四法寶、能說明自己怎麼問 AI）包進「做作品＋發表」。
- **本地判定＋distractor**【規定】：徽章配對、四法寶小考、招牌 Prompt 的法寶檢核，pass/fail **本地規則優先**（預寫對/干擾）；**招牌 Prompt「有沒有用到該法寶」＝AI 審核＋本地後備**（見 §AI）。**AI 定位一句話：阿問只用口吻回應、蓋章收錄、個人化鼓勵——不當關主、不亂判失敗**（實測 AI 會把好問題誤判失敗）。
- **真實應用鐵則**【規定】：招牌 Prompt 要從**真實小任務**寫出（如「幫我把恐龍知識整理成清單」）；「哪個法寶讓答案變好用」靠**AI 回答對比**自己看出，不用文字說教。
- **理解兩層**【規定】：隱性（招牌 Prompt 用對法寶＝證明會用）＋顯性（四法寶小考複述「這個法寶做什麼、什麼時候用」）。
- **成果發表＝兌現（Deliver）**【規定】：每個孩子都要做出一頁可帶走的秘笈並發表——這是模組一的慶祝/兌現，成就感優先、非考試壓力。

## §SCREENS 7-screen 骨架（§20 強制）【規定】
```
0. start    — 難度選擇（G1–G2 / G3）＋ Hook：「畢業考：做出你的 Prompt 秘笈」（視覺承諾今天帶走一本秘笈）
1. recall   — 回顧四法寶（G1–G2 拖拉配對法寶↔功能；G3 Step Flow 2 步）
2. taskA    — 秘笈①五案徽章冊 ＋ ②四法寶學習總覽小考（見 §PARTS）
3. taskB    — 秘笈③四法寶「我的招牌 Prompt」＋ AI 實作（見 §PARTS・核心）
4. summary  — 課堂總結（句子接龍：四法寶各是什麼、何時用；4 個有教學意義的反例）
5. wall     — 秘笈完成牆／偵探結業徽章解鎖
6. done     — Deliver 頁：秀秘笈、兌現 Hook（可列印/分享 URL）＋進入結業發表
```
- **固定附加**：taskA / taskB 完成後 → **Rehearsal Modal**（句子接龍，必答對才關）；每個 screen 進入自動觸發 `setup()`。

## §PARTS 秘笈三部分【規定】（對應 P1U-W06 的貼紙／小考／AI 問答）
### ① 五案徽章冊（回顧・收集・情感連結）
- 回顧 W01–W05 五個關卡（三要素案／格式案／字數案／語氣案／家教班），把每案的**破案徽章**（前作角色/證物去背圖複用）**拖貼**進秘笈封面。集滿有收集感與「我一路走過來」的情感連結。
- 目的＝情感連結，**不是考試**；貼上即可，位置不苛求。

### ② 四法寶學習總覽小考（回顧「我會了」，非考試）
- **4 題**輕鬆小題，回顧每個法寶「做什麼／什麼時候用」（三要素＝把問題問清楚／格式＝叫 AI 排整齊／字數＝要重點或要詳細／語氣＝叫 AI 換口氣）。
- **雙難度（§20 矩陣）**：G1–G2＝**拖拉配對**（法寶 × 功能）；G3＝**Step Flow 一頁一格自由打字**（「____ 法寶是用來 ____ 的」，跨步內容驗證）。
- **本地判定、寬鬆、失敗安全**（不淘汰、可重試、連錯自動放寬）；過了亮「學會了」徽章。
- **防硬 A**：選項/配對隨機、點錯鎖 2＋N＋重洗；基調是「回顧我會了」不是「考倒你」。

### ③ 我的招牌 Prompt（核心・AI 實作・四法寶各一頁）
- 秘笈有**四頁**，每頁對應一個法寶。每頁：給一個**真實小任務**（主題用小朋友有興趣的：海洋生物／恐龍／太空／昆蟲／天氣）→ 學生**用該法寶寫一個「我的招牌 Prompt」**去問阿問 → **AI 審核**「這個 prompt 有沒有用到該法寶」（＋本地後備）→ 阿問給回答 → **收進秘笈**。
- **雙難度**：G1–G2＝**填空式組 Prompt**（法寶積木＋關鍵詞下拉/拖拉，如「請用【清單】把【恐龍】整理給我」）；G3＝**Step Flow 自由打字**（打整句 prompt，附 Hint/模板/範例/內容驗證/具體錯誤訊息＝§20 鐵則 7 五要素）。
- **AI 審核不亂判失敗**：審的是「有沒有用到該法寶」的寬鬆條件；連不上/逾時走本地後備（見 §AI）；退回時給**具體**訊息（「還沒看到你指定格式喔，試試加『用清單』」），不是「請重寫」。
- **發獎封頂**【規定・回灌】：每收錄一頁招牌 Prompt 的獎勵**該段封頂**、以「秘笈完成」為單位結算，**不逐頁無限累加**（呼應 spec-governance「發獎必須封頂」，避免 P1U-W06 問答金幣無上限 bug 重演）。

## §COMPOSE 一頁自動組成【規定】
- 把三部分（五案徽章冊／四法寶小考徽章／四頁招牌 Prompt＋阿問回答）**自動排成每人一頁《我的 Prompt 秘笈》**，版面固定、好看、**可列印**。
- **可分享 URL 回顧頁**（`/games/recap.html?uid=…` 同型）：家長點連結就能看，不一定要列印。
- 頁面上方：孩子名字 ＋「阿問偵探社・結業偵探」稱號 ＋ 模組一累積金幣；主軸「**我學會用 AI 的四個法寶**」。
- **綁 uid 存檔**、跨裝置在；沿用系列 chassis。

## §SHOW 結業發表【規定・翻轉】
- 每人對同學/上台：秀秘笈＋唸出「**我最厲害的一個 Prompt**」＋說它用了哪個法寶、AI 回答有多好用。
- 害羞的可對小組說；全班當觀眾鼓掌。老師端可投影某人的秘笈頁到大螢幕。
- **發表是本週核心**（Deliver）；把學到的講給別人＝翻轉教育。

## §AI AI 對話與理解＝學習主軸【In-Scope 護欄・規定】
> 學習＝**整合四法寶問出好答案**＋**能說明自己怎麼問的**；「做秘笈＋發表」是載體。任何互動都要穿過「用法寶寫 prompt」或「讀懂/評估 AI 回答」。
- **招牌 Prompt** 是主要對話練習：用法寶組 prompt → 讀 AI 回答 → （不夠好可**追問/改寫**再送）。
- **AI 審核＋本地後備（沿用 S2-W04/W05）**【規定】：學生的 prompt 由**平台自建端點**審「有沒有用到該法寶＋三要素」、回饋具體（第十四節，學生不需帳號）；**逾時 10s／連不上 → 本地檢查（有沒有選法寶＋關鍵詞）後備**，不卡學生。
- 評級獎勵「**法寶用得好、問得精準**」，不是猜得準。

## §雙難度矩陣（§20 強制）【規定】
| 環節 | 低年級 G1–G2 | 高年級 G3 |
|------|--------------|-----------|
| recall 回顧四法寶 | 拖拉配對（法寶×功能） | Step Flow 2 步自由打字 |
| ② 四法寶小考 | 拖拉配對 | Step Flow 4 步打字（跨步驗證） |
| ③ 招牌 Prompt | 填空式積木＋下拉/拖拉組 prompt | Step Flow 自由打字（五要素）＋AI 審核 |
| ① 徽章冊 / summary / wall / 發表 | 共用（同一認知關卡，不因難度分流） | 共用 |

## §DATA 資料與工程【一等公民・規定】
- 秘笈內容（徽章位置、小考結果、四頁招牌 Prompt＋AI 回答）存 `localStorage`＋帳號雲端；**綁 uid**；跨裝置取進度較遠者；登出清本機暫存。
- **金幣冪等＋封頂**：組頁/發獎固定交易 ID、查重；每段獎勵封頂（見 §PARTS③）。
- **AI 審核離線後備**：逾時/連不上走本地關鍵詞檢查。
- **缺素材後備**：徽章/立繪缺圖退向量；載入逾時放行。
- **共用電腦驗收腳本（回灌・單機自測碰不到）**【規定】：
  ```
  □ 共用電腦：A 做到秘笈第 2 頁 → 登出 → B 登入開同一課
    → B 全新秘笈，且 B 的雲端紀錄不得含 A 的內容/徽章/金幣
  ```
- **前端信任落差（回灌・如實標）**：完成鎖 `markComplete('game:s2w06')` 與 admin 重做在前端；若無後端身分，屬**擋誤按、非權限控管**——牽涉發幣/過關的真正防作弊須後端把關（同 [[P1U-Arc2-開發規格]] §10；列平台級待補）。
- **全注音渲染**：共用渲染器；圖示非 emoji。

## §CHEAT 防作弊（§20 強制）【規定】
- Hint 框 `user-select:none`、不可複製；G3 自由打字輸入框攔截 `paste`/`drop`，觸發顯示具體 toast。
- **內容驗證非字數**：招牌 Prompt 用「有沒有該法寶關鍵詞/積木＋三要素」判定，不用字數；`aaaaa` 不能過。
- 四法寶小考：拖拉/配對排列數 >> 30 秒能試；選擇題點錯永久鎖定（刪除線＋✗＋disabled）。
- 錯誤訊息具體（「還沒用到【字數】法寶，加個『大約 30 字』試試」），不只「請重寫」。

## §TEACHER 老師端【規定・部分待補】
- **已規劃**：投影某生秘笈頁；**整課重做**（救援）；**全班 CSV 匯出**；一鍵放寬（連錯放寬/AI 連不上走後備）。
- **一級需求誠實狀態**：班級進度總覽/狀態燈（呼應 spec-governance「一級需求連堂未交付＝該補做或誠實降級」）——若平台外部遊戲仍不回寫 studentProgress，**標為待補、不假裝已做**。

## §T 時長（成果發表週・如實標）
- **互動製作部分（小三 f=2）活動耗時模型估 ≈ 13.3 分鐘**（回顧＋徽章冊＋四法寶小考＋四頁招牌 Prompt＋組頁；估算檔 `/tmp` 動作拆解，主線 20 動作）。
- **全課正課 ＝ 老師帶回顧（~8）＋互動製作（~13）＋結業發表（每人 ~1.5 分 × 班級人數 ≈ 20–30）＋組頁/收尾**。**發表是本週核心、佔時合理**——製作短是正常的（同 P1U-W06 §T），**不需硬拉長成密集遊戲**。
- **早完成者延伸**（避免空等）：多寫一頁招牌 Prompt（其他主題）、幫招牌 Prompt 追問改到更好、當**小老師**教同學「怎麼用四法寶組 prompt」、或先自由。→ 以課堂實測校準（呼應第十五/十八節：實測為最終依據）。
