## §GL 遊戲迴圈與判定
- **敘事**【規定】：逃離數碼界**第二層「回聲書庫」**——你選一個想懂的主題，把它的知識**學進書庫**，門才會開。這裡的守衛只給**淺淺的、像回聲一樣的答案**；**想知道更多就再問一次**，內容才會變深、才填得進書庫。（淺答案＝視覺隱喻，引導孩子自然地想追問；不靠文字說教。）
- **核心迴圈（每個角度）**【規定】：**問一個你對這主題好奇的問題（輸入用 §TIER 輔助輪）→ 讀 GPT 回答 → 還想知道更多 → 再問一次（自然追問，一樣用 §TIER 輔助）→ 讀更深的回答 → 把學到的重點填進書庫格**。
  > 追問是「我還想知道更多關於＿＿」的自然延伸，**不是為了練追問格式**；階梯只幫小孩把好奇的問題打出去。
- **學習目標（本關）**【規定】：**用 AI 自然地把一個自選主題學會**——問的內容是真好奇、學的是主題本身；「怎麼把問題打出去」由 §TIER 漸進放手（延續 W07 的輸入練習，但不是本關的學習主旨）。
- **先用後寫（§17）**【規定】：填進書庫格的，**全部來自學生自己問到的回答**；不預寫結論、不先講「這主題的答案是什麼」。
- **本地判定**【規定】：填格過關用**結構條件**（§GATE），不用寫死關鍵字比對（B3）；戰鬥/守衛只是演出與節奏，判定仍在填格。

## §TOPICS 50 主題大題庫【規定・本關特色】
- **學生自選**：進關先從 **50 個主題**裡挑 1 個**自己想研究的**（有搜尋/分類/隨機鈕；挑定後本週固定，可老師端鎖定或開放重選）。
- **題庫 schema**（每個主題一筆）：
  ```
  { id, 主題名, 分類, 角度[ 4–5 個子問題模板 ], 追問鷹架[ 對應每個角度的「往哪裡追問」提示 ] }
  ```
- **分類（涵蓋小三會有興趣＋學業向都可）**：自然科學／生活科技／動物植物／地理天文／歷史人物／身體健康／環境／食物／運動／藝術…（**50 筆內容為題庫資產，另附 `WSQ_TOPICS` 資料檔**；本 spec 定 schema 與規則，不逐筆列）。
- **題目「根據主題」動態對應**【規定】：不同主題**共用同一套題型骨架**（角度數、四階梯分配、追問設計相同），只把**主題名與角度子問題**帶入 → 50 主題不需各寫一套流程，**開發量集中在一套骨架＋一份題庫資料**。
- **答案是即時 GPT，不預寫**：題庫只存「問什麼/往哪追問」，**回答由 GPT 即時產生**；離線時走**通用示範回答**（依角度類型，不是每主題預寫 50 份，見 §MODEL）。

## §TIER 格式階梯（輸入輔助輪・延續 W07）【規定・沿用 W07 §TIER】
> **定位：§TIER 是「幫小孩把好奇的問題打出去」的輔助輪，不是本關的學習主旨**（本關主旨＝把選定主題學會，見 §GL）。輸入方式從完全不打字 → 照範本打整句，漸進放手；**每一階畫面上都看得到「一個好問題長什麼樣」**，讓孩子專注在「想問什麼（主題內容）」而不是卡在打字。內容一律是**孩子對這主題真正好奇的問題／追問**。

| 階 | 輸入方式（問／追問都適用） | 幫到什麼 | 建議題數 |
|----|--------------------------|----------|---------|
| **T1** | **拖詞塊拼出想問的問題**（完全不打字） | 還不會打字也能問出好奇的東西 | ~4 |
| **T2** | **按一下複製範本 → 貼進終端機**送出 | 順手把想問的送出去（複製貼上） | ~6 |
| **T3** | **問句挖空、只補你好奇的關鍵字**（如「多說一點關於＿＿」） | 抓住自己想深入的重點詞 | ~5 |
| **T4** | **照著畫面上一直留著的範本，自己打一句** | 開始自己打出想問的（有範本、非自由造句） | ~1 |

- **內容是真好奇，不是格式**：同一階的題，換的是「這個主題你想知道什麼」；階梯只換輸入方式。
- **§19 例外（A8）**：T4「照範本打整句」不算自由造句、不受「只打關鍵字」限制；無範本的自由造句仍禁止。
- **鷹架＝方向不是答案（§17）**：追問提示只給「往哪裡想」（更詳細／舉例／換個說法／它為什麼會這樣），**不給該主題的正確內容**。

## §GATE 過關與單題判定【規定・沿用 W07 A5】
> 「有沒有學到」＝**書庫收集到關於你選的主題的 M 個重點**（你自己問到、讀懂、摘下來的），不是「格式對不對」。
- **過關＝書庫寫滿 M 題**（`w8gate = w8full`）；左欄顯示「已學到 n / M、還剩 m 個」（對小三比「豐富度」具體）。
- **單題過關條件（`w8ansOk`，全部可觀測、不比對關鍵字）**：
  1. 每一格都填了、且長度 ≥ 4 字；
  2. 各格不是同一句（彼此不同）；
  3. 不是垃圾字串（`junkAns` 硬擋）；
  4. **有追問的角度：追問真的送出過、且更深的回答內容真的被用進填格**——證明「想知道更多 → 再問 → 學到更多」有發生（類比 W07 貼上題「內容須真的出自 AI 回答」）。
- **不用寫死關鍵字（B3）**【規定・回灌】：凡驗證「學生從 AI 即時回答摘出的內容」，**一律不得用寫死關鍵字表比對**（即時回答同義不同字，寫死字會把學生卡死——見 W07 q6 事故）。改用上述結構條件。

## §MODEL 模型與離線後備【規定】
- **單模型即成立**：本關是「自選主題、自然地學會它」，**用 GPT 一個模型就完整**；`CLAUDE_ON=false` 下不需要第二個模型。
- **§COMPARE 條件生效（併入未來）**：若日後 `ANTHROPIC_API_KEY` 上線且要做雙模型，**同輸入鐵則（§POLICY B5）**與**離線示範公平性（B4）**同時適用；**未接金鑰時不得以示範文字冒充某模型的真實回答**。
- **離線後備（B4 公平）**【規定・回灌】：離線示範回答依**角度類型**給通用版（不必每主題預寫 50 份）；若日後有多模型比較，**示範資料不得讓同一個模型在所有題目上都佔優**。
- **回答標名**：`真的回答`／`離線示範`（同 W07）。

## §COMBAT 戰鬥／演出（沿用 W07 引擎）【規定】
- 沿用 W07 的**戰鬥畫布**：迷宮過場、程序化守衛/怪物、受傷／擊破四態演出、序章/過場/結局動畫——**零素材、程序化**。
- 每填滿一題＝擊退一名「回聲守衛」；全部寫滿＝本層門開、通往第三層（W09）預告。
- 演出不參與判定（判定在填格，§GATE）。

## §CHEAT 防作弊（沿用 W07 A9）【規定】
- **paste 政策由題型決定**：**T2（複製貼上追問範本）必須開放 paste**（那正是要教的操作）＋另外驗證「貼進去的內容真的來自範本/回答」；**T4（自己打）擋 paste**，否則「自己打」沒發生。共用關鍵字輸入元件仍無條件攔 paste/drop。
- Hint 框 `user-select:none`；錯誤選項點錯鎖定；**錯誤訊息具體**（沿用 W07 語氣：「還沒完全正確，守衛擋下來了。再看一次要問出來的事。」）。

## §DATA 資料與工程【一等公民・規定・沿用 W07】
- 存檔綁 uid（共用電腦不繼承上一位學生）；`cloudLoaded` 前只寫本機（避免預設值蓋掉雲端）；跨裝置取進度較遠者。
- 金幣冪等：交易 ID `w8_ws_<qid>`／`w8_full`（＋未來 `w8_cmp`）；發獎封頂。
- **共用電腦驗收腳本**：A 做到第 n 題→登出→B 登入→B 全新書庫、不含 A 的填格。
- API 金鑰只在後端；前端完成鎖如實標「擋誤按、非權限」。
