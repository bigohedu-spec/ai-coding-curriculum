# [S3-W07] 偉大衝浪手的完美衝浪搖滾｜GAMMA＋答題卡課程規格 G1–G2

> 來源學習單：[[S3-W07-學習單]]｜對應教案：[[S3-W07-教案]]｜內容版本：`S3W07-2026-09-01-r2`

## §G 規格治理

- **正典聲明【規定】**：本檔是 W07 答案鏈、音軌資產、Prompt 判定、題中小測、狀態、金幣與網站 JSON 的唯一來源；學生題面只讀 [[S3-W07-學習單]]。
- **綁定內容【規定】**：`wiki/worksheets/S3/S3-W07-學習單.md`，revision `S3W07-2026-09-01-r2`。
- **本週可觀察能力【規定】**：學生能從逐題增加雜訊的凱洛對白中，抽取並分類四需求關鍵資訊，放進同一份音樂 Prompt；最後依親子受眾的改口，只替換目標裡衝突的感受語氣。
- **學生的精確轉換【規定】**：A～D 是 `classify + extract + retrieve`：學生從可見對白找出指定類別的原句片段，不摘要、不改寫；E 是依同一段對白中的明確舊值／新值進行一次 `revise`。
- **In Scope【規定】**：從自然句子抽取關鍵片段、依需求欄位分類、A→D 漸退支架、累積 Prompt、固定音軌缺漏判斷、受眾與語氣關係、指定語氣替換、保存五版 Prompt 與音軌。
- **Out of Scope【規定】**：即時音樂品質、樂理、自由改編、多輪修音、第五種需求、獨立設計完整規格與 W08 的全面自我檢查。
- **支架 Profile【規定】**：`guided-chain`；完整 Prompt 骨架與欄位方向仍保留，難度只增加在資料來源。A 加粗關鍵片段，B 提供四個欄位方向，C 只提供數量，D 只提供三個問題；舊段落由答題卡帶入並鎖定，E 才開放完整 Prompt。
- **可數單位【規定】**：0 個序章、5 個主任務、5 段教師預製試聽音軌、4 張需求卡、15 題題中小測、5 次 Prompt 審查、250 金幣。
- **學生版邊界【規定】**：小測、答案索引、證據群組、隱藏保存包、資產 ID、金幣與 JSON 不得加入學習單。

## §P 支架與跨週定位

| 項目 | 設計決策 |
|---|---|
| W06 已會 | 同一份 Prompt 逐題累積四需求；正式需求改變時，要替換衝突舊值 |
| W07 新增 | 從自然句子抓出規格重點；「目標」要對準受眾與感受語氣 |
| A 支架 | 三個權威片段藏在句子中但加粗，Prompt 保留三個命名空格 |
| B 支架 | 對白不加粗，只提示主旋律、聲音效果、節奏、結尾四個尋找方向 |
| C 支架 | 只提示對白中有四個禁止聲音，學生依出現順序抽取 |
| D 支架 | 只留下「誰、場合、感受」三個問題，學生自行分類瘋狂喊話 |
| E 支架 | 舊語氣與新語氣都在凱洛改口句中；只替換一次，不重寫其他需求 |
| 完成證據 | 五版 Prompt、五段音軌、四張需求卡、15 題小測與語氣欄位修改紀錄 |

### Hook／Deliver

- **Hook**：凱洛只說「完美」，Riff 無法知道音樂類型、演奏方法、禁則與受眾感受。
- **Deliver**：學生讓 Prompt 從一行長成四行，再把壓迫語氣改成適合親子觀眾的陽光語氣，完成凱洛的出場曲。

### 五版試聽音軌鏈【規定】

| 回傳 | 固定資產 ID | 已修好 | 仍缺漏／衝突 | 下一步 |
|---|---|---|---|---|
| A／V1 | `s3w07-surfrock-v1-subject-fail-arrangement` | 曲名、類型、用途 | 主旋律、效果、節奏、結尾模糊 | 新增怎麼做 |
| B／V2 | `s3w07-surfrock-v2-arrangement-fail-avoid` | 衝浪吉他、殘響、節奏、結尾 | 混入人聲、悲傷鋼琴、舞曲節拍與靜音 | 新增不能做什麼 |
| C／V3 | `s3w07-surfrock-v3-clean-fail-goal` | 四項禁則 | 不知道使用者、場合與感受 | 新增目標 |
| D／V4 | `s3w07-surfrock-v4-goal-tone-conflict` | 四需求完整 | 壓迫語氣不適合親子觀眾 | 替換感受語氣 |

## §GL 遊戲迴圈與判定

```text
讀凱洛對白 → 依當題支架圈出關鍵片段 → 分到 Prompt 空格
→ 本地檢查 → Lab Music 回傳固定音軌 → 完成三題因果小測
→ 保存需求卡與音軌 → 下一題追加，或在 E 指定替換語氣
```

- **一題一個主要動作【規定】**：A～D 各從對白抽取並追加一種需求；E 只替換 `目標／感受語氣`。音軌與小測是同一修改的回饋。
- **AI 定位【規定】**：生成解說與方向回饋；本地 evidence groups、資產綁定及選擇題決定通關。
- **答案傳遞【規定】**：B～D 只讀前題通過原文；E 讀學生自己的 q4 Prompt，不用教師答案覆蓋。
- **退件【規定】**：保留 Prompt、音軌、小測與修改次數；一次只指出一個空格或缺漏群組。
- **金幣【規定】**：A35＋B40＋C45＋D50＋E80＝250；交易 ID `S3W07:<uid>:<taskId>:pass`。

### 教師正確答案鏈

- A｜做什麼：`請製作名為追浪時刻的 30 秒衝浪搖滾，作為衝浪手出場音樂。`
- B｜怎麼做：`以清脆電吉他演奏，加入海浪般的殘響，搭配快速穩定的鼓點與低音，最後用有力的吉他收尾完成。`
- C｜不能做什麼：`不要有人聲歌唱、悲傷鋼琴、電子舞曲節拍或突然靜音。`
- D｜目標：`給偉大的衝浪手凱洛在親子海灘祭出場時使用，並讓親子觀眾感到緊張壓迫。`
- E｜唯一修改：把 D 的 `讓親子觀眾感到緊張壓迫` 替換為 `讓親子觀眾感到陽光、興奮又安心`；其他三段保留學生通過原文。

### 正確答案隔離規則【規定】

- 完整答案、音軌資產 ID、證據群組與選擇題答案不得渲染到未解鎖學生畫面。
- 學習單對白中的權威片段是 `guided-chain` 的合法原始資料；除 A 外不再以答案條列或加粗呈現。
- 後題骨架由學生已通過原文自動帶入；不得用本節教師答案取代。
- 題中小測只在學生聽完當題音軌後開啟。

## 3. 每題審核標準

| 題 | Prompt 預審 | 主成果通過 | 方向式退件 |
|---|---|---|---|
| A | 追浪時刻／30 秒衝浪搖滾／出場音樂 | V1 同題綁定＋3 checks | 指出曲名、類型或用途中第一項缺漏 |
| B | 電吉他／殘響／鼓點低音／吉他收尾 | V2 同題綁定＋3 checks | 只指出第一項演奏缺漏 |
| C | 人聲／悲傷鋼琴／舞曲節拍／突然靜音 | V3 同題綁定＋3 checks | 只指出第一項未禁止聲音 |
| D | 凱洛／親子海灘祭／緊張壓迫 | V4 同題綁定＋3 checks | 只指出使用者、場合或感受缺漏 |
| E | 四需求仍在；新語氣存在；舊語氣不存在 | V5 同題綁定＋3 checks | 先指向凱洛的緊急改口，再指出修改欄位 |

所有題先拒絕未替換的 `〔……〕` 或 `[任務X留下的需求]`。不因標點、一般錯字或音軌美術品質退件。

### 對白抽取的本地判定【規定】

- evidence groups 檢查必要片段；`maxActiveRequirementChars` 與 `rejectSourceFillerTerms` 防止整段喊話直接貼入。
- 退件只說「你貼入了凱洛的情緒／重複語句，請只留下能回答本欄位的片段」，不得貼回正確片段。
- A～D 接受不影響語意的連接詞與標點差異；不要求學生摘要或改寫凱洛原句。
- `sourceExtraction.supportLevel` 固定為 A4→B3→C2→D1；網站不得偷偷補回較高支架。

## 4. 題中小測

- 無序章與題前檢核；`initialQuestionId` 為 q1。
- A～D 每題音軌綁定後開啟 `review-current`、`failure-diagnosis`、`next-modification` 三題。
- E 的三題檢查修改欄位、成功原因與完成儀式。
- 全部使用本地選擇題；答錯保留 Prompt 與音軌，只指向已看過的音軌或正式資料。

- AI 回饋逾時改用本地 evidence groups；音軌載入失敗則保留 Prompt 與 ticket，顯示同版短文字試聽回報。
- 音軌綁定失敗時保存 assetId、promptHash 與波形縮圖，允許重新綁定同次結果，不要求重打。
- 重新整理或斷線恢復最後題目、Prompt、音軌、小測與修改紀錄；不同 uid 不共用草稿。
- revision 或 schema 不相容時以 `storageVersion` 隔離舊草稿；教師端可匯出舊紀錄，不靜默覆蓋。

## 7. 老師端與翻轉教育

- 老師端顯示目前題、activeRequirement、五版 Prompt、V1～V5 綁定、缺漏群組、小測、修改次數與 E 的 old/new 語氣。
- 先完成者只能問：`音軌已經做對什麼？`、`還缺哪種需求？`、`這個感受適合親子觀眾嗎？`
- 禁止代填、提供完整 Prompt、代選小測、代送出或代修正 E。
- 教師人工放行只用於同義詞漏判；E 不接受同時保留新舊兩種語氣。
