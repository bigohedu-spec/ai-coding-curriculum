# [S3-W01] 工具選擇與初次使用｜正式學習單規格 v21

> 本檔是 S3-W01 的唯一規格來源。實作、GAMMA 與學習單內容若不一致，先更新本規格與學習單 JSON，再調整程式。
> 對應學習單：[[S3-W01-學習單]]｜對應教案：[[S3-W01-教案]]｜難度：G1-G2｜更新：2026-08-03

## 1. 課程目標

學生完成四個短任務，理解「先讀任務、選對工具、寫出符合需求的提示詞、檢查生成結果」的基本流程。

| 項目 | 設定 |
| --- | --- |
| 學期／週次 | S3／W01 |
| 任務名稱 | 工具選擇與初次使用 |
| 主平台 | GAMMA 學習單、Lab Terminal |
| 題數 | 4 題，題後各有 1 題讀題小測 |
| 金幣 | 250（Q1 60、Q2 60、Q3 60、Q4 70） |
| 學生入口 | `/worksheets/S3W01` |
| GAMMA | `https://gamma.app/docs/S3-W01-hixa52whtzl6aas` |

## 2. 學生流程

1. 從 `/worksheets` 開啟 S3W01；左側讀 GAMMA，右側只呈現當前題目的必要操作。
2. 完成當前題的讀題小測，確認要交的成果或適合工具。
3. 依題目回到 Lab Terminal；系統以學習單 ID 與題目 ID 開啟本課專用 session。
4. 學生輸入提示詞後，系統先做 JSON 初審，再做低成本 AI 短審核；兩者通過才可生成。
5. 將文字或已簽章的媒體作品附回當題，送審後自動切到下一題並在上方任務加星號。
6. 四題完成後播放完成回饋、寫入完成紀錄、關閉此學習單 session 的圖片／音樂／影片生成權限。

未完成時保留專用 session 與草稿；完成後移除該 session。一般對話 session 不具備本課媒體生成功能。

## 3. 四題設計

| 題目 | 任務 | 指定工具 | 交付物 | 讀題小測 |
| --- | --- | --- | --- | --- |
| Q1 | 將 AI 工具使用規則整理成 3 點提醒 | Lab Terminal | 文字 | 這題要先產出哪一種成果？ |
| Q2 | 小狗在草地玩紅色球 | Lab Image | 圖片 | 最適合使用哪個工具？ |
| Q3 | 溫暖、放鬆、無人聲的咖啡廳爵士樂 | Lab Music | 音樂 | 這題要交什麼作品？ |
| Q4 | 藍色外套滑雪者在白色雪地往下滑 | Lab Video | 影片 | 最適合使用哪個工具？ |

### Q1｜AI 工具使用提醒

- 產出：3 點短、清楚的文字提醒。
- 文字條件：至少 18 字、最多 260 字、需要 3 個分點，並命中至少 2 個概念：AI、個資／隱私、檢查／確認、老師、提示詞。
- 讀題小測答案：`整理後的文字提醒`。

### Q2｜小狗玩球圖片

- 提示詞必要內容：小狗、草地、紅色球。
- 交付：由 Lab Image 生成、帶有本題簽章的 PNG／JPG／WebP。
- 讀題小測答案：`Lab Image 圖片工具`。

### Q3｜咖啡廳爵士樂

- 提示詞必要內容：咖啡廳、爵士樂、溫暖放鬆、沒有人聲。
- 交付：由 Lab Music 生成、帶有本題簽章的 MP3／WAV／M4A。
- 讀題小測答案：`一段音樂檔`。

### Q4｜滑雪短影片

- 提示詞必要內容：滑雪者、藍色外套、白色雪地、往下滑。
- 交付：由 Lab Video 生成、帶有本題簽章的 MP4／WebM／MOV。
- 讀題小測答案：`Lab Video 影片工具`。

## 4. 學習單 JSON 是必要交付物

固定區塊：

````markdown
<!-- LAB_TERMINAL_WORKSHEET_CONFIG_START -->
```json
{ "schemaVersion": 2, "worksheetType": "gamma-answer", "questions": [] }
```
<!-- LAB_TERMINAL_WORKSHEET_CONFIG_END -->
````

## 5. 生成前檢核與媒體簽章

### 5.1 提示詞初審

1. 空白、亂碼、工具類型錯誤直接退回，並清楚說明缺少內容。
2. 媒體題先依 `promptReviewCriteria.passConditions` 做本地字元命中；去除標點與通用指令後，命中至少 50% 才繼續。
3. 通過本地門檻後，使用低成本短 token 模型做題意與語意檢查；不通過時保留學生文字，指出要補的主題、場景、物件或限制。
4. 只有兩層皆通過，才可呼叫圖片、音樂或影片 API。

### 5.2 生成、保存與驗章

- 每份媒體作品的簽章綁定：`worksheetId`、`taskId`、工具類型、學生提示詞與原始內容雜湊。
- 圖片把 metadata 附在檔案尾端；音樂與影片在檔案 metadata 中保存；後端以 HMAC 驗證。
- 媒體題繳交時只接受「同一學習單、同一題、同一工具」的有效簽章。手動上傳、改名或其他題的檔案不得通過。
- 正式部署必須保存到 Firebase Storage，並把索引與 metadata 同步至 Firestore；Vercel 本機磁碟僅可作暫存，不能當正式保存來源。

### 5.3 圖片快取與 API 上限

- `LAB_IMAGE_CACHE_LIMIT` 預設為 10，限制一份學習單的圖片快取池。
- 相似度門檻為 0.72；相似提示詞優先回用同題已簽章圖片。
- 圖片池未滿時才呼叫圖片 API，生成後立即保存與簽章。
- 圖片池滿時禁止再呼叫圖片 API；若沒有相似結果，隨機回傳同題的已簽章圖片。
- 該題完全沒有可安全回用圖片時，回覆「儲存額度已滿」並請老師從後端刪除快取或提高上限；不得拿別題圖片冒充當題作品。

音樂與影片亦可用各自的 `LAB_MUSIC_CACHE_LIMIT`、`LAB_VIDEO_CACHE_LIMIT` 管理快取；provider cooldown 或可恢復 API 錯誤時，可回用同題已保存素材。

## 6. 介面與回饋要求

- 固定 viewport；左側 GAMMA、右側答題區獨立捲動，右側不得水平捲動。
- 完成一題即自動前往下一題；目前／已完成任務用星號標示。
- 「送 AI 審核」通過後顯示為非按鈕的「任務完成」。
- 附件成功驗章後改成可直接檢視的預覽，移除重複上傳入口。
- 每題後先完成讀題小測，防止學生未讀題就操作工具。
- API、簽章或上傳失敗要用具體文字說明，不清空答案或附件。
- 所有任務完成後顯示賽博彩帶與「舉手告訴老師」完成視窗。

## 7. 實作與部署接口

| 類別 | 位置 |
| --- | --- |
| 前端設定 | `gpt-clone/src/config/gammaAnswerWorksheets.ts` |
| 學習單頁面 | `gpt-clone/src/components/worksheets/GammaAnswerWorksheet.tsx` |
| 題目 JSON 標準 | `gpt-clone/docs/gamma-answer-worksheet-json-standard.md` |
| 生成 API | `POST /api/lab-tools/{text|image|music|video}` |
| 簽章驗證 | `POST /api/lab-tools/signature` |
| 媒體讀取 | `GET /api/lab-tools/asset` |

必要環境變數：`OPENAI_API_KEY`、`NANO_BANANA_API_KEY`、`ELEVENLABS_API_KEY`、`LAB_TOOL_SIGNATURE_SECRET`、Firebase 設定與各媒體 cache limit。

## 8. 驗收條件

- [ ] S3W01 學習單 Markdown 尾端有可解析的 `schemaVersion: 2` JSON。
- [ ] 四題均能從 JSON 載入題目、讀題小測、工具類型與審核條件。
- [ ] 開啟未完成學習單時，建立／選取正確的 S3W01 專用 session。
- [ ] 媒體生成先通過 JSON 50% 初審與 AI 短審核；失敗時顯示原因而不呼叫生成 API。
- [ ] 圖片、音樂、影片保存後能帶簽章回填，且後端能驗證學習單與題目一致。
- [ ] 圖片快取滿額後不再呼叫圖片 API；可回用同題簽章圖片。
- [ ] 四題完成後移除本課 session，並收回媒體生成權限。
