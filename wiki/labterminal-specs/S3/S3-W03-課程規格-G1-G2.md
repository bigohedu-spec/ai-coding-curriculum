# [S3-W03] 午夜車站：零點列車｜GAMMA＋答題卡課程規格 G1–G2

> 來源學習單：[[S3-W03-學習單]]　|　對應教案：[[S3-W03-教案]]　|　難度版本：G1–G2　|　內容版本：`S3W03-2026-08-20-r18-translation-allowed`

## §G 規格治理

- **內容唯一正典【規定】**：學習單保存開場故事、序章文字題、A～E 題目資料、固定 Prompt 與成果要求。本規格負責工程映射、ID、判定、狀態、隱藏資料與題中小測；題中小測不得寫回學習單。
- **GAMMA 邊界【規定】**：左側 GAMMA 只顯示開場故事與 A～E 題面；「序章詢問｜確認現在的場景」只顯示在右側線上學習單答題卡，不得另建 GAMMA 頁面或寫入 GAMMA 內容。
- **綁定內容【規定】**：`contentSource.path = wiki/worksheets/S3/S3-W03-學習單.md`，`contentRevision = S3W03-2026-08-20-r18-translation-allowed`。發布時兩者必須同時吻合。
- **成果鏈【規定】**：A 只保存列車、時間、月台、目的地與車票編號；B 才使用該編號換出圖案順序、生成星孔車票並保存圖案順序；C 以該順序讀取月台訊號表，產出完整摩斯發車碼並教學翻譯 `CAR 7`；D 把發車碼轉成聲音並由廣播確認第 7 節車廂開門。每題不得提前執行下一題的媒體工作。
- **本版最高規則【規定】**：先顯示序章文字題「先別猜列車。你現在在哪裡？」，通過後依序完成三題序章回顧與一題 A 讀題，才進入任務 A。A～E 的 Session 輸入框一律空白且可輸入，學生閱讀學習單的「你可以這麼問」後自行輸入一次 Prompt。
- **題中小測【規定】**：序章固定 `review → review → review → next-reading`；A～E 各固定 `review → next-reading`。每個下一題讀題必須先說明學生此刻所在位置。
- **工具按鈕與不提示工具【規定】**：A～E 沿用預設版面，Lab Terminal、Lab Image、Lab Music、Lab Video 四個按鈕必須全部顯示。`studentToolHints = false` 只表示不高亮、不推薦也不文字提醒學生使用哪個工具，不得隱藏、減少或改排四個按鈕。序章不啟動 Lab Tool，故序章卡不顯示工具操作區。題中小測不得出現工具名稱、哪個工具、選工具或以工具類型作答案。
- **In Scope【規定】**：讀故事、自行輸入並送出序章的單一地點回答、自行輸入並送出 A～E 的一次提問、觀看成果、回顧成果、在明確位置脈絡下讀懂下一段行動。
- **Out of Scope【規定】**：改寫 A～E 題目、學生手算或手動解碼、A～E 額外自由文字作答、第二次正式提問、工具選擇提示、從 W02 複製題目內容。
- **金幣【規定】**：A60＋B50＋C60＋D40＋E40＝250。交易以正式 `taskId` 冪等。

## §GL 基礎循環與判定

```text
讀開場故事 → 序章答題卡自行輸入所在地點 → 序章四題小測 → 進入 A
→ A～E 在空白 Session 輸入框自行輸入一次 Prompt → 主回答通過
→ review：回顧剛完成的可驗證事實
→ next-reading：先看清楚此刻所在位置，再確認下一題要做的事
→ 解鎖下一題
```

- **本地判定【規定】**：每題小測本地比對 `answerIndex`，GPT-5.4 不判定題中小測通過。
- **C 題順序護欄【規定】**：送交 GPT-5.4 審核前，先在伺服器端確認學生明確填入 B 題保存的 `車輪→月亮→星星→時鐘`。只貼月台訊號表不算提供順序；任兩個圖案對調時，不呼叫模型、不輸出錯誤摩斯碼，直接回傳預寫的「回保存站 B 重查順序」提醒。
- **C 題路由保底【規定】**：正常 `/api/lab-tools/text` 與意外落入的 `/api/openai` 都必須套用同一護欄。一般聊天路由以 worksheet/task 身分優先辨識；舊 Session 缺少身分時，再以「月台訊號表＋四圖案＋摩斯發車碼」特徵辨識。錯序回預寫提醒，正序回教師固定答案，兩者皆不得呼叫模型。
- **錯誤安全【規定】**：選錯保留成果；短暫鎖定後重試；提示只指向故事或通關答案，不揭露完整答案。
- **狀態【規定】**：題中小測用穩定 ID 儲存。調整小測順序後，舊草稿不會錯套到另一題。
- **隱藏資料【規定】**：`systemContext` 與 `systemPacket` 只在背景送入 AI 與下一題路由，不可渲染為 GAMMA 內容、通關答案、答題卡或前端可檢視常數。
- **Session 輸入【規定】**：開啟 A～E Session 時不得把 `toolPrompt`、範例或預設回答寫入輸入框；輸入框必須保持空白且可編輯。`toolPrompt` 只作伺服器端審核與正確成果生成的教師參考。
- **序章輸入【規定】**：序章使用右側學習單的文字區，預設值必須為空白，不可自動寫入答案；通過條件為學生自行回答「午夜車站」。序章 `launchTool = false`，不建立 Session、不開啟 Lab Tool。

## 1. 學習單成果鏈（只引用，不新增題目）

1. 序章：只回答自己現在在「午夜車站」；不猜列車。
2. A：月光號、23:40、第 4 月台、倒影城、`4-2-0-3`。
3. B：銀藍色長方形、中央月亮、車輪→月亮→星星→時鐘的星孔車票。
4. C：完整摩斯發車碼 `-.-. .- .-. / --...`，並以教學回傳翻譯為 `CAR 7`／第 7 節車廂。
5. D：把 C 的完整發車碼做成 10～15 秒純電子嗶聲，讓第 7 節車廂開門。
6. E：5～8 秒第一人稱登車回憶；00:00 月光號成為零點列車。

## 2. 每題小測意圖

| 題   | review 回顧      | next-reading 現在要做什麼                       |
| --- | -------------- | ----------------------------------------- |
| 序章 | 23:40／00:00 前／大廳時刻表 | 留在午夜車站大廳，讀懂 A 要找齊的資料 |
| A   | 車票編號 `4-2-0-3` | 依編號換圖案，做成午夜車票                             |
| B   | 星孔順序是車輪→月亮→星星→時鐘 | 到第 4 月台依訊號表組成完整發車碼 |
| C   | 完整發車碼的每組訊號保持分隔 | 把摩斯發車碼做成發車聲 |
| D   | `DOT .` 是短音 | 把 A～D 成果連成登車回憶 |
| E   | 列車長指出第 7 節車廂   | 讀結尾：月光號成為零點列車並回到真正城市月台                    |

所有正解都已出現在本題通關答案或下一段學習單文字；每個 `next-reading` 題幹必須先交代此刻位置，再問下一題的行動，不得加入額外計算、名詞背誦或工具判斷。

## 3. 時長預算

- 四年級、主線目標 50–65 分鐘；依本版 2,475 字閱讀、517 字輸入與 64 次點擊的動作級快速估算，結果 **64.0 分鐘，判定剛好**。
