# S3 W04｜《顛倒博物館》課程規格 G1–G2

> 來源學習單：[[S3-W04-學習單]]  
> 難度版本：G1–G2（小四）｜生成日期：2026-08-21

## §G 規格治理

- **正典聲明【規定】**：本檔是 S3-W04 右側答題卡、題中小測、任務判定與答案傳遞資料的唯一來源。學生故事與題面只讀 [[S3-W04-學習單]]；任何題目資料、答案或驗證改動，先改本檔再發布。
- **綁定內容【規定】**：學生內容 `wiki/worksheets/S3/S3-W04-學習單.md`；教師版 `wiki/lesson-plans/S3/S3-W04-教案.md`；預定課程 ID `S3W04`。
- **In scope【規定】**：學生觀察異常、用自己的中文提出短 Prompt、讀取 AI 回覆、修正一個缺漏、將答案轉為圖片／音樂／影片需求。
- **Out of scope【規定】**：格式控制、精確字數控制、語氣改寫、專業 Prompt 結構、多工具大型專案；這些留給後續週次。
- **跨週技能地圖【規定】**：W02 完整句型填入 → W03 半開放 Prompt 支架 → **W04 自己把問題說清楚** → W05 指定 AI 回答的方法。
- **可數單位【規定】**：1 個零金幣序章讀題站、4 個連續任務、4 張答題卡；每個任務均有「題目前讀題測試 3 題＋完成後題中小測 4 題」，每組題中小測第 4 題固定為口訣情境題；主線 250 金幣。
- **難度假設【假設，待實玩校準】**：目標班級 80% 可在 60 分鐘主線內完成 A–D；未達時，縮短故事文字或改用教師備援媒體，不增加謎題規則。

## §GL 遊戲迴圈與判定

```text
序章讀懂 A 題要問什麼 → 題目前讀題測試 → 找出眼前的問題 →
選擇工具 → 用自己的話問對問題 → 修改答案 → 答題卡保存下一題鑰匙 → 下一展區
```

- **AI 角色【規定】**：AI 協助整理、指出衝突或生成媒體；主成果判定與題中小測一律以本地規則驗證，AI 不當關主。
- **讀題與題中小測【規定】**：序章先檢查學生是否看懂 A 題要處理的資料、要取得的成果和要做的動作；A–D 每題在工具區開啟前都先完成 3 題讀題測試。主成果通過後，再依序完成 4 個題中小測；第 4 題固定用當前展區情境換句話說詢問本週口訣。所有讀題測試與題中小測答對後才可進入下一個階段；答錯只給方向回饋與短暫鎖定，不清空任何成果或紀錄。
- **答案傳遞【規定】**：A 的作品指令決定 B 的畫；B 的星星數量決定 C 的速度；C 的速度與氣氛是 D 的影片材料。後題不可預先展示前題答案。
- **失敗安全網【規定】**：生成服務失敗時保留學生 Prompt 與修改紀錄，允許附上教師備援媒體／分鏡；不可把模型失敗判成學生失敗。

### 送出與審核規則【規定】

| 階段 | 系統行為 | 未通過時的回饋 |
| --- | --- | --- |
| 文字需求送往 Lab Terminal | 不做 Prompt 預審，原文直接送出並正常顯示回答 | 不攔截、不改寫學生輸入 |
| 圖片／音樂／影片 Prompt 送出 | 生成前先做必要條件預審；通過後才開放對應的教師預製媒體 | 只指出缺少的條件類別或檢查方向，不提供答案、關鍵詞清單或完整 Prompt |
| 題目前讀題測試 | 每題工具區開啟前先完成 3 個 `preReadChecks`；序章另先檢查 A 題的讀題理解 | 只指出要回看的題目區塊，不顯示答案或 Prompt 範例 |
| 右側答題卡送審 | 檢查本題成果、前題依賴與媒體附件；主成果通過後開啟 4 個 `readChecks`，第 4 題為口訣情境題；全部答對才寫入完成進度並解鎖下一題 | 保留目前草稿與附件，一次只給一項最重要的修改方向，不直接代改 |

- **媒體來源【規定】**：B、C、D 使用教師預製的圖片、音樂與影片；學生仍須自行撰寫媒體 Prompt 並通過預審。
- **兩階段分離【規定】**：媒體 Prompt 預審通過不等於答題卡通過；答題卡必須另行送審。
- **回饋邊界【規定】**：不得顯示「你應該使用哪個工具」、正確作品編號、完整條件答案或可直接複製的句型。

### 四題如何連在一起【教師／系統專用】

```text
A 還原作品線索
  ↓ 將作品線索寫入 A 答題卡
B 用 A 的作品線索選出圖片條件
  ↓ 將條件中的數量寫入 B 答題卡
C 用 B 的數量決定聲音速度並修正衝突
  ↓ 將修改後的聲音條件寫入 C 答題卡
D 合併 A、B、C 的通關紀錄完成出口影片
```

此圖只存在課程規格與教案，不渲染到學生學習單或解題畫面。

## 2. 四題內容、答案鏈與主成果判定

| 題 | 主成果 | 固定答案／必要資料 | 下一題語意鎖 | 本地判定摘要 |
| --- | --- | --- | --- |
| A 順序錯亂的入口廳 | 整理後的展覽指令 | `品月作有亮的找尋` → `尋找有月亮的作品` | 月亮作品 | `nextKey` 正規化後同時含「尋找、月亮、作品」 |
| B 沒有名字的畫廊 | 圖片與四格條件紀錄 | 月亮、藍色、3 顆星星、不要文字 | 星星數量 3 | 四格資料與圖片 Prompt 均含必要條件；有圖片或備援紀錄 |
| C 說錯話的語音館 | 音樂與聲音條件紀錄 | 3 → 快；衝突＝非常慢；快速、長笛、明亮、無歌詞 | 快速、長笛、明亮 | 紀錄含目標與衝突；音樂 Prompt 含四項必要條件；有音訊或備援紀錄 |
| D 消失的出口展品 | 約 5 秒出口影片 | 藍色月亮、3 顆星星、明亮出口、快速移動、無文字 | 最終成果 | 影片 Prompt 含必要畫面、5 秒與無文字；有影片或備援分鏡 |

### 固定推理鏈

1. A 的文字僅順序異常；整理後的指令選定 B 的月亮作品。
2. B 的 Emoji 分別提供主體、顏色、數量與限制；其中 3 是 C 必需的數字。
3. C 將 3 對照速度牆得到快；「非常慢」是唯一與目標速度衝突的條件。
4. D 整合月亮、藍色、3 顆星星、快速與明亮，生成無可閱讀文字的出口影片。

### 正確答案隔離規則【規定】

- 本節、§2 表格、§2b 審核標準與 JSON 中的 `answerIndex`／`acceptedTerms` 屬教師及機器判定資料，不得插入 GAMMA 學生頁、Prompt 預審回饋、答題卡提示或未通關題目的預覽。
- 題中小測只檢查解題方法、資料來源與修正動作，不得詢問或在題幹中寫出本題正解、下一題鑰匙或最終 Prompt 條件。
- B、C、D 只能在上一題完成後透過 `autoContextFrom` 讀取指定的 `passContent`；完成前不得用 placeholder、範例、預選或錯誤訊息洩漏答案。
- GAMMA 場景圖提示只能表現場景與問題狀態；不得畫出正確作品、正確數量、正確速度或最後影片構圖。

| 題 | Prompt 預審 | 答題卡通過標準 | 未通過時只可提示的方向 |

## 3. 序章、讀題測試與題中小測規則

- **序章【規定】**：`S3-W04-PROLOGUE` 是零金幣、無媒體附件的讀題站；完成 3 題 A 題讀題測試後才解鎖任務 A。不得在序章給出 A 的完整答案或可複製 Prompt。
- **每題讀題測試【規定】**：A–D 的 `preReadChecks` 固定 3 題，在題目成果區與工具入口前出現。題目只確認「眼前資料是什麼、這題要完成什麼、要使用哪一張舊答題卡／哪一類規則」，不可要求學生說出正確答案。
- **學生提問建議【規定】**：JSON 只提供 `studentGuidance` 作為方向提示，不得提供 `toolPrompt`、句型、填空骨架、可選取的範例或任何可直接複製的 Prompt。建議只能提示學生應說清楚的資料種類與目的。
- **題中小測【規定】**：每題固定 4 題，優先使用選擇題。介面必須依 `displayOrder` 由小到大出題；第 4 題的 `isMantraCheck = true`，以當前展區情境換句話說詢問「抓出問題 → 選擇工具 → 問對問題 → 修改答案」，不得直接照抄口訣。`reviewCriteria.requiredReadChecks = 4`，四題全部答對才完成本題。
- 學生學習單不可重複題目、選項或答案；所有測驗只顯示在右側答題卡。
- 選擇題至少 3 個選項，干擾項必須是合理的常見誤解；錯誤選項鎖定 2 秒並重新排列其餘選項。
- 錯誤訊息只指出要回看的資料或思考方向，不提供完整答案。

## 5. 資料、狀態與發布

- 本機答題草稿：以 `storageVersion + worksheetId + userId` 保存學生文字、附件、審核與小測狀態；答錯、退件或重新整理不可清空。
- `passContent`：保存 A 的展覽指令、B 的四格條件、C 的四格聲音資料與 D 的成果摘要；後題以 `autoContextFrom` 明確選取已完成前題，不接受 request 自帶答案。
- Firestore `progress.tasks[taskId]`：只有主成果與 3 個小測都完成後才標記 `completed`；介面以第一個未完成題目作為唯一可前進位置。
- `coinsLedger`：以 `S3W04:<uid>:<taskId>:pass` 作冪等交易 ID；四題合計最多 250 金幣。
- 發布前必檢查：`initialQuestionId = prologue`、序章 3 題 A 題讀題測試皆可本地判定、學生版四個任務標題與 `contentRef` 一致、JSON 可解析、金幣合計 250、A–D 每題均有 3 題 `preReadChecks` 和 4 題 `readChecks`，且第 4 題 `isMantraCheck = true`、後題不含前題答案。
- 送審回饋由 `reviewFeedbackMode = direction-only` 執行：一次回一項缺漏類別，不輸出完整答案或 Prompt；A 的文字輸入不得進入此預審流程。

## 6. 老師端與翻轉教育

- 老師端顯示每題完成狀態、附件／備援狀態、小測作答與需要協助旗標；小測答錯可暫停前進，但不得扣除成果、金幣或清空紀錄。
- 先完成者只能問：`你看到的問題是什麼？`、`你希望 AI 做哪件事？`、`答案是從哪張答題卡來的？` 不可說出答案或代打。
- 媒體生成失敗時老師可放入備援成果，但要保留學生的原 Prompt 與教師覆寫紀錄。

## 7. 驗收清單（DoD）

- [ ] 學生學習單每題只有「背景故事、謎題內容、通關條件、提示」四段，沒有題中小測、完整 Prompt 範例、完成步驟或行為勾選框。
- [ ] 序章在 A 題前完成 3 題讀題測試；學生知道 A 題處理什麼資料、要得到什麼成果及要做什麼動作，才開啟 A 題。
- [ ] A–D 每題工具區開啟前先完成 3 題讀題測試；題目只檢查本題在問什麼，不洩漏正確答案。
- [ ] 題中小測只存在本檔 JSON；每題 4 題且第 4 題固定為 `isMantraCheck = true` 的口訣情境題，作答即時回饋，全部答對後才結算並解鎖下一題。
- [ ] A→B→C→D 的資料依賴成立；任何後題都不能直接展示前題正解。
- [ ] B 題顯示五組 Emoji，且沒有視覺或文案洩漏正確組。
- [ ] A 文字直接輸出；B／C／D Prompt 先預審、通過後開放教師預製媒體，再由答題卡獨立審核。
- [ ] 四題答題卡審核均依 §2b 執行，退件一次只給一項修改方向。
- [ ] 題中小測只考解題方法與資料來源，題幹、選項及錯誤訊息均未洩漏正解或完整 Prompt 條件。
- [ ] JSON 沒有 `toolPrompt` 或任何可直接複製的 Prompt 模板；只有不可選取、不可複製的 `studentGuidance` 方向提示。
- [ ] GAMMA 圖片提示只呈現場景與問題狀態，未畫出任何正確答案。
- [ ] 主成果判定不依賴 AI 主觀評分；媒體失敗有備援且不抹除學生證據。
- [ ] 學生版與題中小測沒有任何第三方 AI 品牌名稱。
- [ ] 首次實課後依完成率與實測時間回填本檔；若 80% 未能於 60 分鐘完成，優先減少閱讀量或介面步驟。
