# [S3-W02] 馬雅星門的六道封印｜GAMMA + 答題卡課程規格 G1–G2

> 來源學習單：[[S3-W02-學習單]]　|　答題卡設定：[[S3-W02-答題表設定]]　|　對應教案：[[S3-W02-教案]]

## §G 規格治理

- **正典聲明**：本規格與 `S3-W02-答題表設定.json` 是右側答題卡的唯一真相；GAMMA 只放學生故事與題目。
- **課程形式**：左側約 70% 為 GAMMA 解謎故事書；右側約 30% 為六張答題卡、Lab 工具入口、輸入型題中小測與送審區。
- **In Scope**：抓重點、選工具、描述問題、使用 AI 轉譯陌生形式、檢查結果、沿用前題資料。
- **Out of Scope**：手算 RGB 距離、手算 Base64、背誦技術名詞、仿造真實馬雅文字、HTML 小遊戲、偵探案件。
- **內容界線**：馬雅遺跡為虛構冒險場景；HEX、英文機器規則與 Base64 是故事中的數位掃描資料，不宣稱為真實馬雅文字。
- **金幣**：六題合計 250；同一題通過後不得重複入帳。
- **狀態保存**：答題卡輸入與附件自動保存。後題需要前題資料時，學生切回舊答題卡複製。
- **筆記本定位**：右上角筆記本只做文字暫存、整理與複製貼上，不保存通關狀態，也不是答案的單一來源。

## §GL 遊戲迴圈與答案鏈

- **玩家角色**：協助研究隊開啟星門的 AI 遺跡譯讀員。
- **每回合**：閱讀新場景 → 遇到看不懂的形式 → 選擇 Lab 工具轉譯或生成 → 完成輸入型小測 → 送審一次。
- **獎勵**：每通過一題解除一道封印；第六題完成後星門亮起。
- **判定**：題中小測先以本地正規化比對；作品與文字成果再依 `reviewBrief` 審查。學生只按一次「送出」，系統合併回傳結果。
- **防硬答**：下一題的必要輸入不在後題重複顯示；必須從前題已保存內容複製。錯誤不清空原答案與附件。

## 3. 一題一次送審

每張答題卡先顯示一個主成果區。學生完成本題的右側填空或附件上傳後，才展開 `postTaskQuiz` 題中小測。

學生流程：

1. 在 Lab 工具完成本題內容或作品。
2. 回填文字或上傳附件；系統確認本題有內容後，顯示題中小測。
3. 完成所有輸入型或選擇型小測。
4. 按一次「送出檢查」。

送出時依序執行：

1. 檢查成果欄位或附件是否存在。
2. 本地驗證 `postTaskQuiz` 全部題目。
3. 依 `reviewBrief` 檢查本題成果。
4. 全部通過才更新題目狀態、發放金幣、開啟下一張答題卡。

若未通過：保留文字、題中小測與附件，只指出 1–3 個缺漏；學生修改後仍使用同一個送出按鈕。

## 4. 題中小測 JSON

題中小測是主題目完成後才出現的獨立區塊，不是右側主填空欄位。主填空與附件負責收本題成果；小測只確認學生剛才是否正確讀題。

```ts
type InputQuizItem = {
  id: string;
  type: "input";
  question: string;
  placeholder: string;
  acceptedTerms: string[];
  normalize: ["lowercase", "remove-whitespace"];
  match: "exact-or-contains-any-term";
  errorMessage: string;
};

type ChoiceQuizItem = {
  id: string;
  type: "choice";
  question: string;
  options: string[];
  answerIndex: number;
  errorMessage: string;
};

type PostTaskQuiz = {
  showAfterTaskCompletion: true;
  items: (InputQuizItem | ChoiceQuizItem)[];
};
```

### 輸入型小測驗證順序

1. 將學生輸入轉成小寫。
2. 移除全部空白字元。
3. 對每一個 `acceptedTerms` 做相同處理。
4. 學生答案完全等於任一詞，或答案包含任一詞，即通過。
5. 未通過顯示本題 `errorMessage`，不得顯示正解。

### 呈現與保存

- 主填空或附件存在後，才顯示 `postTaskQuiz`。
- 一題可有一個輸入題加多個選擇題，用來回顧剛剛發生的事、本課口訣或故事主題。
- 所有小測通過後，學生才看見或可使用送出按鈕。
- 主成果、小測作答和附件都需自動保存；切換題目後回來仍存在。
- 允許學生從自己的舊答題卡或筆記本貼上；本課複製貼上是學習流程的一部分，不攔截 paste。

## 5. 六題正解推理鏈（教師與工程端）

### Q1 → Q2

石板先以 ROT13 隱藏英文字母；數字、`#`、`×` 與標點保持不變。學生請 Terminal 判斷並還原後，得到：

- `#4FC3F7`
- 一輪彎月
- 三座階梯神殿
- 兩棵木棉樹
- 不要文字
- 數量順序 `1-3-2`

Q2 不重複上述答案，只要求學生從 Q1 已保存文字複製。

### Q2 → Q3

Q2 題中小測保存完整色票。Q3 只寫「使用 Q2 保存的色票」，不出現正解色票。

以 Q1 色票計算 RGB 歐氏距離，最近三組為 D、B、F；依原始代號順序排列為 B、D、F：

```text
B Rk9S + D RVNUL + F TEzMg==
= Rk9SRVNULTEzMg==
= FOREST-132
```

### Q3 → Q4

Q4 只提供打亂順序的「數字 → 聲音」規則。學生必須從 Q3 複製 `FOREST-132` 才能得到森林場景與正確播放順序。

### Q4 → Q5

Q5 的機器規則排列為木琴、鈴聲、鼓聲，刻意不等於正確播放順序。學生必須從 Q4 題中小測複製聲音順序。

```text
鈴聲 → MOVE(1) → 向前一步
鼓聲 → ROTATE(-90°) → 向左轉
木琴 → ROTATE(+90°) → 向右轉
```

### Q5 → Q6

Q6 只提供資料來源位置：Q2 石印、Q3 場景、Q5 動作。影片提示不重複任何正解值；缺少任一前題保存內容就無法完成完整影片。

## 6. 自動保存與筆記本

### 答題卡

- `onChange` 後 debounce 自動保存文字、quiz input、附件 metadata 與工具提示詞。
- 保存鍵至少包含 `studentId + worksheetId + questionId`。
- 切換題目、重新整理、返回課程後皆可還原。
- 下一題只讀前題通過狀態，不把正解自動填入新題。

### 右上角筆記本

- 提供純文字暫存區、複製、貼上與清空功能。
- 可跨題保持內容，方便組合長提示詞。
- 不判定答對、不控制解鎖、不發放金幣。
- 筆記本清空不影響任何答題卡紀錄。

## 7. AI 審查與媒體規則

- 文字題 Q1、Q3、Q5 使用 `requiredConcepts`、`minimumKeywordMatches`、長度範圍與 `reviewBrief`。
- 媒體題 Q2、Q4、Q6 必須有 `promptReviewCriteria`、附件類型與工具簽章檢查。
- 題中小測由本地規則驗證，不交給 AI 猜測。
- AI 回饋不直接顯示色票、牆面代號、解碼結果、聲音順序或動作順序。
- 常見回饋格式：「還缺少：前題資料／原始字串／作品附件」。
