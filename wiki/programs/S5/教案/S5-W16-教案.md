# S5 W16｜讓作品有「活的」資料：平台 BO 動態功能（進階功能一）教案

> 模組三 進階功能。原為 S5-W15「外部 API」，W15 改為《遊戲開發模擬器》後本任務歸位到 W16；**因部署平台 Big-Oh 禁止 fetch 外部網址（CSP 只允許平台自己），本週由「串接外部 API」改為「用平台的 `window.BO` 讓作品有跨使用者的活資料」**——同樣達成「作品不再只有寫死的假資料」的目標。
> 對應學習單：[[S5-W16-學習單]]

## 教學目標
1. 能用 Copilot Chat 串接平台的 `BO` 動態功能（排行榜 `BO.score/top`、計數 `BO.bump`、留言 `BO.post/list`、或多人 `BO.room`），把**跨使用者、會變的真實資料**顯示在自己的專案裡。
2. 能加一個使用者控制（按鈕/輸入）主動觸發（送分、送留言、開房間…）。
3. 理解「以前要接**外部 API** 才能拿真實資料，但那需要外部網址和金鑰、還會被平台擋；平台的 `BO` 直接幫你做好存檔/排行/多人，**不需外部網址、不需金鑰**」。

## 三大核心概念對應
- 🎮 遊戲化：專案「有別人的資料、會即時變動」的成就感（例如全班共用一個排行榜）；主線 250。
- 🤖 AI 優先（Vibe Coding）：你是 PM、Copilot 是工程師——**描述功能 → Chat 實作 → 測試 → 迭代**；卡住先問 Lab Terminal / Copilot，不先問老師。
- 🔄 翻轉教育：先完成者當助教，**問「你怎麼描述給 Copilot 的？你的作品上線了嗎（`BO` 只在線上才有）？」**引導同學，不代寫。

## 課前準備
**教師**
- 準備一個 `BO` 動態功能的示範（例：全班共用排行榜 `BO.score('main', 分數)` → `BO.top('main', 10)` 顯示前 10 名；或計數器 `BO.bump('plays')`）。
- 確認學生作品**能部署到 Big-Oh**（`BO` 只在 `.bigoh.uk` 線上版才注入；本機開檔沒有 `BO`）。
- 準備常見錯誤排解：作品沒上線所以 `BO` 是 undefined；學生想 `fetch` 外部網址被 CSP 擋（改用 `BO`）；`score` 與 `top` 用不同榜名。

**學生**
- 已有可跑、且**已部署上線**的個人專案（承 W07 起的作品導向、W14 的部署）。

## Copilot Chat / Lab Terminal Prompt 建議
> - 「我的作品在 Big-Oh 平台上，有全域 `BO`。請幫我做一個排行榜：遊戲結束時 `await BO.score('main', 分數)` 送分，畫面上用 `await BO.top('main', 10)` 顯示前 10 名（`BO.top` 回 `[{name, score, at}]`，名字由平台決定、不用我傳）。」
> - 「讓 id 是 `sendBtn` 的按鈕被點時，用 `await BO.post('guestbook', 輸入框的字)` 送一則留言，再用 `await BO.list('guestbook', 20)` 把最新留言顯示出來。」
> - Bug：「我想 `fetch('https://別人的網站')` 拿資料，但 Console 說被擋（CSP）。平台不讓連外部網址，我該怎麼用 `BO` 達成類似效果？」

## 老師筆記
- **常見問題**：作品沒上線 → `BO` 是 undefined（先 `node bigoh.mjs deploy`）；學生想 `fetch` 外部 API → 被 CSP 擋，引導改用 `BO`（這正是本週的學習重點：平台幫你做好動態功能，不用外部服務、不用金鑰）；`score`/`top`（或 `post`/`list`）用了不同榜名/留言板名。
- **作品導向（第十二節）**：驗收看「在**他的專案**裡運作」，不是獨立 demo。
- **延伸挑戰**：`BO.room` 做一個 4 碼房號的多人連線（教室裡喊房號）；把 `BO.top` 的排行榜做成好看的畫面。
