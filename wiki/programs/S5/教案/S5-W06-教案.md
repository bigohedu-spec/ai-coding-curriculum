## 教學目標

只用**說的**（不自己改程式碼），讓 Copilot Chat 把 `index.html` 變成你的工作室起始頁，經過**至少兩輪修改**，最後按下存檔點。

**成功的樣子**（可觀察的驗收）：

- `index.html` 變成你的工作室起始頁，「關於我」按鈕**點得通**
- 至少經過 **兩輪**「現在…我想要…」的修改
- 用過一次 **Undo**
- `vibe-log.md` 寫好，`git log --oneline` 最上面是 `first vibe coding`
- 截圖包含：**VS Code（看得到 Chat 的對話）和瀏覽器起始頁並排的畫面 ＋ `git log --oneline`**
- 舉手告知老師 ✋

---

## 三大核心概念對應

- 🎮 **遊戲化**：「只用說的」讓 AI 工程師做出自己的起始頁，是第一次體驗 Vibe Coding。
- 🤖 **AI 優先**：Chat 切 Agent 模式改 index.html；明定不執行 Terminal 指令；學生當 PM：下單、驗收、描述修改。
- 🔄 **翻轉教育**：先完成者分享「現在是…我想要…」的修改說法，教同學把需求說清楚。

## 翻轉教育流程

**最先完成的人（助教任務）**：

去找一個卡住的同學，你的任務是**問問題、幫他把單寫清楚，不要幫他打字**：

- 「你的模式選單是 Agent 嗎？」
- 「你想改的那個東西，**現在**長怎樣？你**想要**它變怎樣？」
- 「你有說是『哪一個』按鈕嗎？在頁面的哪裡？」

→ 完成助教任務，向老師申報，領取 **TA 金幣 125** 🪙

**還在進行任務**：先看學習單 → 問 Copilot Chat / Lab Terminal → 問 TA 同學 → 最後才問老師。

## 老師筆記

- **課前準備**：確認上週全員 Copilot 已登入（未登入的學生先處理，否則本週無法進行）。Live Server 與 Git 已在 W02、W03 裝好。
- **常見問題**：
  - Agent 模式要求執行 Terminal 指令（啟動伺服器、安裝套件）：一律 **Skip**，單裡已寫「不要執行任何 Terminal 指令」。若學生按了 Allow 而跑出奇怪東西，用 `git status` / `git restore` 收拾。
  - 新版 VS Code 改完檔案可能已自動存檔、也可能要學生 `Ctrl + S`；Keep 後瀏覽器沒變多半是沒存。
  - 舊版沒有 Agent 只有 Edit：用 Edit 即可，按鈕同樣是 Keep / Undo（舊版可能叫 Accept / Discard）。
  - 學生按了 Keep 後才後悔：Part 6 已帶出 `git restore` 會一併退掉之前沒存檔的修改，提醒「滿意就存檔」的節奏。
  - Copilot 回應慢或額度用完（共用帳號高峰時段）：讓學生先做 Part 4 驗收和寫 `vibe-log.md`，稍後再送。
  - 學生想自己改程式碼：本週明確禁止，目的是練描述；W07 起不限。
  - 學生在單裡寫真名：巡視提醒用暱稱。
- **翻轉教育提示**：Part 5 能自己寫出「現在…我想要…」且一次命中的學生，描述能力已達本週目標，最適合當 TA（幫人改單，而不是幫人打字）。
- **延伸挑戰**：about.html 同風格 + 互相連結，等於提前體驗 W11 的頁面串連。

- **ECT**：主線 56 分鐘（目標 50–65 分鐘），明細見學習單檔尾 ECT 注釋。
