## 教學目標

1. 學生能說明「Prompt（提示詞）」是什麼，並舉例說明清楚與模糊的差別
2. 學生能在 Lab Terminal 輸入並比較模糊版與清楚版的 Prompt，觀察回覆差異
3. 學生能用四格填充結構，寫出一句描述自己想做的 3D 列印作品的 Prompt

---

## 三大核心概念對應

- 🎮 **遊戲化**：「哪個版本比較有用？」的比較實驗，讓學習像在做偵探任務；快速完成者可以進行「Prompt 升級挑戰」
- 🤖 **AI 優先**：每組比較都透過 Lab Terminal 實際測試，讓學生親眼看見 Prompt 好壞對 AI 回覆的影響
- 🔄 **翻轉教育**：先完成的學生可以幫同學審閱 Prompt，問「你的 Prompt 有沒有包含形狀、大小、特別的地方？」

---

## 課前準備

**教師：**
- 在黑板寫上：「Prompt（提示詞）= 你對 AI 說的話」
- 準備一個示範對比：「幫我做一個東西」vs「幫我設計一個可以放鉛筆的圓柱形筆筒，高度大約是一支鉛筆的長度」
- 確認學生的 Lab Terminal 輸入法可以打中文

**學生：**
- 無需準備

## Lab Terminal 建議問法示範

老師在黑板示範第一組（模糊版 → 清楚版），讓學生看到回覆的明顯差異：

```
幫我做一個東西
```

然後立刻輸入：

```
幫我設計一個可以放鉛筆的圓柱形筆筒，高度大約是一支鉛筆的長度
```

問全班：「這兩個回答，哪個比較容易做成 3D 列印的設計？」

**任務 B 的 Prompt 範本結構（老師補充說明）**：
```
幫我設計一個＿＿＿，形狀像＿＿＿，大概＿＿＿大，有＿＿＿
```

## 老師筆記

**常見問題：**
- 學生說「兩個回答看起來差不多」 → 引導他看「哪個回答提到了形狀？哪個沒有？」，幫學生找到具體差異點
- 學生不知道任務 B 要做什麼 → 問「你最喜歡的玩具是什麼形狀的？」或「你想送給爸爸、媽媽什麼禮物？」
- 學生的四格填充只填了一兩格就想組合 → 提醒「四格都填完再組合，這樣 AI 才聽得懂」
- 組合出來的句子不通順 → 低年級不需要語法完美，AI 能理解意思即算成功

**延伸挑戰：**
- 把自己的 Prompt 修改成「第二版」：加一個更具體的細節，再問一次 AI，看有什麼改變
- 問 AI：「我的 Prompt 說清楚了嗎？你覺得還需要補充什麼？」

**教學重點提醒：**
- 本堂課的核心概念是「清楚描述比模糊描述好」，Prompt 只是包裝
- 學生的 Prompt 不需要「正確」，只需要「比模糊版清楚」就算達標
- 任務 B 的四格結構是鷹架，未來幾堂課學生會開始不需要它
