# AI 打字造句 × 3D 列印工作坊｜互動設計規格（雙難度版）

---

## 設計原則

| | 低年級（G1–G2） | 高年級（G3） |
|--|--|--|
| 輸入方式 | 點選、拖拉、積木組句 | 自由打字 |
| 自由度 | 低：從選項中選擇 | 高：自行構思與輸入 |
| 正確答案 | 有：完成即有反饋 | 無：開放式，以完成為準 |
| 閱讀負擔 | 低：圖示優先，文字輔助 | 中：可自行閱讀學習單 |
| Lab Terminal | 點選預設句型送出 | 自由輸入 |

### 低年級互動元件一覽

| 代號 | 元件名稱 | 說明 |
|------|---------|------|
| **MATCH** | 配對拖拉 | 拖曳左欄項目到右欄對應位置 |
| **SELECT** | 單選點擊 | 從 2–4 個選項中點選一個（可附圖示） |
| **MULTI** | 多選點擊 | 從選項中勾選多個正確答案 |
| **BUILD** | 積木組句 | 點選詞塊逐步組合成一個句子 |
| **SORT** | 排序拖拉 | 將元素拖拉至正確順序 |
| **CARD** | 卡片選擇 | 圖文卡片，點選後高亮確認 |
| **PRESET** | 預設送出 | 點選預製問句直接送至 Lab Terminal |
| **PICK** | 回應點選 | 從 AI 回應中點選最有用的一段 |
| **RECALL** | 回憶選擇 | 從 2–3 個選項中點選「上堂課做了什麼」 |
| **SUMMARY** | 今日總結積木 | 兩組下拉積木，組合「今天做了什麼 + 用什麼方法」 |

## 給 Web App 開發的補充說明

1. **難度切換**：由老師在開課前於後台設定（班級層級，不是個人層級）
2. **積木選項的擴充性**：W03-B 的積木選單和 SUMMARY 選單應支援老師在後台自訂選項，不寫死在前端
3. **設計卡的繼承性**：W04 的選擇結果要自動帶入 W05、W06，學生不需要重複填寫
4. **PICK 機制**：Lab Terminal 回應後，app 自動從 AI 回應中用 highlight 標出 2–3 個短句供學生點選，不需要 AI 做額外處理
5. **低年級的 Lab Terminal**：底層仍然呼叫相同的 AI API，只是學生看到的是「點選送出」而非「打字送出」；顯示 AI 回應時，字體較大，重點句自動 highlight
6. **⏸️ 提醒卡的時機**：每個任務的「完成」按鈕點下後才觸發，不是在填寫過程中
7. **SUMMARY 與 RECALL 的 session 對應**：`session_memories` 陣列每堂課追加一筆；開課回顧的選項在下一堂課的 RECALL 中使用（W02 RECALL 的選項對應 W01 的 SUMMARY 答案，此為軟提示，選錯不扣分）
8. **技能牆 persistence**：技能牆狀態需跨 session 儲存，學生每堂課進入 app 時都能看到目前累積了幾塊磚
