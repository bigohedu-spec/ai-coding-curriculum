## 二、設計原則

### 承襲的七條鐵則（見開發範式）

- 反硬 A、內容必要性、視覺優先、實體可視化、短影音結構、客觀驗證、反通靈

其中 **實體可視化** 與 **反通靈** 本週不適用（無 3D 產品、無自由打字）；其餘 5 條全數繼承。

### 動作技能週專屬原則（新增）

#### 原則 M1 ｜ 動作品質，不是動作次數
> 系統要能分辨「真的動作」與「敷衍動作」。

- 站 2「四角探險」：只算「跨螢幕的長距離移動」，短距離微調不算圈
- 站 4「迷宮」：必須沿線 ±40px 內移動，否則自動重置這條
- 每動作有隱形「時長下限」，防止瘋狂拉滑鼠灌次數

#### 原則 M2 ｜ 失誤靜音，節奏優先
> 小一玻璃心，紅框否定會打斷手感練習。

- 點擊偏離目標：不彈紅框，不出聲；目標維持原狀等下次
- 迷宮走偏：線條變透明淡出，回起點重來，**不扣任何進度**
- 全程沒有「錯 X 次就淘汰」的設計

#### 原則 M3 ｜ 進度視覺化，讓 30 次感覺可達
> 30 次一模一樣的動作對小一是漫長的。要把它切成看得見的小段落。

- 站 1 的 30 次 = 6 朵花 × 5 次填滿一朵
- 站 2 的 32 次 = 8 圈，每圈中央大字顯示
- 每次成功 = 一顆小星星飛入進度區

#### 原則 M4 ｜ 判定區放大，容錯優先
> 小一游標飄、抓不穩。目標的實際判定區要比視覺大很多。

- 點擊目標：視覺半徑 40px，判定半徑 80px
- 移動目標：視覺半徑 60px，判定半徑 120px
- 迷宮路徑：視覺寬度 8px，判定容錯 ±40px

#### 原則 M5 ｜ 反饋是節奏，不是說明
> 每個成功動作都有一小段音效（100-200ms）+ 視覺回饋，累積成節奏感。文字回饋越少越好。

## 三、通用互動元件一覽（動作技能版）

## 四、Hook / Repeat / Deliver 架構

### Hook（前 3 秒）— 承諾一個目的

畫面全螢幕黑（模擬電腦沒開）+ 中央大電源按鈕（圖示：AI 生圖 `ui-power.png`）
+ 一行大字「按下按鈕，讓電腦醒過來！」
+ 按鈕呼吸式脈動 + 光暈

學生第一次點擊 → 電源音效 + 螢幕由黑漸亮 + 顯示登入頁面（頭像頁）→ 進入站 1。

**這一次點擊本身就是站 1 的第 1 次**（承接無縫）。

### Repeat（過程中）— 建立心跳節奏

核心訊息：「我可以用滑鼠讓電腦聽我的話」

出現處：
1. Hook 的第一次點擊成功（電腦亮了）
2. 站 1 每次登入成功（桌面出現）
3. 站 3 圖示打中的爆炸動畫
4. 站 4 迷宮完成後的彩虹路徑
5. 每站完成後的過場「你已經完成 N/5 站」
6. 站 5 最後一次登入的全螢幕撒花

### Deliver（結尾）— 兌現承諾

站 5 最後一次成功登入後：
- 桌面完整顯示 + 250 金幣從天而降散落動畫
- 「新手登入」徽章從螢幕上方緩緩落下、彈起、發光
- 全螢幕撒花
- 「舉手告訴老師！」大字 + 舉手圖示動畫
- 螢幕角落出現「我是小老師 👋」按鈕（見翻轉教育流程）

## 五、站別詳細設計

### 站 1｜喚醒與登入練習（30 次）

**互動類型**：CLICK × 30

**畫面**：登入畫面上一個大頭像（AI 生圖 `avatar-*.png` 由老師後台選擇），佔畫面約 30% 高度。頭像下方有名字（純視覺，不需讀）。

**每次動作**：
1. 學生把游標移到頭像 → 點擊
2. 頭像縮小 + 上升動畫 + 「登入中」轉圈（1.5 秒短過場）
3. 桌面短暫顯示（1 秒）+ 桌面中央出現大「登出」按鈕（另一張 AI 生圖 `ui-logout.png`）
4. 學生點擊登出 → 過場（1 秒）→ 回到頭像頁

**判定容錯**：頭像視覺半徑 100px，判定半徑 140px；登出按鈕視覺半徑 60px，判定半徑 100px。

**反饋**：
- 頭像點對：頭像放大 → 光暈 → 短音效（叮）
- 登出點對：按鈕彈跳 → 桌面淡出

**進度區**（畫面下方）：
- 6 朵花輪廓，每完成 5 次登入循環填滿 1 朵花
- 填滿時：花朵盛開動畫 + 短音效 + 該朵花 +1 星從花飛入畫面右上「星星籃」

**過關**：6 朵花全部盛開 → 過場「站 1 完成！」+ 大字「1 / 5」→ 站 2

---

### 站 2｜四角探險（32 次 = 4 角 × 8 圈）

**互動類型**：MOVE × 32

**畫面**：全螢幕深色背景，四個角落各有一個大圓形目標（AI 生圖 `corner-*.png`：星、雲、月、太陽，用來當視覺定錨）。中央大字顯示「第 X 圈 / 8」。

**每次動作**：
1. 一個角的目標亮起 + 呼吸脈動（例：左上「星」亮起）
2. 學生把游標移到那個角
3. 游標進入判定圓區（半徑 120px）+ 停留 0.5 秒 → 該角爆炸成星光 + 短音效 + 亮下一個角
4. 順序：左上 → 右上 → 右下 → 左下（順時針一圈）

**動作品質驗證**（原則 M1）：
- 前一次爆炸到這次進入圓區，游標必須跨過至少 400px 距離，否則不算（防止微調騙圈）
- 每個角進入判定後必須停留 0.5 秒，短於此不算（防止拉過去馬上離開）

**反饋**：
- 進入圓區：圓變亮
- 停留 0.5 秒完成：星光爆炸 + 音效
- 完成一整圈：中央「第 X / 8」數字大變大 + 撒花

**進度區**：
- 中央「第 X / 8 圈」大字，X 從 1 到 8
- 完成 4 圈 = 中場：中央顯示「半場了！」+ 大姆指圖示 + 音效鼓勵

**過關**：完成 8 圈 → 過場「站 2 完成！」+ 「2 / 5」→ 站 3

---

### 站 3｜圖示獵人（30 次）

**互動類型**：CLICK + 老師介入

**畫面**：全螢幕散佈 8 個大圖示（AI 生圖 8 張：花、星、蘋果、月亮、太陽、球、車、狗），每張約 120×120px。位置固定但整體佈局做過視覺平衡。

**兩種模式**（依老師是否使用老師端切換）：

#### 模式 A：老師主導（推薦）
- 老師端顯示切換按鈕「本輪目標 = ○○」，老師口頭喊目標（例：「找花花！」）
- 學生端畫面：所有圖示保持原樣，不顯示提示（因為老師喊出來了）
- 學生點對：該圖示放大 3 倍 → 落金幣 → 淡出重置
- 學生點錯：點到的圖示微微搖頭（左右擺動 0.3 秒）+ 正解的圖示閃 3 次（引導視線），**不扣分、不計錯**
- 老師端下一輪按下「下一題」→ 更新目標

#### 模式 B：自動模式（老師沒用老師端時）
- 畫面頂部顯示大字「找 [目標名]！」+ 目標圖示的小預覽
- 其餘同模式 A

**判定容錯**：每個圖示視覺 120×120，判定範圍 160×160。

**反饋**：
- 點對：圖示放大 + 撒金幣 + 音效（叮咚）+ 「太棒了！」大字閃過（500ms）
- 點錯：**溫和引導**（原則 M2）— 該圖示搖頭 + 正解閃 + **無否定文字**

**進度區**：右上「已完成 X / 30」數字大字。

**過關**：30 次點對 → 過場「站 3 完成！」+ 「3 / 5」→ 站 4

---

### 站 4｜滑鼠迷宮（26 次）

**互動類型**：TRACE × 26（實作為 5 條路線輪流，每條完成算 1 次，最後多 1 條）

**畫面**：全螢幕淺色背景 + 一條路徑（曲線 / 折線 / 波浪，5 種變化）。起點是一個大「開始」按鈕（AI 生圖 `ui-start.png`），終點是一顆大星星（AI 生圖 `ui-star.png`）。路徑本身是 8px 寬的彩色線條 + 描邊。

**每次動作**：
1. 學生點擊「開始」按鈕（大目標，判定 100px）
2. 起點變亮 → 路徑點亮 → 學生沿路徑移動游標
3. 到達終點星星判定範圍 + 點擊 → 完成 1 次

**判定與容錯**（原則 M4）：
- 沿線 ±40px 內都算沿線
- 偏離 > 40px：路徑淡出成半透明 + 音效（叮咚）+ 「回開始重來 →」小字提示 + **不扣進度**
- 觸控式的鼓勵：路徑走過的部分變彩虹色，未走的維持原色

**動作品質驗證**（原則 M1）：
- 從起點到終點必須至少 3 秒（防止直接拉直線騙過）
- 游標必須「沿著」路徑，不能整條跳過去

**反饋**：
- 沿線走：路徑後方持續變彩虹
- 到達終點：星星巨大化 + 全彩虹 + 撒花 + 音效
- 偏離重來：溫和淡出，不打斷情緒

**進度區**：頂部進度條，每完成 1 條迷宮填 1/26。

**路線輪替**：5 條路線循環使用（曲線波、之字、S 形、螺旋、Z 形），第 26 次額外用「終極大迷宮」（比其他長 2 倍）作為收尾儀式。

**過關**：26 條 → 過場「站 4 完成！」+ 「4 / 5」→ 站 5

### 站 5｜正式登入驗收（10 次）

**互動類型**：COMBO × 10（完整登入 → 桌面 → 登出的循環，一氣呵成）

**畫面**：與站 1 相同的登入頁 + 桌面模擬，但**沒有進度花朵**（因為此站是驗收）。

**每次動作**：
1. 頭像頁 → 學生點頭像
2. 登入短過場（1 秒）
3. 桌面顯示（含應用圖示裝飾）+ 中央大「登出」按鈕
4. 學生點登出
5. 回到頭像頁

**判定**：與站 1 相同，但**沒有大幅提示語**（驗收模式）。

**反饋**（簡潔）：
- 每次成功登入 → 金幣 +25 從桌面右下角落入畫面底部「金幣袋」+ 音效
- 顯示總累積：右下「$ 25 → 50 → 75 → ... → 250」

**過關**（第 10 次登入 = Deliver 時刻）：
- 桌面完整顯示 + **不再有登出按鈕**
- 250 金幣從天而降散落全螢幕
- 「新手登入」徽章從螢幕上方緩緩落下、彈起、發光
- 全螢幕撒花
- 3 秒後畫面顯示：「舉手告訴老師！」+ 舉手圖示大動畫
- 螢幕角落：「我是小老師 👋 [點我]」按鈕（引導翻轉教育流程）

## 六、老師介面（Teacher Panel）

老師端另一個 URL（例 `/teacher`）或 App 內快捷鍵切換。

### 全班進度總覽
- 表格：每列一位學生（頭像 + 名字）
- 欄：目前所在站、該站進度、累計金幣、是否舉手
- 顏色狀態：🟢 進行中｜🟡 需協助（站在同一站超過 15 分）｜🔴 舉手中

### 站 3 目標控制器
- 8 張圖示小預覽 + 「發送」按鈕
- 老師點一個圖示 → 全班該站學生的當前目標即時同步
- 「下一題」按鈕 → 隨機挑下一個未用過的圖示

### 小老師派任
- 學生名單旁的「派 A 去教 B」下拉
- 送出後：A 端跳出「請去幫 B」+ 金幣獎勵 125 預告

### 課堂節奏
- 全班進度統計條：顯示各站有多少人
- 時間軸：老師示範 → 學生自由闖關 → 收尾

## 九、給 Web App 開發的補充說明

### 承襲的規則（見 課程網頁開發範式.md）
1. 圖示全部用 AI 生圖，統一 PROMPT 模板（見範式第四章）
2. 全域 `paste` / `drop` 攔截（防作弊）— 本週雖無打字但延續攔截
3. 錯誤反饋原則：具體、視覺、不否定

### 本週專屬考量
1. **判定放大**（原則 M4）：所有點擊目標判定半徑 ≥ 100px；小一游標很飄
2. **禁用彈跳警示**（原則 M2）：不彈 alert、不用紅色否定；小一玻璃心
3. **禁用計時倒數**：破壞手感練習
4. **禁用複雜文字**：站之間只用大圖標 + 箭頭；文字不超過 5 個字
5. **音效節奏**：每個成功動作有 100-200ms 短音效；累積為節奏感
6. **動作品質驗證**（原則 M1）：
   - 站 2 每次移動 ≥ 400px、每角停留 ≥ 0.5s
   - 站 4 每條迷宮 ≥ 3s、沿線 ±40px
7. **重置友善**：任何時候可按大 [重來] 按鈕，不扣進度
8. **游標追蹤**（CURSOR-PULSE 元件）：如果 3 秒內游標沒有移動，用漣漪動畫指出位置（小一常見「找不到箭頭」）
9. **老師端獨立**：分開 URL 或用 Chrome 分頁；學生端不會顯示老師介面
10. **小老師動畫**：完成後不要強迫，做成可選按鈕；小一有些不敢當老師

### 反硬 A 在動作技能週的具體意義
| 硬 A 手法 | 擋法 |
|---|---|
| 站 1：連續猛點同一位置 30 次 | 兩次點擊間必須有 ≥ 1 秒過場（因為要看登入動畫） |
| 站 2：小範圍搖游標騙圈 | 每次移動必須跨 ≥ 400px |
| 站 3：亂點所有圖示 | 只計「點對」，點錯不算但也不扣 |
| 站 4：直接拉直線到終點 | 沿線 ±40px 才算數，且時長 ≥ 3s |
| 站 5：不看畫面猛點 | 完整流程必須有 ≥ 2 秒過場，總時長 ≥ 20 秒 |
