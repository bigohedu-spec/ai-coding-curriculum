## 教學定位

- **本週唯一可觀察能力**：學生能讀懂 NPC 的自然說明，找出要請 AI 做某件事時，**用途、做法、限制**各缺什麼，再自己手動整理成一段「補好三個空格」的 Prompt，交給 Lab Image 做出成果。
- **三需求**：每一站的 Prompt 骨架都有三個空格，學生要自己補滿。三個欄位依站而不同：

| 站 | 鎖定句 | 三個空格 |
|----|--------|---------|
| 河畔農場（A） | 請畫一座木橋。 | 用途／做法／安全限制 |
| 山腰工坊（B） | 請生成一張風車葉片設計圖，白色背景，畫面只出現組合好的葉片與中央接點。 | 外形／數量與組合／完整限制 |
| 霧谷山徑（C） | 請畫一個發光的月亮路標。 | 用途／做法／安全限制 |
| 溪谷鎮古老遺跡（D） | 請畫一枚溪谷鎮修復節的儀式徽章，白色背景，畫面只出現完整徽章。 | 用途／做法／內容限制 |

- **學習單不預填答案**：NPC 回答、Prompt 骨架都**不會**自動寫入筆記；學生只能手動複製、貼上或輸入。
- **每站先過四題邏輯確認**：記得剛才的內容 → 理解漏寫的後果 → 判斷為什麼要加進規格 → 選出清楚、可檢查的寫法。四題全對才取得該段證據（四站共 48 題）。
- **本週不教**：程式控制、自由設計、第五種需求。

## 四站劇情

| 站 | 地點／NPC | 任務 | 完成後的世界變化 |
|----|----------|------|----------------|
| A | 河畔農場／農夫阿穗 | 橋面太窄不安全，菜車過不了河；自由詢問阿穗，把泡泡內的彩色重點整理進筆記，自己組 Prompt 到 Lab Image 做橋 | 斷橋換成修復橋，河道可通行 |
| 途中事件 | 守住運菜車 | 六隻小豬分三波進場，把牠們拖進左上圍欄；撞到菜車扣耐久，三點歸零從第一波重來 | — |
| B | 山腰工坊／工坊師傅阿岩 | 風車葉片大小不一、裂開、轉動搖晃；調查三個物件（外形、中央組合、完整度），三次圖像二選一，再用 Prompt 做出組合葉片 | 新葉片轉動檢查通過 |
| C | 霧谷山徑／守路鳥小嶺 | 觀察山徑旁三個物件，組 Prompt 做安全路標 | 月亮路標發光 |
| D | 溪谷鎮古老遺跡／羅盤守門靈 | 修復節閉幕：製作節慶徽章，並投向四座燈台 | 四燈全亮，收到下一趟奇幻旅程的邀請 |

## 課前準備

**教師：**
- 先自己走一遍四站，特別是 Prompt 組裝與 Lab Image 提交。
- 本機快速內容檢查入口：`/dev/lab-terminal-quest`（只用於檢查，不寫學生進度或金幣）。
- 確認 Lab Image 可用。

**學生：**
- 沒有；使用課程提供的 Lab 工具。

## 課堂流程

> 分鐘數為**依關卡內容估計，未實測**（見老師筆記）。

| 時間 | 活動 | 說明 | 教師角色 |
|------|------|------|---------|
| 0–5 分鐘 | 進場 | 說明今天是「到溪谷鎮修東西」，AI 不會猜，要把**用途、做法、限制**說清楚 | 帶讀 |
| 5–25 分鐘 | A 河畔農場 | 問阿穗 → 整理筆記 → 四題確認 → 組 Prompt → Lab Image 做橋 →（護送運菜車） | 巡堂；不代寫 Prompt |
| 25–40 分鐘 | B 山腰工坊 | 調查三物件 → 圖像二選一 → 九題延伸確認 → 組 Prompt → 葉片轉動小遊戲 | 觀察 |
| 40–50 分鐘 | C 霧谷山徑 | 觀察三物件 → 組 Prompt → 路標 Skill Check | 觀察 |
| 50–58 分鐘 | D 古老遺跡 | 觀察三石板 → 組 Prompt → 蓄力投徽章點亮四燈台 | 觀察 |
| 58–60 分鐘 | 收尾 | 看完成畫面，舉手告知老師 | 驗收 |
| **60–90 分鐘** | **自由遊玩時間** | 學生選擇 Minecraft／Lab Terminal 遊戲／其他老師提供的介面，也可回到完成版地圖自由探索、重玩小遊戲 | 老師觀察，不介入 |

## 三大核心概念對應

- 🎮 **遊戲化**：修橋、修風車、修路標、點燈，世界會隨完成變化；完成獎勵是發光的金色 ◆；小遊戲可重玩。
- 🤖 **AI 優先**：學生要自己決定問 NPC 什麼、哪些重點要寫進 Prompt，再交給 Lab Image；AI 做出的成果要對照需求檢查。
- 🔄 **翻轉教育**：先完成者當 TA，只問「你的 Prompt 三個空格各填了什麼？漏了哪一個？」，不代填；TA 金幣 125。
