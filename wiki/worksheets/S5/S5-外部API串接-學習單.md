## 今天的冒險

到目前為止，你專案裡的資料都是你自己寫死的。今天要讓它**連上真實世界**——從網路上一個公開的 API 抓**即時的真資料**（名言、天氣、貓狗圖片、太空人數量……）顯示在你的專案裡。你是 PM，Copilot Chat 是工程師：你把「要什麼」講清楚，讓它幫你接。

**這個功能要整合進你自己的專案**（作品導向，第十二節）——不是做一個丟掉的練習。

## 本週任務

### 🎯 任務 A：接上一個 API，顯示真實資料　⭐150

**目標（開放，自己決定）**：從一個**免金鑰的公開 API** 抓真資料，顯示在你專案的某一頁。

先選一個免金鑰 API（不用申請帳號，符合工具政策；以下都已實測可用、支援瀏覽器）：
- 隨機名言：`https://dummyjson.com/quotes/random`（回傳欄位 `quote`、`author`）
- 隨機貓圖：`https://api.thecatapi.com/v1/images/search`（回傳陣列，第一筆的 `url` 是圖片網址）
- 隨機人物＋頭像：`https://randomuser.me/api/`（`results[0].name`、`results[0].picture.large`）
- 太空站上現在有幾人：`http://api.open-notify.org/astros.json`（`number`、`people`）⚠️ 只有 http，**本機測試可用；之後部署到網站（https）會被擋**，要上線就別選這個
- 或你自己找一個**不用金鑰**的（不確定就問 Lab Terminal「這個 API 要不要金鑰？是不是 https？」）

> 需要金鑰的 API（如天氣 OpenWeatherMap）今天先不用；若真的想用，請老師統一提供金鑰，不要自己申請帳號。

**成功的樣子**：打開你的專案頁面，畫面上出現一段**每次刷新都可能不同**的真實資料（不是你寫死的）。

### 🎯 任務 B：加一個讓使用者操作的控制　⭐100

**目標（開放）**：加一個按鈕或輸入框，讓使用者可以**主動觸發**抓新資料（例如「再抽一句名言」按鈕、「換一張貓」按鈕）。

**成功的樣子**：在你的專案裡，按下按鈕就會出現新的一筆真資料。

> 主線合計 250（A150 / B100）。做完還有時間 → 挑戰把資料排版變好看（進階，不計入 250）。

## 工具操作（照做，不用問老師）

1. **開啟 Copilot Chat**：VS Code 按 `Ctrl+Shift+I`（Mac：`Cmd+Shift+I`），或點左側邊欄 Copilot 圖示 → 右側出現對話框。
2. **描述功能給它**（見下方 Prompt 範例）→ Copilot 回一段程式碼區塊。
3. **把程式碼放進專案**：點程式碼區塊右上角「插入到編輯器」，或手動複製貼到你的 `.html` / `.js`。
4. **存檔**：`Ctrl+S`（標題列的 ● 消失＝已存）。
5. **測試**：用 `Live Server` 開啟（右下角 Go Live），瀏覽器會自動更新。
6. **看結果對不對** → 不對就回 Chat 描述問題（見 Bug 範例）→ 讓它修 → 再測。
7. **截圖**：截「功能運作中」的畫面（看得到輸入 + 輸出），舉手告知老師。

**如果不對怎麼辦**：
- 畫面空白 / 沒資料 → 打開瀏覽器 F12 看 Console 有沒有紅字，把紅字貼回 Chat。
- 一直轉圈 → 可能 API 網址打錯或要金鑰，問 Lab Terminal 確認。

## 問 Copilot Chat 的方式（描述功能，用白話）

這裡是 Vibe Coding：Copilot **會真的幫你寫程式碼**，所以要把「要什麼」講清楚（不是通靈）。範例：

> - 「幫我用 JavaScript 的 fetch 去抓 `https://dummyjson.com/quotes/random`，把回來的 `quote` 和 `author` 顯示在我頁面上 id 是 `quote` 的元素裡。」
> - 「我有一個 id 是 `newBtn` 的按鈕，幫我讓它被點的時候重新抓一次上面那個 API 並更新畫面。」
> - 「畫面沒有出現資料，Console 顯示 `Failed to fetch`，幫我看可能是什麼原因、怎麼改。」

📌 描述三要素（來自 vibe-coding）：**是什麼 / 長什麼樣子 / 做完後發生什麼**。講越具體，Copilot 一次到位的機率越高。

## 老師筆記

- **常見問題**：CORS 錯誤（某些 API 擋跨網域）→ 引導換一個免金鑰、允許跨域的 API（如 dummyjson、thecatapi、randomuser）。
- **常見問題**：選了 http 的 open-notify，本機好好的、部署後壞掉 → 那是 mixed content（https 頁面不能抓 http）；換成 https 的 API。
- **常見問題**：學生想接需要金鑰的 API → 依第十四節，改用免金鑰的，或老師統一提供金鑰。
- **作品導向提醒**：驗收時看「這個功能在**他的專案**裡運作」，不是一個獨立小 demo。
- **延伸挑戰**：把兩個 API 接進同一頁；或把抓到的資料存進 localStorage 下次打開還在。
