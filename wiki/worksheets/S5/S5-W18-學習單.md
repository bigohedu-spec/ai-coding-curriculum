# S5 W18｜進階功能里程碑：做一個「功能盤點頁」，讓功能真的能用 學習單

> 模組三 進階功能（W13–W18）**里程碑**。這週**不加新功能**——做一個**功能盤點頁**，把前幾週加的功能（雲端 Supabase／外部 API／自選功能…）全部列出來、一個一個測、把壞的修好。

## 今天的冒險

這幾週你的專案長出很多進階功能，但「能跑一次」跟「**完整可用**」是兩回事——常常本機好、上線就壞。今天當自己專案的 **QA＋工程師**：**做一個「功能盤點頁」**，把所有進階功能列上去、每個放一顆「試試看」按鈕、標上狀態（✅ 可用／🔧 待修）→ 一個一個測 → 修好 → 全部變 ✅。

這頁**加進你自己的專案、留著當展示用**（作品導向，第十二節）；里程碑驗收看你**上線的整個專案**。

## 任務 A｜做一個「功能盤點頁」並讓每個功能都變 ✅ ⭐ 250 金幣

**目標（開放，作品導向）**：在你的專案裡**新增一頁「功能盤點頁」**，把所有進階功能列出來，每個有：
- 功能名稱（例：雲端存讀、隨機名言、深色模式、成就…）
- 一顆**「試試看」按鈕/連結**，點了跳到那個功能
- 一個**狀態標記**：✅ 可用 / 🔧 待修

然後用這頁**一個一個測**（在上線網址測，不是只有本機）→ 壞的用 Copilot 修好 → 狀態改成 ✅ → 推上線再驗，直到**全部 ✅**。

**成功的樣子**：打開你**上線網址**的功能盤點頁，每個功能點「試試看」都能正常操作；需要記住的資料重整/換裝置後還在（在 Supabase 裡）；盤點頁上**全部標 ✅**。

> 主線 250（單一任務 A250）。做完還有時間 → 把盤點頁做得好看一點、當作品的導覽頁（進階，不計入 250）。

## 工具操作（照做，不用問老師）
1. **開 Copilot Chat**：`Ctrl+Shift+I`。
2. **做盤點頁**：貼下方 Prompt，讓 Copilot 幫你生一頁 `features.html`（或加在 Welcome Page），列出你的功能＋按鈕＋狀態。
3. **接上你的功能**：把每顆「試試看」連到你已有的頁面/功能（用 `#file` 帶入相關檔案）。
4. **一個一個測**：開**上線網址**的盤點頁，點每顆「試試看」實際操作；壞的把畫面/Console 紅字貼回 Chat 讓它修。
5. **存檔 → `git add . && git commit -m "功能盤點頁" && git push`** → 回上線網址再驗。
6. **狀態改 ✅**：每修好一個就把盤點頁那格改成 ✅。
7. **里程碑展示**：截圖/錄「全部 ✅」，舉手告知老師。

**如果不對怎麼辦**（部署後最常見）：
- 本機好、上線壞 → 多半是 **API 不是 https／要金鑰**（換免金鑰 https）或 **mixed content**。
- 資料存不進 Supabase → 檢查 **RLS 有沒有開**、表名/欄位，把錯誤訊息貼回 Chat。

## 問 Copilot Chat 的方式（描述功能，用白話）
> - 「幫我做一頁 `features.html`：用清單列出這幾個功能（雲端存讀、隨機名言、深色模式…），每個後面一顆『試試看』按鈕連到對應頁面，還有一個可以切 ✅/🔧 的狀態標記。」
> - 「`#index.html` 幫我把這顆『試試看』連到我的雲端存讀功能那一頁。」
> - 「我的『隨機名言』在上線網址按了沒反應，Console 顯示 `Mixed Content`，幫我看怎麼改。」

📌 描述三要素（來自 vibe-coding）：**是什麼 / 長什麼樣子 / 做完後發生什麼**。

## 老師筆記
- **里程碑驗收**（第十二節作品導向）：看學生**上線網址的功能盤點頁全部 ✅**、點每個都能操作、資料進 Supabase——不是看單一 demo。
- **盤點頁是這週的核心產出**：它逼學生把功能列清楚、逐一測，也留下一個好用的作品導覽頁。
- **這週不加新功能**：重點是「把已有的弄到能用」＋建立測試/除錯習慣。
- **部署後常見壞法**：mixed content（http API）、CORS、Supabase RLS 沒開、忘了 push；都引導把錯誤訊息貼回 Chat。
- **工具政策（第十四節）**：雲端一律 Supabase（老師給 anon 金鑰、開 RLS）；API 免金鑰 https；不用 Firebase。
