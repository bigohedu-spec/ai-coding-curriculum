## 任務 A｜打造你的工作室 ⭐ 250 金幣

**任務 ID**：S5-W01-A

### 目標

把 VS Code 變成**你自己的**開發環境，並在裡面做出第一個看得到的網頁。

---

### Part 1：安裝 VS Code（或確認已經有了）

**先看看電腦上有沒有：** 按鍵盤 `Win` 鍵 → 打「code」→ 有出現藍色的 **Visual Studio Code** 圖示 = 已經有了，**直接跳到 Part 2**。

**如果沒有：**

1. 開瀏覽器 → 進 `code.visualstudio.com`
2. 點藍色的大按鈕 **Download for Windows**
3. 下載完點開安裝檔 → 一路按「下一步」
4. 在「選擇附加工作」那一頁，**把「加入 PATH」打勾**（之後用終端機會用到）
5. 按「安裝」→ 完成後打勾「啟動 Visual Studio Code」

**完成後你會看到**：一個深色的視窗，中間寫著「Visual Studio Code」和一些快速連結。

> **如果不對怎麼辦**
> - 安裝到一半說「需要管理員權限」→ 舉手告訴老師，這需要老師處理。
> - 找不到下載按鈕 → 網站會自動偵測你的系統，藍色那顆最大的就是。

---

### Part 2：認識你的工作室（五大區域）

打開 VS Code，對照下面找出五個地方。**每找到一個，在方格打勾**：

- [ ] **活動列**（最左邊那排直的圖示）：切換功能用，最上面那個是「檔案總管」
- [ ] **側邊欄**（活動列右邊那塊）：等一下會顯示你的資料夾和檔案
- [ ] **編輯器**（正中間最大那塊）：打程式碼的地方
- [ ] **面板**（下面那塊，可能是收起來的）：終端機和錯誤訊息會出現在這
- [ ] **狀態列**（最下面那條藍色/紫色的細條）：顯示目前檔案的資訊

> **如果不對怎麼辦**：面板沒看到 → 按 `Ctrl` + `` ` ``（鍵盤左上角、數字 1 左邊那顆）可以開關它。

---

### Part 3：把工作室調成你喜歡的樣子（三項設定）

按 `Ctrl + ,`（逗號）打開設定頁面。上面有一個搜尋框，**照下面三項分別搜尋、修改**：

**① 字體大小**
1. 搜尋框打 `font size`
2. 找到 **Editor: Font Size**
3. 把數字改成你看得舒服的（建議 **16** 或 **18**）
4. **完成後你會看到**：後面編輯器的字立刻變大

**② 自動存檔**（很重要，之後每週都會救到你）
1. 搜尋框打 `auto save`
2. 找到 **Files: Auto Save**
3. 下拉選單改成 **afterDelay**
4. **完成後你會看到**：之後打字停一下就自動存檔，標題列不會再出現 `●`

**③ 佈景主題**（換個你喜歡的顏色）
1. 按 `Ctrl + K` 放開，再按 `Ctrl + T`
2. 用上下鍵預覽不同配色，按 `Enter` 選定
3. **完成後你會看到**：整個 VS Code 換了顏色

> **如果不對怎麼辦**：設定改了沒反應 → 確認你改的是 **Editor: Font Size**（不是 Terminal 的那個）。

---

### Part 4：建立你的專案資料夾

1. 在**桌面**按右鍵 → 新增 → 資料夾
2. 命名為 **`你的英文名-project`**（例如 `kai-project`）——**只用英文、數字、短橫線，不要中文、不要空格**
3. 回到 VS Code → 上方選單 **檔案 → 開啟資料夾**（⚠️ 是「開啟**資料夾**」，不是「開啟檔案」）
4. 選你剛剛建的資料夾 → 按「選擇資料夾」
5. 如果跳出「您信任這個資料夾的作者嗎？」→ 點 **是，我信任**

**完成後你會看到**：左邊側邊欄最上面出現你的資料夾名字（大寫顯示）。

> **如果不對怎麼辦**：側邊欄空空的、沒有資料夾名字 → 你八成是用「開啟檔案」開的。重做第 3 步，選「開啟**資料夾**」。

---

### Part 5：做出你的第一個網頁

1. 把滑鼠移到側邊欄你的資料夾名字上 → 出現幾個小圖示 → 點**第一個（新增檔案）**
2. 檔名打 **`index.html`** → 按 `Enter`
3. 在編輯器裡，把下面這段**照打或複製**進去：

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>我的第一個網頁</title>
</head>
<body>
  <h1>這裡改成你的名字</h1>
  <p>這是我用 VS Code 做的第一個網頁。</p>
</body>
</html>
```

4. **把 `<h1>` 那行改成你自己的名字**，再加一行你想說的話
5. 存檔：`Ctrl + S`（如果 Part 3 設好自動存檔，它會自己存）
6. **打開來看**：在側邊欄的 `index.html` 上按**右鍵 → 在檔案總管中顯示** → 在跳出的視窗裡，**對 `index.html` 點兩下**

**完成後你會看到**：瀏覽器打開，畫面上出現**你自己寫的名字和那句話**。

> **如果不對怎麼辦**
> - 瀏覽器是空白 → 檢查檔案有沒有存（標題列有 `●` 就是沒存），按 `Ctrl + S`。
> - 中文變成亂碼 → 檢查 `<meta charset="utf-8">` 那行還在不在。
> - 點兩下是用記事本打開 → 按右鍵 → 開啟檔案 → 選 Chrome 或 Edge。

---

### 成功的樣子

- VS Code 側邊欄看得到**你的資料夾**和 `index.html`
- 三項設定都做好了（字變大了、佈景換了、不用一直按存檔）
- 瀏覽器打開後，畫面上是**你自己寫的字**
- 截圖包含：**VS Code 畫面（含側邊欄）＋ 瀏覽器顯示你寫的內容**
- 舉手告知老師 ✋

## 本週學習重點

1. 要用「開啟資料夾」，不是「開啟檔案」，左邊才看得到專案。
2. 自動存檔選 afterDelay，標題列就不會有圓點。
3. 改完要存檔、重新整理，瀏覽器才看得到新內容。
4. 第一個網頁的檔名叫 index.html，用瀏覽器打開就能看到。
