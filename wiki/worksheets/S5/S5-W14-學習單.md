## 今天的冒險

到目前為止，你的網頁只能在**你自己的電腦**打開。

今天，你要把它**送上網**——做完之後，你會拿到一個網址，像這樣：

```
https://你的帳號.github.io/你的專案/
```

把這個網址用 LINE 傳給爸媽、傳給朋友，他們點一下就能打開你的作品。**不需要你的電腦開著，全世界都看得到。**

**W14 的目標：把你的專案部署上線，拿到一個真的可以分享的網址。**

## 任務 A｜把你的網頁部署上線 ⭐ 150 金幣

**任務 ID**：S5-W14-A

### 目標

用 Git 指令把你的專案推到 GitHub，開啟 GitHub Pages，拿到一個打得開的網址。

> 💡 就算你的專案還沒做完也沒關係——**現在這個版本就可以先上線**，之後再更新。

---

### Part 1：用指令把專案推上 GitHub（CLI 優先）

在 VS Code 打開**終端機**（選單 `Terminal → New Terminal`，或 `Ctrl + ``）。

確認你在專案資料夾裡，依序輸入這幾行指令（一行一行按 Enter）：

```
git add .
git commit -m "deploy my project"
git push
```

- 完成後你會看到：終端機跑出一串上傳訊息，最後沒有紅色錯誤。
- **如果 `git push` 跳出錯誤或要你登入** → 把整段錯誤訊息複製，貼給 Copilot Chat 問：「我 git push 出現這個錯誤，怎麼解決？」

> 如果這是你第一次 push 這個專案，Copilot 可能會教你先 `git remote add ...`。照它說的做，不懂就把它的指令再貼回去問「這行在做什麼？」

---

### Part 2：在 GitHub 開啟 Pages（網頁設定）

1. 用瀏覽器打開你的 GitHub repo 頁面（github.com 上你的專案）
2. 點上方的 **Settings（設定）**
3. 左側選單點 **Pages**
4. 在 **Source / Build and deployment** 下，**Branch** 選 `main`（或 `master`），資料夾選 `/ (root)`，按 **Save**
   - 完成後你會看到：頁面上方出現一句「Your site is live at https://...」或「正在建置」。

---

### Part 3：打開你的網址

1. 等 **1–10 分鐘**（GitHub 在幫你建置，急不得）
2. 打開 Pages 設定頁顯示的網址 `https://你的帳號.github.io/你的專案/`
3. 確認你的網頁出現了

> **打開是 404？** → 可能還在建置（再等幾分鐘）、分支選錯、或你的首頁檔名不是 `index.html`。把狀況問 Copilot Chat。
>
> **打開是空白或舊版？** → 按 `Ctrl+Shift+R` 強制重整；或確認你有 push 最新版本。

### 成功的樣子

- 在瀏覽器用 `https://...github.io/...` 網址打開你的網頁（**不是** `file://` 開本機檔）
- 截圖包含：**瀏覽器網址列的 github.io 網址 + 你的網頁畫面**
- 舉手告知老師 ✋

完成後進任務 B。

## 任務 B｜認識網路廣告 + 寫你的「未來廣告計畫」 ⭐ 100 金幣

**任務 ID**：S5-W14-B

### 先搞懂：網站上的廣告是怎麼回事？

打開 Lab Terminal，問這幾個問題，把重點記下來：

> 「網站上的廣告是怎麼賺錢的？網站主人做了什麼，廣告才會出現？」

> 「為什麼放廣告的平台（像 Google AdSense）要滿 18 歲才能申請？如果我還沒 18 歲，可以怎麼辦？」

📌 **重要事實**：放廣告的平台規定**要滿 18 歲**才能申請帳號。你現在還不到 18 歲，所以**真的要放廣告，得請爸媽或監護人用他們的帳號申請，錢也會付給大人**。所以今天我們**不真的放廣告**，而是先**規劃**，為將來做準備。

---

### 寫你的「未來廣告計畫」

打開 `project-idea.md`，在最底部新增這個區塊，認真填完（不要留空、不要只寫一兩個字）：

```
## 我的未來廣告計畫
1. 廣告位置：我會把廣告放在頁面的 ___________ ，
   因為這個位置 ___________（為什麼不會太干擾使用者）。
2. 誰來申請：因為平台要滿 18 歲，未來要請 ___________（哪位家長/監護人）幫我申請。
3. 內容品質：廣告平台會審查網站，我的網站要先做到 ___________ 才可能通過。
```

> 想一想再寫：如果一個網站打開全是廣告，蓋住你要看的內容，你還會想用嗎？好的網站是**先有價值，廣告是輔助**。

### 成功的樣子

- `project-idea.md` 裡有完整填好的三點廣告計畫（每一點都有具體內容）
- 截圖包含：**你的廣告計畫**
- 舉手告知老師 ✋

## 🏠 帶回家：想真的放廣告賺錢？

你的網站已經上線了，**真的可以放廣告賺錢**——但放廣告的服務規定要滿 18 歲，所以這一步要**請爸媽幫忙**（用他們的帳號，錢也進他們的帳戶）。

老師會給你一張 **《家長協作任務單》**（[[S5-W14-家長協作任務-AdSense]]），把它帶回家給爸媽看。和爸媽一起決定要不要試試看，請他們在單子上簽名，下次帶回來給老師。

> 不管最後有沒有真的放廣告，**「和爸媽一起做這個決定」就是任務完成**。這就是真正的創業者在做的事——重要的決定，要和投資人（你的爸媽）一起做。
