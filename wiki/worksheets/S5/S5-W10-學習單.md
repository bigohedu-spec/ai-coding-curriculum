## 今天的冒險

你的三個核心功能已經在瀏覽器上跑起來了——陌生人打開你的頁面，可以直接使用你做的東西。

但現在還有個問題：他們不知道這是什麼。沒有介紹，沒有說明，進來就直接是功能。

今天有兩個目標：

**一、給你的專案加一個 Welcome Page**
讓第一次看到你作品的人，不需要問你就能知道這是什麼、能做什麼、怎麼開始使用。

**二、完成三個你計劃中的新功能或修正**
上週做完三個核心功能之後，你一定發現了一些「還想再加」或「需要修一下」的地方。今天把它們做出來。

## 開始前：規劃你今天的三個升級

打開你的 `project-idea.md`，在最底部加一個新區塊，寫下你今天要完成的三件事：

```
## W10 三個升級目標
1. _______________（新功能 / 修正）
2. _______________（新功能 / 修正）
3. _______________（新功能 / 修正）
```

不知道要寫什麼嗎？想一想：
- 上週做功能的時候，有沒有什麼地方「怪怪的」或「感覺還差一點」？
- 用完你的功能之後，有沒有想過「如果能加＿＿就更好了」？
- 有沒有哪個按鈕或輸入框，讓人不知道怎麼用？

寫完三項，存檔（`Ctrl+S` / `Cmd+S`）。開始任務。

## 任務 A｜幫你的專案加上 Welcome Page ⭐ 100 金幣

**任務 ID**：S5-W10-A

### 目標

建立一個**介紹頁面**，讓第一次看到你的專案的人，不需要問你就能知道：這是什麼、能做什麼、怎麼使用。

**一個好的 Welcome Page 至少包含：**
- 你的專案名稱
- 一句話說明這個專案是什麼
- 這個專案有哪些功能（可以是列點）
- 一個進入主要功能的按鈕或連結

---

### 選擇你的做法（兩個選項）

| 選項 | 做法 | 適合情況 |
|------|------|---------|
| **A 選項** | 在現有 `index.html` 最頂端加一個說明區塊 | 你的頁面還不複雜，希望一個頁面就有所有東西 |
| **B 選項** | 新建一個 `welcome.html`，加一個按鈕連結到你的 `index.html` | 你希望介紹頁和功能頁分開，更有「進入感」 |

---

### 如果你選 A 選項（在 index.html 加說明區塊）

1. 打開 `index.html`
2. 在 `<body>` 裡面**最頂端**，加入一個 `<section>` 或 `<div>`，例如：
   ```html
   <section id="welcome">
     <h1>我的專案名稱</h1>
     <p>一句話說明這個專案是什麼</p>
     <ul>
       <li>功能一</li>
       <li>功能二</li>
       <li>功能三</li>
     </ul>
     <a href="#main">▼ 開始使用</a>
   </section>
   ```
   （你可以把 `#main` 改成你的功能區塊的 id，或直接刪掉這個連結）
3. 儲存（`Ctrl+S` / `Cmd+S`）
4. 在瀏覽器重新整理，確認說明區塊出現在頁面最頂端

---

### 如果你選 B 選項（新建 welcome.html）

1. 在 VS Code 點選單 `File → New File`（或按 `Ctrl+N` / `Cmd+N`）
2. 按 `Ctrl+S` / `Cmd+S` 儲存，命名為 `welcome.html`
   - ⚠️ **重要**：確認這個檔案存在你的**專案資料夾**裡，和 `index.html` 在同一個位置
   - 確認方式：左側檔案欄可以看到 `welcome.html` 和 `index.html` 並排出現
3. 在 `welcome.html` 寫你的介紹頁內容，並加入一個跳到主功能頁的連結：
   ```html
   <!DOCTYPE html>
   <html lang="zh-TW">
   <head>
     <meta charset="UTF-8">
     <title>（你的專案名稱）</title>
   </head>
   <body>
     <h1>我的專案名稱</h1>
     <p>一句話說明這個專案是什麼</p>
     <ul>
       <li>功能一</li>
       <li>功能二</li>
       <li>功能三</li>
     </ul>
     <a href="index.html">▶ 開始使用</a>
   </body>
   </html>
   ```
4. 儲存，在瀏覽器打開 `welcome.html`
5. 確認：點了「開始使用」連結，會跳到 `index.html`

---

### 如果你遇到以下情況，可以這樣問：

> 「我想在 HTML 頁面最上方加一個介紹區塊，讓使用者一進來就看到說明，有什麼基本的結構可以參考？」

> 「我想讓介紹頁的標題大一點、背景有顏色、文字置中，有什麼 CSS 可以快速改善外觀？」

> 「我建了 welcome.html，想在裡面加一個按鈕點了跳到 index.html，HTML 裡的寫法是什麼？」

> 「我的 welcome.html 點了連結沒有跳到 index.html，但我確認它們在同一個資料夾，可能是什麼原因？」

---

### 完成條件

1. 打開瀏覽器，可以看到你的介紹頁（在 `index.html` 頂端 **或** 在 `welcome.html`）
2. 介紹頁包含：專案名稱、一句話說明、功能列點、進入功能的按鈕或連結
3. 截圖包含整個瀏覽器畫面（看得到介紹頁的完整內容）

完成之後，請直接舉手告知老師。
