**任務 ID**：S5-W05-A

### 目標

讓 Copilot Chat 在你的 VS Code 裡**真的回答你**，並寫好一份 `my-menu.md`，列出你最想做的 3 個功能。

### Part 1：打開你的專案

1. 打開 VS Code → 上方選單 **File → Open Folder**（檔案 → 開啟資料夾）→ 選你的專案資料夾
2. 確認左邊 Explorer（側邊欄）看得到 `index.html` 和 `about.html`
3. 按 `Ctrl` + `` ` `` 打開 Terminal，打 `git status`

**完成後你會看到**：`nothing to commit, working tree clean`——上週的兩個存檔點都還在。

> **如果不對怎麼辦**
> - 出現 `modified:` 或 `Untracked files:` → 有東西還沒存檔。先打 `git add .`，再打 `git commit -m "save before w05"`。
> - 出現 `fatal: not a git repository` → 開錯資料夾了，重做第 1 步。

---

### Part 2：自己登入 Copilot（用課程帳號）

Copilot 要用**課程統一的 GitHub 帳號**登入——GitHub 規定 13 歲以上才能自己申請帳號，所以課程幫大家準備了一個。**帳號和密碼看老師發的「課程帳號卡」**（或白板上寫的），今天你要**自己**把它登進去。

> ⚠️ **帳號卡的規則**
> - 帳號密碼**只能打在 GitHub 的登入頁**（網址開頭是 `https://github.com`）。別的網站、Chat、Lab Terminal、聊天軟體都**不能**打。
> - 不要拍照、不要抄回家、不要告訴別班同學。用完把卡片還給老師。
> - **不要改密碼、不要改帳號的任何設定**——全班共用一個帳號，你改了，大家都不能用。

1. 看 VS Code **最上方 Title Bar（標題列）**中間偏右，找到 Copilot 的小圖示（像一張戴護目鏡的小臉）
   - 找不到 → 看最左邊 **Activity Bar**（活動列）**最下面**的人像圖示 **Accounts**（帳戶）
2. 點它 → 選 **Sign in to use Copilot**（或 **Sign in with GitHub to use GitHub Copilot**）
3. VS Code 可能跳出「Do you want Code to open the external website?」（要打開外部網站嗎？）→ 按 **Open**（開啟）
4. 瀏覽器打開 GitHub 的登入頁 → **先看網址列**，開頭一定要是 `https://github.com`
5. 在 **Username or email address** 打帳號卡上的帳號，在 **Password** 打密碼 → 按 **Sign in**
6. 如果出現 **Authorize Visual-Studio-Code**（授權 VS Code）的頁面 → 按綠色的 **Authorize** 按鈕
7. 瀏覽器問「要打開 Visual Studio Code 嗎？」→ 按 **Open Visual Studio Code**（開啟）
8. 回到 VS Code，如果問「The extension 'GitHub Copilot Chat' wants to sign in using GitHub.」→ 按 **Allow**（允許）

**完成後你會看到**：Copilot 圖示不再有驚嘆號或「Sign in」的字樣；點左下角的 **Accounts** 人像，看得到課程帳號的名字。

> **如果不對怎麼辦**
> - 寫 **Incorrect username or password**（帳號或密碼錯誤）→ 一個字一個字對照帳號卡重打。大小寫要一樣，密碼裡的 `-` 不要漏。
> - 跳出要你輸入 **verification code**（驗證碼）的頁面 → **舉手** ✋。驗證碼會寄到課程信箱，只有老師看得到。
> - 瀏覽器停在一個空白頁、沒有回到 VS Code → 回到 VS Code 看看，有時候其實已經登入成功了。
> - 登入完 VS Code 沒反應 → 把 VS Code **整個關掉再打開**，用 **File → Open Folder** 開專案，再看一次 Copilot 圖示。
> - 試了兩次都不行 → 先問 TA 同學，再舉手。

### Part 3：打開 Copilot Chat

按 `Ctrl` + `Alt` + `I`。

（或是點 Title Bar 上的 Copilot 圖示 → 選 **Open Chat**）

**完成後你會看到**：VS Code **右邊**（有的電腦是左邊）出現一塊聊天區，標題寫著 **CHAT**，最下面有一個輸入框，寫著類似 `Ask Copilot` 或 `Add context (#), extensions (@), commands (/)` 的灰字。

輸入框旁邊有一個**模式選單**，寫著 **Ask**、**Edit**、**Agent** 其中一個。

👉 **今天請選 Ask**（只回答問題，不會動你的檔案）。點那個選單 → 選 **Ask**。

> **如果不對怎麼辦**
> - 按快捷鍵沒反應 → 上方選單 **View → Chat**（檢視 → 聊天）。
> - 聊天區寫著「Sign in」或「Copilot is not available」→ Part 2 還沒完成，舉手請老師。
> - 找不到模式選單 → 它可能很小，在輸入框的下面或左下角，寫著 `Ask` / `Agent` 的那個字就是。

### Part 4：跟你的工程師打招呼（三個問題）

在 Chat 輸入框打字，按 `Enter` 送出。**每問一題，等它回答完再問下一題。**

**問題 ①**（可以直接複製）

```
你好！我是小學五年級的學生，請用簡單的話告訴我：你是誰？你可以幫我做什麼？
```

**問題 ②**（問上週學的東西）

```
我上週學了 git add、git commit、git restore。請用打電動存檔來比喻，一句話解釋每一個指令。
```

**問題 ③**（你自己想一個）

問一個你真的好奇、跟**電腦或網頁**有關的問題。例如：
- 「網頁上的按鈕是怎麼做出來的？」
- 「遊戲網頁是怎麼知道我按了哪個鍵？」

**完成後你會看到**：每個問題底下都有 Copilot 的回答。回答很長的話，可以往下捲。

> **如果不對怎麼辦**
> - 一直顯示轉圈圈、等很久沒回答 → 等 30 秒；還是不行，按輸入框旁的 **Stop**（停止）方塊，再送一次。
> - 回答太難看不懂 → 再送一句：「**太難了，請用小學生聽得懂的話再說一次**」。
>
> ⚠️ **不要在 Chat 裡打你的真實姓名、住址、電話、學校名字**。PM 只說「要做什麼」，不說自己的個資。

### Part 5：讓它看你的檔案

工程師最厲害的地方，是能**直接看你的程式碼**。

1. 在 Explorer 點開 `index.html`（讓它出現在中間的 **Editor**（編輯器））
2. 在 Chat 輸入框打：

```
請看我現在打開的這個檔案，用三句話告訴我：這個網頁畫面上會出現什麼？
```

3. 送出

**完成後你會看到**：Chat 輸入框上面（或回答的最上面）出現 `index.html` 的小標籤，回答裡講到**你自己寫的名字和句子**。

> **如果不對怎麼辦**：回答裡沒提到你的內容、好像沒看到檔案 → 在輸入框打 `#` → 從跳出的清單選 `index.html`，再送一次。

> 🤔 **注意**：今天是 **Ask** 模式，它只會「說」，不會改你的檔案。**下週（W06）你才會讓它真的動手。**

### Part 6：認識功能菜單

從 W07 開始，你要做一個**自己的專案**。專案是一塊一塊「功能」拼起來的——就像點餐，先看菜單。

**🌐 網頁工具軌**（做一個大家可以用的小工具）

| 功能 | 它讓使用者可以… | 難度 |
|------|----------------|------|
| 歡迎頁（Welcome Page） | 一打開就知道這是什麼網站 | ⭐ |
| 導覽列（Navigation Bar） | 在不同頁面之間切換 | ⭐⭐ |
| 清單 | 新增、刪除一筆一筆的資料（例如待辦事項） | ⭐⭐ |
| 假登入 | 輸入帳號密碼，對了才能進去 | ⭐⭐ |
| 彈出視窗（Popup） | 按一個按鈕，跳出一個小視窗 | ⭐⭐ |
| 搜尋 | 打幾個字，馬上找到符合的資料 | ⭐⭐⭐ |
| 記住資料 | 關掉網頁再打開，資料還在 | ⭐⭐ |
| 留言板（雲端） | 不同的人留言，大家都看得到 | ⭐⭐⭐⭐ |

**🎮 遊戲軌**（做一個可以玩的網頁遊戲）

| 功能 | 它讓玩家可以… | 難度 |
|------|--------------|------|
| 開始畫面 | 看到遊戲名字，按「開始」進入 | ⭐ |
| 計分 | 看到自己現在幾分 | ⭐⭐ |
| 倒數計時 | 時間到遊戲就結束 | ⭐⭐ |
| 生命值 | 受傷會扣血，沒血就輸 | ⭐⭐ |
| 結束畫面 | 看到最後分數，可以再玩一次 | ⭐⭐ |
| 隨機事件 | 每次玩都有不一樣的驚喜 | ⭐⭐ |
| 存檔 | 下次打開還記得玩到哪 | ⭐⭐ |
| 排行榜（雲端） | 跟全班比誰分數最高 | ⭐⭐⭐⭐ |

> 兩個軌可以**混搭**：做遊戲的人也可以加登入；難度**沒有上限**，因為寫程式的是你的 AI 工程師。

**用 Chat 問清楚兩個功能**：從菜單挑**兩個你看不太懂或很好奇**的功能，問 Chat：

```
我想在網頁上做「＿＿＿＿」這個功能。請用小學生聽得懂的話說明：使用者會看到什麼、會怎麼操作？
```

**完成後你會看到**：兩個回答，各自描述了那個功能用起來的樣子。

### Part 7：寫下「我的功能菜單」（`my-menu.md`）

1. 在 Explorer 空白處按**右鍵** → **New File**（新增檔案），命名為 **`my-menu.md`**
2. 照下面的格式填寫（**括號裡的字換成你自己的**），存檔 `Ctrl + S`：

```markdown
# 我的功能菜單

## 我想走哪一軌？
（網頁工具軌 / 遊戲軌 / 混搭）

## 我最想做的 3 個功能
1. （功能名稱）：使用者可以（做什麼）
2. （功能名稱）：使用者可以（做什麼）
3. （功能名稱）：使用者可以（做什麼）

## 我最期待哪一個？為什麼？
（寫一兩句）
```

**完成後你會看到**：Explorer 多了 `my-menu.md`，旁邊有綠色的 `U`（還沒存進存檔點）。

> **怎樣算「寫清楚」？** ❌「計分」→ ✅「計分：使用者每點到一隻怪物就加 10 分，分數顯示在右上角」。**寫到工程師不用再問你就能做**，才是好 PM。
>
> 不確定寫得夠不夠清楚 → 把你寫的貼給 Chat，問：「**如果你是工程師，看我這樣寫，還有哪裡不清楚？**」

## 老師筆記

（給老師的提示，不顯示給學生）

- **課前準備**：
  - 確認課程統一 GitHub 帳號的 Copilot 授權有效、席位足夠。**登入由學生自己用課程帳號操作**（學生未滿 13 歲不可自行註冊 GitHub，課程帳號是機構統一管理的，見 CLAUDE.md 第十四、十六節）。
  - **帳密不寫進學習單**：學習單內容存在 Firestore，可以公開讀取，wiki 也會推上 GitHub。帳密只印在「課程帳號卡」上（或上課時寫白板，下課擦掉），課堂結束收回卡片。
  - **GitHub 裝置驗證碼**：沒開兩步驟驗證的帳號，在新電腦登入時，GitHub 常會寄一組 verification code 到帳號信箱，學生看不到。老師要開著課程信箱，學生舉手時念驗證碼給他。全班同時登入會連續觸發，建議分兩三批登入，或課前先在每台電腦試登一次（登入狀態會保留，之後每週不必重登）。
  - 共用帳號有被改密碼、改設定的風險：學習單已經寫明禁止事項。課後可以到 GitHub 的 Settings → Security log 看有沒有異常；學期中途如果帳密外流，就換密碼、重印帳號卡。
  - 先確認學校網路沒有擋 `github.com`、`*.githubcopilot.com`。
- **常見問題**：
  - Copilot 圖示位置因 VS Code 版本不同：新版在 Title Bar（Command Center 旁），舊版在 Status Bar 右下角。都找不到時用 Activity Bar 最下方的 Accounts。
  - Chat 模式選單在新版可能只有 **Ask / Agent**（Edit 併入 Agent），或另有 **Plan**；本週一律選 Ask。
  - 學生直接用 Agent 模式導致檔案被改：用 Chat 回答下方的 **Undo**，或用 W04 學的 `git restore` 救回——正好複習。
  - Part 5 沒帶到檔案：新版預設會附上目前開啟的檔案；沒有的話用 `#` 手動加入。
  - 學生在 Chat 輸入個資：巡視時留意，提醒 PM 只描述功能。
- **功能菜單**：本學習單的菜單已依 2026-09 Big-Oh 改版調整（雲端類功能改寫為「留言板（雲端）／排行榜（雲端）」，指 W13 起的平台 `BO`；移除 Firebase、外部 API 項目）。[[feature-menu]] 概念頁還是舊版，之後要同步。
- **翻轉教育提示**：Part 7 是本週的核心——能把功能寫到「使用者可以做什麼」的學生，就是 PM 思維起步了，W07 的專案宣言會直接接這份 `my-menu.md`。
