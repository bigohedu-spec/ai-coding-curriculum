# S5 W16｜讓作品有「活的」資料：平台 BO 動態功能（進階功能一）學習單

> 模組三 進階功能。原為 S5-W15「外部 API」，W15 改為《遊戲開發模擬器》後歸位到 W16。**因部署平台 Big-Oh 禁止連外部網址（`fetch` 別人的網站會被擋），本週由「串接外部 API」改為「用平台的 `BO` 讓作品有跨使用者的活資料」**——一樣讓你的專案不再只有寫死的假資料。

## 今天的冒險

到目前為止，你專案裡的資料都是你自己寫死的。今天要讓它**有「活的、別人的」資料**——用平台自帶的 `BO`，做出一個**全班共用、會即時變動**的功能：排行榜、留言板、計數器、或多人連線。你是 PM，Copilot Chat 是工程師：你把「要什麼」講清楚，讓它幫你接。

**這個功能要整合進你自己的專案**（作品導向，第十二節）——不是做一個丟掉的練習。

> 🔑 `BO` 是平台自動幫你準備好的（作品放上 Big-Oh、L2 以上就有）：**不用 import、不用網址、不用金鑰**。`BO` 只在你的線上作品（`.bigoh.uk`）才會出現，本機開檔沒有。

## 任務 A｜用 BO 顯示一個「活的」資料 ⭐ 150 金幣
**目標（開放，自己決定）**：用平台的 `BO`，讓你專案的某一頁出現**跨使用者、會變**的資料。

先選一個 `BO` 功能（都不用金鑰、不用網址）：
- **排行榜**：`await BO.score('main', 分數)` 送分、`await BO.top('main', 10)` 拿前 10 名（回 `[{name, score, at}]`，名字由平台決定、不用你傳）
- **計數器**：`await BO.bump('plays')` 記錄作品被玩了幾次，顯示在畫面上
- **留言板**：`await BO.post('guestbook', 文字)` 留言（先審後顯）、`await BO.list('guestbook', 20)` 顯示最新留言
- **多人連線**：`await BO.room.create({max:8})` 拿一個 4 碼房號，`BO.room.join('K3F9')` 加入（進階）
- 不確定用哪個 → 問 Lab Terminal「我想讓作品有全班共用的○○，該用 BO 的哪個功能？」

> 以前要「連外部 API」才能拿真資料，但那要外部網址和金鑰、還會被平台擋。平台的 `BO` 直接幫你做好這些，**不用網址、不用金鑰**。

**成功的樣子**：打開你的線上作品，畫面上出現一段**跨使用者、會變**的資料（例如排行榜有別人的分數、留言板有別人的留言），不是你寫死的。

## 任務 B｜加一個讓使用者操作的控制 ⭐ 100 金幣
**目標（開放）**：加一個按鈕或輸入框，讓使用者可以**主動觸發**（例如「送出我的分數」按鈕、「留言」輸入框 + 送出鈕）。

**成功的樣子**：在你的專案裡，操作之後 `BO` 的資料就多一筆、畫面也更新（例如你的分數進了排行榜、你的留言出現在留言板）。

> 主線合計 250（A150 / B100）。做完還有時間 → 挑戰把資料排版變好看、或做多人連線（進階，不計入 250）。

## 工具操作（照做，不用問老師）
1. **先確認作品在線上**：`BO` 只在 `.bigoh.uk` 線上版才有。還沒上線 → 先 `node bigoh.mjs deploy`（見 W14）。
2. **開啟 Copilot Chat**：VS Code 按 `Ctrl+Shift+I`（Mac：`Cmd+Shift+I`），或點左側邊欄 Copilot 圖示。
3. **描述功能給它**（見下方 Prompt 範例）→ Copilot 回一段程式碼區塊。
4. **把程式碼放進專案**：點程式碼區塊右上角「插入到編輯器」，或複製貼到你的 `.html` / `.js`。
5. **存檔**：`Ctrl+S`（標題列 ● 消失＝已存）。
6. **重新部署測試**：`node bigoh.mjs deploy`，打開你的 `.bigoh.uk` 網址看對不對。
7. **看對不對** → 不對回 Chat 描述問題 → 讓它修 → 再測。
8. **截圖**：截「功能運作中」（看得到操作 + 跨人的資料），舉手告知老師。

**如果不對怎麼辦**：
- 畫面空白 / `BO is not defined` → 作品沒上線（本機沒有 `BO`），先 `deploy`。
- 你想 `fetch` 外部網址被擋（CSP）→ 平台不讓連外部網站，改用 `BO` 達成類似效果。
- 存了讀不到 → `BO.score`/`BO.top`（或 `post`/`list`）用了不同的榜名/留言板名，要一致。

## 問 Copilot Chat 的方式（描述功能，用白話）
Vibe Coding：Copilot **會真的幫你寫程式碼**，把「要什麼」講清楚。範例：
> - 「我的作品在 Big-Oh 平台上，有全域 `BO`。幫我做排行榜：遊戲結束時 `await BO.score('main', 分數)` 送分，畫面上用 `await BO.top('main', 10)` 顯示前 10 名（回 `[{name,score,at}]`，名字平台給、我不用傳）。」
> - 「我有一個 id 是 `sendBtn` 的按鈕和一個輸入框，幫我讓它被點時 `await BO.post('guestbook', 輸入框的字)`，再用 `await BO.list('guestbook', 20)` 把最新留言顯示出來。」
> - 「我本來想 `fetch` 一個外部 API，但平台把外部網址擋掉了（CSP）。我要做的是○○，可以改用 `BO` 的哪個功能達成？」

📌 描述三要素（來自 vibe-coding）：**是什麼 / 長什麼樣子 / 做完後發生什麼**。

## 🔧 遇到狀況可以這樣問（起點，不是答案）
（第十七節：這些是提問起點，路要自己走）
- 「`BO.top` 回來是一個陣列，我想把前 3 名做成好看的排行榜畫面，怎麼跑迴圈顯示？」
- 「我想在送分之後才更新排行榜、而且顯示『上傳中…』，怎麼做？」
- 「`BO` 還有哪些功能可以用？（存檔、排行、計數、留言、多人、登入）我這個專案適合哪個？」

## 老師筆記
- **常見問題**：作品沒上線 → `BO` 是 undefined（先 `deploy`）；學生想 `fetch` 外部 API → 被 CSP 擋，引導改用 `BO`（這正是本週重點：平台幫你做好動態功能，不用外部服務、不用金鑰）；`score`/`top`（或 `post`/`list`）榜名不一致。
- **作品導向提醒**：驗收看「這個功能在**他的專案**裡運作」，不是獨立小 demo。
- **延伸挑戰**：`BO.room` 做 4 碼房號多人連線；或排行榜/留言板排版變好看。
