## 今天的冒險

上週你叫醒了 AI 工程師，它只會**回答問題**。

今天你要切到 **Agent** 模式——**你說，它做**。

你的 W01 網頁現在只有一行標題、一句話。今天你當 PM，把它變成一個真正像樣的**工作室起始頁**：

> 你**說清楚**想要什麼 → 工程師**做出來** → 你**檢查** → 不對就**再說一次** → 滿意了就**存檔**

這就是 **Vibe Coding**。

## 任務 A｜讓 AI 工程師幫你做起始頁 ⭐ 250 金幣

**任務 ID**：S5-W06-A

### 目標

只用**說的**（不自己改程式碼），讓 Copilot Chat 把 `index.html` 變成你的工作室起始頁，經過**至少兩輪修改**，最後按下存檔點。

---

### Part 1：準備好「工地」和「監視器」

1. **File → Open Folder**（檔案 → 開啟資料夾）→ 選你的專案資料夾
2. 按 `Ctrl` + `` ` `` 打開 Terminal，打 `git status`，確認是 `nothing to commit, working tree clean`
3. 在 Explorer 點開 `index.html`，按右下角 **Status Bar**（狀態列）的 **`Go Live`**
4. 把 VS Code 和瀏覽器**左右並排**（`Win + ←` / `Win + →`）

**完成後你會看到**：右邊瀏覽器開著你 W01 做的網頁，網址是 `127.0.0.1:5500`。這就是你的「監視器」，等一下工程師改了什麼，這裡馬上看得到。

> **如果不對怎麼辦**
> - `git status` 有 `modified:` 或 `Untracked files:` → 先 `git add .` 再 `git commit -m "save before w06"`。**開工前一定要有存檔點**，等一下改壞才救得回來。
> - 沒有 `Go Live` → 在 `index.html` 上按右鍵 → **Open with Live Server**。

---

### Part 2：把工程師切到 Agent 模式

1. 按 `Ctrl` + `Alt` + `I` 打開 Chat
2. 點輸入框旁的**模式選單**（上週選的是 **Ask**）→ 改選 **Agent**

**完成後你會看到**：模式選單寫著 **Agent**。

| 模式 | 它會做什麼 |
|------|-----------|
| Ask | 只**回答**，不動你的檔案（上週用的） |
| **Agent** | 會**直接改你的檔案**（今天用的） |

> **如果不對怎麼辦**
> - 模式選單裡沒有 Agent，只有 **Edit** → 選 **Edit**，效果差不多。
> - Chat 寫著「Sign in」→ 登入掉了，舉手請老師。

---

### Part 3：第一次下單

好 PM 的單要寫清楚**四件事**：**改哪個檔案、上面要有什麼、長什麼樣子、不要做什麼**。

把下面這段**複製**到 Chat，**把底線換成你自己的**，再送出：

```
請幫我把 index.html 改成我的工作室起始頁：
1. 最上面一個大標題：「＿＿＿的工作室」（填暱稱，不要填真名）
2. 標題下面一段自我介紹：我喜歡＿＿＿和＿＿＿
3. 一個按鈕，寫「關於我」，點了會打開 about.html
4. 整個頁面的背景是＿＿＿色，字要看得清楚
只改 index.html，不要新增其他檔案，也不要執行任何 Terminal 指令。
```

**完成後你會看到**：

1. Chat 開始說它要做什麼，然後出現 `index.html` 的小卡片
2. 中間的 Editor 裡，`index.html` 出現**綠色**（新加的）和**紅色**（刪掉的）區塊
3. **右邊瀏覽器已經變了！**
4. Chat 下面出現兩個按鈕：**Keep**（保留）和 **Undo**（復原）

👉 **先看右邊瀏覽器**，大致是你要的樣子 → 按 **Keep**。

> **如果不對怎麼辦**
> - Chat 跳出要執行指令的提示，有 **Allow**（允許）/ **Continue** / **Skip**（略過）按鈕 → 按 **Skip**，然後跟它說：「**不要執行指令，只要改 index.html**」。
> - 它說改好了，但瀏覽器沒變 → 先按 **Keep**，再到 `index.html` 按 `Ctrl + S` 存檔。
> - 它改了別的檔案、或做得完全不對 → 按 **Undo**，把單寫得更清楚一點再送一次。

---

### Part 4：驗收（PM 最重要的工作）

工程師說「做好了」不算數，**PM 自己測過才算**。對照你的單，一項一項在右邊瀏覽器檢查，打勾或打叉：

- [ ] 標題是「＿＿＿的工作室」
- [ ] 有自我介紹，內容是你說的
- [ ] 有「關於我」按鈕，**點下去會打開 `about.html`**（要真的點！看完按瀏覽器的上一頁回來）
- [ ] 背景是你說的顏色，字看得清楚

**完成後你會看到**：你知道哪幾項 ✅、哪幾項 ❌。

> 全部 ✅？很好，但下一關還是要做——真正的 PM 永遠會想再改好一點。

---

### Part 5：修改兩輪（說出「現在」和「想要」）

挑**一個**不滿意、或想變更好的地方，用這個句型告訴工程師：

```
現在＿＿＿＿＿＿（你看到的樣子），我想要＿＿＿＿＿＿（你要的樣子）。
```

例子：
- 「**現在**按鈕在左邊而且很小，**我想要**按鈕在正中間、大一點、是圓角的。」
- 「**現在**點『關於我』沒反應，**我想要**點了就打開 about.html。」
- 「**現在**頁面空空的，**我想要**在自我介紹下面加三個我喜歡的東西，排成一排的小卡片。」

每一輪都要：**送出 → 看瀏覽器 → 滿意按 Keep / 不滿意按 Undo 再說一次**。

**做兩輪**（兩個不同的修改）。

**完成後你會看到**：網頁比 Part 3 結束時多了兩個你要的改變。

> **如果不對怎麼辦**
> - 它改的不是你要的地方 → 說得更具體：「**頁面最下面**那個按鈕」比「按鈕」清楚。
> - 改了三次還是不對 → 按 **Undo**，換一種說法，或問 Ask 模式：「我想要＿＿，我該怎麼描述你才聽得懂？」
>
> ⚠️ **今天的規則：不自己改程式碼，只能用說的。** 這是在練 PM 的描述能力。

---

### Part 6：反悔一次（Undo 與存檔點）

故意下一個**很誇張**的單，例如：

```
把整個網頁的字都變成彩虹色，而且每個字都要上下跳動。
```

看完右邊瀏覽器的結果之後——按 **Undo**。

**完成後你會看到**：網頁**回到上一步的樣子**。

🤔 **Undo 和 W04 學的 `git restore` 有什麼不一樣？**
- **Undo**：只能退回工程師**剛剛那一次**的修改
- **`git restore`**：可以回到**上一個存檔點**——不管中間改了幾次

> 如果你不小心按了 **Keep** → 用 W04 的方法：在 Terminal 打 `git restore index.html`，會回到 Part 1 的存檔點（Part 3～5 的修改也會不見，要重做）。**所以滿意了就要趕快存檔！**

---

### Part 7：按下存檔點 + 寫 PM 筆記

1. 在 Explorer 按 **New File**（新增檔案），命名為 **`vibe-log.md`**，寫下：

```markdown
# Vibe Coding 紀錄 W06

## 我下的第一張單
（把 Part 3 送出的那段貼過來）

## 我改了哪兩次
1. 現在＿＿＿，我想要＿＿＿
2. 現在＿＿＿，我想要＿＿＿

## 下次我會怎麼寫得更清楚
（一句話）
```

2. 存檔，然後在 Terminal 一行一行打：

```
git add .
```

```
git commit -m "first vibe coding"
```

```
git log --oneline
```

**完成後你會看到**：`git log` 最上面是 `first vibe coding`。

- `index.html` 變成你的工作室起始頁，「關於我」按鈕**點得通**
- 至少經過 **兩輪**「現在…我想要…」的修改
- 用過一次 **Undo**
- `vibe-log.md` 寫好，`git log --oneline` 最上面是 `first vibe coding`

## 問 AI 的方式

> 「我想要＿＿，我該怎麼描述你才聽得懂？」（用 **Ask** 模式問，它會教你怎麼下單）

> 「Vibe Coding 是什麼？為什麼說寫程式的人變成了 PM？」（問 Lab Terminal）

> 「Keep 和 Undo 是什麼意思？如果我按錯了怎麼辦？」

📌 **Prompt 小技巧**：工程師最怕「改好看一點」這種單——**好看是什麼？**把它換成看得到的東西：顏色、大小、位置、幾個。「按鈕**大一點、藍色、在正中間**」比「按鈕好看一點」有用一百倍。

## 本週學習重點

1. 第一張單要說清楚：改哪個檔案、要有什麼、長什麼樣子、不要做什麼。
2. Agent 模式的 Chat 會真的幫你改檔案。
3. PM 最重要的工作是驗收：自己打開看是不是想要的。
4. 要修改時，說「現在是……，我想要……」。
5. 改壞了可以 Undo，或回到存檔點反悔。

## 老師筆記

（給老師的提示，不顯示給學生）

- **課前準備**：確認上週全員 Copilot 已登入（未登入的學生先處理，否則本週無法進行）。Live Server 與 Git 已在 W02、W03 裝好。
- **常見問題**：
  - Agent 模式要求執行 Terminal 指令（啟動伺服器、安裝套件）：一律 **Skip**，單裡已寫「不要執行任何 Terminal 指令」。若學生按了 Allow 而跑出奇怪東西，用 `git status` / `git restore` 收拾。
  - 新版 VS Code 改完檔案可能已自動存檔、也可能要學生 `Ctrl + S`；Keep 後瀏覽器沒變多半是沒存。
  - 舊版沒有 Agent 只有 Edit：用 Edit 即可，按鈕同樣是 Keep / Undo（舊版可能叫 Accept / Discard）。
  - 學生按了 Keep 後才後悔：Part 6 已帶出 `git restore` 會一併退掉之前沒存檔的修改，提醒「滿意就存檔」的節奏。
  - Copilot 回應慢或額度用完（共用帳號高峰時段）：讓學生先做 Part 4 驗收和寫 `vibe-log.md`，稍後再送。
  - 學生想自己改程式碼：本週明確禁止，目的是練描述；W07 起不限。
  - 學生在單裡寫真名：巡視提醒用暱稱。
- **翻轉教育提示**：Part 5 能自己寫出「現在…我想要…」且一次命中的學生，描述能力已達本週目標，最適合當 TA（幫人改單，而不是幫人打字）。
- **延伸挑戰**：about.html 同風格 + 互相連結，等於提前體驗 W11 的頁面串連。
