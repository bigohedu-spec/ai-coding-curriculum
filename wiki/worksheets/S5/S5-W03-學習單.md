## 今天的冒險

打電動打到一半，電腦當機——**你忘記存檔。**

寫程式也會這樣：改到一半改壞了，想回到「還好好的那個版本」，卻回不去。

今天你要幫你的專案**裝上存檔系統**。裝好之後，你隨時可以回到任何一個存檔點。

## 任務 A｜幫專案裝上存檔系統 ⭐ 250 金幣

**任務 ID**：S5-W03-A

### 目標

把你 W01 建的專案資料夾，變成一個「**有存檔功能**」的專案，並且看得懂「我從上次之後改了什麼」。

---

### Part 1：打開你的專案 + 打開 Terminal

1. 打開 VS Code
2. **File → Open Folder**（檔案 → 開啟資料夾）→ 選你 W01 建的專案資料夾（⚠️ 一定要「Open **Folder**」）
3. 確認左邊 Explorer（側邊欄）看得到 `index.html`
4. 打開 Terminal：按 `Ctrl` + `` ` ``（鍵盤左上角、數字 1 左邊那顆）

**完成後你會看到**：下方出現一塊黑色（或深色）的區域，最後一行是一串路徑，**結尾應該是你的專案資料夾名字**，後面有一個游標在閃。

> **如果不對怎麼辦**
> - 沒反應 → 上方選單 **Terminal → New Terminal**（終端機 → 新增終端機）。
> - 路徑結尾**不是**你的專案資料夾名字 → 你八成沒用「Open Folder」開專案。關掉 Terminal，重做第 2 步。**這一步錯了後面全部會錯，一定要先弄對。**

---

### Part 2：確認 Git 有沒有裝

在 Terminal 打這一行，然後按 `Enter`：

```
git --version
```

**完成後你會看到**：跑出一行版本號，像 `git version 2.45.1`（數字不一樣沒關係）。

> **如果不對怎麼辦**：如果寫「**無法辨識 'git' 詞彙**」或「**不是內部或外部命令**」→ 這台電腦還沒裝 Git。**先別舉手，這關你自己闖得過！** 往下看「🛠️ 自己把 Git 裝起來」。

#### 🛠️ 自己把 Git 裝起來（只有沒裝的人要做）

真正的工程師遇到「電腦少了一個工具」，都是自己找、自己裝。給你幾個線索：

- **線索 1｜去哪裡下載？** Git 的官方網站是 `git-scm.com`。⚠️ **只從官方網站下載**，搜尋結果裡寫「廣告」或網址怪怪的都不要點。
- **線索 2｜下載哪一個？** 你的電腦是 Windows，找找看網站上哪裡寫著 Windows。
- **線索 3｜安裝畫面一堆英文怎麼辦？** 不用每個都看懂，全部照預設的選項，一直按 `Next`，最後按 `Install`。
- **線索 4（最多人卡在這裡）｜裝好了還是「無法辨識」？** VS Code 要**整個關掉再重新打開**，它才會發現多了 Git。重開後再用「Open Folder」打開專案、打開 Terminal，再打一次 `git --version`。

**卡住了？** 先問 Lab Terminal，例如：

> 「我要在 Windows 電腦安裝 Git，我現在卡在＿＿＿＿（把你看到的畫面或英文抄下來），下一步要按什麼？」

還是不行 → 問 TA 同學 → 最後才問老師。

> ⚠️ **只有這種情況直接舉手**：安裝時跳出視窗，要你輸入**系統管理員的密碼**——這個你沒有，請老師來。

**完成後你會看到**：`git --version` 跑出版本號 → 恭喜你，你自己幫電腦裝好了一個工程師工具，繼續 Part 3！

---

### Part 3：開啟存檔功能（`git init`）

確認 Terminal 路徑是你的專案資料夾之後，打這一行、按 `Enter`：

```
git init
```

**完成後你會看到**：

1. Terminal 跑出一句 `Initialized empty Git repository in ...`（後面是你的資料夾路徑）
2. **左邊 Explorer 的 `index.html` 變顏色了**（通常變綠色，後面多一個字母 `U`）

那個顏色的意思是：「這個檔案還沒被存進任何存檔點。」

> **如果不對怎麼辦**
> - 訊息裡的路徑**不是**你的專案資料夾 → 你在錯的地方開了存檔功能。告訴老師，並回 Part 1 重來。
> - Explorer 沒變色 → 確認 VS Code 開的資料夾，跟你 `git init` 的是同一個。

---

### Part 4：看看「我改了什麼」（`git status`）

打這一行、按 `Enter`：

```
git status
```

**完成後你會看到**：一段英文輸出，裡面會出現 `Untracked files:` 和你的 `index.html`。

**不用全部看懂。** 你只要找到一件事：**你的檔名 `index.html` 出現在裡面**（上週的 `messy.html` 也會在）。

> 🔍 把這次的輸出**截圖**，等一下要比對。

---

### Part 5：新增一個檔案，再看一次（這是今天最關鍵的一步）

1. 在左邊 Explorer 的空白處按**右鍵** → **New File**（新增檔案），命名為 **`about.html`**
2. 在裡面打一行字，例如 `<h1>關於我</h1>`
3. 存檔（`Ctrl + S`）
4. 回到 Terminal，**再打一次**：

```
git status
```

**完成後你會看到**：輸出**跟剛剛不一樣了**——清單裡多了一個名字。

**你的任務**：找出兩次輸出**差在哪裡**，用自己的話說出來（等一下老師會問你）。

> **如果不對怎麼辦**
> - 兩次輸出看起來一樣 → 看 Explorer 有沒有 `about.html`？沒有的話，它可能被建到別的資料夾裡了，重做第 1 步，在**最外層**的空白處按右鍵。
> - 檔名打成 `about.html.txt` 或 `about` → 在 Explorer 對它按右鍵 → **Rename**（重新命名），改成 `about.html`。

> 🤔 **為什麼不是改 `index.html`？** 你可以試試看：改 `index.html` 再 `git status`，輸出會**一模一樣**。因為存檔系統現在只知道「這裡有一個還沒存過的檔案」——它還沒幫你存過任何一版，當然也看不出你改了哪裡。**下週按下第一個存檔點之後，它就看得出來了。**

---

### 成功的樣子

- Terminal 看得到 `git init` 成功的訊息（`Initialized empty Git repository...`）
- Explorer 的檔案有顏色 / 標記
- 跑過**兩次** `git status`，而且你說得出兩次差在哪裡
- 截圖包含：**Terminal 裡看得到 `git init` 成功訊息 ＋ 兩次 `git status` 的輸出**
- 舉手告知老師 ✋

1. 用你自己的話說：`git init` 做了什麼？

## 老師筆記

（給老師的提示，不顯示給學生）

- **常見問題**：
  - Git 沒裝（`無法辨識 'git' 詞彙`）：**讓學生照 Part 2 的「🛠️ 自己把 Git 裝起來」自己裝**，老師不代裝；巡視時只回答「你看線索幾？」。最常見卡點是裝完沒把 VS Code 整個關掉重開（Terminal 吃不到新的 PATH），其次是下載到非官方網站。只有跳出系統管理員密碼時才由老師處理——**課前先確認學生帳號能不能自己安裝軟體**，不行的話這段改成老師課前統一裝。
  - 自己裝好 Git 的學生是很好的 TA 人選（剛走過一遍，最知道卡在哪）。
  - 在錯的資料夾 `git init`（路徑停在 `C:\Users\學生名>`）：關掉 Terminal、用「Open Folder」重開專案再開 Terminal；誤建的 `.git` 刪掉即可。
  - Part 5 一定要用「**New File**」，不能用「改 `index.html`」：`git init` 後還沒有任何 commit，所有檔案都是 untracked，改內容 `git status` 不會有任何變化。學生若自己去改 `index.html` 而困惑，正好接學習單的 🤔 說明，並預告 W04。
  - `git status` 看不懂：正常，只要找出**多出來的那個檔名**。
- **翻轉教育提示**：能用自己的話說出「為什麼改 `index.html` 看不出差別」的學生，理解已經超過本週目標，適合當 TA。
- **延伸挑戰**：刪掉 `about.html` 再 `git status`；或找出隱藏的 `.git` 資料夾，說說它跟「存檔系統」的關係。
