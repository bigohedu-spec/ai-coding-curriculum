## 任務 A｜幫專案裝上存檔系統 ⭐ 250 金幣

**任務 ID**：S5-W03-A

### 目標

把你 W01 建的專案資料夾，變成一個「**有存檔功能**」的專案，並且看得懂「我從上次之後改了什麼」。

---

### Part 1：打開你的專案 + 打開終端機

1. 打開 VS Code
2. **檔案 → 開啟資料夾** → 選你 W01 建的專案資料夾（⚠️ 一定要「開啟**資料夾**」）
3. 確認左邊側邊欄看得到 `index.html`
4. 打開終端機：按 `Ctrl` + `` ` ``（鍵盤左上角、數字 1 左邊那顆）

**完成後你會看到**：下方出現一塊黑色（或深色）的區域，最後一行是一串路徑，**結尾應該是你的專案資料夾名字**，後面有一個游標在閃。

> **如果不對怎麼辦**
> - 沒反應 → 上方選單 **終端機 → 新增終端機**。
> - 路徑結尾**不是**你的專案資料夾名字 → 你八成沒用「開啟資料夾」開專案。關掉終端機，重做第 2 步。**這一步錯了後面全部會錯，一定要先弄對。**

---

### Part 2：確認 Git 有沒有裝

在終端機打這一行，然後按 `Enter`：

```
git --version
```

**完成後你會看到**：跑出一行版本號，像 `git version 2.45.1`（數字不一樣沒關係）。

> **如果不對怎麼辦**：如果寫「**無法辨識 'git' 詞彙**」或「**不是內部或外部命令**」→ 這台電腦還沒裝 Git，**舉手告訴老師**，這需要老師處理。

---

### Part 3：開啟存檔功能（`git init`）

確認終端機路徑是你的專案資料夾之後，打這一行、按 `Enter`：

```
git init
```

**完成後你會看到**：

1. 終端機跑出一句 `Initialized empty Git repository in ...`（後面是你的資料夾路徑）
2. **左邊側邊欄的 `index.html` 變顏色了**（通常變綠色，後面多一個字母 `U`）

那個顏色的意思是：「這個檔案還沒被存進任何存檔點。」

> **如果不對怎麼辦**
> - 訊息裡的路徑**不是**你的專案資料夾 → 你在錯的地方開了存檔功能。告訴老師，並回 Part 1 重來。
> - 側邊欄沒變色 → 確認 VS Code 開的資料夾，跟你 `git init` 的是同一個。

---

### Part 4：看看「我改了什麼」（`git status`）

打這一行、按 `Enter`：

```
git status
```

**完成後你會看到**：一段英文輸出，裡面會出現 `Untracked files:` 和你的 `index.html`。

**不用全部看懂。** 你只要找到一件事：**你的檔名 `index.html` 出現在裡面**（上週的 `messy.html` 也會在）。

> 🔍 把這次的輸出**截圖**，等一下要比對。

---

### Part 5：新增一個檔案，再看一次（這是今天最關鍵的一步）

1. 在左邊側邊欄的空白處按**右鍵** → **新增檔案**，命名為 **`about.html`**
2. 在裡面打一行字，例如 `<h1>關於我</h1>`
3. 存檔（`Ctrl + S`）
4. 回到終端機，**再打一次**：

```
git status
```

**完成後你會看到**：輸出**跟剛剛不一樣了**——清單裡多了一個名字。

**你的任務**：找出兩次輸出**差在哪裡**，用自己的話說出來（等一下老師會問你）。

> **如果不對怎麼辦**
> - 兩次輸出看起來一樣 → 看側邊欄有沒有 `about.html`？沒有的話，它可能被建到別的資料夾裡了，重做第 1 步，在**最外層**的空白處按右鍵。
> - 檔名打成 `about.html.txt` 或 `about` → 在側邊欄對它按右鍵 → **重新命名**，改成 `about.html`。

> 🤔 **為什麼不是改 `index.html`？** 你可以試試看：改 `index.html` 再 `git status`，輸出會**一模一樣**。因為存檔系統現在只知道「這裡有一個還沒存過的檔案」——它還沒幫你存過任何一版，當然也看不出你改了哪裡。**下週按下第一個存檔點之後，它就看得出來了。**

---

### 成功的樣子

- 終端機看得到 `git init` 成功的訊息（`Initialized empty Git repository...`）
- 側邊欄的檔案有顏色 / 標記
- 跑過**兩次** `git status`，而且你說得出兩次差在哪裡
- 截圖包含：**終端機裡看得到 `git init` 成功訊息 ＋ 兩次 `git status` 的輸出**
- 舉手告知老師 ✋

## 老師筆記

（給老師的提示，不顯示給學生）

- **常見問題**：
  - Git 沒裝（`無法辨識 'git' 詞彙`）：課前每台電腦先跑一次 `git --version`，課中發生由老師處理。
  - 在錯的資料夾 `git init`（路徑停在 `C:\Users\學生名>`）：關掉終端機、用「開啟資料夾」重開專案再開終端機；誤建的 `.git` 刪掉即可。
  - Part 5 一定要用「**新增檔案**」，不能用「改 `index.html`」：`git init` 後還沒有任何 commit，所有檔案都是 untracked，改內容 `git status` 不會有任何變化。學生若自己去改 `index.html` 而困惑，正好接學習單的 🤔 說明，並預告 W04。
  - `git status` 看不懂：正常，只要找出**多出來的那個檔名**。
- **翻轉教育提示**：能用自己的話說出「為什麼改 `index.html` 看不出差別」的學生，理解已經超過本週目標，適合當 TA。
- **延伸挑戰**：刪掉 `about.html` 再 `git status`；或找出隱藏的 `.git` 資料夾，說說它跟「存檔系統」的關係。
