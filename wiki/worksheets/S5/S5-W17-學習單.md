# S5 W17｜進階功能二（自選）：由你決定專案的下一塊拼圖 學習單

> 模組三 進階功能（W13–W18）。W16 大家一起做「外部 API」；**W17 換你當家**——從下面的菜單挑**一個**你專案最需要的進階功能，自己做進去。

## 今天的冒險

到這週，你的專案**已經上線了**（GitHub Pages），而且**Supabase 資料庫也在線上**、你也做過**真實登入**——這代表你的功能不用再只存在自己電腦裡了。

今天沒有規定做哪個功能。**你是 PM，你決定「我的專案接下來最需要什麼」**，從菜單挑一個，用 Copilot Chat 幫你實作、整合進專案。

> **這週的新規矩（因為你的專案已經上線 + 有資料庫 + 有登入）**：
> - 需要「記住」的東西 → **存 Supabase，不要只存 localStorage**（這樣換裝置、重新登入都還在）。
> - 能綁使用者的 → **綁登入的使用者**（每個人看到自己的資料）。
> - 做完要能在**已部署的網站（https）**上運作——用到 API 一律**免金鑰、https**（第十四節）。

## 任務 A｜從菜單挑一個進階功能，做進你上線的專案 ⭐ 250 金幣

**目標（開放，自己決定）**：從下面菜單挑**一個跟你專案有關的**功能，用 Copilot Chat 實作、整合進專案，並確認它在**上線的網站**上運作。

> 每個功能都附一段**起手 prompt**——這是「起點」不是「答案」（第十七節）。你要把 `___` 換成你自己的檔名／表名／使用者 id，再依 Copilot 給的結果**測試、修正、迭代**。
> 用到 Supabase 時，把老師給你的 **Project URL＋anon 金鑰＋表名**貼給 Copilot（不要自己申請帳號、不要放 service_role 金鑰）。

**📌 起手 prompt 裡的 `___` 怎麼找**

| 要填的 | 是什麼 | 去哪找 |
|--------|--------|--------|
| **檔名**（`#file`、檔名） | 這個功能要改的檔案 | 看 VS Code 左邊「檔案總管」，找你一直在編輯的那個檔（通常是 `index.html`、`app.js`，遊戲則是 `game.js`）。在 Chat 打一個 `#` 會跳出檔案清單，直接選就好。 |
| **表名**（Supabase 表） | 資料要存進哪張雲端表 | **老師發的那張紙上**（Project URL、anon 金鑰、表名寫在一起）。沒有就跟老師要——**不要自己去 Supabase 開帳號**。 |
| **使用者 id** | 現在登入的是誰 | 你之前做「真實登入」時，登入成功後系統就記住了目前使用者。不知道它存在哪 → 直接問 Copilot：「我登入後，現在這位使用者的 id 存在哪個變數？怎麼在程式裡拿到？」 |
| **條件／清單**（例：成就的達成條件、隨機事件清單） | 這是**你自己決定的內容** | 不用「找」——照你專案想要的規則填（例如「破 10 關」「打敗 Boss」；事件清單自己想 3–5 個）。 |

> 找不到、或不確定填得對不對 → 先問 **Lab Terminal / Copilot**，再問同學，最後才問老師（第十七節求助順序）。

### 🅰️ 存 Supabase、綁使用者的功能（記得住、跨裝置）

**1. 使用者設定（深色模式／個人偏好）**
- 更新後做法：偏好存 Supabase（綁 user_id），登入後自動套用——不再只存 localStorage。
- 起手 prompt：
  > 「我的專案已上線、有登入（使用者 id 是 `___`），也接了 Supabase（URL/anon 金鑰／表名我貼給你）。幫我做一個深色模式切換鈕：使用者選了之後把 `theme` 存進 Supabase 的 `user_settings` 表（欄位 `user_id`、`theme`），下次他從任何裝置登入都自動套用上次的主題。」

**2. 成就系統**
- 更新後做法：達成條件解鎖成就 → 存 Supabase（綁 user_id），跨裝置保留。
- 起手 prompt：
  > 「幫我做成就系統：當使用者達成某條件（例如 `___`）就解鎖一個成就，寫進 Supabase 的 `achievements` 表（`user_id`、`achievement_id`、`unlocked_at`），並在頁面上顯示這位使用者已解鎖的成就清單。」

**3. 商店系統**
- 更新後做法：金幣餘額與已購道具存 Supabase（綁 user_id），買完即時更新畫面與雲端。
- 起手 prompt：
  > 「做一個商店：玩家用遊戲金幣買道具。把 `coins` 餘額和 `owned_items` 存在 Supabase（綁 `user_id`），按下購買時檢查金幣夠不夠、扣款、把道具加入 owned_items，並即時更新畫面。」

**4. 升級系統**
- 更新後做法：等級／經驗值存 Supabase（綁 user_id），達標升級並保存。
- 起手 prompt：
  > 「幫我做升級系統：使用者累積經驗值 `xp` 到門檻就升一級。把 `level`、`xp` 存在 Supabase（綁 `user_id`），每次變動就更新，畫面顯示目前等級和離下一級還差多少。」

**5. 雲端排行榜（取代本地排行榜）**
- 更新後做法：分數寫進 Supabase、讀出所有人的前幾名——因為資料庫在線上，大家看得到彼此。
- 起手 prompt：
  > 「我接了 Supabase（URL/anon 金鑰貼給你），有一個 `scores` 表（`name`、`score`）。遊戲結束時把玩家名字和分數寫進 `scores`，再讀出分數最高的前 10 名，顯示成排行榜。」

### 🅱️ 純前端 / 免金鑰 API 的功能（不需資料庫）

**6. 隨機事件**
- 做法：純前端 `Math.random()`，不需雲端。
- 起手 prompt：
  > 「幫我在遊戲每一回合用 `Math.random()` 從我給的事件清單（`___`）隨機挑一個事件，顯示事件說明並套用它的效果。」

**7. 多人輪流模式（同一台電腦）**
- 做法：用狀態管理記「輪到誰、各自分數」；想保留對戰結果可再寫進 Supabase。
- 起手 prompt：
  > 「幫我做兩個玩家在同一台電腦輪流的模式：用狀態管理記錄現在輪到哪位玩家、兩人各自的分數，畫面清楚顯示現在輪到誰、目前比分。」

**8. 題庫問答（免金鑰 API）**
- 做法：用 **Open Trivia DB**（免金鑰、https、已實測可用）抓題目做問答。
- 起手 prompt：
  > 「用免金鑰的 Open Trivia DB `https://opentdb.com/api.php?amount=10&type=multiple` 抓 10 題選擇題，做成問答遊戲：顯示題目和四個選項（正確答案和錯的要打散），答對加分。這要放在已部署的 https 網站，請確認不用金鑰。」

> 想做**天氣／匯率**之類的？那其實是你 W16 就會的「外部 API」技術，換個免金鑰的 https API 網址就好——不算新功能，但也歡迎自選。

**成功的樣子**：打開你**上線的專案**，這個新功能可以被實際操作；需要記住的資料**重新整理或換裝置後還在**（存進 Supabase 了）。

> 主線 250（單一任務 A250）。做完還有時間 → 把功能再迭代得更順、更好看，或加上「載入中…」「失敗提示」（進階，不計入 250）。

## 工具操作（照做，不用問老師）
1. **開啟 Copilot Chat**：`Ctrl+Shift+I`（Mac：`Cmd+Shift+I`）。
2. **用 `#file` 把要改的檔案帶進對話**（讓 Copilot 接到你現有專案），貼上你選的起手 prompt（填好 `___`）。
3. 用到 Supabase → 把老師給的 **URL＋anon 金鑰＋表名**貼給 Copilot。
4. **插入程式碼 → 存檔（`Ctrl+S`）→ Live Server 測試**。
5. **推上線**：`git add . && git commit -m "加功能" && git push`，到 GitHub Pages 的網址確認**線上版**也能用。
6. **截圖**線上運作畫面，舉手告知老師。

**如果不對怎麼辦**：
- 本機好、上線壞 → 多半是 API 不是 https 或要金鑰（換免金鑰 https），把 Console 紅字貼回 Chat。
- 資料沒存進去 → 檢查 Supabase 表名／欄位對不對、RLS 政策有沒有開，把錯誤訊息貼回 Chat。

## 老師筆記
- **本週重點是「選擇 + 用對持久化」**：專案已上線、DB 在線，學生要練「這個資料該存 Supabase 還是前端」的判斷，不是照抄功能。
- **工具政策（第十四節）**：雲端一律 Supabase（老師給 anon 金鑰、開 RLS）；API 一律免金鑰 https；**不要 Firebase、不要學生自己申請帳號、不要把 service_role 金鑰放前端**。
- **作品導向（第十二節）**：驗收看「功能在**他上線的專案**裡運作、資料真的進 Supabase」，不是本機 demo。
- **常見問題**：本機好上線壞（mixed content / 要金鑰）→ 換免金鑰 https；Supabase 寫不進去 → 檢查表名/欄位/RLS。
- **延伸挑戰**：把這週的功能和舊功能串起來（例如成就 + 雲端排行榜）。
