## 今天的冒險

從今天開始，你有了一個新的工作夥伴：**GitHub Copilot Chat**。它住在你的 VS Code 裡，可以回答你的程式問題、幫你寫程式、解釋錯誤。

今天你要做兩件事：第一，把 Copilot Chat 打開、試用，確認它能正常運作。第二，決定你這個學期要做的專案是什麼，寫下你的「**專案宣言**」。

這個宣言不需要很長，但它是你接下來十幾週所有任務的起點。

## 任務 A｜Copilot Chat 開箱 ⭐ 150 金幣

**任務 ID**：S5-W07-A

### 目標

把 Copilot Chat 打開，完成以下八個動作，每個動作截一張圖。

---

### 動作一：打開 Copilot Chat

按 `Ctrl+Shift+I`（Windows）或 `Cmd+Shift+I`（Mac）。

**完成的樣子**：VS Code 右側出現一個聊天視窗，頂端有 Copilot 的圖示，下方有輸入框。

**如果沒有出現**：
- 問 Lab Terminal：「VS Code 裡的 Copilot Chat 在哪裡？快捷鍵沒有反應怎麼辦？」

---

### 動作二：送出第一個問題

在 Copilot Chat 的輸入框裡，輸入這個問題，然後按 Enter：

```
你好，你是誰？你可以幫我做什麼？
```

**完成的樣子**：Copilot Chat 給出一段回覆，說明它的功能。

---

### 動作三：問一個程式問題

在 Copilot Chat 輸入：

```
JavaScript 的 console.log 是什麼？可以給我一個簡單的例子嗎？
```

**完成的樣子**：Copilot Chat 回覆了說明和程式碼範例。

---

### 動作四：在編輯器裡建立一個新 .js 檔案

1. 按 `Ctrl+N`（Windows）或 `Cmd+N`（Mac）新建一個檔案
2. 按 `Ctrl+S` 儲存，命名為 `test.js`，存在你的專案資料夾裡
3. 在第一行輸入：`console.log("Hello World");`
4. 按 `Ctrl+S` 儲存

**完成的樣子**：VS Code 編輯區有一個 `test.js`，裡面有你輸入的那行程式碼。

---

### 動作五：用 Copilot Chat 解釋你的程式碼

點一下 `test.js` 裡的任意位置，然後在 Copilot Chat 輸入：

```
請解釋我現在這個檔案裡的程式碼在做什麼
```

**完成的樣子**：Copilot Chat 解釋了 `console.log("Hello World")` 的意思。

---

### 動作六：讓 Copilot Chat 幫你寫程式碼

在 Copilot Chat 輸入：

```
幫我在這個 .js 檔案裡加一個函式，功能是把兩個數字加在一起，並且印出結果
```

**完成的樣子**：Copilot Chat 給出了一段 JavaScript 函式程式碼。

---

### 動作七：把 Copilot 給的程式碼貼進你的檔案

1. 點選 Copilot Chat 回覆裡的程式碼區塊右上方的「Copy」按鈕（或 `Ctrl+C`）
2. 在 `test.js` 裡，游標移到最後一行的下方
3. 按 `Ctrl+V` 貼上
4. 按 `Ctrl+S` 儲存

**完成的樣子**：`test.js` 裡有你原來的 `console.log`，加上 Copilot 給的函式。

---

### 動作八：在終端機執行你的程式

1. 按 `Ctrl+\`` 開啟 VS Code 內建終端機（或從上方選單 `Terminal → New Terminal`）
2. 終端機出現後，輸入：
   ```
   cd 你的專案資料夾名稱
   ```
   然後按 Enter（如果已經在正確的資料夾，可以跳過這步）
3. 輸入：
   ```
   node test.js
   ```
   然後按 Enter

**完成的樣子**：終端機印出 `Hello World` 和你函式的執行結果，沒有出現紅字錯誤。

**如果出現錯誤**：
- 問 Lab Terminal：「node test.js 執行時出現『command not found』，是什麼意思？」
- 或：「node test.js 執行出現紅字，錯誤訊息是 [貼上你的錯誤]，怎麼解決？」

---

### 完成條件

動作一到八，每個動作各截一張圖，共 8 張。

完成之後，請直接舉手告知老師。

## 任務 B｜寫下你的專案宣言 ⭐ 100 金幣

**任務 ID**：S5-W07-B

### 目標

決定你這個學期要做什麼專案，建立一個 `project-idea.md` 檔案，寫下你的**專案宣言**。

這個宣言是你整個學期的方向——你之後所有的函式、頁面、功能，都是在為這個專案服務。

---

### 想一想：你要做什麼？

你的專案必須是一個**網頁工具**——使用者可以在瀏覽器上操作，做到某件事。

幾個方向供你參考（但你可以做完全不同的東西）：
- 一個讓你輸入分數就能換算成等級的計算機
- 一個讓你記錄每天心情的小工具
- 一個可以隨機給你推薦今天要做什麼的頁面
- 一個讓你輸入數字就能算出某個結果的計算工具（任何你覺得有用的計算）

**判斷標準**：這個工具是你自己想用的嗎？如果你做完，你會每週打開它一次嗎？

---

### 建立 project-idea.md

1. 在 VS Code 裡按 `Ctrl+N` 新建檔案
2. 按 `Ctrl+S` 命名為 `project-idea.md`，存在你的專案資料夾裡
3. 按照以下格式填寫：

```markdown
# 我的專案

## 專案名稱
（你的專案叫什麼？）

## 一句話說明
（用一句話說明這個工具是做什麼用的）

## 使用者是誰？
（誰會用這個工具？是你自己、同學、還是某個特定的人？）

## 預計要做的三個功能
1. （功能一：說明這個功能讓使用者可以做什麼）
2. （功能二：說明這個功能讓使用者可以做什麼）
3. （功能三：說明這個功能讓使用者可以做什麼）
```

4. 填好之後，按 `Ctrl+S` 儲存

---

### 如果你遇到以下情況，可以這樣問：

> 「我想做一個網頁工具，但不知道要做什麼好。可以幫我想三個適合小學生做的網頁工具點子嗎？」

> 「我想做的是＿＿，這個用 JavaScript 可以做到嗎？大概要怎麼做？」

---

### 完成條件

1. `project-idea.md` 已建立，四個欄位都有填寫
2. 「預計要做的三個功能」每個都說清楚了使用者能做什麼
3. 老師口頭確認：「這個方向可行，接下來可以開始動手」

完成之後，請直接舉手告知老師。
