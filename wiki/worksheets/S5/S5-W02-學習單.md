## 任務 A｜幫工作室裝上神兵利器 ⭐ 250 金幣

**任務 ID**：S5-W02-A

### 目標

在 VS Code 裡安裝並**真的用過** Live Server 和 Prettier，再把 Copilot 安裝好（先不登入）。

---

### Part 0：打開你的專案

1. 打開 VS Code
2. 上方選單 **File → Open Folder**（檔案 → 開啟資料夾）→ 選你 W01 建的專案資料夾（例如 `kai-project`）
3. 確認左邊 Explorer（側邊欄）看得到 `index.html`

> **如果不對怎麼辦**：Explorer 空空的 → 你可能用了「Open File」。重做第 2 步，選「Open **Folder**」。

---

### Part 1：找到擴充套件商店

1. 看最左邊的 **Activity Bar**（活動列），找一個**四個小方塊、其中一塊飛出來**的圖示，點它
   （或直接按 `Ctrl + Shift + X`）
2. 左邊上方會出現一個搜尋框，寫著「Search Extensions in Marketplace」（在 Marketplace 中搜尋擴充功能）

**完成後你會看到**：左邊變成一個「商店」（**EXTENSIONS**），列出很多擴充套件，每個都有圖示、名字、作者和下載數。

> 🔍 **怎麼挑對的那一個？** 同名的套件可能很多個。看三件事：
> ① **名字完全一樣** ② **作者對**（下面每一個都會告訴你作者是誰）③ **下載數很多**（通常是幾百萬、幾千萬）

> **如果不對怎麼辦**：Activity Bar 找不到那個圖示 → 直接按 `Ctrl + Shift + X`，一定打得開。

---

### Part 2：神兵一 🔴 Live Server（自動更新）

**安裝**

1. 在商店搜尋框打 `Live Server`
2. 找到 **Live Server**，作者是 **Ritwick Dey**
3. 點藍色的 **Install**（安裝）按鈕

**完成後你會看到**：按鈕變成 **Uninstall**（解除安裝）或齒輪圖示，而且 **VS Code 最下面的 Status Bar（狀態列）右邊多了一個 `Go Live`**。

**試用（這是重點！）**

1. 回到 Explorer（Activity Bar 最上面那個圖示），點開 `index.html`
2. 點 Status Bar 右下角的 **`Go Live`**
3. 瀏覽器會自己打開你的網頁，網址列看起來像 `127.0.0.1:5500/index.html`
4. **把 VS Code 和瀏覽器左右並排**（拖視窗到螢幕左邊、右邊，或按 `Win + ←` / `Win + →`）
5. 在 `index.html` 裡改一句話 → 存檔（`Ctrl + S`）→ **眼睛盯著右邊的瀏覽器**

**完成後你會看到**：你一存檔，右邊的網頁**自己就變了**，不用再點兩下、不用按重新整理。

> **如果不對怎麼辦**
> - 跳出 Windows「防火牆」視窗 → 舉手告訴老師，這需要老師處理。
> - 沒看到 `Go Live` → 在 `index.html` 上按**右鍵** → 選 **Open with Live Server**，效果一樣。
> - 存檔了網頁卻沒變 → 確認瀏覽器網址開頭是 `127.0.0.1:5500`，而不是 `C:/Users/...`（後者是舊方法打開的，不會自動更新）。
> - 想關掉 → 點 Status Bar 右下角的 `Port : 5500`，它會變回 `Go Live`。

---

### Part 3：神兵二 🧹 Prettier（自動排版）

**安裝**

1. 回到商店（`Ctrl + Shift + X`），搜尋 `Prettier`
2. 找到 **Prettier - Code formatter**，作者是 **Prettier**
3. 點 **Install**（安裝）

**做一個「亂七八糟」的檔案來試**

1. 在 Explorer 按 **New File**（新增檔案），命名為 **`messy.html`**
2. 把下面這段**整段複製貼上**（它故意排得很亂）：

```html
<!DOCTYPE html><html><head><meta charset="utf-8"><title>亂亂的網頁</title></head><body><h1>我的房間</h1>
<ul><li>書桌</li>
      <li>床</li><li>
  衣櫃</li></ul>
         <p>這段程式碼好亂喔</p></body></html>
```

3. 按 **`Shift + Alt + F`**（Format Document，排版文件）

**完成後你會看到**：所有程式碼**自動縮排、一行一個**，變得整整齊齊。

> **如果不對怎麼辦**
> - 跳出「There are multiple formatters...」（有多個格式器，要用哪一個？）→ 點 **Configure...**（設定預設值）→ 選 **Prettier - Code formatter**，再按一次 `Shift + Alt + F`。
> - 按了沒反應 → 右鍵點編輯器空白處 → 選 **Format Document**（格式化文件）。

**讓它每次存檔都自動排好**

1. 按 `Ctrl + ,` 打開 **Settings**（設定）
2. 搜尋 `format on save` → 把 **Editor: Format On Save** **打勾**
3. 搜尋 `default formatter` → 在 **Editor: Default Formatter** 下拉選單選 **Prettier - Code formatter**
4. 回到 `messy.html`，**故意把幾行縮排弄亂**，然後 `Ctrl + S`

**完成後你會看到**：一按存檔，程式碼就自己排好了。

---

### Part 4：神兵三 🤖 GitHub Copilot（先請進門）

1. 回到商店，搜尋 `GitHub Copilot`
2. 找到 **GitHub Copilot Chat**，作者是 **GitHub**（名字旁邊有藍色勾勾 ✓）
3. 點 **Install**（安裝）

**完成後你會看到**：Activity Bar 或 VS Code **最上方的 Title Bar（標題列）**多了一個 Copilot 小圖示（像一張戴護目鏡的小臉）。

> ⚠️ **今天先不要登入！**
> 安裝完可能會跳出「Sign in」「Sign in to use Copilot」之類的提示——**直接按右上角的 ✕ 關掉**。
> Copilot 要用**課程統一的帳號**開通，W05 老師會帶大家一起做。今天先把它請進門就好。

> **如果不對怎麼辦**
> - 一搜就看到它已經是「Installed」（已安裝）或「Disabled」（停用）→ 你的 VS Code 本來就內建了，**不用再裝**，直接進 Part 5。
> - 搜到很多個 Copilot 很亂 → 只認作者 **GitHub**、有藍勾勾的那個。

---

### Part 5：盤點你的神兵（已安裝清單）

1. 打開商店（`Ctrl + Shift + X`）
2. 把搜尋框**清空**，在搜尋框打 `@installed`
3. 你會看到**所有已安裝的擴充套件**

**檢查表**——找到一個打一個勾：

- [ ] Live Server（Ritwick Dey）
- [ ] Prettier - Code formatter（Prettier）
- [ ] GitHub Copilot Chat（GitHub）

**完成後你會看到**：三個都在清單裡，而且**沒有**顯示「Disabled」（已停用）。

> **如果不對怎麼辦**：某一個寫「Disabled」→ 點它 → 按 **Enable**（啟用）。

---

### 成功的樣子

- 用 Live Server 開著網頁，**存檔後瀏覽器自己更新**
- `messy.html` 被 Prettier 排得整整齊齊，而且**存檔就會自動排版**
- Copilot 已安裝、**還沒登入**
- 截圖包含：**`@installed` 清單（看得到三個套件）＋ 左右並排的 VS Code 和 Live Server 瀏覽器畫面（網址是 `127.0.0.1:5500`）**

## 本週學習重點

1. 裝擴充套件之前，要先看名字、作者、下載數。
2. Live Server 讓你一存檔，瀏覽器的網頁自己更新。
3. Prettier 可以把亂亂的程式碼排整齊，存檔也能自動排。
4. Copilot 今天只安裝、不登入，之後老師會帶大家開通。

## 老師筆記

（給老師的提示，不顯示給學生）

- **常見問題**：
  - Live Server 第一次啟動會觸發 Windows 防火牆提示，需教師權限；建議課前在每台電腦先跑一次。
  - 學生裝錯同名套件（例如其他作者的 Live Server、Prettier 的 fork）——口頭只問「作者是誰」。
  - `Shift + Alt + F` 第一次會跳「選擇預設格式器」，學生常直接按 Esc 導致沒反應；Part 3 已寫處理方式。
  - Copilot：新版 VS Code 可能已內建 Copilot Chat、裝完會跳登入提示。**本週一律不登入**，W05 用課程統一帳號開通（學生未滿 13 歲，不可自行註冊 GitHub；見 CLAUDE.md 第十四、十六節）。
- **翻轉教育提示**：Part 2 結束時能說出「網址為什麼是 127.0.0.1」的學生，通常理解夠深，適合當 TA。
- **延伸挑戰**：讓快的學生比較「點兩下打開」和「Live Server 打開」的網址差別，並向全班說明一次。
