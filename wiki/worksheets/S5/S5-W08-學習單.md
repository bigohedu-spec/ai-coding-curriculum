## 今天的冒險

上週你決定了你的專案，也列出了三個預計要做的功能。

今天的目標：**把這三個功能，一個一個寫成 JavaScript 函式，讓它們可以在終端機執行**。這是你的專案第一次真正「動起來」——雖然還不是在瀏覽器上，但每個函式都會產生真實的輸出。

你會用到 Copilot Chat 幫你寫程式。你的工作是：告訴它你要做什麼，理解它給你的程式碼，測試它能不能動，然後整合進你的專案檔案。

## 開始前：設定你的工作環境

1. 打開 VS Code，用 `File → Open Folder` 開啟你的**專案資料夾**
2. 打開 `project-idea.md`，看一下你的三個預計功能是什麼
3. 確認專案資料夾裡有一個 `.js` 檔案（上週的 `test.js`，或建一個新的 `main.js`）
4. 打開 VS Code 內建終端機（`Ctrl+\``）
5. 在終端機輸入以下指令，確認你在正確的資料夾：
   ```
   pwd
   ```
   終端機會印出你現在所在的路徑。確認路徑的最後一段是你的專案資料夾名稱。
   如果不對，用 `cd 資料夾名稱` 切換過去。

## 任務 A｜功能一：寫出你的第一個函式 ⭐ 100 金幣

**任務 ID**：S5-W08-A

### 目標

把你的**第一個預計功能**，用 Copilot Chat 寫成一個 JavaScript 函式，並且在終端機成功執行。

---

### 步驟

**步驟一：在 Copilot Chat 描述你要的函式**

打開 Copilot Chat（`Ctrl+Shift+I`），輸入你的請求。參考格式：

```
我在做一個＿＿的工具。我需要一個 JavaScript 函式，
功能是＿＿。請幫我寫這個函式，並且在最後加上一行呼叫它的程式碼，
讓我可以直接用 node 執行看到結果。
```

把 `＿＿` 換成你的專案說明和功能描述。

**步驟二：把程式碼貼進你的 .js 檔案**

1. 點選 Copilot Chat 回覆裡的程式碼，點「Copy」複製
2. 在你的 `.js` 檔案裡，找到一個空白的地方貼上
3. 按 `Ctrl+S` 儲存

**步驟三：在終端機執行**

在終端機輸入：

```
node 你的檔案名稱.js
```

例如你的檔案叫 `main.js`，就輸入 `node main.js`，然後按 Enter。

**完成的樣子**：終端機印出了你的函式的執行結果，沒有紅字錯誤。

**如果出現錯誤**：
- 把紅字的錯誤訊息複製，在 Copilot Chat 輸入：
  ```
  我執行 node 時出現這個錯誤：[貼上錯誤訊息]，是什麼問題？
  ```
- 根據 Copilot Chat 的說明修改程式碼，再試一次

---

### 完成條件

1. `.js` 檔案裡有你的第一個函式
2. 終端機執行 `node 你的檔案.js` 後，印出預期的結果，沒有錯誤

完成之後，請直接舉手告知老師。

## 任務 B｜功能二：加上第二個函式 ⭐ 80 金幣

**任務 ID**：S5-W08-B

### 目標

用同樣的方式，把**第二個預計功能**也寫成函式，加進同一個 `.js` 檔案。

---

### 注意事項

- 把兩個函式都放在同一個 `.js` 檔案裡
- 每個函式後面都要有一行呼叫它的程式碼（`函式名稱(測試參數)`），這樣執行時才能看到輸出
- 執行時，兩個函式的結果都會印出來

**如果你遇到以下情況，可以這樣問：**

> 「我在同一個 .js 檔案裡有兩個函式，執行 node 時兩個的結果都要印出來，怎麼確認？」

> 「我的第二個函式需要用到第一個函式的結果，可以這樣做嗎？怎麼寫？」

---

### 完成條件

1. `.js` 檔案裡有兩個函式，都有對應的呼叫程式碼
2. 終端機執行後，兩個函式的結果都印出來，沒有錯誤

完成之後，請直接舉手告知老師。

## 任務 D｜整理你的程式碼（進階） ⭐ 50 金幣（進階加碼，不計入 250）

**任務 ID**：S5-W08-D

### 目標

你的三個函式現在可以動了。任務 D 是讓你的程式碼更整齊、更好讀。

選其中一個方向（或多個）：

**方向一：幫每個函式加上說明注釋**

在每個函式上方加一段注釋，說明這個函式做什麼：

```javascript
// 功能：把輸入的分數換算成 A/B/C 等級
// 輸入：score（數字）
// 輸出：等級字串（'A'、'B'、'C'）
function gradeScore(score) {
  ...
}
```

**方向二：讓輸出更清楚**

把 `console.log` 改成更清楚的格式，讓人一眼就知道是哪個函式的結果：

```javascript
console.log("=== 功能一結果 ===");
console.log(myFunction(10));
```

---

### 如果你遇到以下情況，可以這樣問：

> 「JavaScript 函式的注釋有標準格式嗎？JSDoc 是什麼？」

> 「我想讓終端機的輸出更好看，console.log 可以輸出顏色嗎？」

---

### 完成條件

1. 三個函式都有說明注釋，或輸出格式已整理清楚
2. 終端機執行仍然正常，三個結果都印出來

完成之後，請直接舉手告知老師。
