## 闖關進度

- [ ] 🔍 **回顧**：答對「我們最後打倒了誰？」

- [ ] 🖱️ **② 我學會了**：5 個小回顧 ☐左鍵 ☐右鍵 ☐滾輪 ☐拖拉 ☐WASD
- [ ] 🎤 **③ 問問 AI**：挑一種海洋生物，**按住麥克風念出問題** → 問滿 **5 題**
- [ ] 🖨️ **小成品**：看自己的那一頁，列印／存 PDF
- [ ] 🙋 **上台發表**：說一句「我的海底冒險」

## 老師筆記（對照實作）

- **頁面**：`/games/p1u-w06-showcase.html`（學習單 `ws_p1u_w06`「海底小英雄・成果發表」）。不是 canvas 遊戲，是 DOM 單頁，上方步驟條：回顧 → 貼王城 → 學會了 → 問 AI → 小成品；小成品頁有「列印／存 PDF」與「上台發表 ▶」。做完再進來會直接看到上次的小成品。
- **② 我學會了**（5 項，判得寬鬆）：左鍵點亮 3 顆寶石（＝打）、右鍵點盾牌（＝擋住，平板可長按）、滾輪把魔法充滿（＝放魔法）、把「小英雄」拖進王城、用 WASD／方向鍵把潛水員移到金色圈。
