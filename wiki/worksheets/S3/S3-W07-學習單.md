## 今天的任務

偉大的衝浪手凱洛要在親子海灘祭挑戰最漂亮的一道浪。他只對浪音機 Riff 說：

> **「幫我做出完美的衝浪搖滾！」**

Riff 卻不知道「完美」是什麼。你是**浪潮音樂規格師**，要讓同一份 Prompt 依序擁有：

> **做什麼＋怎麼做＋不能做什麼＋目標＝規格**

每次送出後，Lab Music 會回傳一段試聽音軌。最後，你還要依正式變更單修改不適合親子觀眾的語氣。

## 開始前｜四道浪花規格

同一份 Prompt 會一直長大：

```text
A 加入「做什麼」
→ B 保留 A，再加入「怎麼做」
→ C 保留 A、B，再加入「不能做什麼」
→ D 保留 A、B、C，再加入「目標」
→ E 保留四種需求，只修改衝突的語氣
```

每題都是：**讀凱洛的對白 → 圈出關鍵資訊 → 分到正確空格 → 送出 → 聽音軌**。答題卡會保存舊內容，E 才開放完整 Prompt。

凱洛會越來越興奮，重要資料也會藏得越來越深：

```text
A 關鍵詞有加粗
→ B 只告訴你四個尋找方向
→ C 只告訴你要找四個禁止聲音
→ D 只留下「誰、場合、感受」三個問題
```

不要把凱洛整段喊話貼進 Prompt。只取能回答空格的關鍵資訊。

## 任務 A｜決定要做什麼

**任務 ID**：S3-W07-A

### 目前問題

Riff 只知道要做「很厲害的音樂」，連曲名、音樂類型與用途都不清楚。

### 凱洛的對白｜做什麼

凱洛把衝浪板立好，還能慢慢說話：

> **凱洛：**「先穩穩來。曲名叫 **追浪時刻**，我要一段 **30 秒衝浪搖滾**，拿來當 **衝浪手出場音樂**。好，這樣夠清楚吧？」

### 抓重點支架 A

這一題先幫你把三個答案加粗。判斷它們分別是曲名、音樂類型，還是用途；不要複製其他語助詞。

### 可複製追加 Prompt｜3 個空格

```text
做什麼：請製作名為〔曲名〕的〔音樂類型〕，作為〔用途〕。
```

### 完成成果

替換三個空格並送出，取得試聽音軌 A。先聽出已經做對什麼，再找下一個缺口。

## 任務 B｜安排音樂怎麼演奏

**任務 ID**：S3-W07-B

### 從音軌 A 找缺口

音樂類型已經正確，但主旋律、效果、節奏與結尾都很模糊。Riff 還不知道怎麼演奏。

### 凱洛的對白｜怎麼做

凱洛聽見第一段音軌，眼睛立刻亮了起來，講話速度開始加快：

> **凱洛：**「喔喔，浪開始動了！主旋律一定要用清脆電吉他，像浪尖在發亮！聲音效果再加上海浪般的殘響，下面要有快速穩定的鼓點與低音推著我衝，最後用有力的吉他收尾！快快快，下一道浪要來了！」

### 抓重點支架 B

這次不再加粗。從對白找出四段資料：**主旋律、聲音效果、節奏、結尾**。

### 可複製追加 Prompt｜4 個空格

```text
做什麼：[任務A留下的需求]
怎麼做：以〔主旋律〕演奏，加入〔聲音效果〕，搭配〔節奏〕，最後用〔結尾〕完成。
```

### 完成成果

保留 A，追加本題一行並取得試聽音軌 B。這一題只處理音樂怎麼演奏。

## 任務 C｜擋住不適合的聲音

**任務 ID**：S3-W07-C

### 從音軌 B 找缺口

主旋律與節奏清楚了，卻混進人聲、悲傷鋼琴、電子舞曲節拍，途中還突然安靜。要明確說出不能出現的內容。

### 凱洛的對白｜不能做什麼

音軌 B 一播出，凱洛抱著衝浪板原地跳了起來，語速比鼓點還快：

> **凱洛：**「停停停停——我不要人聲歌唱！那個悲傷鋼琴又是從哪裡漂來的？電子舞曲節拍不要追著我的浪跑！還有，絕對不准突然靜音，我衝到浪頂時不能整片海突然沒聲音啊啊啊！」

### 抓重點支架 C

凱洛的喊話裡藏著 **4 個不能出現的聲音**。自己圈出來，再依出現順序放進四個空格。

### 可複製追加 Prompt｜4 個空格

```text
做什麼：[任務A留下的需求]
怎麼做：[任務B留下的需求]
不能做什麼：不要有〔禁止一〕、〔禁止二〕、〔禁止三〕或〔禁止四〕。
```

### 完成成果

保留 A、B，追加本題一行並取得試聽音軌 C。這一題只檢查四項禁止內容。

## 任務 D｜對準衝浪手與觀眾

**任務 ID**：S3-W07-D

### 從音軌 C 找缺口

曲子乾淨完整，卻沒有說要給誰、在哪裡使用，也沒有指定希望觀眾感受到什麼。

### 凱洛的對白｜目標

音軌 C 乾淨多了。遠方第一道大浪升起，凱洛興奮到一邊揮舞衝浪板、一邊對 Riff 大喊：

> **凱洛：**「浪來了浪來了浪來了——先記住，是給偉大的衝浪手凱洛，就是我！在親子海灘祭出場時用！我要讓親子觀眾感到緊張壓迫，像巨浪從頭頂轟隆隆蓋下來一樣！就是這個！一定超強！衝啊啊啊！」

### 抓重點支架 D

不提供欄位清單了。只問自己三件事：**給誰使用？在哪個場合？希望觀眾有什麼感受？**

### 可複製追加 Prompt｜3 個空格

```text
做什麼：[任務A留下的需求]
怎麼做：[任務B留下的需求]
不能做什麼：[任務C留下的需求]
目標：給〔使用者〕在〔使用場合〕時使用，並〔感受語氣〕。
```

### 完成成果

保留前三行，追加目標並取得試聽音軌 D。四種需求已經齊全，但還要聽聽語氣是否適合真正的觀眾。

## 任務 E｜改成適合親子觀眾的語氣

**任務 ID**：S3-W07-E

### 音軌 D｜衝突線索

四種需求都有了，但音樂讓現場變得過度緊張。小朋友不敢靠近，凱洛也覺得這不像陽光海灘上的出場曲。

### 凱洛的緊急改口｜正式變更

凱洛看到小朋友躲到遮陽傘後面，終於發現自己興奮過頭。他踩著沙子衝回混音台：

> **凱洛：**「不對不對不對！我剛才把『讓親子觀眾感到緊張壓迫』塞進目標，難怪大家都不敢靠近！正式改成『讓親子觀眾感到陽光、興奮又安心』！只換目標裡這一段，其他全部保留——快快快，浪已經來了！」

### 本題操作｜替換舊語氣

打開 A～D 的完整 Prompt，比較凱洛先說的舊感受與後來改口的新感受。在「目標」只替換這一段，不要增加第五種需求，也不要重打其他三行。

### 送出前檢查

- [ ] 做什麼、怎麼做、不能做什麼、目標都還在。
- [ ] 目標只留下新的感受語氣。
- [ ] 其他已通過內容沒有被刪掉。

### 完成成果

送出修訂後的完整規格，取得完美音軌 E。

## 卡住了嗎？

- 不知道要補什麼 → 先聽「已經做對什麼、還缺什麼」。
- 找不到上一版 Prompt → 回到右側已完成的規格卡，不要重打。
- 空格不知道放哪裡 → 對照同名欄位，一次處理一格。
- E 題卡住 → 查看凱洛的緊急改口，比較引號裡的舊感受與新感受。
- 系統退件 → 只修正它指出的那一類缺漏，其他內容先保留。
- 音軌沒有載入 → 保留 Prompt 與通過紀錄，查看同版文字試聽回報並告訴老師。
