## 開始前｜同一份 Prompt 會一直長大

四種需求各自回答一個問題：

| 需求 | 它回答什麼？ | 這週的例子 |
|---|---|---|
| **做什麼** | 要產出什麼？ | 建造月面基地 |
| **怎麼做** | 怎麼排、怎麼連、放哪裡？ | 艙體位置與連接 |
| **不能做什麼** | 什麼不准出現？ | 不得有電線或火焰 |
| **目標** | 給誰？希望有什麼效果？ | 讓救援隊快速進入 |

> **別只看關鍵字**：「入口放正面」是**怎麼做**；「讓救援隊快速進入」是**目標**。

Prompt 不會重新開始：

```text
A 加入「做什麼」
→ B 保留 A，再加入「怎麼做」
→ C 保留 A、B，再加入「不能做什麼」
→ D 保留 A、B、C，再加入「目標」
→ E 檢查四種需求，修改互相衝突的舊指令
```

每題先判斷：**上版修好什麼 → 現在還錯什麼 → 屬於哪種需求 → 這題只修哪段**。

操作時：**保留對的 → 填本題 → 送出 → 看新影片**。E 才開放整份 Prompt。

## 卡住了嗎？

- 不知道要補什麼 → 看施工影片，先找「做對什麼、還缺什麼」。
- 找不到上一版 Prompt → 回到右側已完成的規格卡，不要重打前面內容。

- E 題卡住 → 直接查看星野隊長的正式變更單。
- 系統退件 → 只修改它指出的那一類缺漏，其他已通過內容先保留。
