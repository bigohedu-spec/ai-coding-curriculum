## 開始前｜需求與規格

一種需求，只回答一個問題：

| 需求    | 要回答的問題           |
| ----- | ---------------- |
| 做什麼   | 要 AI 產生什麼？主體是什麼？ |
| 怎麼做   | 畫面如何安排？部件怎麼組合？   |
| 不能做什麼 | 哪些錯誤或危險不能出現？     |
| 目標    | 給誰使用？希望帶來什麼效果？   |


解題技巧：

```text
看故事開場 → 看洛可生成的錯誤結果 → 聽村長說明目前狀況
→ 複製村長指定的內容 → 貼到相同名稱的空格
→ 檢查排版 → 取得並觀察本題藍圖
```

每完成一題，會回傳下一張藍圖，右側也會保存你寫過的內容。下一題只要接著補新的需求，不必重打前面的內容。

看到 `〔填入……〕` 時，先複製整段 Prompt，再把村長口中相同名稱的內容貼進空格。A～D 逐格貼入；E 把 A～D 的內容貼到正確標題下。

排版規則：**一種需求放一行，需求名稱放前面，關鍵內容放在冒號後面。**

## 卡住了嗎？

- 分不清需求 → 回到「需求與規格」，看每一種需求回答哪個問題。
- A～C 不知道怎麼開始 → 先找村長說出的相同欄位名稱，再複製欄位後面的內容。
- D 卡住 → 找村長說出的使用者、要辨認的內容與希望感受，再貼進三個同名空格。
- E 卡住 → 回到 A～D 通關紀錄逐段複製，再貼到相同名稱的標題後面。
- 不知道錯在哪裡 → 比較框內提示詞和 Lab Tool 回傳的魔法藍圖，找出它還在猜什麼。
- E 題缺內容 → 查看右側 A～D 已取得的需求卡。
- 右側說少了一種需求 → 只補那一種，不要刪掉其他內容。
- Lab Tool 沒有回圖 → 保留完整規格並告訴老師，不必重新輸入。
