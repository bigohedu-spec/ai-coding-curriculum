# Learning Progression｜四年學習進展路徑

## 定義

這個課程採用「技能螺旋上升」設計：同樣的技能（例如 Prompt、創作、程式邏輯）在不同學期用更高的要求重現，而非一次教完。學生不會感覺在重複，但實際上在每個螺旋層都加深了掌握度。

---

## 四年技能地圖

### Prompt Engineering 螺旋

| 學期 | 層級 | 技能點 |
|------|------|-------|
| S1 小三上 | 入門 | 三要素格式（角色＋背景＋問題） |
| S2 小三下 | 進階 | 格式控制、字數控制、語氣控制 |
| S3 小四上 | 任務化 | 任務卡重點 → 提示詞 → AI 評審修正 |
| S4 小四下 | 創作級 | 完整作品 Prompt 流程 |
| S5 小五上 | 程式輔助 | Copilot Prompt、程式說明 Prompt |
| S6–S8 | 產品級 | 驅動完整專案的 Prompt 策略 |

### 創作能力螺旋

| 學期 | 層級 | 產出 |
|------|------|------|
| S1 小三上 | 初稿 | 興趣相關的圖文作品 |
| S2 小三下 | 完整作品 | AI 繪本（企劃→腳本→插圖→排版） |
| S3 小四上 | 任務素材 | 依規格產出文字、圖片、音樂、影片小素材，並通過 AI 評審 |
| S4 小四下 | 數位產品 | HTML/CSS 頁面 + AI 繪本 |
| S5–S6 | 互動作品 | JavaScript 互動網頁 |
| S7–S8 | 真實產品 | 上架、市場驗證、作品集 |

### 技術能力螺旋

| 學期 | 層級 | 技術點 |
|------|------|-------|
| S1–S2 小三 | 工具使用者 | 用 AI 工具完成指定任務 |
| S3 小四上 | 任務執行者 | 讀任務卡、選工具、填學習單、送 AI 評審、依回饋修正 |
| S3 小四上（後段） | VS Code 前置 | 開資料夾、開 HTML、改文字/圖片、看瀏覽器結果、描述錯誤 |
| S4 小四下 | HTML/CSS | 靜態網頁製作 |
| S5 小五上 | VS Code 工作流 | VS Code + GitHub Copilot + JavaScript |
| S6 小五下 | AI 加速開發 | 完整互動作品 |
| S7–S8 小六 | 產品思維 | 專案管理、上架、市場驗證 |

---

## 興趣主軸（貫穿四年）

```
S1 W17 → 建立「興趣清單」（五件喜歡的事）
S1 W18 → 第一個興趣相關作品
S2     → 把興趣做成繪本
S3     → 把興趣拆成可評審的素材任務
S4     → 把興趣做成網頁 / 完整數位作品
S5–S6  → 把興趣做成互動作品
S7     → 把興趣做成真實產品上架
S8     → 從興趣中嘗試獲利
```

這條主軸從第一學期開始，絕對不能在課程改版時切斷。
