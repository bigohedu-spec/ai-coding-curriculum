# Feature Menu｜功能菜單

## 定義

功能菜單是學生在 S5 模組二起用來選擇「下一個要做什麼功能」的參考清單。每個功能都是學生專案的一塊積木，學生從菜單裡選一個，然後用 [[vibe-coding]] 的方式讓 Copilot Chat 幫他實作出來。

---

## 首次出現

- 學期：[[S5-小五上-VSCode工作流]]
- 週次：W5（認識功能菜單）、W7（選定初始功能清單）

---

## 使用規則

1. 學生的專案方向決定優先參考哪個軌（Web App 軌 / 遊戲軌）
2. 兩個軌的功能**可以混搭**——做遊戲的學生也可以加登入系統
3. 功能的**技術複雜度沒有上限**——學生可以嘗試任何功能，由 Copilot Chat 承擔實作難度
4. 老師不強制指定哪個功能，但可以在學生卡太久時建議先跳過、改做其他功能
5. 每個功能完成後，可以繼續往更難的版本演進（例如：假登入 → Firebase 真實登入）

## Web App 軌功能菜單

### 基礎功能（W7–W12 首選）

| 功能 | 說明 | 難度 | 技術關鍵字 |
|------|------|------|-----------|
| **Welcome Page / Landing Page** | 專案介紹頁，說明這個 app 是什麼、能做什麼 | ⭐ | HTML + CSS |
| **登入表單（假登入）** | 帳號密碼輸入框，比對預設帳密，成功跳頁 | ⭐⭐ | HTML form + JavaScript |
| **儀表板（Dashboard）** | 登入後的主畫面，顯示使用者資訊和主要功能入口 | ⭐⭐ | HTML + CSS grid/flex |
| **資料輸入表單** | 讓使用者填寫資料並顯示出來（例如待辦事項、筆記） | ⭐⭐ | HTML form + JavaScript |
| **清單功能** | 顯示一串資料，可以新增、刪除 | ⭐⭐ | JavaScript array + DOM |
| **搜尋功能** | 在現有資料裡即時搜尋並顯示結果 | ⭐⭐⭐ | JavaScript filter |
| **Navigation Bar** | 讓所有頁面都有導航列，可以在頁面間切換 | ⭐⭐ | HTML nav + CSS |
| **Modal / Popup** | 點按鈕後出現彈出視窗 | ⭐⭐ | CSS + JavaScript |

### 進階功能（W13–W18）

| 功能 | 說明 | 難度 | 技術關鍵字 |
|------|------|------|-----------|
| **資料持久化（localStorage）** | 使用者關掉頁面再打開，資料還在 | ⭐⭐ | localStorage |
| **使用者設定儲存** | 記住使用者的偏好（深色模式、語言、名字等） | ⭐⭐ | localStorage |
| **連接外部 API** | 呼叫免費 API 取得真實資料顯示在頁面上 | ⭐⭐⭐ | fetch() + JSON |
| **天氣功能** | 呼叫天氣 API，顯示今日天氣 | ⭐⭐⭐ | OpenWeatherMap API |
| **匯率換算** | 呼叫匯率 API，讓使用者換算貨幣 | ⭐⭐⭐ | 匯率 API |
| **隨機名言 / 隨機圖片** | 每次刷新顯示不同內容 | ⭐⭐ | Public API（quotable.io 等） |
| **真實登入系統（Firebase Auth）** | 真正的帳號系統，可以註冊、登入、登出 | ⭐⭐⭐⭐ | Firebase Authentication |
| **雲端資料庫（Firebase / Supabase）** | 資料存在雲端，不同裝置都能讀取 | ⭐⭐⭐⭐ | Firestore / Supabase |
| **即時更新** | 資料更新時頁面自動更新，不需要重新整理 | ⭐⭐⭐⭐ | Firebase Realtime Database |

## 遊戲軌功能菜單

### 基礎功能（W7–W12 首選）

| 功能 | 說明 | 難度 | 技術關鍵字 |
|------|------|------|-----------|
| **開始畫面（Title Screen）** | 遊戲標題、開始按鈕、簡短說明 | ⭐ | HTML + CSS |
| **關卡選擇畫面** | 顯示所有關卡，點擊進入對應關卡 | ⭐⭐ | HTML + CSS grid + JavaScript |
| **遊戲主畫面** | 核心玩法的介面（視遊戲類型決定） | ⭐⭐⭐ | 視遊戲類型 |
| **計分系統** | 追蹤並顯示分數 | ⭐⭐ | JavaScript variable + DOM |
| **倒數計時器** | 遊戲限時，時間到就結束 | ⭐⭐ | JavaScript setInterval |
| **生命值 / 血條** | 顯示玩家生命值，受傷減少 | ⭐⭐ | JavaScript + CSS |
| **結束畫面** | 遊戲結束後顯示分數和重新開始按鈕 | ⭐⭐ | JavaScript condition + DOM |

### 進階功能（W13–W18）

| 功能 | 說明 | 難度 | 技術關鍵字 |
|------|------|------|-----------|
| **存檔系統** | 存下玩家進度，關掉重開還在 | ⭐⭐ | localStorage |
| **商店系統** | 玩家可以用金幣購買道具或升級 | ⭐⭐⭐ | JavaScript object + localStorage |

| **成就系統** | 完成特定動作後解鎖成就並顯示 | ⭐⭐⭐ | JavaScript + localStorage |

| **隨機事件** | 每次遊玩有不同的隨機元素 | ⭐⭐ | Math.random() |
| **多人輪流模式** | 兩個玩家輪流在同一台電腦操作 | ⭐⭐⭐ | JavaScript state management |
| **API 整合** | 呼叫外部 API 取得遊戲內容（例如題庫） | ⭐⭐⭐ | fetch() |

## 選功能的建議策略

### 第一次選（W7–W8）
從自己的專案方向挑一個 **⭐⭐ 難度** 的功能開始。太簡單的功能 30 分鐘做完沒成就感；太難的功能會卡太久失去動力。

### 之後的每個週次
每週新功能的難度可以稍微提升，但每週至少有一個功能完成並在瀏覽器上可以操作。

### 遇到功能做不出來
1. 先在 Copilot Chat 裡換一種方式描述
2. 問 Lab Terminal「這個功能大概要用到什麼技術？」
3. 請老師幫忙判斷「這個功能是不是超出目前的可行範圍？」
4. 如果真的太難，換一個稍微簡單的功能，下學期再回來挑戰這個
