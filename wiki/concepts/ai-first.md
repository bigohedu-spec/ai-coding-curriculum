# AI First｜AI 優先原則

## 定義

學生遇到任何問題時，第一步是問 AI，而不是舉手問老師或等待老師說明。這個原則培養學生主動運用 AI 解決問題的習慣，也是這堂課最核心的能力訓練。

---

## Lab Terminal

課堂中統一使用 **Lab Terminal** 作為主要的 AI 提問工具。詳細說明見 [[lab-terminal]]。

| 項目 | 說明 |
|------|------|
| 定義 | AI 助理 + 遊戲平台 + 點數商店的整合系統（非單純查詢工具） |
| AI 功能 | 透過 API 串接 AI 模型，不需帳號登入，老師可監控對話記錄 |
| 遊戲功能 | 內建學習遊戲、Gacha 抽卡、商店，與 Minecraft 共用點數系統 |
| 取代對象 | 所有「只是為了提問」的 ChatGPT 或 Claude 使用場合 |
| 保留對象 | 無。舊版保留的「工具比較任務」（例如 S2-W08 雙 AI 大比拼）已於 2026-08-20 取消，S2 模組二也在 Lab Terminal 內完成（見下方） |

## 工具使用判斷規則

設計或審視任務時，遵照以下規則決定使用哪個工具：

```
學生需要「問問題、得到答案」
→ 使用 Lab Terminal

學生需要「比較不同 AI 的差異」
→ 仍用 Lab Terminal（後端路由多個真實模型，學生不需帳號；目前上線只接 GPT）

學生需要「生成圖片」
→ 使用 Lab Image

學生需要「寫程式」
→ 使用 VS Code + GitHub Copilot

學生需要「生成音樂/影片」
→ 使用 Lab Music / Lab Video（S3 W01 起的實際工具；Suno 仍是授權保留工具）
```

## 對課程設計的影響

### 受影響的任務類型
以下類型的 EX 任務中，工具欄位「ChatGPT」或「Claude」改為「Lab Terminal」：
- 資料查詢型任務（AI 偵探、AI 大哉問）
- Prompt 練習型任務（問法大比拼、完美 Prompt 挑戰）
- 創作輔助型任務（AI 幫我寫故事、AI 故事腳本）
- 學習輔助型任務（AI 家教挑戰）

## AI 優先的課堂文化

這個課程的求助順序是固定的：**學習單 → Lab Terminal → 同學助教 → 老師（次數有限）**。

老師的角色從「解答者」轉變為「提問策略教練」：
- 學生問老師問題時，老師的第一個回應是：「你問過 Lab Terminal 了嗎？你怎麼問的？」
- **學生詢問老師的次數需要被適度限制**，讓學生養成優先使用 Lab Terminal 的習慣
- 每個任務的學習單都提供具體的 Prompt 範例，讓學生知道「遇到這個問題，應該這樣問 AI」
- 學生學的不是答案，是問對問題的能力
