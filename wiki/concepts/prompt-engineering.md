# Prompt Engineering｜提示詞工程

## 定義

Prompt Engineering 是這個課程的核心主軸技能。指的是「如何用準確的語言描述讓 AI 給出你要的結果」。從小三的基礎問法，到小六的複雜任務拆解，這個技能貫穿四年。

## 核心 Prompt 框架（S1 建立，全課程適用）

```
角色：你是一個 ___
背景：我是一個 ___，正在做 ___
問題：請用 ___ 方式，幫我 ___
```

進階版（S2 加入）：
```
角色 + 背景 + 格式要求（條列/表格/段落）+ 字數限制 + 語氣要求
```
