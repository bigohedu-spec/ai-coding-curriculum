# Project-Centric Design｜作品導向設計

## 定義

S5 模組二（GitHub Copilot 正式入場）起，所有 EX 任務的產出必須是學生個人專案的一部分，而非孤立的練習題。學生每學期的最終目標是擁有一個**可展示、可上線**的真實作品。

這個原則的根本邏輯是：有了 AI 輔助，學生能產出的品質遠超傳統程式教育。如果課程設計沒有跟上這個事實，就是在浪費 AI 帶來的槓桿效應。

---

## 設計背景

**傳統程式教育的天花板**：學生需要先學語法 → 再學結構 → 再嘗試小專案 → 最後才能做出「成品」，通常要花幾個學期甚至幾年。

**AI 輔助後的現實**：學生在接觸 Copilot 的第一堂課，就能靠 Prompt 指令產出一個可執行的遊戲。這代表**起點已經大幅提高**——如果課程設計還停在「寫一個 function 練習」的層次，等同於刻意壓低天花板。

**正確方向**：中間學習的一切（函式、參數、DOM 操作、API 串接……），本質上都是在為學生精修他們的個人專案。每個任務都是專案的一塊磚，而不是練習完就丟棄的暖身。

## 作品導向三原則

### 原則一：專案宣言優先

進入 S5 模組二時，每位學生必須完成「我的專案方向宣言」——一句話說明自己要做什麼：

> 「我要做一個 ___________，讓 ___________ 可以 ___________。」

此後所有任務，成功條件都包含「這個功能已整合進你的專案」。

---

### 原則二：每個任務 = 專案的一個功能

任務設計框架從「寫一個 ______」改為「為你的專案加入 ______」。

| 舊設計（孤立練習） | 新設計（作品導向） |
|----------------|----------------|
| 讓 Copilot 寫一個函式，任意功能都行 | 為你的專案加入一個你需要的函式 |
| 設計三個不同的函式 | 為你的專案設計三個核心功能，每個用一個函式實作 |
| 學習 DOM 操作 | 用 DOM 操作讓你的專案多一個可點擊的互動元素 |

功能的具體內容由學生決定（配合他們的專案方向），老師設定技術框架。

---

### 原則三：學期末必有可展示版本

每個學期的里程碑任務，成功條件包含「專案可以被展示或部署」。

| 學期 | 作品狀態里程碑 |
|------|-------------|
| S5 | 本地可執行的互動專案，核心功能運作，有截圖 / 錄影展示 |
| S6 | 功能完整的專案，已用 Git 做版本控制，可在 VS Code 完整執行 |
| S7 | 專案已部署上線（GitHub Pages / Vercel / Netlify 等），有公開網址 |
| S8 | 已分享給真實使用者，收集回饋，嘗試變現或獲得訂閱 |

## 「專案宣言任務」設計規格

建議在 S5-W07 或 S5-W08 加入一個前置任務（或作為 W07 的 B 任務）：

**任務：我的專案方向宣言**（類型：EX，金幣：20）

| 步驟 | 說明 |
|------|------|
| 1 | 用 Lab Terminal 探索可能方向（遊戲？工具？藝術？故事？） |
| 2 | 和 Copilot 對話，確認這個方向用 JavaScript 可以做到 |
| 3 | 在 VS Code 新增 `project-idea.md`，寫下一句話宣言 |
| 4 | 截圖提交 |

成功條件：有一個清楚的方向宣言，後續任務都朝這個方向設計。

## 對 S5 模組設計的影響

| 模組 | 原設計 | 作品導向後 |
|------|--------|----------|
| 模組一 W1–W6 | VS Code 環境設定 | **不變**（技能習得階段，孤立練習可接受） |
| 模組二 W7–W12 | Copilot 技術練習 | **加入「專案宣言」前置任務（W7 或 W08）；W8–W12 每個任務都在為專案加功能** |
| 模組三 W13–W18 | JavaScript 基礎 | **每個 JS 語法任務都對應「我的專案需要這個功能」** |
| 模組四 W19–W22 | 興趣方向深化 | **不變（本已是專案導向）** |
| 模組五 W23–W24 | 學期回顧 | **里程碑成功條件改為「可展示的完整專案」** |

## 常見設計誤區

**誤區一：「讓學生自由發揮」 = 沒有框架**
作品導向不是讓學生隨心所欲，而是老師設定技術框架（「這週用函式」），學生在框架內決定內容（「做我的遊戲的積分系統」）。

**誤區二：「每個學生方向不同，很難統一教學」**
老師教的是框架（函式怎麼用），不是內容（函式做什麼）。內容由學生決定，這是設計上就要接受的分歧。

**誤區三：「學生還沒學夠就要做專案太難了」**
Copilot 的存在讓這個擔憂失效。學生不需要記語法——他們需要的是「想清楚自己要什麼」，這正是 Prompt 訓練的核心。
