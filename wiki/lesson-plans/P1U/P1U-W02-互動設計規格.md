# P1上 W02 互動設計規格｜海底城冒險：找寶物、打海怪

> 對應教案：[[P1U-W02-教案]]　承接：[[P1U-W01-互動設計規格]]（動作技能週 M1–M5 範式）

> 型態：**操作型遊戲（動作技能週）**；核心迴圈 **練習動作 → 取得物資 → 擊退怪物**。

## §G 規格治理
- **正典聲明**：本 spec 為唯一真相；成品若迭代，回填本檔（呼應 W01 的偏離教訓）。
- **綁定實作檔**：`public/games/p1u-w02-ocean.html`。
- **In Scope**：滑鼠強化（複雜/嚴格/按錯有後果）＋ **WASD 入門移動**，包在海底冒險迴圈裡。
- **Out of Scope**：滑鼠基礎教學（W01 已教）、閱讀理解王城（W01）、打字輸入（WASD 只是方向鍵、非打字，打字屬更後面）。
- **跨週技能地圖（模組一，暫定）**：W01 滑鼠大滿貫＋方向/閱讀 → **W02 滑鼠強化＋WASD 入門** → W03+ 待與使用者定（本課後鍵盤/滑鼠協同續深化）。
- **可數單位**：**區**（海底城區域，本課 3 區）；**關**（區內一個小挑戰）；**波**（擊退怪物一波）；**回合**（一次攻防）。
- **互動詞彙表（單一真相）**：滑鼠左鍵＝藍、右鍵＝橘、雙擊＝藍×2、滾輪＝綠；WASD 四鍵＝黃、鍵面標 W/A/S/D＋方向箭頭；物資＝金色、海怪＝紫、氧氣條＝青。
- **識字負荷**：文字極少（≤5 字＋圖示），本課**不需閱讀理解**；鍵位用大圖示教。
- **跨切面**：存檔續玩（記到第幾區第幾關、氧氣/物資）、金幣 idempotent 入錢包、純前端。
- **素材**：AI 生圖統一風格、透明背景、未載入退回向量；角色跨頁一致。
- **老師端＋翻轉教育**：一級需求，見 §六、§Deliver。
- **⚠ 待對齊**：金幣值（P1U 經濟未定）；按錯懲罰力道（實測挫折度）。

## §GL 遊戲迴圈與判定
- **迴圈**：玩家＝小潛水員；每關 **練一個動作 → 用它採物資 → 用動作/物資擊退海怪**；贏＝寶物＋金幣＋推進劇情。
- **本地判定**：動作品質、按對/按錯、WASD 到位、combo 順序，**全本地判**（可離線可重現）。AI 只做海底夥伴鼓勵/導覽口吻，**不當關主**。
- **時長靠深度不靠重複**：×2 內容來自**新機制**（WASD、追移動目標、拖拉、combo、新海怪類型、3 個區），不是把 W01 動作重播。**全程有跳關鈕。**

## 一、動作技能原則（沿用 W01 M1/M3/M4/M5；M2 改「懲罰版」）
- **M1 動作品質**：追點需真的跨距移動＋停準；WASD 需按對鍵到位；combo 需正確順序（防假動作）。
- **M2〔本週修改〕按錯有溫和後果**（依課程需求加難）：按錯/點錯 → **氧氣 −1 / 掉一個物資 / 海怪前進一步**；**非致命**（氧氣歸零不淘汰，回本關起點重來該波，物資可再採回）。**不用紅框否定、不倒數壓力、不淘汰。** 懲罰是「遊戲變難一點」，不是「你失敗了」。
- **M3 進度視覺化**：每區進度地圖、物資計數、擊退波數看得見。
- **M4 判定放大**：仍比成人大，但**比 W01 略縮**（嚴格化）；追移動目標的判定隨速度給合理容錯。
- **M5 反饋即節奏**：每個成功動作短音效＋視覺；採到物資、擊退海怪有爽感回饋。

## 三、Hook / Repeat / Deliver
- **Hook（≤15 字）**：「潛下海底城，搶回被海怪藏起的寶物！」畫面：潛水員入水、海底城剪影、氧氣條亮起。
- **Repeat（核心訊息）**：「**看清楚再出手，按對才前進**」——出現在每次採物資、每次擊退、氧氣變化時。
- **Deliver**：破 3 區後——寶箱大開＋撒金幣＋「海底探險家」徽章＋恭喜大圖；**「舉手告訴老師」＋「我是小老師 👋」按鈕**（翻轉教育，補 W01 之缺）。

## 四、關卡設計（3 區 × 迴圈；內容 ≈ W01 ×2）

### 第 1 區｜淺海：滑鼠強化
- **練習**：AIM-MOVE 追點會游動的小魚/珍珠（比 W01 靜態難）。
- **取得物資**：DRAG-TO 把採到的珍珠拖進採集袋（拖錯位置＝按錯，扣氧氣）。
- **擊退怪物**：對海怪弱點 AIM-MOVE 連點一波（波數 3–5）；點錯身體＝扣氧氣、海怪前進。
- **新機制**：DBL 開寶箱、WHEEL 換魚叉/網子。

### 第 2 區｜海溝：WASD 入門
- **練習**：WASD-MOVE 走到發光格（先單鍵：W 上/A 左/S 下/D 右，大鍵位圖示提示）。
- **取得物資**：走位到物資格採集（走錯方向不扣氧氣、但採不到；踩到海膽＝扣氧氣）。
- **擊退/閃避**：海怪衝過來 → 用 WASD **走位閃避**到安全格（被撞＝扣氧氣、退回）。
- **進階（視情況）**：斜向 W+D 等兩鍵。

### 第 3 區｜寶藏城：滑鼠 + WASD 綜合
- **練習→取得→擊退合一**：用 WASD 走位靠近寶物，同時用滑鼠 AIM-MOVE/RCLICK 應付海怪；COMBO（先右鍵放護盾、再左鍵攻擊）。
- **關主海怪（Boss，簡化版）**：WASD 閃避牠的衝撞 + 滑鼠點弱點；分 2 波；**非致命、可重來該波、有跳關**。
- 破關 → Deliver。

## 五、按錯懲罰與反硬 A（兩張表）
**防挫折（全域不變式：非致命）**
| 情境 | 作法 |
|------|------|
| 氧氣歸零 | **不淘汰**，回本關/本波起點重來；採物資回補氧氣 |
| 卡關/逾時 | 逾時給提示動畫；**全程有跳關鈕**；必要時 autoDemo |
| 按錯 | 溫和後果（−氧氣/掉物資/怪前進），**無紅框、無倒數、無「失敗」字樣** |

**反硬 A（客觀門檻；按錯有成本正好擋亂點）**
| 手法 | 擋法 |
|------|------|
| 亂點狂點 | 點錯 −氧氣（亂點會被自然懲罰）；AIM-MOVE 需點在移動目標上才算 |
| 假動作騙移動 | 追點需真的跨距＋停準（M1）；WASD 需實際到達目標格 |
| combo 亂按 | 必須正確順序，否則不觸發 |
| 拖拉亂丟 | 只有拖進正確容器才算，拖錯 −氧氣 |

## 六、老師端（一級需求）
- 全班進度總覽（各生在第幾區/關、氧氣、金幣）；狀態燈 🟢/🟡（卡同關過久）/🔴（舉手）。
- 難度微調：**按錯懲罰力道**（輕/中）全班或個別可調（因應小一挫折度）。
- 小老師派任；教師端網址。
