# P1上 Arc 3｜小熊麵包坊 W13–W18 教案

> 一份涵蓋 Arc 3 六堂課的教案。**Arc 3 ＝一款 3D 經營遊戲**《小熊麵包坊》（WASD 走動、靠近站點就互動、雇員工排順序自動化），六堂課＝同一家店逐週長大。**取代原本的 Minecraft 模組三。**
> **⚠️ 以遊戲現況為準（成品即真相）**：遊戲是 Cocos 試點 `hc-pilot`（原始碼 `C:\Dev\Cocos\Projects\hc-pilot`）。原規格中熊奶奶、搗蛋浣熊、打字接訂單、接力／蛋糕／外送已作廢；2026-09-29 版的「每週開一樣新東西」切法也已作廢，改成**每週一張任務表**（W13 學會做三明治、W14 三明治自動化），之後的內容用高價解鎖格切開。開發細節見開發規格 `specs/cocos-web-games/p1u-arc3/P1U-Arc3-小熊麵包坊-開發規格.md`（該檔可能落後於遊戲，衝突時以遊戲為準）。

## 教學目標（整個 Arc）
1. **做事情要有順序**：一件事由好幾個步驟組成；步驟有先後；**順序錯了結果就壞掉**。
2. **把順序教給別人**：用拖卡片排出正確順序，員工就會一直照著做（自動化）；排錯要自己找出第一個錯的地方（除錯）。
3. **先問、再做**：第一次做新東西前，先用麥克風問 AI，知道要做什麼、為什麼順序重要。
4. 附帶：WASD＋空白鍵操作（取代原 Minecraft 的 WASD 練習）、滑鼠拖曳（複習模組一）。

## 第一堂（W13）特別流程
- **開場動畫**（第一次玩才有，不能跳過，每張卡要等 5 秒才能按下一步）：你是小熊、麵包坊的老闆 → 不會的事就去問 AI → 賺金幣買下幫手、排好順序店就會自己賺錢 → 今天的目標：去問 AI，學會做三明治。之後每次進來只顯示一張卡片（這週的任務表標題＋接著要做的任務）。
- 開場紅箭頭指向 **AI 機器人**：先問 3 個問題（按住麥克風念出問題 → 放開後按鈕會轉圈圈「等一下，正在聽…」→ 聽 AI 回答 → 答小考）才拿得到鐮刀。**念錯 2 次會出現「念不出來？直接問」**（在視窗最下面、沒有外框，給老師按）。
- 第一次使用麥克風，瀏覽器會跳權限視窗，老師先示範按「允許」。
- 自己做第一個麵包時，故意讓學生看到**順序錯的後果**（例：麥子沒磨粉就拿去烤 → 烤焦），撿起失敗品會問「怎麼會變成這樣？」（關掉後 5 秒內不會再問）。

## 操作速記（給老師帶讀）
| 想做什麼 | 怎麼做 |
|---|---|
| 走路 | W A S D（畫面上的上下左右） |
| 割麥子 | 拿著鐮刀走進麥田就會自動割；背包滿了割下來的麥子會掉在地上（浮著、有光圈），之後可以撿 |
| 拿東西 | 走進綠色框就自動拿；地上的東西走過去就撿 |
| 放東西、付錢 | 站在藍色框或升級圈裡按**空白鍵**（按住一直放） |
| 收錢 | 碰到收銀台的金幣，金幣會全部飛進背包 |
| 機台的框 | **左邊藍色＝放進去、右邊綠色＝拿出來**；小熊和員工放在同一堆，小熊可以拿走任何人做好的 |
| 升級 | 紫色虛線圓圈：上面金幣、下面數字＝還要幾個金幣，LV↑＝升一級 |
| 不知道去哪 | 跟著右上角任務表和**紅色箭頭**；很遠的時候小熊腳邊也有箭頭 |
| 音樂 | 右下「♪ 開／關」 |

### 升級圈
- **員工（變快／拿更多）、貨架「加一層」**：隨時都在，隨時可以升。
- **工具（變快／放更多）、小熊（跑更快／背包／鐮刀）**：一次只出現一個（有紫色光柱），升一級就換下一個，避免小朋友一次面對太多選擇。
- 鐮刀等級越高，能割越高級的麥田，高級麥割一株噴比較多麥子（麵包不分等級，一個 30 金幣）。

### 員工怎麼工作（看到員工停下來時可以這樣解釋）
- 照順序板一格一格做，做完從第一格再來。
- 每次都想**一次拿滿手**：成品夠就拿；不夠就回上一步補料；出發前會先看，不夠就不白走。
- 東西被小熊拿走了，會搖搖頭回去重做（小熊優先）。
- 手上的東西放不進去、機台也停了超過 5 秒，會拿去垃圾桶丟掉。
- 順序排錯會做出失敗品、頭上冒「？」、說「流程好像怪怪的，快告訴我怎麼做！」，順序板把**第一個錯的格子**標紅框。
- 小松鼠缺麵包或果醬會先拿工具旁現成的，沒有就自己做。

## 老師角色
- **提問教練**：不代排順序；引導「員工第一步要做什麼？」「紅框是第幾格？那一格前面少了什麼？」
- **看順序板**：員工出錯時面板會把**第一個錯的格子**標紅框，請學生從那一格往前想。
- **提醒打掃**：地上有失敗品或果醬時，員工順序板不能按開始（客人照常進店），要學生自己撿去丟、站上果醬擦乾淨。
- **派小老師**：先過關者去教同學「怎麼排順序」。

### 老師工具（幫卡住的學生）
- 畫面右下角 ⚙ → 用鍵盤打密碼 `BIGOH666`（跟字母要塞同一組，只擋學生亂按，不是權限控管）→ 按 Enter。
- 功能：**完成目前的任務**、**加金幣**（剛好夠買目前的解鎖格）、**幫員工排好順序**、**清掉地上的東西**、**小熊回到店裡**（卡在牆或角落時）。
- 每次使用都會記在學生的存檔裡（看得出哪些學生被救過）。

## 三大核心概念對應
- 🎮 遊戲化：經營、升級、員工指數變快、顧客付錢、離線收入（下次回來有金幣山）——強動機。
- 🤖 AI 優先：每樣新東西先**用麥克風問 AI**（問答全預寫、不連 AI，同字母要塞緊急任務做法）。
- 🔄 翻轉教育：先過關者當小老師；學生自己找錯、自己修順序。

## 老師筆記
- **出錯不扣任何東西**：順序錯只做出看得出壞掉的失敗品，要花時間善後；答錯只鎖 2 秒。
- **存檔**：從 `/play/hc-pilot` 進去才會存（右下角會顯示「已存檔 時間」）；平常約 60 秒存一次，關分頁時立刻存。讀不到雲端存檔時會顯示「讀不到存檔，這次不會存檔」，避免空白進度蓋掉舊存檔。
- **離線收入**：**學會做三明治（問完 AI「三明治怎麼做」，W13 任務表第 15 項）之後才開始有**。學生離開期間員工繼續賺錢（最多算 7 天），回來時跳「歡迎回來」，收銀台旁出現金幣山，走過去碰一下就會全部飛進背包。
- **遊玩紀錄**：存檔裡同時記學生的有效遊玩時間（掛機、切走分頁不算）、每天一筆、各里程碑花的時間、卡關次數，給之後調整數值用。網址加 `?dev=1` 玩的會標記排除。
- **電腦要開硬體加速**：Chrome 關掉「使用圖形加速功能」會卡到約 20 fps。上課前檢查教室電腦（`chrome://settings/system`）。
- **麥克風**：教室吵時辨識會失敗，念錯 2 次後可以按「直接問」繼續。
- **平台金幣尚未接上**（P1U 經濟尚未遷移），遊戲內金幣不會變成平台金幣。
