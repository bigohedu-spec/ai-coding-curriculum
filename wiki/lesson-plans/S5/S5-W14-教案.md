> 📌 本週把 S7 才正式登場的「部署」概念**提前體驗**：帶全班把自己的專案用 **Big-Oh CLI** 一鍵部署，拿到一個**真的可以傳給別人打開的網址** `https://<名字>.bigoh.uk`。部署平台採自架的 **Big-Oh Hosting**（免費、零金錢門檻、免審核即時上線）。

---

## 教學目標

1. 學生能說出「本機打開檔案」與「部署上線」的差別：部署後，任何人用網址都能打開你的網頁，不需要你的電腦。
2. 學生能用 **Big-Oh CLI（終端機指令）** 把專案部署上線，拿到一個公開可訪問的 `.bigoh.uk` 網址。
3. 學生能說明網路廣告的基本運作（有人看/點才有收入），並理解**廣告平台需年滿 18 歲、且 Big-Oh 平台已在外框幫你處理廣告——作品裡不能自己放廣告碼**；能為自己的作品寫一份「未來（長大或家長自架網域）若要放廣告的計畫」。

---

## 三大核心概念對應

- 🎮 **遊戲化**：拿到「一個真的網址、可以傳給爸媽和朋友打開」是本學期最大的成就感跳躍——作品從「只有我自己電腦看得到」變成「全世界都打得開」。這是 S8「市場驗證 / 獲利」長線劇情的第一個鉤子。
- 🤖 **AI 優先**：Big-Oh 部署指令由學習單詳細步驟帶；遇到部署被退回（含中文錯誤訊息）先照訊息修、或問 Copilot Chat；廣告與部署的概念問題問 Lab Terminal。求助順序維持「學習單 → Copilot Chat / Lab Terminal → TA 同學 → 老師（每節最多 3 次）」。
- 🔄 **翻轉教育**：先成功部署的同學是天然的 TA，核心引導句「你 `node bigoh.mjs deploy` 有印出網址嗎？`login` 那步你在瀏覽器按允許了嗎？打開網址是空白還是有畫面？」——幫同學排查，不直接代操作。

## 課前準備

**教師：**
- **自己先完整走一遍 Big-Oh 部署**：在一個有 `index.html` 的專案根目錄跑 `curl -o bigoh.mjs https://cdn.bigoh.uk/cli/bigoh.mjs` → `node bigoh.mjs login`（在瀏覽器 `bigoh.uk/cli` 輸入代碼、按允許）→ `node bigoh.mjs deploy` → 拿到 `.bigoh.uk` 網址、打開確認。把每一步在投影幕上演示清楚。
- 準備對照示範：用 `file://` 在自己電腦打開一個網頁 vs 用 `https://xxx.bigoh.uk` 網址打開同一個網頁，讓學生感受「本機 vs 上線」的差別。
- **確認學生登入路徑**：`bigoh.uk/cli` 需要學生已從**課程網站按「發布」跳轉登入過**；若學生在該頁看到「你還沒有登入」，請他回課程網站按一次「發布」再回來輸入代碼。
- **廣告部分課前想清楚立場**：本週只教「概念 + 媒體素養 + 未來計畫」，**不實際申請廣告帳號、作品裡也不能放廣告碼**（平台會自動退回；平台自己在外框處理廣告）。準備 1–2 個學生熟悉的網站截圖，指出廣告位置作為討論素材。
- 安全提醒：作品部署後任何人都看得到程式碼。提醒學生——**金鑰、密碼、廣告碼都不可以放進作品裡**（放了部署會被退回）；需要雲端就用上週的 `BO`（平台幫你處理金鑰）。

**學生：**
- 確認 VS Code 裡的專案正常、`index.html` 在專案根目錄且檔名全小寫。
- 想一想：如果有人問「你的網站網址是什麼？」你希望給他什麼名字（slug：小寫英數 - ，3–30 字）。

## 課堂流程

| 時間 | 活動 | 說明 | 教師角色 |
|------|------|------|---------|
| 0–8 分鐘 | Hook：本機 vs 上線 | 老師用 `file://` vs `https://...bigoh.uk` 對照示範，問：「哪一個你可以用 LINE 傳給阿嬤，她點了就打得開？」帶出「部署」 | 主導對照示範 |
| 8–45 分鐘 | 任務 A：部署上線（CLI 優先） | 學生用 Big-Oh CLI 三步（抓工具 → login → deploy）把專案上線 → 拿到 `.bigoh.uk` 網址並打開確認 | 巡視卡點（最常見：login 沒在瀏覽器按允許、slug 被別人用了[換名字]、部署被退回[照中文訊息修]）；投影幕同步演示 |
| 45–58 分鐘 | 任務 B：認識廣告 + 寫廣告計畫 | 學生用 Lab Terminal 研究網路廣告怎麼運作、年齡規定、以及「為什麼平台幫你處理廣告、作品裡不能放廣告碼」，並為自己的作品寫一份「未來廣告計畫」 | 帶一段全班討論：「廣告太多會怎樣？」「為什麼平台要滿 18 歲？」 |
| 58–60 分鐘 | 截圖 + 舉手告知老師 | 截圖：A（瀏覽器網址列顯示你的 `.bigoh.uk` 網址 + 你的網頁畫面）、B（你的廣告計畫） | 確認成功條件，特別確認「網址真的打得開」 |
| **60–90 分鐘** | **🎮 自由遊玩時間** | 學生使用本週賺取的金幣，在 Minecraft / Lab Terminal 小遊戲 / 其他介面自由活動 | 觀察，不介入 |

> ⚠️ 任務必須在 60 分鐘內完成。**部署成功 = 拿到一個打得開的網址**，這是本週主線；廣告是「認識 + 規劃」，不實作。若有學生上週的專案還沒做完（例如雲端還沒接好），**仍可部署現有版本**——部署不需要功能全部完成。
> ⚠️ **不要用迴圈重試部署**（每人每天只有 20 次配額）。被退回時，錯誤訊息是中文、會說要改什麼，照著改再手動跑一次。

## Lab Terminal Prompt 建議

本週 Lab Terminal 用於**部署與廣告的概念理解**：

- 「把網頁『部署』是什麼意思？跟我在自己電腦打開 HTML 檔有什麼不同？」
- 「為什麼把作品放到平台上，全世界就都看得到我的網頁？」
- 「網站上的廣告是怎麼賺錢的？網站主人做了什麼，廣告才會出現？」
- 「為什麼放廣告的平台（像 Google AdSense）要滿 18 歲才能申請？如果我還沒 18 歲，可以怎麼辦？」
- 「為什麼我的作品裡不能自己放廣告碼？（提示：平台會自己在外框處理廣告）」

> 部署被退回、網址打開空白等**技術問題**：先看中文錯誤訊息照著改，或問 Copilot Chat。

## 老師筆記

**關於廣告主題的處理（重要）：**
- 本週廣告部分是**知識、媒體素養與未來規劃**，**不實際申請任何廣告帳號、作品裡也不放廣告碼**。原因有二：(1) Google AdSense 等廣告平台規定**發布者須年滿 18 歲**，未滿須由**家長以自己帳號**申請、款項付給該成人；(2) **Big-Oh 平台會自動掃描並退回含廣告碼的作品**——平台自己在外框處理廣告，作品裡不可以放。
- 這正好接上 CLAUDE.md 第十六節 S8 的「家長參與框架」與媒體素養：**網站可以賺錢，但要負責任地、在大人協助下、用合規的方式進行**（例如未來家長自架網域）。
- 帶討論時強調**媒體素養**：廣告太多會趕走使用者；好的網站先有價值、廣告是輔助。避免把課程導向「塞滿廣告賺錢」。

**部署常見問題：**
- **`BO is not defined` 之類在本機測試才有**：`BO` 只在線上版才注入；部署上線後就有。
- **部署被退回（中文訊息）**：照訊息改——常見是「有廣告碼」「有金鑰/資料庫設定」「檔名不允許或中文檔名」「作者名不能用真名（改暱稱）」「網址已有人用（換 slug）」「今天上傳太多次（明天再來或請老師調配額）」。
- **`login` 卡住 / 說沒登入**：請學生回課程網站按一次「發布」再回 `bigoh.uk/cli` 輸入代碼、按允許。
- **打開是空白**：多半是自己寫了 `<script type="importmap">`（平台會自動注入，不要自己寫）、或用了外部網址載入資源（被 CSP 擋）。先看 Console。
- **雲端功能在線上版才會動**：上週的 `BO` 就是要在 `.bigoh.uk` 上才有——這正是「上線後才用得到雲端」的真實體驗。

**安全提醒（連回 W13）：**
- 作品部署後程式碼公開可見。**金鑰、密碼、廣告碼都不可放進作品**（放了部署會被退回）。需要雲端就用 `BO`——平台幫你把金鑰藏在後台，你手上不需要有金鑰。借這機會讓學生理解「危險的東西不放在自己手上，才安全」。

**家長協作任務（選做，帶回家）：**
- 課堂結束時發下 **《家長協作任務單》**（[[S5-W14-家長協作任務-AdSense]]）：說明**在 Big-Oh 上作品內不能放廣告碼**，真的要放廣告是**未來、由家長以成年帳號、在家長自架的網域**上進行的合規路徑。
- 向學生說清楚：**這一步要爸媽幫忙、而且是未來的事**；而且**不管最後有沒有放廣告，「和爸媽一起認識、做出決定 + 簽名帶回」就算完成**——這是 S8 家長參與框架的提前體驗。
- 老師收回簽名單即可，**不評價家庭的選擇**。

**教學重點提醒：**
- 本週主線是「拿到一個打得開的網址」的成就感，不是把專案做完美。哪怕專案還很陽春，能上線就是成功。
- **CLI 優先**：部署強調用 **Big-Oh CLI 指令**（`node bigoh.mjs deploy`，符合課程 CLI 優先工作流）。
- 廣告計畫由學生依自己的專案決定，沒有標準答案；老師只確認「有寫、有想到家長與內容品質、知道作品內不能放廣告碼」。
