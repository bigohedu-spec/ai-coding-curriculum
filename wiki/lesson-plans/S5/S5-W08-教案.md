# S5 W08｜為你的專案寫函式 教案

## 基本資訊

| 項目 | 內容 |
|------|------|

| 週次 | W08 |
| 模組 | 模組二：專案啟動 + Copilot 工作流（W7–W12） |

## 任務一覽

| 任務 ID | 名稱 | 金幣 | 核心動作 |
|---------|------|------|---------|
| S5-W08-A | 為專案寫第一個函式 | 100 | 用注釋告訴 Copilot 你的專案需要什麼，生成並執行 |

---

## 教學目標

1. 學生能將「我的專案需要什麼功能」轉換為具體的 Copilot 注釋，讓 AI 生成對應的函式
2. 學生能理解參數的概念——讓同一個函式對不同輸入做不同的事
3. 學生能用自己的話解釋 Copilot 生成的程式碼，確認理解而不只是複製貼上

---

## 三大核心概念對應

### 🎮 遊戲化
- 四個任務分層解鎖，完成 A 才能做 B
- 全部完成者解鎖「專案工程師 Lv.1」稱號
- 先行者 TA 機制：協助同學完成同一任務，獲得該任務金幣的 50%
- 「最獨特的函式命名」課堂票選：得票最高者 +5 金幣

### 🤖 AI 優先
- **Copilot 的角色**：根據學生的注釋生成程式碼——注釋越貼近專案，結果越有用
- **Lab Terminal 的角色**：理解概念（什麼是函式？參數是什麼？這行程式碼做了什麼？）
- 關鍵教學點：「你的注釋就是你對 AI 的指令。指令越清楚，結果越接近你要的。」

### 🔄 翻轉教育
- 老師開場只說 2 分鐘：「上週你宣告了你的專案，今天你開始為它寫程式。」然後發學習單
- 從 A 到 D，學生自行推進，不等老師
- 老師最多回答 **3 個問題**（黑板計分）

## 課前準備

**教師：**
- 快速確認每個學生都有 `project-idea.md`（沒完成 W07-B 的學生需要先補）
- 準備一個自己的 demo 專案，展示「注釋貼合專案」的樣子（例如：猜謎遊戲的 `checkAnswer()` 函式）
- 黑板：老師問題次數計分欄；旁邊寫「你的函式是為你的專案設計的嗎？」提醒全班

**學生：**
- `project-idea.md` 已完成（有宣言 + 核心功能清單）
- VS Code 開啟，Copilot 正常
- 專案資料夾已建立

## Lab Terminal Prompt 建議

**A 任務：想不出要為專案設計什麼函式：**
```
我的專案是（你的宣言）。請幫我想 3 個這個專案可能需要的 JavaScript 函式，每個用一句話描述它做什麼。
```

**B 任務：理解「參數」：**
```
我是小學生，JavaScript 函式的「參數」是什麼意思？用我的專案（你的宣言）舉一個例子說明。
```

**D 任務：讀懂程式碼：**
```
這段 JavaScript 程式碼在做什麼？請用繁體中文一行一行解釋：
[貼上程式碼]
```

## 老師筆記

**最常見的問題：**
- **「我的注釋寫的功能和我的專案沒有關係」**：黑板上的提醒語「你的函式是為你的專案設計的嗎？」就是為了抓住這個情況。發現這種情況時，問學生：「你的 project-idea.md 說核心功能是什麼？能不能為那個功能寫一個注釋？」
- **「Copilot 生成的和我想的不一樣」**：正常且好！讓學生修改注釋讓它更具體，這個迭代過程才是最重要的學習
- **「函式執行後沒有輸出」**：只定義了函式但忘記呼叫——在函式下方加 `函式名稱()`
- **「不知道我的專案需要什麼函式」**：引導用 Lab Terminal 的 A 任務 Prompt

**與作品導向的連結點（尾聲提問）：**
- 「你今天為專案加了什麼功能？」
- 「你的注釋和你的專案有關係嗎？」
- 「下週你想再為專案加什麼？」
