## 實施方式調整說明

本版再次調整教材製作邏輯：

- 2026-07-20 起，S3-W01 不再以「看展示台認工具」為主。
- 改為讓學生先試用四個輕量 Lab 工具，再處理分發任務。
- 重複的是同一套任務循環：**拿到任務 → 選擇工具 → 根據需求下提示詞 → 看結果 → 下一個任務**。
- Prompt 審查保留為「看結果」前的送出門檻，不拆成額外主步驟。
- 任務類型固定為四類：文字類、圖片類、影片類、音樂類。
- 程式類 / VS Code 從 S3-W01 移除。VS Code 仍保留在後續課程，不在本週提前練習。
- 音樂工具學生端命名為 Lab Music；工程端底層 API 選用 ElevenLabs Music。

## 教學目標

1. 能辨認四類任務：文字類、圖片類、影片類、音樂類。
2. 能知道四個適配工具「叫什麼、怎麼用」：Lab Terminal、Lab Image、Lab Video、Lab Music。
3. 能用預設提示詞組出符合任務的 prompt。
4. 能在送出前通過 prompt 審查，確認 prompt 有任務關鍵字。
5. 建立 S3-W01 核心口訣：**先看任務是什麼，再用對的工具**。

## 三大核心概念對應

- 遊戲化：學生扮演「AI 工具調度員」，用四個 Lab 工具處理 8 張任務卡，點亮工具地圖。
- AI 優先：Lab Terminal 是本週主線平台，也是求助入口。學生先看任務，再判斷要用哪個工具。
- 翻轉教育：先完成者當小老師，只能問提示問題，不代點、不直接給答案。

## 課前準備

**教師**

- 確認 Lab Terminal 課程頁已依 [[S3-W01-課程規格-G1-G2]] 建置完成。
- 確認課程頁包含：
  - 4 張工具介紹卡：文字類、圖片類、影片類、音樂類。
  - 4 個工具站：Lab Terminal、Lab Image、Lab Video、Lab Music。
  - 每個工具都能讓學生選預設提示詞與任務關鍵字，不要求自由長打字。
  - 每次送出前都有 prompt 審查，列出缺少的任務關鍵字。
  - 8 張任務卡，每類 2 張。
  - done 頁金幣結算與「我可以當小老師」按鈕。
- 準備投影畫面，示範一張任務卡的五步循環。
- 不需要佈建任何 MC / Minecraft 場景。
- 不需要學生實際登入外部服務；Lab Music 底層 ElevenLabs Music API 由後端處理。

**學生**

- 登入 Lab Terminal。
- 拿到 [[S3-W01-學習單]]。
- 本週不需要先開 Lab Image、Lab Video 或 Lab Music 的獨立頁面；所有練習都在 Lab Terminal 互動頁內完成。

## Lab Terminal 使用方式

本週不是開放式聊天任務，而是 Lab Terminal 內的互動課程。

先完成四個工具試用，才開始處理任務卡。

每張任務卡都照同一套五步循環：

1. 拿到任務。
2. 選擇 Lab Terminal、Lab Image、Lab Video 或 Lab Music。
3. 根據需求下提示詞。
4. 看結果。
5. 下一個任務。

系統會在第 3 步後做 prompt 審查；審查通過才會進到看結果。

學生卡住時，先照這個順序：

1. 看任務卡的產出。
2. 想它要用文字、圖片、影片，還是音樂工具。
3. 看 prompt 審查缺少哪個關鍵字。
4. 問小老師或老師：「我卡在哪一步？」

可用提示語：

1. `這張任務卡要做出什麼？`
2. `它應該用 Lab Terminal、Lab Image、Lab Video，還是 Lab Music？`
3. `我的 prompt 還缺哪個任務關鍵字？`

## 老師筆記

**常見問題**

- 學生問「今天要進 Minecraft 嗎？」答：「今天主線不進 Minecraft。這週已在 2026-07-17 移除 MC，因為 Lab Terminal 就能完成同一個學習目標。」
- 學生以為要實際打開 ElevenLabs 或其他外部頁面：提醒「今天只看得到 Lab Music，底層 API 由系統處理。」
- 學生問「那 VS Code 呢？」答：「VS Code 是後續課程，這週只練文字、圖片、影片、音樂四類。」
- 學生只記工具名稱，不看任務：追問「這張任務卡想做出什麼？」
- 學生 prompt 太空泛：請他找任務裡的名詞和數字，例如「30 秒」「抽卡動畫配音」「金色寶箱」。

**教學重點提醒**

- 本週不是背工具名稱，而是先完成工具試用，再建立「拿到任務 → 選擇工具 → 根據需求下提示詞 → 看結果 → 下一個任務」循環。
- Prompt 審查是看結果前的送出門檻，用來確認學生有抓到任務關鍵字。
- 四個適配工具要和後續週次呼應：
  - Lab Terminal：本週與後續文字整理、提示、改寫入口。
  - Lab Image：後續圖片素材任務。
  - Lab Video：S3-W02 與後續影片任務。
  - Lab Music：S3-W03 與後續音樂任務；工程底層 API 為 ElevenLabs Music。
- 核心口訣至少出現三次：開場、任務卡練習、驗收。

**延伸挑戰（進階，不影響主線）**

- 請學生新增一張自己的任務卡，並說出它應該用哪一個工具，以及 prompt 必須包含哪些關鍵字。
- 快速學生可在自由時間幫下一週 S3-W02 預想：如果圖片要變成影片，會需要哪些素材？
