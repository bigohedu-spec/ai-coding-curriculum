## 教案職能聲明

本教案只負責課堂執行，不保存另一份題目或網站設定：

- 學生故事、謎題資料、解謎須知與提示詞，讀 [[S3-W03-學習單]]。
- 任務 ID、金幣、完整答案鏈、判定、D→E 文字鑰匙與內嵌 JSON，讀 [[S3-W03-課程規格-G1-G2]]。
- 本教案只保存教學目標、時間、教師引導、課前測試、差異化、技術備援與翻轉教育。
- 若具體列車、圖案、密文或摩斯資料變更，先改課程規格與學習單；教案只在教學節奏受影響時更新。

## 教學目標

學生能夠：

1. 從表格、圖案、密文與燈號中找出解題需要的資料。
2. 分辨「取得資料的順序」與「重新排列的順序」。
3. 使用前一張答題卡保存的答案完成下一題，不重新猜測。
4. 面對半開放任務時，先判斷要產出什麼，再自行選擇適合入口。
5. 用 AI 整理或生成後，自己檢查順序、顏色、限制與前後一致性。
6. 將文字、圖片、音訊、對話與影片串成完整解謎歷程。

核心口訣：

> 先找線索，再做正確操作，最後自己檢查。

## 三大核心概念對應

| 核心概念 | 本課實踐 |
| --- | --- |
| AI 優先 | 學生先整理問題與前題資料，再請 AI 協助檢查、解碼或生成 |
| 遊戲化 | 六個車站空間形成不可跳答的答案鏈；每題通過點亮一站 |
| 翻轉教育 | 先完成者只能提醒資料來源、分組方式或檢查方向，不可說答案 |

## 課前準備

### 文件與發布

- 確認 [[S3-W03-課程規格-G1-G2]] 內只有一個 `LAB_TERMINAL_WORKSHEET_CONFIG` 區塊，且可解析。
- 從課程規格 Markdown 抽取設定，禁止匯入或維護獨立 `S3-W03-答題表設定.json`。
- 執行發布 preflight：六個題目標題、內容版本、金幣 250、小測比例與 D→E payload 全部通過。
- 確認左側學生內容來自 [[S3-W03-學習單]]，右側題中小測來自課程規格內嵌 JSON，沒有同一題兩份文字。

### 答題卡與狀態

- 確認 A–F 共六張答題卡都會自動保存文字、提示詞與附件 metadata。
- 確認每題只有主成果送審；題中小測作答後立即回饋，沒有小測送出按鈕，也不控制題目完成。
- 確認 B–F 會讀取前題通過狀態或答題記錄，不在後題直接顯示前題答案。
- 確認錯誤與退回不會清空學生草稿、附件、筆記本或小測答案。
- 確認金幣使用冪等交易；重玩不重複入帳。

### D、E 技術測試

- 先用教師測試帳號完成 D，確認答題記錄區才在通過後出現 `MORSE_KEY_VERSION: 1`。
- 確認 D 未通過時，E 看不到文字鑰匙，也不能從前端原始資料提前取得。
- 確認 E 可直接讀取 D 的 AI 可閱讀摩斯文字鑰匙，不需要 AI 聽懂音訊。
- 準備標準摩斯音訊供 D 題生成失敗時使用；標準 payload 與教師答案以課程規格 §3、§4 為準。

### 媒體與教室

- 測試圖片、音訊、影片生成與附件上傳；確認工具入口可用，但學生題面不直接提示工具名稱。
- 準備耳機或控制全班音量，避免 D 題同時播放造成干擾。
- 準備 B、D、F 的教師標準素材；生成服務逾時時可手動放行，但要保留學生提示詞。
- 將每題內容拆為「場景／謎語／解謎須知／提示詞」短卡，不在同一畫面顯示完整長文。

## 課堂流程

| 時間 | 學生活動 | 教師任務 |
| --- | --- | --- |
| 0–8 分鐘 | 進入午夜車站，測試答題卡自動保存與筆記本 | 示範「答題卡是正式紀錄，筆記本只是暫存」；說明小測只回答、不送出 |
| 8–18 分鐘 | A：篩選時刻表並完成旅客廣播 | 只問「哪些狀態一定不能搭？」；不說列車答案 |
| 18–28 分鐘 | B：依時間、月台與閱讀順序產生車票 | 用手勢分開「先取出」與「再排列」；不說符號順序 |
| 28–39 分鐘 | C：排列密文、測試位移方向並生成站務對話 | 提醒位移量來自前題資料；兩方向都可試，合理句子才保留 |
| 39–50 分鐘 | D：選燈色、轉短長訊號並生成摩斯音訊 | 檢查短／長／字母停頓／單字停頓；生成不穩時發標準音訊 |
| 50–59 分鐘 | E：讀取 D 通過後文字鑰匙，解出登車指令與對話 | 確認學生用 answer record，不要求重新上傳音訊；不說解碼結果 |
| 59–68 分鐘 | F：整合 A–E 生成登車影片 | 請學生逐項指著舊答題卡說資料來源，再開始生成 |
| 68–75 分鐘 | 六站回顧、補件、舉手驗收 | 看完整答案傳遞鏈與 D→E 狀態，不逐題重講答案 |
| 75–90 分鐘 | 分享、自由活動或小老師協助 | 驗收成果；安排先行者協助尚未完成者 |

> 主線動作級估算為 64.5 分鐘，接近上緣。若班級閱讀速度較慢，F 題影片生成可先用提示詞＋教師示範影片完成，學生影片列為課後補完。

## 單題固定節奏

```text
讀短卡 → 找前題鑰匙 → 自己先判斷 → 完成文字或作品 → 回填答題卡 → 送主成果檢查
```

右側題中小測獨立於以上流程：

- 每題 1 選擇＋2 填入。
- 只作答、即時回饋，不按送出。
- 不列入成果通過、解鎖或金幣條件。
- 選擇題不向學生顯示正解。

## 六題教師引導

### A｜錯亂時刻表

教師只引導篩選方法：

- `哪三種狀態代表不能搭？`
- `剩下那一列有哪些欄位要全部保存？`
- `廣播有沒有把必要資料都說到？`

若學生直接猜，要求他逐列說明排除理由。答案與驗證讀課程規格 §3／§6。

### B｜打孔車票

教師用兩階段語言：

1. `先用時間與月台取出四個圖案。`
2. `再用閱讀順序重新排列。`

學生若把兩種順序混合，請他在筆記本先寫「原始四個」與「最後四個」兩行，不直接提供任何圖案。

### C｜加密月台

- 先檢查學生是否真的使用 B 的符號順序。
- 再問位移量從哪張答題卡取得。
- 允許同時測試前移與後移；保留能形成完整英文句子的方向。
- 不把本題固定成 ROT13，也不要求手算整張字母表。

### D｜摩斯隧道

- 先問學生要看哪個顏色，再讓他抄訊號。
- 用手拍示範「短、長、字母停頓、單字停頓」，不示範完整答案節奏。
- 音訊提示詞要包含明確秒數與禁止內容；若結果像音樂，提醒加入「純訊號、單一嗶聲、無旋律」。
- 模型生成失敗不算學生失敗；保留提示詞後改用標準音訊。

### E｜神祕列車長

- 本題正式輸入是 D 通過後的文字鑰匙，不是音訊辨識。
- 若看不到鑰匙，先查 D 是否真正通過與 payload 是否成功寫入；不要把答案口頭補給學生。
- 請學生先保留點線分組，再請 AI 解碼；若全部連成一串，要求回到 `LETTER_GAP` 與 `WORD_GAP`。

### F｜零點列車

生成前讓學生完成口頭點名：

- A 提供哪一類乘車資料？
- B 提供哪一類視覺資料？
- C、D、E 各提供哪一個不可缺少的畫面或聲音條件？

只檢查來源與完整性，不在教案重複列出具體答案；固定答案鏈讀課程規格 §3。

## 差異化與防挫折

| 情境 | 教師作法 |
| --- | --- |
| 閱讀較慢 | 一次只開一張短卡；先讀表格或密碼資料，再讀提示 |
| 不會整理前題資料 | 讓學生在筆記本建「A／B／C」三行資料區，不代填內容 |
| 凱薩位移卡住 | 讓 AI 同時輸出前移與後移結果，學生只判斷哪個是完整句子 |
| 音訊不像摩斯碼 | 保留提示詞與作品，改用教師標準音訊；D 仍可完成 |
| E 看不到鑰匙 | 教師查狀態與 audit；必要時 teacher override 補發 payload |
| 影片生成逾時 | 先交完整影片提示詞，使用教師示範影片完成口頭驗收，課後補作品 |
| AI 回覆太長 | 請學生要求「只列出本題需要的六個欄位」或「只檢查一件事」 |

## 翻轉教育流程

### 先行者可以做

- 問同學「這題要從哪一張舊答題卡找資料？」
- 提醒「先取出，再排列」或「保留點線分組」。
- 協助確認成果是否已回填、附件是否上傳。
- 示範如何讀錯誤訊息，不代替修改。

### 先行者不可做

- 說出可搭列車、符號順序、正確燈色、摩斯解碼或車廂編號。
- 代替同學操作、上傳、送審或使用 teacher override。
- 從教師規格或答案區複製內容給同學。

## 課堂成功條件

- A–F 六張主成果答題卡通過；小測作答狀態不影響完成。
- B–F 的成果可說明資料來自哪一張前題答題卡。
- D 的學生音訊或提示詞有保留；E 使用系統文字鑰匙完成，不依賴音訊辨識。
- 媒體模型失敗時使用備援，不把技術失敗算成學生錯誤。
- 六題通過後只入帳一次主線 250 金幣。

## 老師筆記

### 教師答案

不在教案複製答案。請使用 [[S3-W03-課程規格-G1-G2]]：

- §3「六題內容、答案鏈與判定」：完整固定推理鏈。
- §4「D → E 技術備援」：標準摩斯 payload。
- §6「內嵌網站設定 JSON」：小測正解、可接受輸入與錯誤訊息。

### 常見問題

- 學生把題中小測當送審條件：提醒小測只回答，主成果才送審。
- 學生問「這題要用哪個工具」：反問「最後要交文字、圖片、音訊還是影片？」不要直接說入口名稱。
- 學生只看後題猜答案：請他指出前題答題記錄中的來源欄位。
- 學生從網頁原始資料看到 D 鑰匙：這是實作缺陷，立即停用該版本並依規格修正，不當成一般課堂問題。
- 網站與學習單標題不一致：停止發布，檢查 `contentRevision` 與 `contentRef`，不可直接在網站手改。
