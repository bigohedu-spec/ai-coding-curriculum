## 教學定位

本週只練習「用自己的文字，把問題說到 AI 聽得懂」。不要求學生使用專業 Prompt 結構，也不因少量錯字、口語或標點不完整退件。

評量的重點是：

1. 學生是否指出目前問題。
2. 學生是否說出希望 AI 做什麼。
3. 是否提供必要資料。
4. AI 回答或作品是否能幫助下一步。

核心口訣：

> **看見問題 → 自己問清楚 → 檢查結果。**

## 課前準備

- 確認學生版每題只顯示「背景故事、謎題內容、通關條件、提示」，沒有教師答案、完整 Prompt 範例、完成步驟、行為勾選框或題中小測題目。
- 確認右側答題卡的小測內容只從 [[S3-W04-課程規格-G1-G2]] 載入；本週每題為 4 題選擇題，其中 1 題要配合當前展區換句話說詢問本週口訣。主成果通過後依序作答，全部答對才結算並前往下一題。只有單一精確答案且沒有其他回答空間時，後續課程才保留文字題。
- 測試文字、圖片、音樂、影片四種工具與答題卡自動保存。
- 預先放入 B 題符合條件的圖片、C 題短音樂、D 題約 5 秒出口影片；學生的媒體 Prompt 通過預審後才開放對應素材。
- 確認 B、C、D 後題只讀取前題已保存的通關紀錄；未通過時不顯示完整資料。
- 確認學生畫面與教師口頭引導都不提示工具名稱、工具入口或「這題要用哪個工具」。

## 今天的送出規則

| 學生送出的內容 | 系統處理 | 教師處理 |
| --- | --- | --- |
| A 題文字需求 | 不預審 Prompt，直接正常輸出文字回答 | 不先改寫學生問法；等答題卡送審後再看成果是否足以推進 |
| B 題圖片 Prompt | 先審查主體、顏色、數量、限制四類條件 | 未通過時只問缺少哪一類；通過後開放預製圖片 |
| C 題音樂 Prompt | 先審查速度、樂器、氣氛、人聲限制及速度衝突 | 未通過時只提醒比較條件；通過後開放預製音樂 |
| D 題影片 Prompt | 先審查畫面、移動、時間、限制及前題資料 | 未通過時只請學生回看缺少的資料來源；通過後開放預製影片 |
| 任一題右側答題卡 | 獨立審核本題成果與前題依賴 | 一次只給一個修改方向，不提供答案或完整 Prompt |

媒體 Prompt 通過只代表可以取得預製素材，不代表整題通過。學生仍須將成果放入右側答題卡並另行送審。

## 四題如何連在一起

```text
A 還原作品線索
  ↓ 將作品線索寫入 A 答題卡
B 用 A 的作品線索選出圖片條件
  ↓ 將條件中的數量寫入 B 答題卡
C 用 B 的數量決定聲音速度並修正衝突
  ↓ 將修改後的聲音條件寫入 C 答題卡
D 合併 A、B、C 的通關紀錄完成出口影片
```

這張資料鏈只供教師備課與系統建置，不投影、不口述，也不放回學生學習單。

## 四題答案鏈與語意鎖

| 題目 | 題目完整答案 | 給下一題的語意鎖 | 為何不能確切跳關 |
| --- | --- | --- | --- |
| A | `品月作有亮的找尋` 重新排列後為「尋找有月亮的作品」 | 月亮作品 | B 有太陽、月亮、星星、山、海等作品；A 的指令才決定要查看哪一幅 |
| B | 五組中由 A 指向 `④ 🌙 ＋ 🟦 ＋ 3⭐ ＋ 🚫📝`＝月亮、藍色、3 顆星星、不要文字 | 星星數量 3 | C 只有 1～4 對應表；沒有 B 的數字，無法確定速度 |
| C | B 的 3 對照速度牆得到「快」；與「非常慢」衝突。有效音樂條件為快速、長笛、明亮、無歌詞 | 快速、長笛、明亮 | D 必須使用快速感或明確朝出口移動感，並以明亮感完成影片 |
| D | 約 5 秒影片：藍色月亮、3 顆星星、明亮出口、快速移動感、無可閱讀文字 | 最終出口展品 | 必須同時帶入 A、B、C 的資料，不能只靠單一數字解鎖 |

### 防跳關實作檢查

- B 題同時顯示太陽、海、星星、月亮、山五組 Emoji；不以顏色、預選或教師語氣暗示正確組，選擇只依 A 題保存的指令。
- C 題不重複展示 B 的星星數量，只展示 1～4 的對應規則。
- D 題只從學生通過紀錄讀入 A～C 的資料；未完成的欄位應為空白。
- D 的成果檢查至少確認：藍色月亮、3 顆星星、明亮出口、快速移動感、無可閱讀文字。

### 正確答案隔離規則

- 上表、教師 Prompt 範例、評審條件及課程規格 JSON 都是教師／系統資料，不得出現在 GAMMA 學生頁、題目提示、Prompt 預審回饋或未通關題目的預覽。
- 題中小測只問解題方法與資料來源，不問正確作品、正確數量、正確速度或最後影片的完整條件。
- 教師只能在學生已自行取得某項答案後，確認該項是否可用；學生尚未取得前，不得以口頭重述、反問內容、指向位置或操作示範透露答案。
- GAMMA 圖片只畫場景與問題狀態。任務 A 不出現可讀句子；B 不凸顯正確畫框；C 不視覺化正確速度；D 不預演正確出口影片。

## 各題教師引導與評審

### A｜順序錯亂的入口廳（15 分鐘）

**學生任務：** 自己請 AI 整理異常文字，取得選畫指令。

**可接受的 Prompt 範例（僅教師版）：**

1. `這段字的順序好像亂掉了，可以幫我排成正常中文嗎？品月作有亮的找尋`
2. `請把這段順序怪怪的文字整理成讀得懂的句子：品月作有亮的找尋`
3. `我看不懂這串中文字，想知道它原本要說什麼，請幫我重新排列。`

**不應接受：** `幫我。`、只貼原始文字卻沒有說希望 AI 做什麼、只輸入「答案是月亮」而沒有處理題目資料。

**常見錯誤與提示：**

- 學生逐字亂猜：`你覺得這串字的順序有沒有怪怪的？`
- 學生只貼資料：`你有給資料了，現在再說一次你希望 AI 幫什麼。`
- AI 只解釋沒有整理：`請它做一件更清楚的事：把文字排成正常句子。`

**評審條件：** A 題文字不做 Prompt 預審。答題卡送審時，須同時保存學生觀察、求助目標、原始怪文字、學生 Prompt、AI 整理結果、完整展覽指令與修改次數；整理結果須能唯一指定 B 題的其中一幅作品。

### B｜沒有名字的畫廊（15 分鐘）

**學生任務：** 用 A 的指令選畫，自己問懂 Emoji，再寫圖片需求。

**可接受的 Prompt 範例（僅教師版）：**

1. `這些符號是做圖片的條件嗎？🌙＋🟦＋3⭐＋🚫📝，請幫我說明。`
2. `我要做一張圖片，請把這些 Emoji 整理成圖片要有什麼和不能有什麼。`
3. `請做藍色月亮和三顆星星的圖片，不要放文字。`

**不應接受：** 未使用 A 指令就選其他作品、圖片需求少了月亮／藍色／3 顆星星／無文字等必要條件，或只寫 `做一張漂亮圖片`。

**常見錯誤與提示：**

- 忘了數量：`你有說星星要幾顆嗎？`
- 圖片出現字：`看看符號裡有沒有一個是在提醒「不要出現」的東西。`
- 直接把 Emoji 當成圖片 Prompt：`先弄懂每個符號的意思，再用自己的話做圖。`

**評審條件：** 圖片 Prompt 預審先確認主體、顏色、數量、限制四類均有描述，再開放預製圖片。答題卡送審時，須正確選擇月亮作品；符號解讀與圖片需求完整表達「月亮、藍色、3 顆星星、不要文字」；四格資料、修改次數與圖片均已保存。

### C｜說錯話的語音館（15 分鐘）

**學生任務：** 使用 B 的 3 得到「快」，請 AI 指出聲音條件衝突，再自行改寫。

**可接受的 Prompt 範例（僅教師版）：**

1. `上一題是 3，這裡 3 是快。我想做快的音樂，長笛、明亮、非常慢、沒有歌詞，哪一個不對？`
2. `我的目標速度是快。請幫我檢查這些條件有沒有相反：長笛、明亮、非常慢、無歌詞。`
3. `請做快速明亮的長笛音樂，不要歌詞。`

**不應接受：** 未使用 B 的數字就猜速度；保留「非常慢」又要求快；只輸入 `做音樂`，沒有速度、樂器或限制。

**常見錯誤與提示：**

- 不知道先看哪裡：`你的數字換成了什麼速度？`
- AI 已給答案但學生沒改音樂需求：`現在把找到的速度放進你自己的音樂要求。`
- 音樂出現歌詞：`你有沒有寫出不想要人聲？`

**評審條件：** 音樂 Prompt 預審先確認速度、樂器、氣氛與人聲限制，且沒有保留互斥速度，再開放預製音樂。答題卡送審時，學生須能從 B 題記錄取得 3 並說出其對應速度；識別「非常慢」為衝突；保存四項聲音資料、音樂與修改次數。

### D｜消失的出口展品（15 分鐘）

**學生任務：** 不使用句型，整合 A～C 寫 40～60 個中文字的影片需求。

**可接受的 Prompt 範例（僅教師版）：**

1. `生成約五秒的奇幻博物館影片，藍色月亮和三顆星星快速飛向明亮出口，畫面明亮神祕，不要可閱讀文字。`
2. `做一段五秒影片：鏡頭快速穿過明亮博物館，前方有藍色月亮和剛好三顆星星，沒有任何文字。`
3. `在明亮的博物館裡，藍色月亮帶著三顆星星快速往出口移動，約五秒，氣氛像清亮的長笛，不要文字。`

**不應接受：** 未使用星星數量、沒有藍色、沒有出口或快速感、出現可閱讀文字、只寫 `做出口影片`。

**常見錯誤與提示：**

- 少了星星數量：`你的影片有月亮了，前面保存的星星數量在哪裡？`
- 快速感不明：`想想鏡頭或月亮要怎麼移動，觀眾才知道它很快。`
- 一次塞進太多新條件：`先保住前面一定要用的資料；其他想法可以少一點。`

**評審條件：** 影片 Prompt 預審先確認畫面主體與顏色、星星數量、出口、快速移動、約 5 秒及無文字，再開放預製影片。答題卡送審時，Prompt 約 40～60 字或清楚呈現同等資訊量；資料可追溯至 A～C；影片、Prompt 摘要與修改次數均已保存。

## 統一退件回饋原則

一次只指出一個最重要的缺漏，不提供完整正確 Prompt。

可使用的回饋：

- `你有貼資料，但還沒告訴 AI 要幫你做什麼。`
- `AI 已經解釋符號了，現在想想怎麼把它們變成圖片要求。`
- `你已經找到目標條件，再比較原本哪一項和它相反。`
- `你的影片需求還少了一項前題資料，回到通關紀錄逐項核對。`

禁止用錯字、標點、口語化或沒有專業術語作為退件理由。

## 課堂流程

| 時間 | 學生活動 | 教師任務 |
| --- | --- | --- |
| 0–5 分鐘 | 故事開場、答題卡與「資料可複製，問題自己打」 | 只說明每區要達成的目的與檔案形式；不說工具名稱、不指定入口 |
| 5–19 分鐘 | A：整理異常文字與題中小測 | 只問「你看到哪裡怪？你想請 AI 做什麼？」 |
| 19–33 分鐘 | B：選畫、讀 Emoji、做圖片與題中小測 | 檢查學生先使用 A 的指令，再提醒四項圖片條件 |
| 33–47 分鐘 | C：速度換算、找衝突、做音樂與題中小測 | 讓學生先從 B 卡找數字，不直接說速度 |
| 47–60 分鐘 | D：整合資料、做出口影片與題中小測 | 請學生在生成前逐項說出每條資料來源；影片逾時改留 Prompt＋備援分鏡 |
| 60–90 分鐘 | 自由遊玩時間 | 學生選擇 Minecraft、Lab Terminal 小遊戲或老師提供的介面；老師觀察，不介入 |

## 技術備援

| 狀況 | 備援方式 |
| --- | --- |
| 文字工具回覆太長或偏題 | 請學生改成「只整理這段資料」或「只找一個衝突」；必要時教師提供非答案的結果格式 |
| 預製圖片無法載入 | 保留已通過的學生 Prompt；重新載入或由教師上傳同一張圖片，不要求學生改 Prompt |
| 預製音樂無法播放 | 保留已通過的學生 Prompt；重新載入或由教師上傳同一段音樂，不要求學生改 Prompt |
| 預製影片逾時或無法播放 | 保留已通過的學生 Prompt；改用同內容分鏡成果卡，不要求學生改 Prompt |
| 學生輸入困難 | 可複製原始資料與 Emoji；教師可提供關鍵詞字卡，但不提供完整問句 |
| 答題卡未保存 | 先保留學生畫面截圖或筆記本內容，修復後再回填；不可要求學生重打整段 Prompt |

## 差異化與同儕協助

先完成的學生可以問同學：

- `你現在看到的問題是什麼？`
- `你希望 AI 做哪一件事？`
- `這個答案能讓你進下一題嗎？`

先完成的學生不可以說出倒序文字答案、選畫答案、速度答案、衝突條件或完整影片 Prompt，也不可以代打、代生成、代上傳。

## 成功條件與 W05 銜接

- 四張答題卡各保存問題、目標、學生 Prompt、AI 結果、下一題鑰匙與修改次數。
- B、C、D 分別保存圖片、音樂、影片或其技術備援紀錄。
- 學生能至少舉出一次「我修改了哪一句，AI 才比較懂」。

結尾告訴學生：

> 現在你已經會自己問 AI 了。下一步，要學的是讓 AI 按照你指定的方法回答。
