# S3 W05 教案｜失落規格的溪谷

> Runtime Release：`S3W05-LTQ-R20-CLEAR-SPEC-LOGIC-20260915`
> 正式機讀內容在 `gpt-clone/src/config/s3w05QuestData.json`；本教案不重抄題目與答案。

## 教學目標

學生能從 NPC 對話或固定圖像證據中，辨認可檢查的條件、說出漏寫可能造成的具體失敗，並以清楚寫法手動組成 prompt。學生不需要把資訊強制分類或依固定順序排列。

## 課程流程

| 階段 | 學生活動 | 教師觀察 |
|---|---|---|
| 問題導入 | 看見無法使用的設施 | 學生是否先描述「哪裡不能用」。 |
| 證據蒐集 | 自然提問或觀察 B 站固定葉片圖 | 學生是否回到原話／原圖，而不是靠猜。 |
| 四題確認 | 內容、漏寫後果、規格理由、清楚寫法 | 學生能否用具體失敗說明漏寫的影響。 |
| 組 prompt | 手動複製、貼上或輸入已確認的條件 | 不替學生貼入；提醒他們檢查是否足以修好問題。 |
| 成果與挑戰 | Lab Image 產出、葉片轉動／路標／燈台挑戰 | 只有完成後才出現對應世界改變。 |

## 各站提醒

- A：修好橋後，學生必須自己走進運菜林道，完成三波小豬護送，才到 B。
- B：只教葉片的外形、中央組合、完整度；不要延伸到升降台、風車塔、曲柄或房屋。
- C：完成圖片後的 Skill Check 是修復後挑戰，不是另一份規格題。
- D：結局是溪谷鎮修復節的閉幕，徽章投向四座燈台；不得使用星門、傳送或馬雅遺跡說法。

## 技術準備與驗收

測試入口：`/dev/lab-terminal-quest`。發布或課前驗收使用：

```text
npm run test:s3w05-release
npm run test:s3w05-phaser-data
npm run test:s3w05-phaser-runtime
npx tsc --noEmit
```

五態檢視入口：`/dev/s3w05-phaser-states`。學生端需要同時可用鍵盤、滑鼠或觸控操作；作答面板開啟時，移動與 E 互動應一併鎖住。

## 課時狀態

R20 的動作級估算為 **99.8 分鐘**，超過 50–65 分鐘主線目標。原因是完整流程含 48 題確認、四次 Lab Image、運菜林道路途事件，以及 B／C／D 完成挑戰。

因此目前版本適合約 100 分鐘的完整體驗；若課程只能安排 50–65 分鐘，需由課程負責人決定要拆成兩次課、把哪一部分改為選修，或重設題數。不要以跳過閱讀、略過理解確認或代替學生組 prompt 的方式壓縮時間。
