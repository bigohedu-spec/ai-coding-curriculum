## 教學目標
1. 熟悉基本操作：能在 Minecraft 移動、挖掘、放置方塊，完成基本生存動作。
2. 留下第一個作品：在世界中建造能代表自己的東西，建立「這是我做的」身份感。
3. 體驗點數閉環：第一次完成任務獲得點數，理解 Minecraft 與 Lab Terminal 共用同一個點數錢包。

## 三大核心概念對應
- 🎮 遊戲化：本週啟動點數系統。任務 → 截圖 → 教師確認 → 點數發放的閉環，點數可在 Minecraft 與 Lab Terminal 兩平台消費（Gacha）。第一次發點數公開宣告，強化成就感。
- 🤖 AI 優先：本週主線以 Minecraft 操作為主；**課前用 Lab Terminal 暖身互動課**（見下）讓學生先認識操作/點數/求助順序，並知道「下週起遇到問題先問 Lab Terminal」。
- 🔄 翻轉教育：學生自行讀學習單就開始操作，不等老師逐步說明。求助順序：學習單 → Lab Terminal → 同學助教 → 老師（每人每堂最多 3 次；本週寬鬆執行、宣告規則生效）。

## 課前準備
**教師**
- 確認所有學生帳號可登入伺服器；Lab Terminal 暖身互動課可開啟。
- 準備公開宣告：第一次發點數的儀式。
- 黑板建立「問老師次數」追蹤欄。

**學生**
- 電腦已安裝 Minecraft Java 版；拿到學習單。

## 課堂流程（第十三節 60+30 結構）

## Lab Terminal 使用
- **暖身互動課**（課前 ~8 分鐘）：見 [[S1-W01-課程規格-G1-G2]]（操作配對、點數閉環、求助順序）。
- **主線提問**：本週 Minecraft 操作若卡住，先問 Lab Terminal，例：
  > 「Minecraft 裡怎麼挖樹？需要工具嗎？」　「Minecraft 截圖存在哪裡？怎麼找到？」

## 翻轉教育流程
| 角色 | 流程 |
|------|------|
| 先行者（助教） | 完成任務 A 後舉手 → 老師指派 → 協助一位同學完成 A（提示操作，不替他截圖）→ 領 TA 點數 30 點（A 的 50%） |
| 進行中學生 | 看學習單 → 問 Lab Terminal → 問助教同學 → 問老師（限 3 次） |

> ⚠️ 學生來問老師先反問：「學習單上有說嗎？」「問過 Lab Terminal 了嗎？」

## 老師筆記
**常見問題**
- 不會截圖 → 提示看學習單（不直接告知）。
- 蓋的東西「太小/不像樣」→ 只要刻意建造都接受，不設門檻。
- 問老師超過 3 次 → 「今天次數用完了，請問 Lab Terminal。」

**教學重點提醒**
- 第一堂目標是「讓學生喜歡來這裡」，完成品質不重要。
- 首次進入很生疏（游標亂飄、找不到方塊），這是正常的，給足時間、耐心等待手感。
- 問老師次數規則今天宣告，下週起正式嚴格執行。

**延伸挑戰（進階，不影響主線）**：建造物加顏色/裝飾；或找一個天然有趣地點（洞穴/懸崖/村莊）截圖分享。
