# AI 繪本 L3｜生圖與挑圖 開發規格（給工程 LLM）

> 對應教案：[[繪本示範課-L3-AI生圖-教案]]。所屬：[[AI繪本示範課-總覽]]。承 L2（[[繪本示範課-L2-故事腳本-教案]]）存好的**八格故事**、承 L1 的**定裝主角**。
> **本課最重要的技術＝確保「所有頁面的角色外觀一致」**——因此 **§P 一致性 Prompt 架構是本規格的主角**，其餘（流程、UI、資料）都服務它。
> 生圖模型：**Google Nano Banana（Gemini Flash Image）**（總覽已選定），image-to-image／參考圖 + 批次 API。
> 學生只做「挑圖」；**絕不露 prompt**。

## §G 規格治理
- **正典聲明**：本 spec 是唯一真相；成品迭代回填本檔。
- **綁定實作檔**：`public/games/picturebook-l3-pick.html`（或整合進繪本工作坊 app 的 L3 分頁）。
- **In Scope**：依 L2 八格故事**逐頁生圖**（角色一致）＋**逐頁挑圖**（一次一頁、每張最多重生 1 次）＋挑定存檔給 L4。
- **Out of Scope**：改故事（L2）、封面/成書（L4）、prompt 教學（學生不碰 prompt）。
- **輸入**：L2 存好的八格故事（綁 uid）＋ L1 定裝主角圖與角色設定表。
- **輸出**：每頁挑定 1 張插圖（綁 uid），供 L4 一鍵成書。

## §FLOW 流程（依需求：預生 + 逐頁 + 重生一次）
1. **切頁**：把 L2 八格自動排成 **8–12 頁**（低年級 8、高年級 10–12），每頁一句「這頁在演什麼」。
2. **開場即背景預生全部頁（≈12 張）**【規定】：**學習單/課程一開始，就批次背景生成整本每頁各 1 張**（不是等學生翻到才生）。顯示總進度（「畫好 X／12 頁」）。→ 學生逐頁時圖已就緒、**秒開不等待**。
3. **逐頁挑圖・一次一頁**【規定】：**畫面一次只顯示「當前這一頁」**（不並列全部）。每頁：
   - 顯示這頁的預生圖。
   - 兩個動作：**[就用這張]** ／ **[重生一次]**（顯示「還可重生 1 次」）。
   - 按重生 → 生第 2 張（同角色同畫風、只換一點鏡頭/表情/構圖）→ 從（原＋新）**挑一張定案**。
   - **每張圖最多重生 1 次**【規定・覆寫總覽「換批上限 3」→ L3 內頁 = 1 次，顧成本】。
   - 定案 → 存檔（綁 uid）→ **下一頁**。
4. **挑完整本** → 進 L4 成書。做不完的頁次：老師端或 L4 補。

> 為什麼預生＋逐頁：預生免掉每頁等生圖的空檔；逐頁讓小朋友專注一頁、不被整本淹沒（第十九節：一次一件）。

## §P 一致性 Prompt 架構【本課核心・最重要】
> 目標：**任何兩頁擺一起，都是同一隻主角、同一畫風**。做法＝**把「角色」與「畫風」鎖死、每頁只變「這頁在做什麼」**。

### 生圖公式（每頁都用同一個組裝，順序固定）
```
[參考圖：L1 定裝主角圖]                     ← 最強的一致性錨（image-to-image / character reference）
＋ [角色設定表]（鎖定，一字不差每頁重貼）      ← 物種/顏色/特徵/配件/五官
＋ [這頁畫面]（唯一變數：場景＋動作＋表情＋鏡頭） ← 由 L2 該格故事產生，只描述「非角色」的部分
＋ [統一風格後綴]（鎖定，每頁自動接）           ← 畫風/色盤/光線/媒材
＋ [負面詞]（鎖定）                          ← no text in image、不要換角色、不要變色
```

### 五個鎖定件（學生看不到、不可改）
1. **角色設定表（最關鍵）**：L1 定裝後產生一段**固定文字**（例：「a small round orange clownfish with one chipped fin, big shiny eyes, tiny red backpack」）。**每頁生圖都原封不動重貼這段**——絕不讓模型每頁自己重寫角色描述（那是外觀漂移的頭號原因）。
2. **定裝主角圖當參考圖**：用 L1 那張定裝圖做 image-to-image／character reference，鎖住長相（比文字更強）。
3. **統一風格後綴**：全書同一段畫風描述，每頁自動接（例：「soft warm children's storybook illustration, teal-and-blue palette, gentle lighting」）。
4. **負面詞/護欄**：`no text/letters in image`、`same character`、`consistent colors`，避免跑字、換角色、變色。
5. **只有「這頁畫面」是變數**：從 L2 該格故事萃取**場景＋動作＋表情＋鏡頭**，**只描述背景與動作，不重新描述主角外觀**（外觀交給前兩件）。

### 一致性保障（工程必做）
- **主角描述逐頁重貼、不重寫**；**參考圖/seed 固定**。
- **系統自動一致性重試（不計入學生的「重生 1 次」）**：若某頁生出的圖偵測到角色明顯不像（顏色/物種/配件對不上），系統**自動用更強的參考權重重生**，直到像為止——這是後台品保，不消耗學生額度。
- **驗收**：抽查全書任兩頁，主角**物種/顏色/特徵/配件一致**；畫風一致；圖內無文字。

### 範例（示意，實際由後台組裝）
> 參考圖：`clownfish_hero_ref.png`｜角色設定表：`a small round orange clownfish with one chipped fin, big shiny eyes, tiny red backpack`｜這頁畫面：`swimming nervously into a dark coral cave, looking scared`｜風格：`soft warm children's storybook illustration, teal-and-blue palette`｜負面：`no text, same character, consistent colors`

## §DATA 資料與工程【一等公民】
- **挑定圖存檔綁 uid**：`bookPages/{uid}[pageN] = 挑定圖`；跨裝置取進度較遠者；登出清本機暫存。
- **預生佇列**：開場 enqueue 全部頁批次生圖；每頁一個穩定 key，**冪等**（重整/回來不重複生、不重複扣成本）。
- **重生額度**：每頁 `regenUsed ≤ 1`（學生額度）；系統一致性重試另計、不受此限。
- **缺圖/逾時後備**：某頁未生好 → 顯示載入/佔位；逾時放行、退向量佔位圖，不卡課堂。
- **成本**：Nano Banana 批次；一本預生 12＋學生重生（每頁最多 1）≈ 可控（呼應總覽成本估）。

## §UI / 雙難度
- **一次一頁**、大圖、[就用這張]/[重生一次]兩顆大鈕、進度「第 X／N 頁」；不並列全部。
- **高年級（小四五六）**：8–12 頁；重生時可加一句「想要更＿＿（傍晚/開心/熱鬧）」微調（仍不碰 prompt，選詞而已）。
- **低年級（小二三・第十九節）**：8 頁；只有 [用這張]/[重生] 兩顆，圖示化、點一下；口頭說「為什麼挑」。

## §TEACHER 老師端
- 全班進度（各生挑到第幾頁）；**一鍵「幫某生把某頁重生」**（額度外，救援用）；教師端網址。
- 加彩蛋（招牌活動）：對某頁「加一個小細節」再生（老師可代按，不占學生額度）。

## §DoD 驗收清單
- [ ] 開場**批次背景預生全部頁**（≈12 張）＋進度顯示；逐頁秒開不等待
- [ ] **一次只顯示一頁**（不並列全部）；[用這張]/[重生一次]；**每張最多重生 1 次**（覆寫總覽 3）
- [ ] **§P 一致性 prompt 架構落實**：角色設定表逐頁重貼不重寫、定裝圖當參考圖、統一風格後綴、負面詞；每頁只變「這頁畫面」
- [ ] **一致性驗收**：抽任兩頁主角同一隻（物種/顏色/特徵/配件）、畫風一致、圖內無字
- [ ] 系統自動一致性重試（角色不像→加強參考重生），不計入學生額度
- [ ] 挑定圖綁 uid 存檔、冪等；缺圖/逾時後備放行
- [ ] 學生**看不到 prompt**；雙難度（頁數/微調詞）；老師端進度＋救援重生＋彩蛋
- [ ] In/Out：只做逐頁生圖＋挑圖；不改故事（L2）、不成書（L4）
