# Minecraft 生存入門 L01｜採集與合成：做出你的第一套工具 教案

## 基本資訊
| 項目 | 內容 |
|------|------|
| 年級 | 通用（建議小三左右；可插入任一已導入 Minecraft 的學期） |
| 模組 | Minecraft 生存入門（4 堂：採集合成 → 生存建築 → 座標導航 → 探險回家） |
| 課次 | L01 |
| 時間 | 90 分鐘（60 分鐘任務 + 30 分鐘自由遊玩） |
| 任務 ID | MCS-L01-A、MCS-L01-B |
| 工具 | Minecraft（Java 版，生存模式）+ Lab Terminal（查合成表用） |
| 金幣 | A：150 / B：100（主線合計 250） |

## 教學目標
- 學生能砍樹取得木頭，並合成木板、木棍、工作台。
- 學生能用工作台做出一整套木製工具（鎬、斧、劍、鏟）。
- 學生能用木鎬挖石頭，升級出石製工具並做出熔爐。

## 三大核心概念對應
- 🎮 遊戲化：從「空手發呆」到「擁有整套工具」，闖過採集→合成的關卡，拿 250 金幣與「工具學徒」進度。
- 🤖 AI 優先：不記得某個東西怎麼合成時，**先問 Lab Terminal**（見下方 Prompt 建議），不是先問老師。
- 🔄 翻轉教育：先做完的同學當「小老師」，用動作示範合成步驟給卡住的同學看（不直接幫按）。

## 課前準備
**教師：**
- 確認每台電腦能進入同一個生存模式世界（或各自的世界），出生點附近有樹木。
- 準備一張放大的「基礎合成流程圖」：原木 → 木板 → 木棍 / 工作台 → 工具。
- 自己先示範一次完整流程（砍樹到石製工具），時間控制在 8 分鐘內。

**學生：**
- 進入生存模式世界，站在出生點。
- 認得滑鼠左鍵（打/挖）、右鍵（放/使用）、E（打開物品欄）。

## 課堂流程
| 時間 | 活動 | 說明 | 教師角色 |
|------|------|------|---------|
| 0–8 分鐘 | Hook + 老師示範 | 「空手是活不下去的——今天把你的第一套工具做出來！」老師示範砍樹→合成→做工具。 | 示範 |
| 8–35 分鐘 | 任務 A：木頭與工作台、木工具 | 學生砍樹收集木頭，合成工作台，做出整套木製工具。 | 巡視、管理小老師 |
| 35–56 分鐘 | 任務 B：石頭與升級 | 用木鎬挖石頭，升級成石製工具，做出熔爐。 | 巡視、管理小老師 |
| 56–60 分鐘 | 截圖 + 舉手告知老師 | 學生截圖物品欄，舉手 | 確認 |
| **60–90 分鐘** | **🎮 自由遊玩時間** | 學生用本週賺取的金幣，在 Minecraft / Lab Terminal 小遊戲 / 其他介面自由活動 | 老師觀察，不介入 |

## Lab Terminal Prompt 建議
本堂以 Minecraft 操作為主，但**遇到「某個東西怎麼合成」時先問 Lab Terminal**：

> - 「Minecraft 裡工作台要用什麼合成？要放幾個木板？」
> - 「石鎬的合成表長什麼樣子？材料要怎麼擺？」
> - 「熔爐需要幾個圓石？怎麼排列？」

📌 小技巧：問的時候講清楚「要合成什麼」和「你手上有什麼」，Lab Terminal 給的答案會更準。

## 翻轉教育流程
**先完成的小老師 🏆：**
1. 舉手告知老師
2. 老師指派去示範合成步驟給一位卡住的同學看（用動作示範，不直接幫他按）
3. 幫助成功後，領取 TA 金幣：**A 75 / B 50（對應任務的 50%）**

**還在進行的學生：** 不會合成先問 Lab Terminal → 再看小老師示範 → 最後才問老師。

## 成功條件
| 任務 ID | 金幣 | 成功條件 |
|---------|------|---------|
| MCS-L01-A | 150 | 截圖物品欄，顯示已有工作台與整套木製工具（鎬/斧/劍/鏟至少 3 種）；舉手告知老師 |
| MCS-L01-B | 100 | 截圖物品欄，顯示已有石製工具（至少石鎬）與一個熔爐；舉手告知老師 |

## 老師筆記
**常見問題：**
- 砍完樹拿到的是「原木」，要先在物品欄把原木變成木板才能合成。
- 只用物品欄的 2×2 格做不出工具，要先放下工作台、對它按右鍵打開 3×3。
- 工具耐久用完會壞：提醒多備一點木頭/石頭。
- 找不到石頭：往地下挖幾層，或找山壁；泥土下面就是石頭。

**教學重點提醒：**
- 重點是「採集 → 合成」的循環手感，多做幾次自然會記住，不必背合成表。
- 鼓勵卡住先問 Lab Terminal，養成 AI 優先習慣。

**延伸挑戰（進階，不計入 250）：** 多做一個儲物箱把材料收好；或收集煤炭當熔爐燃料。
