# Minecraft 生存入門 L03｜座標導航：永遠找得到回家的路 教案

## 基本資訊
| 項目 | 內容 |
|------|------|
| 年級 | 通用（建議小三左右；需能讀多位數數字） |
| 模組 | Minecraft 生存入門（4 堂） |
| 課次 | L03 |
| 時間 | 90 分鐘（60 分鐘任務 + 30 分鐘自由遊玩） |
| 任務 ID | MCS-L03-A、MCS-L03-B |
| 工具 | Minecraft（生存模式，F3 除錯畫面）+ Lab Terminal |
| 金幣 | A：150 / B：100（主線合計 250） |
| 前置 | L01–L02（有家可以當基準點） |

## 教學目標
- 學生能打開 F3 除錯畫面，找到自己的 XYZ 座標。
- 學生能記下「家」的座標，並理解 X / Z 是水平位置、Y 是高度。
- 學生能往指定方向移動，觀察座標數字的變化，並走回家附近。

## 三大核心概念對應
- 🎮 遊戲化：「迷路了怎麼辦？學會這串神秘數字，你永遠找得到回家的路。」把座標當成尋寶密碼。
- 🤖 AI 優先：不確定「X、Y、Z 是什麼意思」先問 Lab Terminal。
- 🔄 翻轉教育：先學會看座標的同學，示範怎麼開 F3、數字在畫面哪裡。

## 課前準備
**教師：**
- 確認學生的 Minecraft 可用 F3 顯示座標（部分鍵盤需 Fn+F3）。
- 準備一張大圖：F3 畫面上「XYZ」在哪一行、各代表什麼（X/Z 水平、Y 高度）。
- 示範一次：開 F3 → 找到座標 → 記下家的座標 → 走幾步看數字變化。

**學生：**
- 已完成 L01–L02，站在自己的家門口。
- 準備一張紙或在旁邊記下數字。

## 課堂流程
| 時間 | 活動 | 說明 | 教師角色 |
|------|------|------|---------|
| 0–8 分鐘 | Hook + 老師示範 | 「這串數字，是你回家的密碼。」老師示範開 F3、找座標、記家的座標。 | 示範 |
| 8–34 分鐘 | 任務 A：找到並記下家的座標 | 學生開 F3，找到自己站的 XYZ，記下「家」的座標，截圖 F3 畫面。 | 巡視、管理小老師 |
| 34–56 分鐘 | 任務 B：走動觀察座標變化 | 往一個方向走約 50 格，觀察哪個數字在變（X/Z），理解 Y 是高度；再走回家附近。 | 巡視、管理小老師 |
| 56–60 分鐘 | 截圖 + 舉手告知老師 | 截圖記錄的座標與變化，舉手 | 確認 |
| **60–90 分鐘** | **🎮 自由遊玩時間** | 學生用金幣自由活動 | 老師觀察，不介入 |

## Lab Terminal Prompt 建議
> - 「Minecraft 的 F3 畫面裡，X、Y、Z 各代表什麼？」
> - 「我想記住我家的位置，應該記哪幾個數字？」
> - 「往北走的時候，座標的哪個數字會變大還是變小？」

📌 小技巧：把你「在畫面上看到的數字」也告訴 Lab Terminal，它能幫你解讀那代表什麼。

## 翻轉教育流程
**先完成的小老師 🏆：**
1. 舉手告知老師
2. 老師指派去示範「怎麼開 F3、座標數字在哪一行」給還沒找到的同學
3. 幫助成功後，領取 TA 金幣：**A 75 / B 50**

**還在進行的學生：** 先問 Lab Terminal → 看小老師示範 → 最後才問老師。

## 老師筆記
**常見問題：**
- F3 畫面資訊很多，學生找不到座標：指出「XYZ」那一行即可，其他先忽略。
- 分不清 X 和 Z：讓學生只往一個方向走，看哪個數字動，就是那個方向的軸。
- 數字有負號或小數：告訴他們記整數、負號也要記（代表方向）。

**教學重點提醒：**
- 這堂認知負荷較高（讀數字、記數字、判斷方向），節奏放慢，多讓學生走幾趟親眼看數字變化。
- 座標是下一堂「探險回家」的關鍵前置，務必讓每個人都記下家的座標。

**延伸挑戰（進階，不計入 250）：** 在家門口用方塊排出家的座標數字當「門牌」。
