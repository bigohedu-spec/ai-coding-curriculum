# Minecraft 生存入門 L02｜生存建築：天黑前蓋好你的家 教案

## 基本資訊
| 項目 | 內容 |
|------|------|
| 年級 | 通用（建議小三左右） |
| 模組 | Minecraft 生存入門（4 堂） |
| 課次 | L02 |
| 時間 | 90 分鐘（60 分鐘任務 + 30 分鐘自由遊玩） |
| 任務 ID | MCS-L02-A、MCS-L02-B |
| 工具 | Minecraft（生存模式）+ Lab Terminal |
| 金幣 | A：150 / B：100（主線合計 250） |
| 前置 | L01（需要工具採集建材） |

## 教學目標
- 學生能採集建材（木頭 / 圓石 / 泥土任一），蓋出一間四面封閉、有屋頂和門的小屋。
- 學生能在天黑前躲進屋內安全過夜（不被怪物攻擊）。
- 學生能在屋內放置火把照明，並做出一張床（或儲物箱）。

## 三大核心概念對應
- 🎮 遊戲化：「太陽下山，怪物要來了——你能在天黑前蓋好家嗎？」限時求生的挑戰感，蓋好家＝闖關成功。
- 🤖 AI 優先：不知道「床怎麼做」「火把要什麼材料」先問 Lab Terminal。
- 🔄 翻轉教育：先蓋好的同學示範「怎麼把牆封起來、門怎麼裝」給還在蓋的同學。

## 課前準備
**教師：**
- 確認世界時間可設定，或安排課堂節奏讓學生經歷一次「天黑」。
- 準備一張「最小生存屋」示意圖：四面牆 + 屋頂 + 一個門 + 屋內火把。
- 示範一次快速蓋出封閉小屋（8 分鐘內）。

**學生：**
- 已完成 L01，身上有工具。
- 站在一塊比較平的空地附近。

## 課堂流程
| 時間 | 活動 | 說明 | 教師角色 |
|------|------|------|---------|
| 0–8 分鐘 | Hook + 老師示範 | 「天黑前蓋好家，不然怪物會來！」老師示範採建材→圍牆→蓋屋頂→裝門。 | 示範 |
| 8–36 分鐘 | 任務 A：蓋出封閉小屋 | 採集建材，蓋出四面牆、屋頂、一個門的封閉小屋，天黑躲進去。 | 巡視、管理小老師 |
| 36–56 分鐘 | 任務 B：照明與床 | 屋內放火把照明，做出一張床（或儲物箱）。 | 巡視、管理小老師 |
| 56–60 分鐘 | 截圖 + 舉手告知老師 | 截圖小屋外觀與屋內，舉手 | 確認 |
| **60–90 分鐘** | **🎮 自由遊玩時間** | 學生用金幣自由活動（Minecraft / Lab Terminal 小遊戲 / 其他） | 老師觀察，不介入 |

## Lab Terminal Prompt 建議
遇到不會做的東西先問 Lab Terminal：

> - 「Minecraft 的床要用什麼材料做？需要幾個羊毛和木板？」
> - 「火把怎麼合成？需要什麼材料？」
> - 「怎麼樣的房子晚上怪物才進不來？」

📌 小技巧：把「你想達成什麼」講出來（例如「我想晚上不被怪物打」），Lab Terminal 會給你更完整的建議。

## 翻轉教育流程
**先完成的小老師 🏆：**
1. 舉手告知老師
2. 老師指派去示範「怎麼把牆封起來、屋頂怎麼蓋、門怎麼裝」給卡住的同學（動作示範，不代蓋）
3. 幫助成功後，領取 TA 金幣：**A 75 / B 50**

**還在進行的學生：** 先問 Lab Terminal → 看小老師示範 → 最後才問老師。

## 成功條件
| 任務 ID | 金幣 | 成功條件 |
|---------|------|---------|
| MCS-L02-A | 150 | 截圖顯示一間四面封閉、有屋頂和門的小屋（外觀看得出封閉）；並在屋內安全度過一次天黑；舉手告知老師 |
| MCS-L02-B | 100 | 截圖顯示屋內有火把照明，以及一張床（或一個儲物箱）；舉手告知老師 |

## 老師筆記
**常見問題：**
- 只圍牆沒蓋屋頂，怪物（蜘蛛）會爬進來：提醒一定要封頂。
- 門裝反或留縫：示範門的正確方向與貼合。
- 屋內太暗會刷出怪物：強調火把照明的重要。
- 沒有羊毛做不了床：可先用儲物箱替代，床留到有羊毛再做。

**教學重點提醒：**
- 建築不要求好看，重點是「封閉 + 能過夜」這個生存目標達成。
- 蓋牆是大量重複放方塊的動作，正好練手感，不用急。

**延伸挑戰（進階，不計入 250）：** 幫家開一扇窗（玻璃）；或在門口放火把當路標。
