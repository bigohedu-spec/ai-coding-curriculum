# Minecraft 生存入門 L04｜探險與回家：走出去，帶寶物回來 教案

## 基本資訊
| 項目 | 內容 |
|------|------|
| 年級 | 通用（建議小三左右） |
| 模組 | Minecraft 生存入門（4 堂，本堂為模組收尾） |
| 課次 | L04 |
| 時間 | 90 分鐘（60 分鐘任務 + 30 分鐘自由遊玩） |
| 任務 ID | MCS-L04-A、MCS-L04-B |
| 工具 | Minecraft（生存模式，F3 座標）+ Lab Terminal |
| 金幣 | A：150 / B：100（主線合計 250） |
| 前置 | L01–L03（要有工具、家、會看座標） |

## 教學目標
- 學生能先記下家的座標，帶著工具往一個方向出發探險。
- 學生能找到並記錄一個新地點（洞穴入口 / 村莊 / 不同生態域任一），採集一個當地特有物品。
- 學生能用 F3 座標判斷方向，安全回到出發的家。

## 三大核心概念對應
- 🎮 遊戲化：「別再待在家了！走出去，帶一個寶物回來——再靠座標找到回家的路。」冒險 + 回家的雙重成就。
- 🤖 AI 優先：不確定「往哪走會有村莊」「這個地形叫什麼」先問 Lab Terminal。
- 🔄 翻轉教育：先回到家的同學，分享「怎麼看座標判斷回家方向」給還在外面的同學。

## 課前準備
**教師：**
- 提醒安全原則：出發前工具、火把帶齊；記下家的座標；天黑或危險就先撤。
- 準備「探險目標卡」：洞穴 / 村莊 / 不同生態域（沙漠、雪地、海邊等）任選一種當目標。
- 示範一次：記家座標 → 往一個方向走 → 找到目標截圖 → 看座標走回家。

**學生：**
- 已完成 L01–L03，身上有工具、會看 F3 座標。
- 先在家門口記下家的座標。

## 課堂流程
| 時間 | 活動 | 說明 | 教師角色 |
|------|------|------|---------|
| 0–8 分鐘 | Hook + 老師示範 | 「走出去，帶一個寶物回來！」老師示範記座標→出發→找目標→靠座標回家。 | 示範 |
| 8–38 分鐘 | 任務 A：出發探險找目標 | 記下家座標，往一個方向探險，找到並截圖一個新地點，採集一個當地物品。 | 巡視、注意安全、管理小老師 |
| 38–56 分鐘 | 任務 B：靠座標回家 | 用 F3 座標判斷回家方向，安全回到出發的家。 | 巡視、協助判斷方向 |
| 56–60 分鐘 | 截圖 + 舉手告知老師 | 截圖探險地點、戰利品、回到家的座標，舉手 | 確認 |
| **60–90 分鐘** | **🎮 自由遊玩時間** | 學生用金幣自由活動 | 老師觀察，不介入 |

## Lab Terminal Prompt 建議
> - 「Minecraft 裡村莊通常在什麼地形出現？怎麼找比較快？」
> - 「我家的座標是 X＝100、Z＝200，我現在在 X＝100、Z＝260，要往哪個方向走才會回家？」
> - 「洞穴探險要注意什麼安全問題？」

📌 小技巧：把「你家的座標」和「你現在的座標」都告訴 Lab Terminal，它能幫你判斷回家的方向。

## 翻轉教育流程
**先完成的小老師 🏆：**
1. 舉手告知老師
2. 老師指派去示範「怎麼比較兩個座標、判斷往哪走回家」給還在外面的同學
3. 幫助成功後，領取 TA 金幣：**A 75 / B 50**

**還在進行的學生：** 先問 Lab Terminal → 看小老師示範 → 最後才問老師。

## 成功條件
| 任務 ID | 金幣 | 成功條件 |
|---------|------|---------|
| MCS-L04-A | 150 | 截圖顯示一個離家有段距離的新地點（洞穴/村莊/不同生態域），以及一個當地採集到的物品；舉手告知老師 |
| MCS-L04-B | 100 | 截圖顯示已回到出發的家（座標與出發時的家座標相符或非常接近）；舉手告知老師 |

## 老師筆記
**常見問題：**
- 走太遠迷路：這正是要用座標的時機，引導比對「現在座標」和「家座標」。
- 天黑遇到怪物：提醒先挖洞躲起來或往回撤，安全優先。
- 找不到村莊/洞穴：目標可放寬為「走到一個和家不一樣的生態域」即算數。
- 忘記記家座標：先回 L03 補記，沒有基準點就無法驗收回家。

**教學重點提醒：**
- 本堂把前三堂（工具、家、座標）整合成一次真正的「出門冒險」，是模組的高潮。
- 探險是大量移動的開放任務，鼓勵學生自己判斷方向，老師只在安全與卡關時介入。

**延伸挑戰（進階，不計入 250）：** 沿路每隔一段放一個方塊當「路標」，回程更快；或帶回兩種不同生態域的物品。
