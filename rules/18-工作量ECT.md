## 十八節、學習單工作量量化規則【不可違反】

> ⚠️ 每份學習單**定稿前**必須通過此驗證。驗證結果以 HTML 注釋形式附於學習單最底部，供日後審查。

### 核心原則

**主線任務（任務 A 到最後一個非可選任務）的 ECT 加總，必須落在 50–65 分鐘之間。**

- 低於 50 分鐘 → 不得定稿，必須增加任務或擴大範圍
- 高於 65 分鐘 → 拆分至下週，或將部分任務標為「進階可選」
- 進階可選任務（通常是最後一個任務）不計入主線，供快速完成的學生繼續挑戰

> 規則背景：課堂實測顯示，過短的學習單讓學生在 30 分鐘內全部完成。量化規則讓設計者在撰寫前就能自我檢查，不必等到課堂才發現份量不足。

---

### 標準估計完成時間（ECT）

以下時間以「一般速度學生、有 Copilot / Lab Terminal 輔助」為基準。

**固定項（每份學習單必加）**

| 項目 | ECT |
|------|-----|
| 閱讀學習單並理解任務說明 | 5 分鐘 |
| 全部截圖 + 舉手告知老師 | 2 分鐘 |

**S1–S4 Minecraft 任務**

| 任務類型 | ECT |
|---------|-----|
| 完成一個基本動作（挖、放、跳、截圖） | 2 分鐘 |
| 建造小型結構（< 20 方塊） | 12 分鐘 |
| 建造中型結構（需規劃 + 材料收集） | 22 分鐘 |

**S5+ 程式任務**

| 任務類型 | ECT | 說明 |
|---------|-----|------|
| 用 Copilot 寫一個函式（首次嘗試） | 12 分鐘 | 含理解建議、測試執行 |
| 用 Copilot 寫一個函式（已熟悉流程） | 8 分鐘 | 直接產出 |
| 把函式連接到 HTML（首次：按鈕 + 事件 + 顯示） | 12 分鐘 | |
| 把函式連接到 HTML（已熟悉流程） | 7 分鐘 | |
| 填寫一份結構化思考 / 規劃表格 | 5 分鐘 | 如邊界情況四格表 |
| 處理一個邊界情況（含實作） | 8 分鐘 | |
| 加入多行注釋說明（JSDoc 格式） | 5 分鐘 | |
| 使用 #file 引用並整合功能 | 10 分鐘 | |

**S7+ 部署任務**

| 任務類型 | ECT |
|---------|-----|
| 設定並推送到 GitHub Pages（首次） | 18 分鐘 |
| 設定並推送到 GitHub Pages（已熟悉） | 8 分鐘 |

### 計算步驟

1. 列出所有主線子任務（不含進階可選）
2. 固定加入：閱讀 5 分鐘 + 截圖告知老師 2 分鐘
3. 查表填入 ECT；無對應類型時自行估計並說明理由
4. 加總，與 50–65 分鐘目標對照
5. 在學習單最底部加入以下格式的驗證注釋：

```
<!-- ECT 計算
閱讀學習單：5 分鐘
任務 A：[說明] = X 分鐘
任務 B：[說明] = X 分鐘
（進階）任務 X：[說明] = X 分鐘（不計入主線）
截圖告知老師：2 分鐘
主線合計：XX 分鐘（目標 50–65 分鐘）
-->
```

### S5-W09 示例計算

| 子任務 | ECT |
|--------|-----|
| 閱讀學習單 | 5 |
| 任務 A：功能一，寫函式（首次）+ 連頁面（首次） | 12 + 12 = 24 |
| 任務 B：功能二，寫函式（熟悉）+ 連頁面（熟悉） | 8 + 7 = 15 |
| 任務 C：功能三，寫函式（熟悉）+ 連頁面（熟悉） | 8 + 7 = 15 |
| 截圖告知老師 | 2 |
| **主線合計（A + B + C）** | **61 分鐘 ✓** |
| （進階）任務 D：邊界情況思考 + 實作 | 5 + 8 = 13 |
