## 十五、學習單步驟詳細度規則【不可違反】

> ⚠️ 本節規定適用範圍：**工具操作步驟**。學習目標的認知過程（解題、思考、實作路徑的選擇）不適用本節，適用十七節。

### 核心原則

**學習單中的工具操作步驟，都必須詳細到學生不需要問老師就能完成工具本身的操作。**

> 背景：課堂實測顯示，步驟過於簡略的學習單（例如「打開 VS Code」、「問 Copilot」）導致學生在 20 分鐘內就完成全部內容，遠低於設計的 60 分鐘任務時間。詳細的工具操作說明是必要條件。

### 強制要求

**每個操作步驟必須包含：**

1. **具體動作**：點哪裡、按什麼鍵、輸入什麼
2. **預期結果**：做完這一步之後，畫面上會出現什麼
3. **如果不對怎麼辦**：常見的失敗狀況和排除方式

### VS Code + Copilot 操作的特別規定

凡涉及 VS Code 操作的學習單，必須包含以下層級的細節：

| 步驟類型 | 必須寫到的粒度 |
|---------|-------------|
| 開啟 VS Code | 在哪裡找到圖示、第一次開啟看到什麼畫面 |
| 建立新檔案 | 具體選單路徑（File → New File）或快捷鍵（Ctrl+N） |
| 開啟 Copilot Chat | 具體位置（左側欄圖示 / 選單路徑）、Chat 視窗長什麼樣子 |
| 輸入 Prompt 給 Copilot | 提供 2–3 個可直接複製使用的 Prompt 範本 |
| 接受 Copilot 建議 | Tab 鍵接受 / 點擊「Accept」按鈕的說明 |
| 執行程式 | 具體方式（右鍵 → Run Python / 終端機指令） |
| 儲存檔案 | Ctrl+S / Cmd+S，確認已儲存的視覺訊號 |
| 截圖確認 | 截圖工具、截哪個範圍，截好後舉手告知老師 |

### 任務份量規定

- **每週 EX 任務設計目標**：讓一般速度的學生剛好在 55–60 分鐘內完成主要任務（A）
- **進階任務（B/C/D）**：供快速完成 A 的學生繼續挑戰，不強制
- **驗收標準**：如果教師在課堂上觀察到大多數學生在 30 分鐘內就完成全部內容，學習單份量不足，下次修訂時必須加倍

### 學習單自我審核清單

撰寫學習單後，逐一確認：

- [ ] 每個步驟，學生不問老師也能完成？
- [ ] 有提供 2–3 個 Copilot Prompt 範本？
- [ ] 每個步驟後有說明「完成後你會看到什麼」？
- [ ] 有說明常見錯誤和排除方式？
- [ ] 內容份量估計需要 50–60 分鐘才能完成？
