## 十六、部署政策【S7 為正式里程碑；S5 起可提前體驗】

> **2026-09 決策**：作品部署與雲端後端全面改用自架的 **Big-Oh Hosting（bigoh.uk）**。
> 規範來源：`RULESFORAI.md` / `DEPLOYFORAI.md`（線上版 `https://bigoh.uk/llms.txt`），實作一律以這兩份為準。
> 原本的 GitHub Pages ＋ Supabase ＋ 公司 GitHub 帳號三層架構已作廢，不再保留舊條文（歷史見 git log：`ee99d71` 之前的 CLAUDE.md 第十六節）。

### 部署方式

- **部署**：Big-Oh CLI——`curl` 抓 `bigoh.mjs` → `node bigoh.mjs login`（學生本人在瀏覽器授權）→ `node bigoh.mjs deploy` → `https://<slug>.bigoh.uk`。
- 免審核、即時上線；重跑同一個 slug 即更新，保留 3 版。
- 配額：每位學生 5 個作品、每天 20 次部署、單作品 24MB。
- **雲端／後端**：平台自動注入的 `window.BO`（存檔、排行、留言、多人、帳號），詳見第十四節（`rules/14-工具使用政策.md`）。學生免帳號、免金鑰。
- 作品內**禁止**：外部網址 `fetch`、`<script type="importmap">`、任何金鑰或資料庫設定、廣告碼（平台會掃描退回）。

### S8：突破層與家長參與

- 「研究免費方案 vs 付費方案、哪些需要家長授權」是正式任務，不只是技術決定。
- 需要付費服務的學生，必須帶一份說明（工具名稱、費用、用途）請家長簽核，簽核過程計入任務成功條件。
- 老師的說法參考：「就像真正的新創公司要決定要不要花錢買伺服器，你也需要說服你的投資人（爸媽）。」

### 網路廣告政策【對應 S8 獲利長線】

- **課堂內（學生）只到概念與未來規劃，不在課堂上申請廣告帳號、不放真實廣告。**
- 事實依據：Google AdSense 等平台規定發布者須年滿 18 歲；未滿 18 歲須由家長／監護人以自己的帳號申請，款項付給該成人。
- 學生的廣告任務一律設計為「認識運作＋寫未來廣告計畫」，計畫至少包含：
  1. 廣告位置，以及「為什麼不會太干擾使用者」的理由
  2. 未來由哪位家長／監護人協助申請
  3. 網站要達到的內容品質
- **媒體素養**：好的網站先有價值、廣告是輔助；課程不得導向「塞滿廣告賺錢」。

#### 家長協作真實設定（選做，回家進行）

允許有意願的家庭讓孩子的網站放真實廣告，但僅限以下合規路徑：

- 必須由家長／監護人以**自己的成年帳號**申請，收入付給該成人；學生不得自行申請。
- 以**家長任務單**形式帶回家（範例：`wiki/worksheets/S{N}/...-家長協作任務-AdSense.md`），由家長操作。
- 任務單必須誠實揭露：審核不保證通過、收入通常極少、需達 US$100 付款門檻、需自訂網域（小額花費）、需家長個人與稅務資料、不可點擊自己的廣告（違規停權）、兒童導向網站的廣告法規限制。
- 完成標準是「家長與孩子一起做出決定並簽名帶回」，三種選擇（設定／先用免費網址試／暫不參與）同等完成，老師不評價家庭選擇。
- 廣告碼**不得**放進 Big-Oh 作品；真要放廣告，是在家長自架的自訂網域上進行（平台在外框處理自己的廣告）。
- 這是 S8「市場驗證／獲利」家長參與框架的提前體驗，S5–S7 皆可採用。
