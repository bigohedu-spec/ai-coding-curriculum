# Minecraft 任務清單｜AI 程式設計課程 四年完整版

## 說明

本文件定義四年課程（小三到小六，共八學期，每學期 24 週）的所有 Minecraft 任務。
所有課程任務皆透過 Minecraft 發布、驗收、獎勵，形成閉環。

---

## 任務類型定義

| 類型代碼 | 名稱      | 說明                                                |
| ---- | ------- | ------------------------------------------------- |
| MC   | 純 MC 任務 | 完全在 Minecraft 內完成（探索、建造、解謎、指令方塊）                  |
| EX   | 外部工具任務  | 在 MC 接任務，去外部工具完成（ChatGPT、Canva、VS Code 等），回 MC 繳交 |
| MS   | 里程碑成就   | 學期或模組結束時解鎖，代表階段完成                                 |
| RT   | 定時任務    | 每週固定刷新，培養回訪習慣                                     |

## 金幣獎勵基準

| 難度 | 金幣範圍 |
|---|---|
| 簡單（體驗性） | 20–30 |
| 中等（有明確產出） | 40–60 |
| 困難（創作型、需時間） | 70–100 |
| 里程碑 | 150–300 |
| 定時任務 | 20–30 |

---

## MVP 驗收方式（初期）

外部工具任務（EX）的驗收：
- 學生完成後截圖，提交給老師
- 老師在後台手動觸發任務完成，系統發放金幣
- 之後逐步替換為 AI 介面自動判斷

**任務 ID：S1-W01-A**

類型：MC

類型：MC

# 附錄：特殊任務類型

## 定時任務（每週刷新）

以下定時任務貫穿所有學期，每週一刷新：

**RT-001 每週探索任務**
說明：在地圖中找到本週的隱藏寶箱或新增的知識石碑。
金幣：20–30（隨學期難度增加）
備註：寶箱位置每週更換。

**RT-002 每週 AI 工具挑戰**
說明：用指定的 AI 工具完成一個迷你挑戰（不同週有不同工具和任務）。截圖成果。
金幣：25–40

**RT-003 同學回饋任務**
說明：對任何一個同學的作品或 Minecraft 建造給一句具體的回饋（不能只說「很好」，要說具體觀察）。
金幣：20

## 給 Minecraft 開發者的技術備註

1. **金幣系統**需要跨系統同步（Minecraft ↔ AI 對話介面），MVP 階段可先由老師後台手動發放。

2. **外部工具任務（EX）的驗收**：MVP 階段學生截圖提交給老師，老師在後台手動觸發任務完成。後期替換為 AI 介面自動判斷。

3. **每個學期的里程碑任務**需要有特殊的視覺效果（煙火、音效、門打開動畫）。

4. **工程師基地解鎖**（S5-W06）和**實現者基地解鎖**（S7-W01）是整個四年最重要的兩個儀式點，特別需要投入設計。

5. **永久個人展位**（最終里程碑）建議設計成一個固定的展覽區，每個畢業生有一個地塊，永久保留他們四年的作品展示。

6. **Demo 台**（小六上模組二）建議設計成可以放置告示牌和展示台的固定區域，每個學生有自己的 Demo 台位置。
