# 成果頁的踩坑與處理

> 格式：症狀 → 原因 → 處理。來源：成果頁 session 2026-10-22～10-28 的紀錄【實做】。可信度標記見 `../SKILL.md`。標「（遊戲端）」的是遊戲那邊的修正，列在這裡因為會讓成果頁出錯。

## A. 版面與文字

### 1. 六週總覽頁的標題被推出畫面頂端
- **原因**：六張週卡加注音，比一個畫面還高。
- **處理**：改成一週一列的任務表；說明用另一組短句（約 15 字）；標題不折行。

### 2. 中文換行斷在怪地方（「不懂就／問，」「機器／人」「的店／長！」）
- **原因**：瀏覽器預設任兩個中文字之間都能斷。
- **處理**：句段 `inline-block` ＋ `Intl.Segmenter` 詞斷 ＋ 課程詞表 ＋ 標點黏詞；長段落只用詞不拆開那一層（細節見 `design-method.md` §5）。

### 3. class 名稱撞到舊樣式，字跟字中間空出一大格
- **原因**：換行用的 class 與成果頁早期「單字牆」留下的樣式撞名，那個樣式會加內距、改字級。
- **處理**：改用專用、不會撞名的 class。**在舊頁面加 class 前先 grep 有沒有同名**。

### 4. 頁籤用 `inline-block` 時負 margin 推不上去
- **原因**：`inline-block` 在行框裡，負的 `margin-top` 推不動。
- **處理**：改成 `display:table`（一樣置中），負 margin 就推得動。

### 5. 背景分頁時整頁空白，或測試時動畫檢查一直卡住
- **原因**：分頁在背景時 `IntersectionObserver` 與 `requestAnimationFrame` 不會跑。
- **處理**：浮現動畫漸進增強＋3 秒退路；驗證動畫用前景無頭瀏覽器。

## B. 資料與週次

### 6. W18 過關後顯示「6 / 5 週」
- **原因**：成果頁原本把 W18 當成「就是這一頁」，遊戲後來把 W18 改成真的一週（最終決戰），也會記過關紀錄。
- **處理**：總週數改為 6，W18 的標題與說明跟遊戲對齊。**遊戲端改週次結構時，總週數、任務表／路程、結尾的「完成」判斷都要跟著改。**

### 7. 舊紀錄的 `made` 有欄位但全是 0
- **症狀**：某週賺了很多錢，做出來的東西卻是 0 個。
- **原因**：個數計數是 10/21 才開始；在那之前開始、之後才過關的那一週會是一排 0；老師跳關記的週也是 0。
- **處理**：`made` 加總是 0 時，也用金幣換算推估。

### 8. 「數字怪怪的」其實是測試資料的問題
- **症狀**：「大部分學生」的情境裡，問 AI 只有 3 次，員工順序只有兩位。
- **原因**：手寫的假資料只放一個主題、兩位員工。
- **處理**：測試資料一律從遊戲實際存檔做（`verification-and-restyle.md` §2）。

## C. 流程與課後複習

### 9. 課後複習直接開時是死路
- **症狀**：直接開遊戲（不經網站）打完 W18，到了成果頁只看到「這個連結少了一個代號」。
- **原因**：直接開遊戲時遊戲不知道 uid，換到課後複習時沒帶 uid。
- **處理**：複習頁沒有 uid 時，就在複習頁顯示「全部完成，回學習單」，不再連到成果頁。

### 10. 打贏後重新整理，進不了課後複習（遊戲端）
- **症狀**：學生打贏後還沒按「去課後複習」就重新整理，任務表停在「去課後複習」卻沒有按鈕。
- **原因**：結束畫面只在打贏當下出現一次。
- **處理**：載入時只要是「打贏了、還沒複習」，就重新跳出結束畫面。

### 11. W18 過關紀錄漏記（遊戲端）
- **症狀**：有些學生打贏了，存檔裡卻沒有 W18 紀錄 → 成果頁少一週。
- **原因**：原本等 2 秒爆炸動畫播完才記，這 2 秒內關掉就漏了。
- **處理**：打倒的那一刻就記並馬上存；載入時發現「打贏了但沒有 W18 紀錄」就補記並馬上存（不等 20 秒的延遲存檔）。

## D. 測試與工具

### 12. 在建置版裡找不到遊戲元件
- **原因**：建置時類別名被壓縮。
- **處理**：改用「有某個特定欄位（例如 `weekRecs`）的元件」找。

### 13. 無頭瀏覽器裡 Playwright 截 Cocos 畫面逾時
- **原因**：軟體繪圖下主執行緒被吃滿，`screenshot` 卡在等字型。
- **處理**：改用 CDP `Page.captureScreenshot`。

### 14. 觸發「打贏」後結束畫面不出現
- **原因**：載入要 20～30 秒；有存檔先跳「歡迎回來」視窗，沒存檔先跳 4 頁教學；有任何視窗開著結束畫面就排隊等。
- **處理**：先等「準備中」消失、確認到了 W18，關掉視窗，最後才觸發。

### 15. 用 Edit 工具改 bakery worktree 的檔案被 hook 擋
- **原因**：hook 把 `gpt-clone-bakery` 當成主 checkout；但小熊麵包坊的規定是所有東西放 bakery worktree。
- **處理**：改用 Node 腳本做「舊字串必須恰好出現一次」的替換，並保留原換行格式。
- **待確認**：這樣算不算合規，要問負責人【未驗證】。

### 16. 重撈 Firestore 學生存檔被權限擋下
- **處理**：不繞過；改用測試環境裡現有存檔加遊戲跳關產生的存檔。

## E. 協作（銜接約定）

- **遊戲端改了 `recordWeek` 或存檔欄位**（新增、改名、改語意），成果頁要同步檢查：
  - 統計函式讀的每一個欄位；
  - 補齊規則（`forms-and-data.md` §5）；
  - 遊戲裡的步驟、商品、地點名稱對照表與**售價表**，兩邊要一起改；
  - 週次標題與說明要跟遊戲任務表標題對齊。
- **遊戲端改了週次結構**（例如 W18 從「看成果」變成真的一週）：總週數、任務表／路程、結尾「完成」判斷都要改。
- **遊戲端改了 `review` 訊息或結束畫面**：整條流程重跑，嵌入與直接開兩種都要。
- **commit 前確認檔案沒漂移**：曾發生另一個 session 先把你還沒 commit 的改動一起 commit 進去。commit 時只 add 自己的檔案。
- **遊戲端有人同時在改**：改前先看 `git log`；建置只關「這次建置自己開的」Cocos 程序（見 `skills/cocos-web-game/reference/pitfalls.md` #3）。
