# 成果頁的設計方法

> 來源：P1U 小熊麵包坊 W18 成果頁 2026-10-22～10-28 的改版紀錄【實做】；S2 W06 的「給家長」寫法【文件】；`labterminal-course-spec/reference/shipped-benchmarks.md` 的 C6／C7。可信度標記見 `../SKILL.md`。

## 1. 給誰看、講什麼（負責人 2026-10-28 定的方向）

- **主要是家長**。家長不知道遊戲內容，所以**不放**：學生花了多少時間（分鐘、天數）、遊戲進度細節（關卡、等級、遊戲金幣、週次標籤）。
- **只講兩件事**：
  1. 這門課**為什麼這樣設計**（在練什麼、現在學有什麼好處、為什麼需要這個教材）；
  2. 學生**做到了什麼**——用**次數和個數**說，不用時間說。
- 文案風格：精簡、不要廢話、不署名；「給家長」那種頁，一句粗體主張接一句說明（參考 S2 W06 recap 的寫法：為什麼程式課在教怎麼問問題）。文案是草稿，負責人沒逐字定稿。

## 2. 頁數與內容組織（小熊麵包坊 10-28 定稿，共 11 頁，可當範本）

1. 封面
2. 這門課在練什麼（順序＋自動化＋AI 三件事合起來練什麼）
3. 學生做到了（一頁總覽，只放次數和個數）
4. 順序：學生排的步驟卡
5. 自動化：員工、機器人
6. AI：問過的主題收成一頁
7. 除錯：做錯了自己改對
8. 做出來的東西
9. 為什麼現在學
10. 給家長的話：孩子走過的路，加上「學了什麼／未來的挑戰／為什麼需要這個教材」三句
11. 結尾：教材完成、課後複習成績、回學習單／分享／列印

原則：**一頁講一件事**；學習到的差別靠**孩子自己的紀錄**呈現（他排的順序、他問的問題），而不是文字說教。

## 3. 美術與遊戲一致

- 直接抄遊戲 UI 的色票與形狀，不另外發明。小熊麵包坊：奶油色底（`#FFF8E7`／`#FFF3D6`）、暖橘粗框（`#F9A825`）、大圓角卡片、咖啡色字（`#4E342E`、次要 `#8D6E63`）、橘色大標（`#E65100`）、綠色按鈕（`#43A047`、陰影 `#2E7D32`）。色值從**遊戲原始碼畫面板的那段**讀出來。
- **每一頁就是一張「遊戲面板」**：頁面背景是地板（店裡的地板），面板壓一個頁籤在上緣框線正中間。
- **頁籤就是簡報標題**：負責人要求放大（14px → 18～22px），要壓在面板上框線正中間，用 `margin-top` 算中線，三種尺寸都量過。
- **畫面不能空**（負責人：「元素太空、每頁都一樣」）：
  - 用 inline SVG 畫遊戲裡的東西與員工頭像，**不用外部圖檔**；
  - 每一段換一種排法：數字方塊、步驟卡片、貨架、主題標籤、路線；
  - 每一段換地板顏色與頁籤顏色；
  - 地板兩側放兩個跟這頁有關的大圖示。

## 4. 動態與漸進增強

- 面板進場彈一下；地板圖示慢慢浮動、滑到那一頁時飄進來、捲動時有視差。
- 用 CSS 的 `rotate`／`transform`／`translate`／`scale` **分開疊**，互不覆蓋。
- 系統設定「減少動態效果」時全部關掉。
- **浮現動畫一定要漸進增強**：預設就看得見；只有確定 `IntersectionObserver` 真的會回報，才在 `html` 掛 class 把元素藏起來等進場；**3 秒內沒觸發就整個放棄動畫**並讓每頁 active。不這樣做，背景分頁或觀察器沒觸發時家長看到一片空白。

## 5. 字型、注音與換行

- 全部用 `/courses/bpmf.css` 的「Bpmf GenSen」（字本身帶注音）。**新寫的中文要確認字型 subset 有含到**，沒有的字會掉注音；`bpmf.css` 是兩段式 subset（常用字＋長尾按需），比舊 `recap.html` 寫死的 `bpmf-b.woff2` 安全。
- 注音讓一行變高：`line-height` 放寬到 **1.7～1.95**，版面預留高度。
- **中文換行**（瀏覽器預設任兩個中文字之間都能斷，會出現「不懂就／問，」「機器／人」）：
  - 照標點切成**句段**，句段用 `inline-block`，放不下就整段換行；
  - 句段太長，用 `Intl.Segmenter` 切成**詞**，只在詞與詞之間換行；
  - 另加一份**課程詞表**，因為內建斷詞會把「機器人」切開；
  - 標點黏前一個詞，開括號黏後一個詞；
  - 長段落（信件）只用「詞不拆開」那一層，不然每個逗號後都斷行。

## 6. 手機與矮螢幕

- 一頁一個畫面：`100dvh` ＋ `scroll-snap`。
- 驗收尺寸：**420×860、360×740、1280×800**；另加 `max-height` 媒體查詢，在矮螢幕收緊間距與字級。
- 六張週卡加注音會比一個畫面高：改成**一週一列的任務表**，說明用另一組短句（約 15 字），標題不折行。

## 7. 列印

- `@media print`：每頁改成高度自動、拿掉地板、圖示、按鈕、翻頁圓點，面板強制不透明、不播動畫。
- 按鈕呼叫 `window.print()`；分享按鈕複製目前網址（含 `uid`）。

## 8. 「同型」要連形式也一樣

說「跟 P1U-W06 同型」是連呈現形式都要一樣：家長成果頁是**整頁滑動的 slide deck**，不是一張靜態文件（S2 W06 第一版做成靜態秘笈被退）。家長頁也**要自己一支**，不能共用寫死別系列 key 的頁面（會一片空白）。
