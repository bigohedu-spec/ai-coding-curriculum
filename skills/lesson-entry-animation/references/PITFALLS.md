# 踩過的坑（做進課動畫前一定要看）

## 環境（這台電腦）

| 問題 | 做法 |
|---|---|
| 沒有 python／ffmpeg | 用 `uv run --with pillow --with numpy --with scipy python …`；需要音檔處理用 scipy |
| `C:\tmp\wave.py` 這類檔案會遮住標準函式庫（`import wave` 壞掉） | 腳本不要放在會被 import 路徑吃到的資料夾，或不要 import 同名模組 |
| Windows 的 node 讀不到 `/c/tmp` | 用 `C:/tmp`；複雜 node 指令寫成檔案再執行（bash 的引號會壞） |
| 大段 heredoc 在 Bash 會壞 | 用 Write 工具寫檔 |
| 內建瀏覽器分頁被隱藏時：`requestAnimationFrame` 變很慢、CSS 動畫不前進、截圖逾時 | 先拍一張小截圖喚醒；用「定格」模式看畫面；換頁時間點會因此偏晚，不是 bug |
| 內建瀏覽器的 JS 觸發的 click 不算使用者操作，`AudioContext` 解不了鎖 | 「點一下開始」要用真實點擊（`computer left_click`），其餘按鈕可用 JS |
| 程式存檔會觸發 HMR，頁面狀態被重置（又回到「點一下開始」） | 每次改完要重新點開始；批次改完再驗證 |
| dev server 用 `npx next dev -p 3210`（在主資料夾 `gpt-clone` 根目錄；主站是 3000）；偶爾會掛 | 用 `curl` 檢查 200 再開頁 |
| 內建瀏覽器在 125% 縮放螢幕上，`zoom` 截圖的裁切範圍對不上（截到的是放大的一塊） | 用整頁 `screenshot`，不要靠 `zoom` 裁；舞台太寬時把 `main` 設成 `width:76vw` 再截（只為截圖，會出 hydration 警告，不是程式問題） |
| 截圖常慢一拍（顯示上一個畫面） | `__go` 之後等 0.8～1 秒再截，或先拍一張小圖喚醒 |
| 窗格被隱藏／關掉時，長時間跑的 JS 會中斷、頁面可能被重新載入 | 檢查一次跑一兩頁（每次呼叫 < 40 秒），結果直接回傳，不要放在 window 等之後讀 |
| 窗格被隱藏太久，重新開頁時 React 沒有接手（`window.__go` 不存在、按鈕沒反應），看起來像 dev server 壞了 | 先拍一張 `screenshot` 喚醒窗格再等幾秒；用 `typeof window.__go` 確認。**不要去重開別人開的 dev server**（先用 netstat／程序指令確認是誰開的） |
| 互動頁最後一題答完要念「答對」＋結語（doneClip）＋等 2 拍才換頁，約 8～10 秒 | 驗「會不會換頁」要等夠久或逐秒記錄，不要等 5 秒就判卡住 |
| Bash 裡 `node -e '…'` 太長會引號解析失敗（整個沒執行） | 長的批次修改寫成檔案、或用 Edit 工具逐一改 |
| Python 在 Windows 印 ✓ 等符號會 cp950 錯誤 | 加 `PYTHONIOENCODING=utf-8` |
| 要輸出 mp3 但沒有 ffmpeg | `uv run --with soundfile`：libsndfile 1.2 支援 `format="MP3"` |
| 內建瀏覽器被藏起來時，畫面時鐘幾乎不走：用 JS 連續測互動會全部落在「還沒準備好」（只有喀聲）、截圖也會慢半拍看不到跳字 | 邊測邊截圖讓它保持在跑；跳字用 `innerText` 檢查有沒有出現，不要只看截圖 |
| 新課登記到 `lessons/index.ts` 後，審稿頁 404 | `getStaticPaths` 在 server 啟動時就固定了，要重開 dev server |

## 網站 CSS

- **全站 CSS 把所有元素設成等寬字**：每個要顯示中文／注音的元素都要自己設 `fontFamily`（`"Bpmf GenSen","Bpmf GenSen X","Noto Sans TC",…`），不能靠繼承。
- **全站 `img{max-width:100%}`**：定位用的圖要 `max-width:none`（`sc.layer` 已處理）。
- 用 `dangerouslySetInnerHTML` 放 `<style>`，不要在 JSX 放含引號的字串（SSR 與 client 的跳脫不同會 hydration 錯誤）。不要在 `next/head` 放 stylesheet（會警告但可用）。
- 字太粗的描邊會蓋住注音：標題用細描邊（`text-stroke` 約字級的 4～5%）。

## 聲音

- **瀏覽器擋自動播放**：`AudioContext.resume()` 在沒有使用者操作時不會失敗也不會完成，**不能 await**。流程用「點一下開始」解鎖。
- 排程音符要用**絕對的音訊時間**；不要用 `setTimeout` 對拍。
- **動物語**：慢速（每字 > 0.1 秒）會變成一顆一顆的嗶嗶聲，恐怖谷。解法是字幕卡拉 OK＋必要時真人錄音；或快速咕噥（每字約 0.07 秒、相鄰重疊）。電腦合成的咕噥（鋸齒波＋共振峰）也有恐怖谷，已淘汰，用真人音節素材。
- 字典沒收的字：用固定咕噥代替，字幕要標示；新課用字要掃缺字。
- 重新開始音樂（再看一次）要**換掉各層輸出節點**，才能作廢已排好的音；`stop()` 的延遲清除要用世代 token，避免誤停新的音樂。
- AudioContext 關閉前檢查 `state !== "closed"`。

## 畫面與程式

- 自己寫的 `useEffect` 裡別在 render 期間讀會變的 ref 做決定；時鐘讀值用 `cref.current`。
- `groove`／晃動讀絕對拍數；**頁內的動作讀 `b`（相對於頁）**，不要混用。
- `popScale(p)` 在 `p ≤ 0` 回傳 `[0,0]`（看不見）：文字／字幕要用 `Math.max(0.06, p)`，否則亮起的第一格字會消失。
- 動畫起始放大倍率別超過 1.7，靠邊的字會衝出舞台。
- 使用者打的字要限制顯示（打字欄只顯示最後 14 字、泡泡內自動縮小、`maxLength`）。
- **卡片角落的標籤／徽章會被後畫的卡片蓋住**（S2-W03 第 7 頁「太長／太短／剛好」被蓋一半，負責人抓到）：突出卡片外的小標籤要給 `zIndex`，或寫在卡片元素「之後」。`__sweepOverlap` 只查 UI 蓋角色，**查不到 UI 蓋 UI**——要用 `document.elementFromPoint` 對標籤**內部**水平 25%／50%／75% 三個點（垂直置中）檢查最上層是不是它自己（**不要點角落**：膠囊形標籤的圓角外面不屬於標籤，會誤判；也要在卡片完全彈出後、窗格可見時檢查）。
- 對話框／牌子／卡片要和場景同一個質感（紙張、暖棕細邊、柔影），不要黑粗框；**格子與卡片共用同一組座標、都用 `box-sizing: border-box`**，否則會有位移。
- 店面素材上原本畫死的煙要用 `SHOP_CLIP` 挖掉，否則和動態煙重疊。
- 暫代素材（小狐狸＝小兔染色、AI 機器人＝CSS）要在回報裡標明，並列入待補清單。

- **長字超出紙張／卡片**（S2-W05 筆記第一條超出紙 6px）：`__sweep` 只查超出舞台，查不到超出容器；要量 `容器右邊 −（字的 left＋scrollWidth）` ≥ 0。
- 卡片／便利貼裡的短字（例：「明天帶水壺」）可能被擠成兩行：短字加 `whiteSpace: nowrap` 並留寬度；長段落要量 `scrollHeight > clientHeight`（被切掉）。

## 配音（S 系列，語音生成；詳見 VOICE-TTS.md）

- 機器人後製不要用環形調變、降取樣（負責人：「太電了、會破音」）；所有角色要**統一響度**，否則一個大聲一個小聲很刺耳。
- whisper 聽寫抓不到破音字讀音（長度），要請負責人聽；「周／週、麽／麼、哦／喔、BB」是假警報。
- 台詞一改，畫面對準關鍵字的 `charBeat` 索引要重算；台詞變長，字幕條變寬會蓋到兩側角色，要重跑遮擋掃描。
- 台詞裡的 `、` 會讓字幕切成兩字一段，列舉改用半形空白；不要用 `『』`、英文字母。
- 負責人在試聽頁點選的聲線存在頁面變數裡，用 JS 讀出來，不用再問一次。
