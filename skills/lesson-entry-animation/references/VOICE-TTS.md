# 語音生成配音（S 系列起；第一個實例 S2-W03）

> **S5 W01／W02 旁白的最新定案（2026-10-20）**：先讀 [S5-YU-NATURAL.md](S5-YU-NATURAL.md)。採小宇 v4、stability 0.4、similarity 0.75；W01 保留已確認的 `[conversational voice]`，W02 最新確認為 `[confident, friendly conversational voice]`，避免低落語氣。只固定增益並重新對時。此範圍不使用下方舊的 OpenAI 預設、trim／變速後製或普遍同音替換流程；其他課程依其既有選聲與實際讀音證據處理。

> P 系列（小一）用動物語／鍵盤語，**不要**改成這套。S 系列（小三以上）負責人 2026-10-12 定：
> 角色用**語音生成**的真人感配音（不能有明顯的非人感）；機器人角色也用語音，再**後製**成機器人聲。

## 1. 流程

```
台詞清單 JSON → 試聽（選聲線）→ voice-build.mjs 生成＋後製 → voice-check.mjs 聽寫檢查 → 頁面用 makeVoice 排時間 → 瀏覽器檢查字幕
```

1. **先試聽，再全錄**（便宜的先驗）：`scripts/lesson-entry/tts-audition.mjs` 每個角色生 3 句、5 個左右的聲線候選；機器人用 `robotize.py` 出多種強度。做一個靜態試聽頁放在 `public/lesson-entry/_audition/<堂代號>/`（已 gitignore），讓負責人在頁面上點選；**他點選的結果在頁面的變數裡**（S2-W03 是 `pickDet`／`pickBot`），用內建瀏覽器的 JS 讀出來即可，不用再問。
2. **台詞清單**：`scripts/lesson-entry/voice-lines/<堂代號>.json`
   - `voices`：角色 → `voice`（OpenAI 聲線）、`style`（語氣指示，**要寫「台灣國語口音、不要大陸腔」**）、`robot`（機器人後製強度或 null）。
   - `lines`：`id`（建議 `p<頁>-<用途>`）、`who`、`text`。互動頁的提示句、對錯回饋也要放進來。
   - **這份 JSON 是台詞的唯一來源**；腳本 script.md 只放摘要並指向它。
3. **生成**：`node scripts/lesson-entry/voice-build.mjs <堂代號>`
   - 模型 `gpt-4o-mini-tts`（可下語氣指示），輸出 wav；原始 wav 依「文字＋聲線＋語氣」快取在 `scripts/lesson-entry/.voice-cache/`，只重生改過的句子。要單獨重生一句：刪掉那句的快取檔再跑。
   - 後製 `voice_post.py`：統一響度（RMS −20 dB、峰值 ≤ 0.7、柔性限幅）、頭尾修掉多餘靜音、（機器人）後製、算出**每個字的發聲時間**、存成 mp3（`public/lesson-entry/voice/<堂代號>/<id>.mp3`）。時間表寫到 `src/config/lessonEntry/voice/<堂代號>.json`。
   - 費用很低：一堂 36 句約新台幣 1 元。
4. **聽寫檢查**：`node scripts/lesson-entry/voice-check.mjs <堂代號>`（whisper 轉回文字比對）。
   - 只抓得到「念錯字、聽不清楚」；**破音字讀音（長度 ㄔㄤˊ／ㄓㄤˇ）轉成文字一樣，抓不到**。
5. **破音字一律在生成前替換成只有一個讀音的同音字**（負責人 2026-10-12：長度有時會念成ㄓㄤˇ，建議用「嘗」）：台詞 JSON 的 `say` 表＝送去語音生成時的替換（`{"長度":"嘗度","太長":"太嘗","好長":"好嘗"}`），**字幕仍顯示原文**；替換字必須同字數（voice-build 會檢查），每字時間才對得上。本來就念另一個音的詞（例：校長 ㄓㄤˇ）不要放進表。新課寫台詞時先掃一遍破音字（長、重、行、樂、還、教、少、數、只、了…），會念錯的就加進 `say`。
   - 試過用聽音檔的模型（gpt-audio）判讀音：同一個音檔前後判出相反結果、常常回「請提供音檔」，**不可靠，不要拿來當驗收依據**。同音替換只能減少誤讀，**不能保證錄音讀音正確**；最後須實際聽辨，或用經已知正確／錯誤樣本校準的音訊發音評量。
   - **發音與聽寫分開驗收**（2026-10-19 S2W11「鑄」）：高聽寫相似度、字幕對時、台詞轉拼音都不等於音素與聲調正確。負責人回報錯讀的字，即使不是多音字也列入必聽清單，記錄正確注音、原音雜湊、帶前後文的局部試聽與確認結果；音檔改動就重新確認。未實際驗過不得標示「讀音通過」。可用 `scripts/lesson-entry/pronunciation-audit.mjs <堂代號>` 建立離線清單；它只定位與切片，不判斷聲音。若使用雲端發音評量，須確認中文／台灣華語的實際功能限制，不把總分當成聲調已辨識的證據。
   - 常見的假警報：周／週、麽／麼、哦／喔、「嗶嗶」→ BB。真的念錯的例子：「不夠好」被念成「無夠好」→ 刪快取重生就好。

## 2. 機器人聲後製（`robotize.py`）

- **v1 被退件**（「太電了、會破音」）：環形調變（35～50 Hz）＝嗡嗡電流聲；降取樣＝沙沙顆粒；而且後製版被放大到比原音大聲約 11 dB，跟其他角色接著播時特別刺耳。
- **v2（現行）**：稍微升調（librosa 相位聲碼器，不變快）＋淡淡的高八度和聲＋很短的機殼回音（10 ms、低回授）＋喇叭等化（150 Hz～7 kHz）＋頭尾淡入淡出＋**所有角色統一響度**。強度 R1 輕／R2 中／R3 明顯；S2 選 **R1**。R3 會開始影響聽懂（whisper 聽錯），不推薦。
- 「急跳點數量」不能當破音證據（人聲齒音本來就很多），要拿同響度的原音對照。

## 3. 台詞長度（負責人 2026-10-12：「文字的內容不用那麼短」）

- S 系列（小三以上）台詞用**完整的句子**，一句約 15～25 字；不要像 P 系列那樣切成 5～8 字的短句。
- 字幕仍是一次一段（逗號切開），**每段 ≤ 14 字**。
- 不要用 `、` 列舉（字幕會在 `、` 切成 2 個字一段閃過去）；列舉用**半形空白**：`清單 表格 步驟 重點`。
- 不要用 `『』` 等不在標點表裡的符號（會被當成一個字，字幕時間對不上）；台詞只用中文字＋`，。！？：；`＋空白，不用英文字母。
- 口訣維持學習單原文，不加長。
- 台詞照常寫標點（配音要靠它停頓、字幕靠它切段），**畫面上的字幕與大字只顯示 ！？**，其他標點由程式拿掉（見 SKILL 規則）。

## 4. 頁面怎麼用

```tsx
import VOICE from "@/config/lessonEntry/voice/S2-W03.json";
const VO = makeVoice(VOICE as unknown as Record<string, VLine>);   // lib/lessonEntry/voiceLines.ts
export const S2W03_VOICE = { base: "/lesson-entry/voice/S2-W03", ids: VO.ids }; // 登記在 lessons/index.ts 的 voice

const C1 = VO.seq(2.2, ["p1-hi", "p1-case"], 0.6);   // 依音檔長度自動接續排（第一句第 2.2 拍開始、句間 0.6 拍）
const b = useStep(VO.lastEnd(C1) + 1, A, C1, "clip", done);  // voice 用 "clip"
const sp = VO.speaking(C1, b);                         // 現在誰在說話 → 角色 talking
VO.charBeat(C1[1], 9)                                  // 第 1 句第 9 個有聲字在第幾拍 → 畫面動作對準關鍵字
A.sayClip("p3-ok")                                     // 互動頁立刻說一句（回傳取消函式）
```

- **畫面動作要對準台詞裡的關鍵字**（念到「皇冠」燈才閃、念到「清單」那張卡才翻上來），用 `charBeat(cue, 第幾個有聲字)`；**台詞一改，索引就要重算**。驗算方法：把台詞去掉標點與空白後取第 i 個字，看是不是那個關鍵字。
- 有聲字的索引＝去掉 `，。！？、～：；` 與空白後的第幾個字（和 `animalese.tokenize` 一致）。
- 字幕：`<Sub font={DFONT} size={4} tight left={…} />`。S 系列不用注音字型；`tight` 收緊字距；左側有角色時用 `left` 讓字幕往右。
- 口訣頁的大字可以跟著念的字亮起，**但底下仍要有字幕列**（負責人：「一樣會需要字幕」）。

## 5. 驗收（我自己）

- 每頁每一句，在 20％／50％／85％ 三個時間點都有對應字幕（腳本見 CHECKLIST D2）。
- `__sweep`／`__sweepOverlap` 每頁都要空的；台詞變長後最常出事的是**字幕條變寬蓋到兩側角色**。
- `voice-check.mjs` 通過；網路請求確認每個 mp3 都 200。
