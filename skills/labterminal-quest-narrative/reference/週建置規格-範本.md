## §E 線索交易

每筆一張表。**一筆交易 = 一個互動點 = 一張來源卡 = 一題 = 一條線索。**
題型只能是 `choice`（選擇）或 `fill`（填充）；NPC 行為格式見 [[lab-terminal-quest-question-npc-contract]]。

### 本站 `npcProtocol`

| 階段 | `action` | 對白／資料來源 |
|---|---|---|
| 靠近 | `lookAtPlayer` | 一句處境對白 |
| 讀來源 | `pointAtSource` | `transaction.sourceCard.lines` |
| 選擇題 | `watchChoice` | 無答案提示 |
| 填充題 | `holdBlankBoard` | 無答案提示 |
| 答對 | `nodAndRevealClue` | 收錄 `clueText` |
| 答錯 | `replaySource` | 重播同一來源卡 |
| 完成 | `celebrate` | 本站物理世界改變 |

### {交易 id}

| 欄位 | 內容 |
|---|---|
| `sourceLabel` | 站內唯一，**不得與該站 NPC 同名**（V-12） |
| `worldOffset` | 相對站錨點的位移（不是絕對座標） |
| `interactionRadius` | |
| `sourceCard.lines` | 逐句列出，對應 §D 的對白 |
| `interaction` | `{ id, kind, config }`；`kind` ∈ none/pick/order/rotate/drag-snap/path |
| 小遊戲選型理由 | **G-1 同構**：手做的動作跟這題知識怎麼同構 |
| `question.type` | `choice` 或 `fill`，封閉清單 |
| choice：`question.text`／`options`／`answerIndex` | options ≥3；每個錯誤選項都能被來源卡排除。用計量詞時來源卡要並列足夠項目（D-8、V-5） |
| fill：`promptTemplate`／`blank` | `promptTemplate` 恰有一個 `＿＿`；以鍵盤輸入第一個 accepted answer 後，逐字等於來源句 |
| `answerEvidence` | `{ lineIndex, keywords }`；keywords 同時出現在該來源句與正解選項 |
| `optionMisconceptions` | 每個錯誤選項錯在哪（index 對齊 options，正解為 null） |
| `clueText` | 中性線索，可從來源卡完整取得（V-7），**不標分類** |
| 需求分類 | do／how／avoid／goal（**僅供內部對照，不得呈現給學生**，A-6） |
