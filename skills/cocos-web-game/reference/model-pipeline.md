# 3D 模型與渲染：做法與預算

> 來源：hc-pilot 的 3D 模型交接文件（2026-09-29）、負責 Cocos 的 session 交接、專案記憶。本檔只寫做法與限制，不含原始碼或模型檔。
> **時效說明**：`3D模型-交接.md` 寫成時「所有 3D 物件都是程式用方塊／圓柱／球拼的」；之後已有 bpy 腳本產生的低模 glb（小熊、帽子等）。下方「現況」以交接與記憶為準，細部座標與大小表請讀原文件。

## 1. 現況【交接＋記憶】

- **模型有兩種來源**：① `_source/blender/*.py`（`bear.py`、`bear_outfits.py`、`props.py`、`factory.py`、`farm.py`…）用 **bpy 腳本產生低模再匯出 glb**；② 家具／道具多數是**程式方塊組成**：`solid(parent, 'box:w,h,l' | 'cyl:rt,rb,h' | 'sph:r' | 'cone:r,h', hex, x,y,z)`，一個網格一個顏色。
- 模型載入的建議接法：放 `assets/resources/models/<分類>/`，用 `resources.load` 在開場預先載入；每個「生成某物件」的函式先找有沒有載入好的模型，**沒有就退回原本的程式拼法**（素材沒載入也要能顯示）。
- 使用者全域有 `blender-image-to-3d`、`retopologizing-game-characters` 等 skill，Cocos 負責 session **沒有用它們做過 hc-pilot**，不保證適用【未驗證】。Blender MCP 同樣沒用過。

## 2. 硬限制（預算）

| 項目 | 目前（2026-09-29） | 上限 |
|------|------|------|
| 建置 gzip 後總大小 | 約 1.6 MB | **≤ 5 MB**（首次可玩） |
| 單一素材檔 | — | ≤ 500 KB（超過要寫理由） |
| 幀率 | 內顯（Intel UHD）1080p 約 130～140 fps | 教室電腦最低 30、目標 60 |
| draw call | 約 56 | 不要明顯變多 |

## 3. 渲染方式（改之前要懂）

- 所有 3D 物件共用**一個材質** `assets/art/unlit-vertex-color-instanced.mtl`（Unlit＋頂點色＋GPU Instancing）。**同一個網格＋同一個材質＝只畫一次**，這是效能能撐住的原因。
- 立體感是**假光影**：依法線把亮暗烘進頂點色（程式裡的 `shade()` 之類的函式），場景裡**沒有燈光**（Main Light 在程式裡關掉）。
- 麥田約 450 株，每株只有**一個節點、一個網格**（`compositeMesh` 合併）。換成模型後一株仍然只能一個 `MeshRenderer`、共用網格。
- 會大量重複出現的東西（麥子、手上拿的物品、金幣、框）一定要共用網格與材質。
- 頂點色或一張很小的調色盤貼圖（例如 32×32 PNG，UV 對到色塊）；風格方向 low-poly、平面著色。

## 4. 座標、尺度、朝向慣例

- **1 單位＝1 公尺**，**Y 朝上**，模型**原點在底部中心**（站在地上 y=0），**正面朝 +Z**。
- 鏡頭：從右前方往左後方看，水平轉 45 度、往下約 53 度（鏡頭位置＝目標＋(6.7, 12.5, 6.7)）。玩家主要看到物件的正面（+Z）、右側面（+X）和頂面；背面與左側面幾乎看不到，可以做簡。
- 手上的物品疊在背後，一個 0.42 高，太高會穿插；失敗品 8 種必須「一看就知道壞掉」（暗、歪），程式會自動在頭上加紅色 ✕。
- 玩家角色的第一個子節點（`Body`）用來做走路晃動，**要保留這個結構**；機台根節點原點要在底部（加工時有壓扁彈跳動畫）；垃圾桶蓋子是 `trashBody.children[0]`。
- 框、箭頭、升級圈、地板字**不換**，維持程式產生。
- 物件大小對照表（小熊、小兔、小松鼠、磨坊、烤箱等）見 `3D模型-交接.md` §4，判定範圍是照這些大小調的，新模型盡量對齊。

## 5. 流程（量產前先做試點）

1. 先做一個試點（小熊）：建模 → 匯入 → 程式接上 → 退回機制 → 建置 → 截圖 → 量 fps，給負責人看過風格再量產。
2. 員工與顧客 → AI 機器人 → 機台與家具 → 手上物品、失敗品、鐮刀 → 麥子（最後，效能最敏感）。
3. 換好一類就建置、截圖、量效能，再換下一類。

## 6. 工具與版本

- **Blender 3.6**：`C:\Program Files\Blender Foundation\Blender 3.6\blender.exe`，可 `--background --python` 用腳本產生／轉檔。**帽子腳本只能用 3.6**（4.5 的 glTF 匯出參數不相容）。
- 原始檔（高面數、AI 生成原檔、`.blend`）放專案外或 `_source/`，**不進建置**（B-3）。
- 授權：用免費素材包（Kenney、Quaternius 等 CC0）要記錄授權；AI 生 3D 要減面、重新上色。

## 7. 要負責人決定的事

美術風格參考圖、模型來源（自製 low-poly／AI 生成／免費素材）、角色是否要骨骼動畫（會多開引擎模組、檔案變大，第一版建議不做）、上色方式、哪些物件優先。
