# 活動耗時估算器

## 你的任務

把一份教案 / 學習單 / 互動課程的活動，拆成原子動作，用 `scripts/ect_estimator.py` 算出總耗時（秒、分鐘），並判定相對目標區間是太長、太短還是剛好。**計算一律走腳本，不要自己心算**（確保可重現）。

## 模型（使用者校準）

- 年級係數 `f = (年級+1)/2`：一年級=1、三年級=2、五年級=3、二/四/六=1.5/2.5/3.5。
- 基準（一年級）：打字 8 秒/字、找元件點擊 8 秒/次、閱讀 2 秒/字（打字 1/4）、單則指令閱讀上限 10 字。
- 速度隨 f 變快（÷f）、閱讀字數上限隨 f 變大（×f）。
- 完整動作表與固定動作（截圖/告知老師/思考等）見 `reference/action-catalog.md`。

## 步驟

1. **取得活動內容**：讀使用者指定的教案/學習單（`程式教育課/wiki/...`），或使用者直接貼的內容。確認**年級**（沒講就問）。
2. **拆動作**：把每個活動拆成 `reference/action-catalog.md` 裡的動作。字數要實際數（讀說明的字數、要打的字數）；點擊/拖拉數要對應實際 UI 操作。
3. **組 spec JSON**：格式見 `examples/sample-activity.json`：
   ```json
   {
     "grade": 3,
     "target_min": [50, 65],
     "activities": [
       { "label": "讀任務說明", "action": "read", "chars": 18 },
       { "label": "拖拉配對", "action": "drag", "count": 5 },
       { "label": "打字描述", "action": "type", "chars": 25 },
       { "label": "截圖", "action": "screenshot", "count": 1 }
     ]
   }
   ```
4. **執行**：
   ```
   python3 scripts/ect_estimator.py <spec.json>
   # 換年級重算：--grade 1 ；換目標：--target 50 65 ；輸出 JSON：--json
   # 快速試算：python3 scripts/ect_estimator.py --grade 5 --type 40 --read 30 --click 10
   ```
5. **解讀並建議**：把判定（太長/太短/剛好）與逐動作秒數呈現給使用者。
   - **太短** → 依 CLAUDE.md（低年級重 repetition、高年級加 Step Flow 步驟/擴大任務）建議怎麼補。
   - **太長** → 建議拆到下週或標部分任務為「進階可選」。
   - **閱讀超量警告** → 對應第十九節，建議拆指令或改用圖示/互動。

## 注意

- 目標區間預設 50–65 分鐘（第十八節主線）。里程碑週或單一活動可自訂 `target_min`。
- 物理/認知動作（截圖、告知老師、思考）設為固定秒數、與年級無關，必要時用每個動作的 `seconds` 欄位覆寫。
- 本模組是「動作級細估」，與第十八節「任務級粗估」互補；判定基準仍對齊第十八節。
- 估算是設計輔助，非硬性；課堂實測仍是最終依據（呼應第十五、十八節的實測背景）。
