- **正典聲明**：本 spec 是此課的**唯一真相**；程式跟著 spec 走，**要改方向先改 spec**（任何偏離回填本檔）。

- **In Scope（本課教）**：{列出}　**Out of Scope（不教、屬哪週）**：{列出，擋範圍蔓延}

- **互動詞彙表（單一真相）**：{每個操作的 詞/顏色/動作，如 右鍵=橘=「點右鍵」}
- **DoD + 參考範例**：定性詞（「像遊戲/情緒給滿」）翻成可勾條目 + 一張參考畫面 → 見 §8 驗收清單。

- **素材規格**：統一風格 + 透明背景 + 自動裁切 + **未載入退回向量**。

> **遊戲迴圈要 v1 就寫**，不可事後補。判定必須本地化，AI 只陪伴。
- **遊戲迴圈**：玩家扮演＝{誰}；每回合做＝{什麼有趣的事}；贏了拿到＝{獎勵/揭露}。
- **本地判定 + distractor**：{每站 pass/fail 的本地規則；哪些選項是錯的清單}。**AI 定位一句話：只潤飾/角色化回應，不判定、不當關主。**
- **真實應用鐵則**：問題從**客觀事實**組出；選項**不得洩題/不得像答案**。
- **時長靠深度不靠重複**：達成手段＝{藏熱點/N選M/多層Q&A/大地圖/遇敵…}；**禁重複灌水**；**全程有跳關鈕**。
- **防硬 A 參數**：選錯鎖選項 {2＋N} 秒（連錯升冪）｜每題選項 ≥2｜逾時放行 {N} 秒｜失敗非致命（autoDemo）。
- **金幣**：{每案/關 × 數量 = 總額}，**idempotent 入帳號錢包**。
- **角色設定圖鑑**：{外觀描述，確保跨頁一致}。
- **（探索型）大地圖拓撲**：{事件點座標、遇敵機率、戰鬥規則}。
- **UI-UX 底線**：大框、可讀對比（別黑字配深底）、筆記本記線索、進度條、角色跨頁一致、破關恭喜大圖。

## 6. 資料結構與狀態（給工程 LLM）
- `SCREENS = [...]`，線性 index 推進；每個 screen 一個 `setup{Screen}()`。
- 進度 / 已得金幣 / 難度存 `localStorage`；**跨切面（第一版就定）**：存檔續玩、帳號綁定、金幣入錢包、資安。
- 通過某 screen 才解鎖下一個（不可跳關）。
- 防作弊輔助：`lockWrongOption`、`blockPaste`、`validate{Screen}()`。
