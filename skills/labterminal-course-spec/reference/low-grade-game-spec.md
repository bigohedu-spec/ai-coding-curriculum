# 低年級教育遊戲 Spec 準則（P1U / 注音世代）

> 來源：P1U-W02 王城故事線 spec vs 上線成品的六視角比對回饋。**去蕪存菁後的權威準則**，與 `game-course-design.md`（遊戲性/判定）、`spec-governance.md`（治理）、`lesson-design-guide.md`（概念課站結構）併列。凡低年級（小一二、注音世代）教育遊戲 spec 一律適用。

## 0. 一句話 meta 原則（最重要）
> **spec 把「內容 / 敘事 / 視覺」寫死寫具體（地基，寫死省事）；把「難度 / 失敗 / 手感」標成「假設，待實玩校準」（變數，寫死返工）；把「狀態 / 資料 / 容錯」升級成一等公民正式章節。**
- 事後證明：spec 的內容/敘事幾乎全被忠實實作且正確；凡 spec 去規定底層輸入/失敗代價/難度數值/狀態資料的地方幾乎全被實測推翻（都是未經目標年齡實玩、未考慮真實裝置/網路/帳號的理論推得值）。

## 1. 條款分級（每條 spec 都要標；治理級規則）
- **規定**：親測 or 內容/敘事/視覺——工程必須照做。
- **推定**：從他章/前作推得——**與已上線成品衝突一律以成品為準**，附正典實作檔路徑；交付時附「待核對推定清單」。
- **假設（待實玩校準）**：難度/失敗/手感決策——標明並排一輪**低年級實玩校準節點**，不得當定論。

## 2. 敘事與理解
- **每段劇情寫「因」不只「果」**：場景 spec 分寫「玩家看到的果」＋「必須被揭露的因」＋指定用哪個互動揭露；不得只給果就進理解題（否則理解題退化成背圖）。
- **把「問對問題」設計成教學動作**：需揭露背景的 NPC 寫成多輪問答，每輪一個正解問題（問對才推進、揭露因果）＋2–3 個似是而非干擾問題（問錯給非致命軟回饋、不推進）。天然對齊「會問問題」的 AI 素養。
- **理解檢核兩層**：隱性建構（選對問題＝證明懂處境）＋顯性複述（泡泡題問「剛剛整段發生什麼」）；顯性題資訊必須先在隱性層出現過（避免用考試教學）。
- **防硬 A 是理解效度前提**：鎖時 2＋N（連錯升冪）＋點錯重排位置＋非致命＋正解恆藏於 ≥3 個似是而非干擾中。只鎖時擋不住記位置，只洗位置擋不住高速輪點——**缺一不可**。
- **干擾項＝同場景合理但與因果矛盾**：禁洩題、禁荒謬。
- **敘事深度 vs 文字極簡會衝突**：鋪因果要寫完整句、會突破「≤5 字」；全注音只解決「讀得出音」不解決「讀得懂意」。spec 明標「識字/閱讀負荷預算」＋緩解手段（全注音/關鍵句配圖/語音），由 spec 端取捨。

## 3. 難度與戰鬥手感（用表格，不用哲學句）
- **命中要有重量**：零代價的成功＝沒手感。「失敗代價」是**可調旋鈕**（0→輕→重），**預設值須實玩**，不預設歸零。
- **安全網分兩層**：
  - **A 層 終局保護〔寫死不可調〕**：0HP 不淘汰、不退回更前進度、永遠能重試同關。
  - **B 層 即時懲罰〔逐關可調〕**：單拍扣血/斷連段/本關重來。**難度只動 B；審查只查 B 有沒有動到 A。**
- **難度成長兩條線**：量＝逐關數列（連段 1→3、縮圈速度、攻擊頻率）；質＝每關一個新機制（反向躲/全屏閃/破甲/二階段暴怒）。只調量會無聊。
- **重來單位是一級難度參數**：明訂失敗後重玩多長（單拍/本小關/整場/整關）；長 boss 要檢查點或階段保留（避免一失誤重打兩分鐘逼近耐挫上限）。
- **留技能天花板**：主操作定義「新手能過/高手能炫」兩線（連段＋PERFECT/combo），重複遊玩＝練習，難度曲線＝教學曲線。
- **保底出口是低年級不變式**：可提高難度但不可移除「非懲罰性前進路徑」。若移除跳關鈕，走 change-control 記錄，並補「自適應出口」（失敗 N 次自動放寬該拍/慢動作預告/老師端一鍵放寬），不留死路。
- **難度跨裝置等價**：為每個目標輸入（滑鼠/觸控/螢幕尺寸）定判定寬容度＋失敗補償，**寫進 spec 別藏程式碼**（實測發現觸控 miss 被暗中改判命中）。

## 4. 上手與低年級適配
- **新輸入必有專屬教學關，一次只練一個**：用機制強制「當下唯一正確操作」（如做完自動回中立位），把「學操作」與「懂劇情」兩種認知負荷分開。
- **連載每集開場必做「上集回顧＋本集目標預覽」**：一句一頁回顧、點出本集衝突、可視化目標（秀 N 個空欄位）。孩子隔週不記得劇情。
- **判定 ≥ 視覺 2–3 倍、點擊 ≥100px**：每元素標兩個尺寸；低年級游標會飄，「到了卻沒反應」是致命的。
- **上手第一秒不白屏**：載入畫面＋進度；明訂「阻塞等待 → 逾時（如 10s）強制放行 → 缺圖退回向量」優先序。
- **控制方案跨週統一、以前一週上線成品為單一真相**：spec 憑空自訂的新對照表不得覆蓋既有肌肉記憶；同一動作全程綁同一指令，強化版用「同鍵加強」而非換鍵。

## 5. 獎勵與動機
- **全程可視、即時、顯總量**：常駐 HUD「目前/總量」＋每次獲得跳動數字＋「+N」浮字＋音效；不可只在結局給。「還差多少滿」是撐長流程的主引擎。
- **收集閉環頭—中—尾一條線**：開場預告 N 個空欄位 → 逐關點亮（每個收集物可辨識：顏色/名字/對應關）→ 結局「親手交付」儀式關。spec 當一條寫別拆散。
- **獎勵綁具體學習成就**：每份獎勵綁一個學習動作（答對理解題/打敗某關）；禁純點擊/純時間/純進場發獎。
- **TA（小老師）升為必填收尾任務**：按鈕文案＋利他任務＋實質獎勵＋獨立交易 ID。
- **跨集金幣（綁帳號、老師端可見）為主、單集徽章點綴**；**頒獎是必須設計的情緒高點**：英雄稱號＋多感官慶祝＋入袋播報＋集滿總覽，獨立儀式畫面。

## 6. 美術與資訊視覺化
- **一角一圖、全程複用（角色即識別碼）**：每角色/地點只產一張權威去背圖，所有場景複用；禁第二版（跨頁一致是理解題成立的地基）。
- **難度視覺數列**：「越強越難」綁單調遞增視覺變數（體積優先，其次深色/特效密度/佔畫面比），寫成數列（如 sizeK 0.78→1.34）。孩子讀不懂數字但看得懂「更大更黑更兇」。
- **關卡 ≥4 聚合成俯瞰地圖**：每關代表圖當 marker、路徑串起，回答「我在哪/去過哪/還要去哪」。
- **marker 三態**：done（綠+勾）/ active（高彩脈動+光暈，唯一焦點）/ future（壓暗但仍可辨識，別全黑）。
- **canvas 承載資訊圖示禁 emoji**（部分裝置渲染成豆腐字＝資訊遺失）；用向量或去背 PNG；**每 sprite 有向量 fallback**、去背執行期自動裁切、載入失敗/逾時放行。

## 7. 資料與工程（一等公民正式章節）
- **分數是金流語意資料，發獎一律冪等**：每次入帳有「學生×關卡×事件」固定交易 ID，發放前查重；明文寫「重整/斷線重連/回關重玩/多裝置/整章重玩」都不重複入帳或漏計。**（此條保證「同一成就只計分一次」，本身不禁止重玩。）**
- **「計分冪等」與「玩家重玩權」拆成兩個決策**：先回答「分數是不是學習憑證」，再決定「能否重玩已完成關卡」。二選一並記錄理由：(A) 冪等＋允許無計分自由重玩〔推薦，兼顧練習與保底出口〕；(B) 冪等＋完成即鎖〔防重刷、但犧牲重練與保底出口〕。**別像本案兩準則各寫一半互相矛盾。**
- **進度＝單調不可逆分數**：phase 偏序＋完成數壓成單一可比值；本地 vs 雲端衝突**取進度較遠者，絕不盲蓋**。
- **把失敗/離線/缺資產當正常狀態寫進 spec**：網路/帳號不可用時本地為即時真相、雲端背景備份、未就緒靜默略過；資產載入失敗有向量/文字後備照常進行；載入有逾時上限強制放行。每條回答「X 掛掉時學生看到什麼、能不能繼續玩」。
- **全注音/在地化排版是子系統不是排版開關**：附「渲染驗收清單」（逐字注音對位、聲調位置、非中文字間距、過長自動縮排、emoji 可用性）；可複用注音渲染器登記為共用元件。
- **「成品即真相」寫成正式衝突裁決條款**：推得（非親測，尤其底層輸入/失敗/難度）標「推定值」＋「與成品不符以成品為準」；清掉過時殘留註解（如 header 仍寫「全程可跳關」但功能已移除）。

## 8. 一句話收束
> spec 對「世界長什麼樣、發生什麼故事、畫面怎麼呈現」要寫到能驗收；對「玩起來多難、失敗多痛、資料怎麼存」要承認是假設、標好裁決規則、留實玩校準節點。
