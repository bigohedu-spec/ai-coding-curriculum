# 互動遊戲課設計準則（Game-Course Design）

> 來源：S2-W01《阿問偵探社》開發回饋（把「三要素記憶回放」重寫成偵探解謎 RPG）。**去蕪存菁後的可複用規則**。
> 與 `lesson-design-guide.md`（站結構/白話 prompt）、`spec-governance.md`（規格治理）併列。凡「要做成有遊戲性的互動課」都適用。

## 最貴的教訓：遊戲迴圈第一版就寫進去（不要事後補）
> 純練習（對的學習目標、但沒有遊戲迴圈）做出來就「不像遊戲、情緒價值不足」；敘事/探索/戰鬥/破關全事後硬補 → 成本高、長歪、反覆改 schema。
- **規則**：寫學習目標的**同時**，旁邊就附一條**遊戲迴圈**：玩家扮演誰／每回合在做什麼有趣的事／贏了拿到什麼。**禁「先寫純練習、做完才想怎麼包成遊戲」。**

## 七條可複用原則
1. **學習目標 + 遊戲迴圈（v1 同時寫）**——最貴的彎路就是裸練習。
2. **真實應用＝從客觀事實出發**；選項**不得洩題、不得像答案**。（例：客觀「窗邊有陽光照進來」✓ vs 洩題「水缸放窗邊很曬」✗ ——讓孩子自己把事實組成問題。）
3. **判定本地化、AI 只陪伴**：pass/fail **一律本地規則 + 預寫 distractor 清單**（可離線、可重現）；AI 只做「合規潤飾／角色化回應／揭露預寫好的線索／個人化鼓勵」，**best-effort、不當關主**。（實測 AI 會把一個**完美的問題誤判為失敗**，交給 AI 判又不穩、難重現、斷網就崩。）
4. **時長靠探索深度、不靠重複**：用「新的觀察／選擇／探索」堆時間——藏熱點（真+干擾）、5 選 3、多層 Q&A、大地圖自由走、隨機遇敵——**禁用重複同一動作灌水**；且**永遠有跳關鈕**當逃生口。
5. **防硬 A 是需求（不是加分項）**：選錯 → **鎖選項 2＋N 秒（連錯升冪）**；角色/問題**恆 ≥2 個選項**（不得只有一個正確選項讓人硬 A）。
   〔2026-07 修正，見 low-grade-game-spec.md §3〕**「失敗非致命」不等於「零代價」**：命中要有重量，零代價＝沒手感。改用**安全網分兩層**——**A 層終局保護寫死不可調**（0HP 不淘汰、不退更前進度、永遠能重試同關），**B 層即時懲罰逐關可調**（單拍扣血/斷連段/本關重來）。**失敗代價是旋鈕（0→輕→重），預設值須經目標年齡實玩校準**，不預設歸零。
6. **情緒價值有底線**：大框、**可讀對比**（別黑字配深底）、**筆記本記線索**、進度條、**角色外觀跨頁一致**、能附圖就附圖、破關給**恭喜大圖**。
7. **spec 描述意圖與體驗**；實作端可依實況微調互動；**成品即真相，回收反寫回 spec**（呼應 spec-governance 追溯）。

## 下次直接寫進 spec 的欄位（別即興決定）
- [ ] 每站/案的**本地判定規則 + distractor 清單**
- [ ] 現場**藏點數量**、真假比例、**是否給提示**
- [ ] **防硬 A 參數**：鎖時公式（2＋N）、最低選項數（≥2）、逾時放行秒數
- [ ] **時長目標 + 達成手段**（列出用哪些「深度」機制，**不准重複灌水**）
- [ ] **金幣配置 + 寫入方式**（idempotent 入帳號錢包）
- [ ] **角色設定圖鑑**（外觀描述，確保跨頁一致）
- [ ] 若探索型：**大地圖拓撲**（事件點座標、遇敵機率、戰鬥規則）
- [ ] **AI 角色定位一句話**：只潤飾、不判定

## 學習目標穿透護欄（2026-07；遊戲化易漂移，必守）
> 遊戲外殼（偵探/戰鬥/探索）會隨「加難度、更好玩」不斷長大，很容易把**真正的學習目標**擠成背景板。
- **每一分額外的「動腦/難度」都必須穿過學習目標本身**——例：AI 素養課的變難要花在「怎麼跟 AI 講」或「讀懂 AI 給的東西」，不能漂成純推理解謎。
- **一句自檢**：這個新機制訓練的是學習目標，還是只是遊戲爽度？只是爽度 → 改設計讓它承載學習目標，或砍掉。
- 寫進 spec 當 **In-Scope 護欄**，並列進 DoD 逐關檢查（呼應 spec-governance 的 In/Out of Scope）。

## 補充（2026-07，見 low-grade-game-spec.md）
- **動作集是封閉集合**：spec 明列「就這幾個動作/這幾種輸入」；**新增動作或輸入視為破壞單一真相的變更，走 change-control**（本案 spec 明文排除滾輪，成品卻加了「魔法＝滾輪」漂移）。
- **難度成長要量＋質兩條線**：量＝數列（連段/速度/頻率）；質＝每關新機制。只調量會無聊。
- **重來單位是一級難度參數**：單拍/本關/整場；長 boss 要檢查點。

## 與其他準則的關係（重要修正）
- **修正 `lesson-design-guide.md` 原則②**：先前寫「pass/fail 交 AI 判讀」——**實測不可靠**。更正為：**pass/fail 用本地判定 + distractor**；AI 對「清晰/方向」的判讀只能當**體驗回饋/潤飾**，**不得作為及格線**。
