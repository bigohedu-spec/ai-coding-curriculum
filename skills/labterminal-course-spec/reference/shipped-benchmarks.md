## A. 每堂課的開場：What → Why → How，一頁只講一件事【所有課程一律照做】（L12–L40）

開場是**三個獨立畫面**，按「下一步」翻頁；缺一不可、順序不可換、**不可以擠在同一頁**。

| 頁 | 標題（固定這樣問） | 這一頁只放 | 寫作要求 |
|---|---|---|---|
| 1 | 我們今天要做什麼？ | 一句大字＋一句補充＋今天用到的工具／角色圖示 | 大字寫**帶得走的能力**，不是今天的操作。例：「學會用不同的 AI，把任何事情學起來」＞「挑一個大題目來研究」 |
| 2 | 我們為什麼要做？ | 一句大字＋一句補充 | 寫「**對他有什麼差別**」，不要寫「這是課綱要求」。小三不吃課綱 |
| 3 | 我們今天要怎麼做？ | 編號帶（1234） | 一條一句，四條以內；是流程預告，不是操作說明書 |

**為什麼拆三頁**：S2-W07 這一頁改了三版才對——第一版是四條等粗的待辦清單＋兩張一模一樣的卡（沒有主角、沒有理由）；第二版補了 Why 但仍同頁（還是一面牆）；第三版才拆成三頁。

**版面鐵則**
- 每頁垂直置中、**只有一個焦點**，不要加第四塊。
- 同一句話不要講兩次（曾經「不用登入、不用帳號」在兩張卡各講一次，白佔一整塊）。
- 頂端標題列已寫課名，開場**不要再放一樣的大標**。
- 要有**進度點**，學生才知道還有幾頁開始。
- 按鍵必須在**一屏內**看得到：教室筆電 1366×768，扣瀏覽器外框約剩 600 高，要為矮螢幕收緊版面，不是只縮字級。
- 大字的斷行點自己寫死，不要交給瀏覽器亂斷。

## B. 上線通則：每個遊戲型課程都要做到（L46–L58）

這些與 CLAUDE.md「學習單上線五元素」互相呼應；規格階段就要寫進去，否則上線時最容易漏。

1. **GAMEKEY 逐字等於 worksheet 的 `gameKey`**；多週共用一個遊戲時，worksheet 的 `gameKey` 要用整個遊戲的 key（例 `s2mod2`），否則卡片讀不到進度。
2. **存檔競態閘**：進場先樂觀渲染、再非同步讀雲端的課，寫檔前一定要確認雲端已讀完（`cloudLoaded`），否則進場那一下會用預設值蓋掉雲端存檔，換電腦回來變成「從頭開始」。
3. **完成鎖**：接了完成鎖，就一定要在後台「重做入口」登記該課，否則破關即永久鎖死（資料庫規則禁刪，救不回來）。
4. **金幣 HUD 只顯示累計數字，不顯示「/總額」**（總額含小老師，正常玩到不了，會像有領不到的一段）。
5. **worksheet 文件最常漏建**：`tasks[].coins` 合計＝遊戲最大金幣（含小老師）；班級 ID 與 semester 格式**從同系列既有 worksheet 撈，不要猜**。
6. **逐週獨立的 worksheet 文件要保留**：多週共用一個入口時，仍須為每週建一筆（可不發布），因為「今日待發」要靠它產生家長簡介與小考。內容要跟著遊戲更新，不能放著過時。
7. **動工前**：打開同系列上一週的成品，確認引擎、調色盤、chassis、章節結構 → **fork 它**再改（優先於從頭寫）→ 生圖前先看上一週實際素材（尺寸、alpha、畫風）。

## C. 互動與評量的設計基準（來自 S2 成品被退／改版的教訓）

### C1. 讓「差別」靠回答自己看出來，不靠文字說教（L66–L72）
S2-W06 的「挑句子」關：候選句**只有一句真的用到該法寶**，選錯時阿問會**真的照那句爛 prompt 回答一次**——沒說格式就寫成一大段、沒說口氣就回一堆術語。學生親眼看到「沒用法寶 → 答案不好用」。

### C2. 先讀再答：給學生停下來讀回答的空間（L73–L74）
每答完一層就**停住等學生自己按「下一句」**。直接跳下一層，回答會被下一層的候選句一閃蓋掉——而這一課的學習正是發生在「讀那個回答」。

### C3. 「念出來才算問出去」的規則（L75–L78）
- **只有選對的那一句要念**；念爛 prompt 沒有練習價值。
- **判定要寬鬆**：實測一字不差 1.00、漏幾個字 0.79、亂念 0.05，門檻 0.5 擋得掉亂念、又不為難念漏字的小三。
- **一定留退路**：拿不到麥克風（權限、沒麥克風、不支援）就立刻放出「念不出來？直接送出」，連續兩次沒念好也放出來。不能因硬體問題卡住學生。
- **念完才寫進存檔**：選對的當下只設不進存檔的暫存旗標，否則念到一半重整就變成「沒念就收錄」。

### C4. 小考不考定義，考「剛剛親眼看到的差別」（L79–L81）
定義在別處已考過；一頁一題，必答對才收錄、才發金幣。用存檔推導「該考了」，不要另開旗標（旗標會在重整後落到沒有畫面的空白頁）。

### C5. 發獎要封頂、要冪等（L82–L83）
`paid` 旗標＋固定交易 id 雙重把關，每段只給一次；寫滿獎用「**補到 250**」計算（250 減掉已發的單題幣），不要逐題硬加。重寫一頁、重做都要實測零超發（P1U-W06 問答金幣曾超發）。

### C6. 「同型」要連形式也一樣（L84–L88）
說「跟 P1U-W06 同型」，是連呈現形式都要一樣：家長成果頁是**整頁滑動的 slide deck**，不是一張靜態文件。家長頁也**要自己一支**，不能共用寫死別系列 key 的頁面（會一片空白）。浮現動畫要漸進增強（偵測不到 `IntersectionObserver` 或沒觸發就直接顯示，避免家長看到空白）。

### C7. 成果頁存文字、不存 id（L85–L86）
收錄時把阿問的回答與說明一起寫進存檔，家長頁直接畫存檔裡的字，不自己再抄一份題庫——兩邊各抄一份就會漂。

### C8. AI 即時回答的課怎麼設計（S2 模組二，L140–L260）
- **判定只看結構，不判語意**：程式判不出「哪一句在語意上答對了」；用寫死關鍵字表判即時回答，正是 `game-course-design.md` 禁止的事。驗證只做結構（至少 N 字、確實出現在那段回聲裡，比對前先正規化標點空白）。
- **追問句要自我完備**：回答 API 是無狀態的，每次送出都是全新對話。實測問企鵝、追問回來整段在講海豚。
- **出題順序：先挑一句、再照那一句出題**，不要反過來。
- **一定要有後備**：逾時、沒金鑰、回看不懂時，退回「程式確定知道的事」當正解；離線示範依「角度類型」給通用版，不必每個主題預寫。
- **後備題不當小考題**：全是後備題就退回方法題。
- **一次只出現一題**，沒輪到的格子連題目都不顯示；出題呼叫在背景做、擋重複，失敗也要記下。
- **「正在等 AI」的旗標不能存進存檔**（掉線會整關鎖死）；「目前在第幾階段」不要用某個暫存欄位判（同一個坑踩了三次）。
- **要學生複製的內容，整段訊息都要能選取**；但提示框仍維持不可複製。
- **別讓學生整段貼上 AI 回答而幾乎不用讀**：第一版「照完成條件寫一段答案」就因此被退，改成要從回答裡挑出對應的那一句。

### C9. 週次解鎖鏈不能被網址繞過（L612–L650，Arc 2）
「上一週過關才開下一週，沒有例外」。曾放行「學習單連結指定的那一週（`?week=N`）免解鎖」，結果學生點 W12 的卡片就能跳過前面；`?week=` 現在只用來預選高亮，不解鎖。

### C10. 週與難度分離（L650 附近）
週＝課綱閘門，全班同步；難度＝另一個軸。自適應難度預設關閉（每局固定起點、分數每局從 0 算），要開再開。

## D. 注音：兩條路，不要併用（L1150–L1178）

| 路 | 做法 | 缺點 |
|----|------|------|
| A | `/courses/zhuyin.js`（DOM ruby＋手維護字典） | 缺字就沒有注音，做完要掃一次 `.zc` 裡 `.zb` 為空的；AI 生成的文字靠 API 回字典 |
| B（新頁面一律走 B） | 自帶注音的字體 `BpmfGenSen`，設 `font-family` 就有注音，零 JS、零字典；canvas 也吃 | 一字一音（破音字由字體決定）；subset 沒含的字沒有注音，新增中文後要重建 subset；同一頁不能兩套併用（雙重注音） |

AI 繪本工作坊是例外：四堂一律走 A，才不會同一門課裡兩種注音長相。

## E. 規格與成品的關係（延伸 `spec-governance.md`）

- **衝突以成品為準**（§G）；刻意跟 spec 不同的地方，要在規格裡明寫並回填，例如「不載 zhuyin.js，因 S2 是小三、W01–W05 成品都沒注音」。
- **取消的路線要回填**：S2-W06 的高年級（G3）路線在 2026-08-20 取消，連帶 AI 不再當關主；規格的「雙難度矩陣」與 DoD 都要跟著改，否則規格與成品對不上。
- **規格寫「同型」時，要指到具體檔案與形式**（見 C6），不要只寫兩個字。
- **數值標註**：沒實測過的數值一律標「假設／待實測」，不要寫成定案（見 `low-grade-game-spec.md`）。
