# 版控上手：一次性設定（給專案負責人）

> 這份只做**一次**。做完就把 repo 交給團隊（見最後「邀請團隊」）。
> 前提：已裝 [Git](https://git-scm.com/)、[Git LFS](https://git-lfs.com/)、[GitHub CLI `gh`](https://cli.github.com/)。

## 步驟 1｜把資料夾搬離 OneDrive（必做）
在**檔案總管**把整個 `程式教育課` 資料夾**剪下**，貼到非同步位置，例如：
```
C:\Users\sunny\dev\程式教育課
```
> 為什麼：OneDrive 即時同步會和 Git 打架、弄壞 `.git`。之後用 Git 當唯一同步管道。

## 步驟 2｜開終端機、進資料夾
```powershell
cd C:\Users\sunny\dev\程式教育課
```

## 步驟 3｜初始化 Git ＋ LFS
```powershell
git lfs install
git init
git branch -M main
git add .
git commit -m "chore: 初始化課程 wiki repo（含 .gitignore/.gitattributes/CONTRIBUTING）"
```
> `.gitattributes` 已就位，所以第一次 `add` 就會用 LFS 收 pdf/docx/圖片。

## 步驟 4｜用你的機構帳號登入 GitHub CLI
```powershell
gh auth login
```
> 選 GitHub.com → HTTPS →用**課程用的機構/公司帳號**（跟 Copilot/部署同一個，見 CLAUDE.md 第十六節）。

## 步驟 5｜建私有 repo 並推上去（CLI 一行）
```powershell
gh repo create 程式教育課 --private --source=. --remote=origin --push
```
> 若組織帳號，用 `gh repo create <組織名>/程式教育課 --private --source=. --remote=origin --push`。

## 步驟 6｜保護 main（強制走 PR 審查）
GitHub 網頁 → repo → **Settings → Branches → Add rule**：
- Branch name pattern：`main`
- ✅ Require a pull request before merging（Require approvals：1）
- ✅ Do not allow bypassing the above settings

或用 CLI：
```powershell
gh api -X PUT repos/{owner}/程式教育課/branches/main/protection ^
  -F required_pull_request_reviews.required_approving_review_count=1 ^
  -F enforce_admins=true -F restrictions=
```

## 步驟 7｜邀請團隊
```powershell
gh repo view --web       # 打開 repo 網頁
```
網頁 → **Settings → Collaborators and teams → Add people**（或把 repo 放進組織的 team）。
給每位成員：
1. repo 網址
2. 請他們讀 `CONTRIBUTING.md`
3. 非工程夥伴：Obsidian 裝 **Obsidian Git** 外掛（自動 pull／定時 commit）。

---

## 團隊成員每次的日常（給每個人）
```powershell
# 開工前
git pull
git switch -c lesson/s2-w03-字數控制    # 開分支做事

# 做完
git add .
git commit -m "lesson(S2-W03): 新增字數控制五案"
git push -u origin lesson/s2-w03-字數控制
gh pr create --fill                      # 開 PR 給人審
```
審核者對照 `CONTRIBUTING.md` 的 PR 清單 → 合併進 `main`。

> Obsidian Git 版：外掛會自動 pull/commit，push 與開 PR 建議仍在 GitHub 網頁或 `gh` 做，確保走審查。
