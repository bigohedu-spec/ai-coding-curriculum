# Lab Terminal Quest 規格

此目錄是 Lab Terminal Quest 與 Phaser runtime 的唯一規格區，與課程 wiki 分離。

| 目錄            | 內容                                       |
| ------------- | ---------------------------------------- |
| `standards/`  | 敘事、關卡設計、題型、素材、生產流程與 Phaser runtime 的跨週規範 |
| `S{N}/`       | 該學期的劇本世界觀                                |
| `S{N}/W{NN}/` | 該週建置規格、題庫、QA、實作交接與活動資料                   |

課程的學生學習單與教師教案仍在 `wiki/`；它們只以一般 Markdown 連結指向此處的實作規格。新增 Quest 資料不得再寫入 `wiki/concepts/` 或 `wiki/labterminal-specs/`。
