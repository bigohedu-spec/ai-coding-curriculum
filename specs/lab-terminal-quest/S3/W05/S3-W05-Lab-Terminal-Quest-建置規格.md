## 2. 學習目標與核心訊息

學生面對壞掉的設施，能先從委託人的自然對話中找出可觀察、可檢查的資訊，理解漏寫的後果，選出能減少 AI 誤解的清楚寫法，最後手動整理為 prompt。

本週不要求學生把資訊分類為四個固定格或依固定順序寫 prompt。關鍵是把修好問題的條件說清楚，讓 AI 少猜測，學生也能自行檢查。

承重牆檢驗：因為 prompt 漏掉可檢查的條件，所以橋、葉片、路標或節慶徽章不能真正完成它們的任務。

## 3. 最終關卡循環

```text
看見具體問題 → 向 NPC 自然提問／觀察固定圖 → 取得正常對白或圖像證據
→ 四題客觀確認（內容、漏寫後果、加入規格理由、清楚寫法）
→ 手動複製與整理 prompt → Lab Image 產出與本地驗收
→ 完成挑戰與可見的世界改變
```

- A、C、D：每站三段可任意順序提問；每段四題，共 12 題。NPC 回答是可反白複製的正常對話。
- B：三個觀察點（外形、中央組合、完整度）；每點先看同一張固定葉片圖、完成正誤圖二選一，再完成四題確認，共 12 題。
- 全關共 12 組資訊、48 題客觀確認。答錯鎖定該錯項並顯示具體誤解回饋；四題全對才取得可放入 prompt 的證據。
- 學生必須手動複製、貼上或輸入；系統不得自動把 NPC 回答或 prompt 骨架填進筆記。

## 4. 地圖、任務與世界後果

世界固定為 `960×7500`，玩家邊界為 `x:80–880`、`y:260–6500`。四站錨點依序為河畔農場 `(360,1300)`、山腰工坊 `(640,2700)`、霧谷山徑 `(340,4100)`、溪谷鎮古老遺跡 `(520,5500)`。

| 站 | 玩家要解決的問題 | 資訊組 | 提交後後果 |
|---|---|---:|---|
| A 河畔農場 | 菜車因窄且不安全的橋無法過河 | 3 | 藤橋可通行；開放運菜林道。 |
| A→B 運菜林道 | 菜車要安全抵達工坊 | 路途事件 | 三波小豬；拖入圍欄保護菜車，才可進入工坊。 |
| B 山腰工坊 | 舊葉片大小不一、破損而搖晃 | 3 | 生成組合好的四葉片與中央接點，完成葉片轉動檢查。 |
| C 霧谷山徑 | 濃霧中路標方向不清 | 3 | 路標修好後進行寬判定 Skill Check，霧散開。 |
| D 溪谷鎮古老遺跡 | 修復節需要記錄成果的節慶徽章 | 3 | 把徽章投向四座燈台，完成閉幕表演。 |

每站完成後可留在修復後地圖探索；不自動跳站或傳送。主線金幣固定 250：序章 10、A 55、B 60、C 60、D 65。

## 5. B 站固定美術與內容邊界

固定本機資產：

- 正確觀察圖：`/assets/s3w05/stage-b/observations/blade-assembly.png`
- 錯誤圖：`blade-wrong-shape.png`、`blade-wrong-unassembled.png`、`blade-wrong-damage.png`

三個觀察點都使用同一張已組合的四葉片圖；每次只替換觀察標題、短解說與具體替代文字。正確圖只能有四片大小與外形一致、細長外端略寬、表面完整的葉片，以及必要的小型中央接點。B 站學生內容與產出不得出現風車塔、房屋、人物、升降台、乘客、曲柄或其他機械物件。

提交的圖片只允許組合好的葉片與中央接點；接著進行 3、2、1 倒數、8 秒內至少 12 下的葉片轉動檢查。12 下是過關門檻而非上限，重玩按鈕不得與連點區重疊。

## 6. 結局敘事

D 站是溪谷鎮修復節的閉幕。玩家已修好藤橋、風車與路標，因此依照鎮上傳統設計記錄成果的節慶徽章，並親手把它投向四座燈台。四燈全亮即完成閉幕，鎮民邀請玩家準備下一趟奇幻旅程。

不得恢復馬雅遺跡、星門、傳送、星印或古老旅圖等舊情節。

## 7. 資料與 Runtime 邊界

- Phaser 擁有地圖、移動、碰撞、NPC／設施五態、互動半徑、世界動畫與完成挑戰。
- React 擁有對白、題目、答案、複製貼上、prompt、附件驗收、進度與金幣帳。
- Phaser 不得持有 `answerIndex`、`answerEvidence`、`optionMisconceptions`、`requirement`，也不得以內容 ID 分支。
- 內容、編輯器、碰撞編輯器與文字正典都必須從 `questData.world` 讀取；舊的 standalone Task A 地圖、Gamma iframe 與 DOM 地圖不可重新接回主線。
- 舊 Firestore 草稿必須由 `normalizeS3W05ContentConfig()` 遷移或隔離，不能移除四題確認、B 固定美術、C／D 自然提問或完成挑戰。
