# W17 等錢時的小任務（送外觀）— 修改說明

負責人 2026-10-22：W17 中間等錢的空檔，用小任務填，做完送小熊外觀。細節交給 Claude 決定（本文件）。
只改 `assets/scripts/game/BakeryArcade.ts`（`updateBonus` 附近）和 `ArcadeConfig.ts` 加一個設定；不新增模型、不改任務表。

## 決定

| 題目 | 決定 | 理由 |
|---|---|---|
| 價錢 | 維持方案 A（小鴨、小羊 15000，期限 17／24／30／34，已寫進 ArcadeConfig.ts） | 中等學生要填的空等最少（18.6 分） |
| 外觀 | 用現有 5 套（`HIDDEN_CHAINS` 的獎勵），送還沒有的 | 不用新建模型；隱藏任務的關卡、場上道具都做好了 |
| 幾關換一套 | **10 關一套（直接用現有的鏈子）** | 原本想 5 關一套，但外觀只有 5 套、而且週末做完的隱藏任務也要用同一批：5 關一套中等學生一週就會用掉 5～6 套，快的學生做完任務表後就沒有隱藏任務撐到 40 分。10 關一套，中等學生約 3 套 |
| 套用到哪幾週 | 只有 W17 | W17 才有這麼長的空等；其他週沒實測 |

## 行為

1. **出現**：W17（`curWeekNo() === 17`）、本週任務表還沒做完、不是在補上一週（`!lateFor(17)`），而且目前這一項要花錢（`goalCost() > 0`）、預計還要等至少 `ARCADE.waitTask.minWait` 分鐘：
   `等待分鐘 = (goalCost() − coins − pileValue()) ÷ max(300, earnPerMin())`
   → 沒有正在做的就發一個隱藏任務鏈（沿用 `hqLeft()` 的順序，一次只發 1 個），跳 `hiddenAppear()`（台詞改成「等金幣的時候，來做隱藏任務吧！」）。
2. **暫停**：錢夠了（`goalCost() − coins − pileValue() ≤ 0`）、或目前這一項不用花錢（排順序、問 AI、組機器人、做蛋糕）→ `hq.on = false`，**`hq.q／k／p` 留著**（跟 W15 開始時暫停的寫法一樣）。`tickHidden` 會因為 `hqCur()` 變 null 自動把光圈、寶箱、神秘客人收掉，任務表下面的加碼欄也會消失，箭頭回到主任務。
3. **接著做**：下一次又要等錢（等待 ≥ minWait）→ `hq.q` 還有就 `hq.on = true` 從同一關繼續；沒有了才再發一個。
4. **做完一鏈**：照原本 `hqNext` 送外觀；W17 中途的提示文字改成「錢夠了就回去完成任務表喔！」（不要寫「下一個隱藏任務：…」，下一個要等下次等錢才出現）。
5. **不影響原本的機制**：不設 `wt.bo`；本週任務表做完以後照原本的 `updateBonus` 流程發隱藏任務撐到 40 分（`hq.w !== curWeekNo()` 那段會把新的接在 `hq.q` 後面，還沒做完的那一鏈繼續）。客人偷偷補錢的期限照舊，所以總時間不變，小任務只是讓等的時間有事做。

## 設定（ArcadeConfig.ts）

```ts
/** W17 等錢時的小任務（負責人 2026-10-22）：目前要花錢、預計還要等 minWait 分鐘以上 → 發隱藏任務（送外觀）；錢夠了就暫停【假設】 */
waitTask: { weeks: [17], minWait: 2 },
```

## 程式草稿（`updateBonus` 裡、`this.tickHidden();` 前面）

```ts
this.tickWaitTask();
```

```ts
/** W17 等錢的小任務：要等錢就發／接著做隱藏任務，錢夠了就暫停（進度留著） */
private tickWaitTask() {
  const W = ARCADE.waitTask;
  const wk = this.curWeekNo();
  if (W.weeks.indexOf(wk) < 0 || this.weekAllDone() || this.lateFor(wk)) return;
  const cost = this.goalCost();
  const need = cost - this.coins - this.pileValue();
  const waitMin = need > 0 ? need / Math.max(300, this.earnPerMin()) : 0;
  if (this.hq.on) { if (cost <= 0 || need <= 0) { this.hq.on = false; this.saveSoon(); } return; }
  if (cost <= 0 || waitMin < W.minWait) return;
  if (!this.hq.q.length) {
    const nx = this.hqLeft()[0];
    if (nx === undefined) return; // 外觀都拿完了：不發
    this.hq.q = [nx]; this.hq.k = 0; this.hq.p = 0;
    this.stats.inc('waitTask');
  }
  this.hq.on = true;
  this.hiddenAppear();
  this.saveSoon();
}
```

（`hqLeft()` 第一次用之前 `hq.order` 可能還是空的：把 `hqAssign` 裡「第一次隨機排順序」那段抽成 `hqOrderInit()`，兩邊都先叫它。）

## 驗收（build 後在測試環境）

1. 跳到「W17 ▸ 第 6 項」（請小鴨），身上金幣設成 0：幾秒內任務表下面出現紫色「隱藏任務：…」，小熊頭上說「等金幣的時候，來做隱藏任務吧！」。
2. 做完一關以後把金幣設成 15000：加碼欄消失、場上的光圈／寶箱收掉、箭頭指回解鎖格。
3. 買下小鴨 → 排小鴨（不用花錢，不出現）→ 第 8 項請小羊、金幣 0：同一鏈從剛剛那一關接著做。
4. 做滿 10 關：送外觀，提示「錢夠了就回去完成任務表喔！」；衣櫃裡多一頂帽子。
5. 本週任務表做完：照原本流程發隱藏任務，沒有重複發已經拿過外觀的那一鏈。
6. 存檔讀回：做到一半的那一關還在（`hq.q／k／p`）。
7. `suite.mjs 輸送帶` 沒有新增失敗（之前那 3 個是腳本的問題，另外修）。
