# P1U Arc 3｜小熊麵包坊｜開發規格（W13–W18 單一遊戲・Cocos）

> **狀態：原型可玩，依原型回填（成品即真相）**。2026-09-29 負責人決定：**以現在的原型框架跑六週**，原規格中原型沒有的設計（熊奶奶、搗蛋浣熊、打字接訂單、重複卡、2D 畫面、接力／蛋糕／外送／蛋糕節）**全部作廢**（見 §11 否決紀錄）；之後再往這個框架加內容、切週次進度。
>
> **spec 是唯一真相**：程式跟著 spec 走，要改方向先改 spec；開發中長出的機制要回填本檔（見 §13 追溯表）。
> 工程面一律服從 [`cocos-web-game-standard.md`](../standards/cocos-web-game-standard.md)（版本、目錄、`lt-game/1` 協定、預算、AI 規則、驗收 K-1～K-10）；本檔只寫**這一款遊戲**的教學目標、玩法與內容。
> 低年級設計準則沿用 `skills/labterminal-course-spec/reference/low-grade-game-spec.md`。教學面見 wiki [[P1U-Arc3-教案]]。
>
> 條款分級：**【規定】** 不可違反；**【推定】** 預設值，可改但要記錄；**【假設】** 待小一實玩校準。
> 依低年級準則：內容／故事／畫面寫死；難度／門檻／數值一律標【假設】，單一真相在 `ArcadeConfig.ts`。

## §0 定位

| 項目 | 內容 |
|---|---|
| 課程位置 | P1 上（小一上）模組三 W13–W18，接在 Arc 1《海底城》（滑鼠）、Arc 2《字母要塞》（鍵盤 A–Z）之後；**取代原本的 Minecraft 課程** |
| 遊戲名稱【規定】 | 《小熊麵包坊》 |
| 形式【規定】 | 3D Arcade Idle（參考 *My Little Universe*、*Overcooked*、*KIBO*）：小熊用 WASD 走動，靠近站點就互動；**同一款遊戲、同一家店一路玩六週**，每週開放新東西 |
| 核心教學目標【規定】 | **做事情要有順序**：一件事由好幾個步驟組成、步驟有先後、順序錯了結果就壞掉、排好的順序可以交給幫手一直重複做 |
| 附帶練習 | WASD 走路＋空白鍵（取代原 Minecraft 的 WASD 練習）、滑鼠拖曳（複習模組一）、用麥克風問 AI |
| 目前實作 | 試點專案 `C:\Dev\Cocos\Projects\hc-pilot`（場景 `BakeryArcade.scene`），建置到 gpt-clone `public/games/cocos/hc-pilot/`。正式專案 `p1u-arc3` 尚未開（§10） |
| 每堂課遊玩時間【推定】 | 35～40 分鐘 |

### §0-1 整款遊戲唯一的核心學習動作【規定】

雇到員工後，**學生必須自己把步驟卡拖進順序板、排對順序**，員工才會照著做（排好會一直重複做）。不得被「付錢就自動」取代。

### §0-2 學習節奏：先問、再自己做、做過才教別人【規定】

每一種新東西都照這個順序（負責人 2026-09-29）：

1. **問 AI**：第一次做之前，先到 AI 機器人那裡用麥克風問 3 個問題，知道自己要做什麼、順序為什麼重要（§3-4）。
2. **自己做**：學生自己一站一站做過幾次。
3. **才考流程、才雇員工**：解鎖格的流程題只考**已經做過**的東西；自己做過幾次後才能雇員工，用排卡片教員工做。

## §1 小一適配【規定】

| 限制 | 對策（as-built） |
|---|---|
| 識字量少 | 畫面上**所有文字都有注音**（遊戲自帶注音子集字型，§7-3）；選項寫短、兩行內 |
| 手眼協調還在練 | 走進站點的框就自動拿東西；放東西只要按空白鍵（按住會一個一個放）；拖曳卡片放開時自動吸附最近的格子 |
| 耐挫力低 | **出錯不扣任何東西**：順序錯只做出看得出壞掉的失敗品，要自己撿去丟、打掃乾淨；答錯只鎖 2 秒、重新洗選項 |
| 不知道下一步去哪 | 紅色箭頭永遠指著下一步；目標很遠時小熊腳邊多一個指路箭頭（§3-11） |
| 受不了重複作業 | 重複的事交給員工；升級讓員工和站點越來越快 |

## §2 世界與角色【規定】

- **故事**：小熊接手森林裡的麵包坊。店在中間，麥田圍住整家店，店前面有一條馬路，客人從左右兩邊走過來買東西。小熊先學會做麵包，再請小兔、小松鼠幫忙，店越開越大。
- **角色**：

| 角色 | 身分 | 外觀 |
|---|---|---|
| 小熊 | 玩家（戴白色廚師帽） | 背後疊著手上的東西（最多 5 個【假設】） |
| AI 機器人 | 問 AI 的地方（§3-4） | 店中間，有還沒問的問題時頭上跳橘色驚嘆號 |
| 小兔 | 麵包員工（紅帽） | 一開始很慢，可升級 |
| 小松鼠 | 三明治員工（黃帽、紅圍裙） | 一開始很慢，可升級 |
| 顧客 | 從馬路走來，頭上顯示想要什麼 | 拿到對的東西打勾付錢；拿到壞的皺眉、拿去丟垃圾桶、不付錢 |

### §2-1 地圖【規定；座標為推定】

- 鏡頭水平轉 **45 度**斜角俯視（負責人：比較立體）。WASD 是**畫面上的**上下左右。
- 中間是麵包店（約 43×25 公尺；加了框和升級圈後放大 1.2 倍），**麥田圍住整家店**，由內而外一級、二級、三級，等級之間留一條小路，小路上寫等級。
- 店裡站點**刻意散開、不排成一條線**，下一步去哪只靠紅色箭頭提示。
- 店前面是馬路（有車道線），客人從左右兩邊沿著馬路走過來。

### §2-2 站點與商品【規定】

| 線 | 站點 | 做什麼 |
|---|---|---|
| 麵包線 | 工具架（拿鐮刀）、麥田、磨粉、揉麵、烤、上架（展示櫃）、收錢 | 麥 → 麵粉 → 麵糰 → 麵包 → 上架 → 客人付錢 |
| 果醬 | 莓果叢、煮果醬 | 莓果 → 果醬（可以上架賣，也是三明治的材料） |
| 三明治線 | 切開、塗果醬（台上要先放果醬）、組合、櫃檯、收錢 | 麵包 → 切開的麵包 → 塗好果醬 → 三明治 → 櫃檯 → 客人付錢 |
| 共用 | 垃圾桶、解鎖格、AI 機器人、各升級圈、員工順序板、麵包盒（給小松鼠拿麵包） | — |

## §3 核心機制（as-built）

### §3-1 操作【規定】

| 動作 | 怎麼做 |
|---|---|
| 走路 | WASD／方向鍵（畫面上的上下左右） |
| 拿東西（採收、拿成品、收錢、撿地上的東西） | 走進框裡自動拿 |
| 放東西（放進站點、上架、放櫃檯、放麵包盒、丟垃圾桶、付錢解鎖、付錢升級） | 站在框（或升級圈）裡按**空白鍵**，按住會一個一個放 |
| 題目、順序板、問 AI | 滑鼠；選擇題也可按 1／2／3；**填空題一律拖拉**（負責人要求） |

### §3-2 站點的框：放入／拿取【規定】

- 每個加工站用一個**正方形框框住機台**（45 度鏡頭下看起來是菱形），沿菱形的垂直對角線切成畫面上的**左右兩半**：**左半藍色「放入」、右半綠色「拿取」**（負責人：不要用圓形實體、框住模型、切成左右兩塊）。
- 框裡有**流動的小箭頭**（特效）：左半往機台流進去、右半從機台流出來。站進哪一半，那一半的三角形淡淡亮起來。
- 其他範圍（拿鐮刀、上架、櫃檯、垃圾桶、收錢、順序板…）也都用框：放東西藍框、自動拿綠框、員工順序板橘框。
- 同一站做出來的東西不會被放回同一站；一站最多堆 4 個輸入、4 個輸出【假設】。

### §3-3 順序錯＝做出失敗品【規定】

每一站收什麼、做出什麼（表外的東西這站不收，按空白鍵會跳紅色 ✕）：

| 站 | 放對 | 放錯會變成（失敗品） |
|---|---|---|
| 磨粉 | 麥 → 麵粉 | 麵糰 → 糊糊；麵包 → 麵包屑 |
| 揉麵 | 麵粉 → 麵糰 | 麥 → 麥稈團；麵包 → 糊糊 |
| 烤 | 麵糰 → 麵包 | 麥 → **烤焦的麥子**；麵粉 → 白粉塊 |
| 煮果醬 | 莓果 → 果醬 | — |
| 切開 | 麵包 → 切開的麵包 | 切開的 → 麵包屑；塗好果醬的 → 果醬糊麵包 |
| 塗果醬 | 切開的 → 塗好果醬 | 沒切的麵包 → 果醬糊麵包（**還會噴出果醬灘**）；塗好的再塗 → 果醬糊麵包 |
| 組合 | 塗好果醬的 → 三明治 | 只切沒塗 → 乾巴巴三明治；沒切 → 壓扁的麵包 |

- 失敗品**顏色暗、形狀歪、頭上有紅色 ✕**，一看就知道壞掉。
- 失敗品可以放上架，但客人會拒收、拿去丟；學生要自己撿去垃圾桶（紅箭頭會先指垃圾桶）。
- **每次撿起失敗品都問「怎麼會變成這樣？」**（三選一，正解是順序錯的那個原因；三個選項一律兩行、每行 ≤5 字、同一字級，避免學生挑「字最多」的）。原因題庫見 `QuizData.ts` 的 `WHY`。

### §3-4 問 AI【規定】

- 做法同字母要塞的「緊急任務」：**問題、回答、小考全部預寫**（老師審過、本地直接回、不連 AI），學生要用**麥克風念出問題**才問得到；念不出來 2 次【假設】後出現「念不出來？直接問」。
- 流程：念出問題 → 語音辨識 → 念對（題目中文字對上五成【假設】）→ AI 想一下 → 回答一個字一個字打出來 → 打完才出三選一小考 → 答對下一題；答錯鎖 2 秒、重洗選項。
- **三個主題、各 3 題**（內容見 `AiMissions.ts`）：怎麼做麵包（開局）、怎麼做果醬（解鎖果醬區後）、怎麼做三明治（解鎖三明治區後）。
- **守門**：還沒問過該主題，拿鐮刀／摘莓果、放進煮果醬／三明治各站會跳「先問 AI」擋住；紅箭頭先指 AI 機器人。
- ⚠ 暫時偏離正典 C-1：遊戲自己呼叫 `/api/transcribe`（§8）。

### §3-5 員工與順序板【規定】

| 員工 | 卡片（卡片匣刻意打亂） | 正確順序 |
|---|---|---|
| 小兔 | 揉麵、上架、採麥、烤、磨粉 | 採麥 → 磨粉 → 揉麵 → 烤 → 上架 |
| 小松鼠 | 塗果醬、放櫃檯、拿麵包、組合、切開 | 拿麵包 → 切開 → 塗果醬 → 組合 → 放櫃檯 |

- 走進員工家旁邊的**順序板框**打開面板（路過員工本人不會誤觸）；打開時員工停下來走回家。
- 把卡片拖進 5 格，按「開始」後員工**照順序一格一格做、做完從第一格再來**。
- 排錯時員工真的照錯的做：做出失敗品掉在地上、塗果醬沒切還會噴果醬灘；面板標出**第一個出錯的格子**（紅框：學生要找的是順序從哪裡開始錯）。
- **地上髒了不能開工**：要先把地上的失敗品撿去丟、站在果醬灘上擦乾淨。亂到極限（地上 12 個失敗品或 16 灘果醬【假設】）員工自己停下來。
- 小兔只割一級麥；小松鼠從**麵包盒**拿麵包（學生把麵包放進麵包盒），塗果醬台要有果醬。

### §3-6 麥田等級與血條【規定；數值假設】

- 靠近成熟的麥子就自動揮鐮刀；麥子有**血條**，鐮刀越高級扣越多（看得出鐮刀升級的差別）。
- **越外圈越高級、越難割**：一級（黃）、二級（橘）、三級（紅）；**鐮刀等級不夠割不動**（頭上跳「要 2 級鐮刀」）。
- **麥子等級一路帶到麵包**，高級麥做的麵包比較貴。

| | 一級 | 二級 | 三級 |
|---|---|---|---|
| 麥子血量 | 3 | 8 | 18 |
| 長回來（秒） | 6 | 8 | 10 |
| 麵包賣價（金幣） | 2 | 4 | 7 |
| 鐮刀每下扣血（1／2／3 級鐮刀） | 1 | 3 | 7 |

### §3-7 解鎖格＋題目【規定】

- 地上一次只出現一個解鎖格，站上去按空白鍵放金幣，付滿後答對一題才解鎖。**選擇題、填空題輪流**；填空題一律拖拉。
- 解鎖格只放「開新東西」的；升級改用升級圈（§3-8）。

| 順序 | 解鎖 | 價錢【假設】 | 出現條件 | 題目（只考做過的） |
|---|---|---|---|---|
| 1 | 雇小兔 | 4 | — | 選擇：做麵包，第一步要做什麼？（採麥） |
| 2 | 果醬區 | 8 | — | 填空：採麥 → 磨粉 → ？ → 烤（揉麵） |
| 3 | 三明治區 | 10 | **先做 3 罐果醬** | 選擇：做果醬，第一步要做什麼？（摘莓果） |
| 4 | 雇小松鼠 | 12 | **先自己做 3 個三明治** | 填空：拿麵包 → ？ → 塗果醬 → 組合（切開） |

- 條件沒滿足時解鎖格照樣出現，地上寫「先做 3 罐果醬（1／3）」，按空白鍵跳 ✕。
- ⚠ 暫時偏離正典 C-2：正解放在遊戲裡（§8）。

### §3-8 升級圈【規定；價錢假設】

- **所有可用的道具都能升級**（負責人）：每個加工站、鐮刀、兩位員工旁邊各一個**紫色虛線圓圈**，上面畫**金幣圖示＋還要幾個金幣＋「LV1 ↑」**（升滿顯示 MAX）。站進去按住空白鍵付金幣，**價錢每級 ×2**。

| 升級 | 價錢 | 最高 | 效果 |
|---|---|---|---|
| 加工站（7 站各自） | 4、8、16、32 | 5 級 | 每級加工時間 ×0.75 |
| 鐮刀 | 6、12 | 3 級 | 能割二級／三級麥、每下扣血變多、鐮刀變大變色 |
| 員工（小兔、小松鼠） | 5、10、20、40 | 5 級 | **一開始很慢，指數成長**：每級速度 ×1.6（2 級 1.6 倍、5 級 6.6 倍） |

### §3-9 顧客與收錢【推定】

- 展示櫃或櫃檯有東西時，每 2.5 秒【假設】來一位客人（各最多 2 位），從馬路左右兩邊走過來。
- 客人拿走最前面那個：麵包、果醬、三明治 → 打勾、走到收錢區放金幣（麵包依等級 2／4／7、果醬 3、三明治 6【假設】）；失敗品 → 皺眉、拿去丟、不付錢。
- **地上髒的時候三明治客人不會來**（逼學生打掃）。

### §3-10 紅色箭頭【規定】

- 紅色箭頭在下一步的目標上方跳動。優先順序：身上有失敗品 → 垃圾桶；地上髒 → 去打掃；還沒問 AI → AI 機器人；沒鐮刀 → 工具架；再依身上拿的東西指向下一站。
- **目標超過 7 公尺【假設】**時，小熊腳邊多一個貼地的紅箭頭，一前一後地脈動、指向目標方向（負責人：箭頭太遠時要帶學生走過去）。
- 已經站在麥田裡（旁邊就有能割的麥）就不顯示箭頭。

## §4 六週切分【推定：負責人 2026-09-29 決定用現在的框架跑六週，進度切分待負責人確認】

> 遊戲內的解鎖順序已經是這個順序；**「週次開關」尚未實作**（目前一次玩到底），見 §10。

| 週 | 單元 | 本週開放 | 帶進的順序觀念 | 過關條件【假設】 | 之後可加的內容 |

## §7 畫面與技術【推定】

### §7-1 畫面
- **3D**（Unlit＋頂點色假光影＋GPU Instancing），程式產生幾何、零美術素材。麥子一株一個合併網格。
- 站名、放入／拿取、價錢等文字**畫在地板上**（不擋畫面，全部轉成正對鏡頭）；只有員工名牌與泡泡浮在頭上。
- **螢幕適配**：比 16:9 寬固定高度 720、比 16:9 窄固定寬度 1280，至少看得到 1280×720；視窗改大小時 HUD 跟著移到角落。

### §7-2 效能
- 內顯（Intel UHD）1920×1080 約 130～140 fps。
- ⚠ **瀏覽器要開硬體加速**：Chrome 關掉「使用圖形加速功能」時 WebGL 改用 CPU 模擬，只剩約 20 fps（2026-09-29 負責人電腦實測）。上課前要檢查教室電腦。

### §7-3 注音
- 遊戲自帶 **Bpmf GenSen Rounded 子集字型**（SIL OFL，約 190 KB），只收遊戲用到的字；負責人 2026-09-29 核准（正典 T-2）。
- 字型只有預設讀音：破音字靠改寫句子避開（§6）；輕聲（例：子）顯示本調，已接受。

### §7-4 大小
- 建置 gzip 後約 1.6 MB（上限 5 MB）。
